# マーティン・セリグマンのwell-being論

- well-beingとは「自己実現している状態」「構造化された幸福」「良く在ること」「健幸」「福祉」「持続的幸福」
- well-beingは PERMAから構成される。
- さらに拡大して、PERMA-PEM-SEAの拡張モデルも考える。

（well-beingの構成要素）

P：positive emotion（前向きな感情）

E：engagement（没頭）

R：relationship（良好な人間関係）

M：meaning（自分よりも大きな意味に触れること感じること）

A：accomplishment（成長と達成感）

P：physical stability（身体的安定）

E：economical stability（経済的安定）

M：mental stability（精神的安定）

S：strength（水）

E：environment（土壌）

A：attention（日光）

- 心身がほどほどに健康で、経済的にもほどほどに安定した上で、良好な人間関係に支えられ、自分よりも大きな意味に触れており、日々にpositiveな感情があり、何かに没頭し、成長や達成感を味わうことができているという、自己実現が長期間持続している状態。

- happiness（幸せ）はwell-beingと混同しやすいが、happinessはpleasure（快楽）と同じく一過性の感情で、well-beingの要素であるpositiveな感情の一つにすぎない。

- 人生における真の目的は、富・名誉・成功ではなくwell-beingである。この目的であるwell-beingを見失うと、本来well-beingの「手段」でしかないさまざまなものを、「目的」であると錯覚して、人生を見失い、迷走し始めるようになる。

- このようなものには、結婚や仕事のように社会的に「良いこと」として受け入れられているものから、アルコールやギャンブルのような嗜癖の対象まで、実に多様である。

- 自分のwell-beingにとって大切な人（1割未満）と、そうでない人（9割以上）をしっかりと区別し、後者のために（余計な関わりを持ってしまうなどして）できるだけ大切なwell-beingのための時間を失わないように気を付け、必要あらばいつでも「損切り」する決断をしなければならない。

- 「誰も彼もが自分にとって大事な仲間」というのはNFRAPなスキーマである。

- well-beingを実現するための手段がアスピレーションである。

- well-beingの実現のためには、身体・精神・経済的安定が100点満点である必要は全くない。

- どんなに大金をかき集めても、well-beingが「金で買い戻せるもの」ではないことは、Steve Jobsをはじめ、多くの人間が晩年に後悔とともに証明している。

- 金がなくなれば、むしろwell-beingが良く「見える」ようになることもある。

- 「依存症」＝「well-being欠乏症」

- well-beingの欠乏は、代償として特定の物質や行為に対する依存や嗜癖を引き起こしやすい。

- 依存症の治療として断酒会は非常にFRAPであるが、それは「良好な人間関係」の再構築など、well-beingの改善が治療の核心部として行われているからであり、それは「依存症＝well-being欠乏症モデル」の裏付けとなっている。それゆえAIアプリを用いた、well-beingの改善が依存症の特効薬となり得る。

- EBM（evidence based medicine）からWBM（well-being based medicine）へ。結果がwell-beingを向上させるものであればその医療は有用で行うべきであるが、そうでなければその医療はするべきではない。

# PERMAモデルの詳細

- well-beingの構成要素

①positiveエモーション（ポジエモン）

- うれしさ、幸せ（ハピネス）、楽しさ、快楽（プレジャー）、感謝、やすらぎ、希望、畏敬の念など本人が「positive」と感じられる感情をすべて。

- 日常生活の中の小さな行動、小さな言葉が小さなPEを生み出し、「塵も積もれば山となる」。これがPEの本質。

- 持続期間は問わない（一過性でも持続的でもよい）

- 論語「述而篇」

「子いわく、粗食を食らい、水を飲み、肘を曲げて、これを枕とす。楽しみもまたその中にあり。不義にして富み且つ貴きは、我において浮雲の如し。」

金持ちになったり、高い位置につかなくても、誰にでもpositive感情は開かれている。

- アーティストや人気俳優が直接会ったこともないファンの心をつかむのは、彼らの仕事が人々のpositive感情を引き起こすものだから？

- ホストやホステスに依存する人は、自分の人生で見失ったwell-beingの代用を彼らから得ようとしているが、本物のPEは「非売品」である。

- コールガールが売春で稼いだ金をすべて、ホストに貢ぐことをいとわないのは、彼女らがwell-beingを金で買えるものと勘違いをしているからだ。（金がなくなったら捨てられる。いつかは必ず破綻するNFRAPなスキーマ））

- ドラッグやギャンブルも同じ構造である。資本主義は、カネでwell-beingが買えるという妄想を生み出し、多くの人生を狂わせている。

- 依存対象には多かれ少なかれ「技術的」なwell-being要素がある。（喪失モデル）

②エンゲージメント

何かに時間を忘れて没頭すること。（趣味や仕事に夢中になること）

- 「何か」は持続可能、コントロール可能でなければ、それは「依存」である。

- あらゆる依存症はこれを満たすが、ほとんどは持続不可能（体が壊れる、金が尽きる）なのでイネーブラーの存在なしには維持できず、いつかは必ず破綻する。

③リレーションシップ

- 良好な（対等で安定し互いのwell-beingを高め合うような）人間関係。

- 強い絆、信頼関係

- 「量」ではなく「質」

④meaning

- 生きる意味

- 自分の人生は「自分よりも大きな意味を持つ何か」（家族、組織、地域、社会）の役に立っている（貢献している）という実感

- ネガティブ思考では見えなくなる

⑤accomplishment

- 成長と達成感

- 「これだけのことができた」という実感

熟達・やり遂げた感覚

# aspiration（希望）P153

- well-beingを自分の価値観や現実に基づいて具体化したもの。「自分自身にとっての」well-being。

- well-beingを実現するための手段。

- 同定質問

「どんな人生になってほしいですか？」

「子供の頃、どんな人生を思い描いていましたか？」

- その人の「人生で何が最も大切」に関する中核信念がその人の「価値観」である。

- 価値観が希望の土台となる。

- 人生の分岐点にて私たちが何を選び、どう行動するかは価値観によって形作られる。

- 価値観に沿った生き方・過ごし方ができていないと感じる時、私たちはどんなに「成功」していても抑うつや依存症に陥る。

- 希望や価値観を同定したら次にそれらを達成することでどのような意味（よいこと）があるのかを考えさせる。

- 明るい未来を想像させ、positiveな感情をかきたてる。・

- 「自分の人生」「自己イメージ」「人生の目的」「自己コントロール感」「他者とつながっている感覚」という観点で希望を達成する意味を考える。

aspiration（希望）＝well-being（充実した状態）×バリュー（価値観）×アビリティ（能力）

個別的目標＝普遍的目標×個別的文化・経験（各個の健康・経済力）

多くの人はご家族や友人のwell-beingを願うが、aspirationやルートまで自分の考えを一方的に押し付けてしまうから、衝突する。

- aspirationを同定したら、実現可能なステップ（小目標）に分けて、一つ一つ達成していく。

- 理想的な部活やスポーツ、結婚生活などがwell-beingのイメージに近いが、どんな活動でも究極的な目的はwell-beingであるので、FRAPなスキーマになればなるほどwell-beingに近づける。（ルート、手段の違いにすぎない）

- 人生においてwell-beingを感じている時期とは、「キラキラしておらず、地味だが充実していた」などと肯定的に思い出される。

- 一方、well-beingを感じていない時期は「成功は明日が自分の人生を生きていなかった」「仕事ばかりするのではなく、もっと家族との時間を持つべきだった」などと否定的に思い出される。

- well-beingを感じている時の努力は、どんなに大変でも苦痛ではなく喜びとなる。

- negativeスキーまでは、実現しているはずのwell-beingも元々存在していないように見えなくなる。

- well-beingの具体的な目標、希望（aspirations）とそれに至る道、方法、経路（ルート）は人それぞれであり、一つに限定されない。

- 結婚もaspirationのひとつにすぎない。結婚のようになにか一つのaspirationを絶対視するのはNFRAPなスキーマ。結婚以外の手段（aspiration）でもwell-beingは実現する。

- 一つのaspirationに到達したら、そこにずっといてもいいが、別のaspirationに向かうことでwell-beingが継続できることもある。

- ただし自分にとってのFRAPなaspirationでなければ、well-beingの実現が難しい。

- 依存症の治療方針として、well-beingに至るための依存対象以外のFRAPのaspirationを一つ以上提示する。患者が何に依存しているかは、aspirationを考える上でヒントになる。
