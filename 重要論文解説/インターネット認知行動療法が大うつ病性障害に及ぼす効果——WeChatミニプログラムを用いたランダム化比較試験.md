# インターネット認知行動療法が大うつ病性障害に及ぼす効果——WeChatミニプログラムを用いたランダム化比較試験 精読ノート

> 役割：日本トップクラスのサイエンスコミュニケーターとしての精読プロンプトに基づく分析結果

## 1. 概要（500字以内）

中国では大うつ病性障害（MDD）の人のうち治療を受けているのは約1割にすぎず、専門家の不足とスティグマ（精神疾患への偏見）が壁になっている。中山大学などのチームは、中国で最も普及したSNS「WeChat」上で動くミニプログラム「Morning Mood」によるインターネット認知行動療法（ICBT）を、非盲検の2群ランダム化比較試験で検証した。18〜60歳のMDD外来患者84人を、週1回・全7モジュールのICBT群（40人。非専門職が電話やWeChatで受講を促すだけの支援）と、通常治療を続ける待機リスト対照群（44人）に割り付けた。主解析（全モジュール完了者31人と対照43人）では、治療後のうつ症状尺度PHQ-9がICBT群で約4.8点低く、反応率は58%対16%、寛解率は55%対9%だった。不安、心理的苦痛、自己効力感も改善したが、スティグマ、社会機能、生活の質には差がなかった。完了率は78%で、完了者の71%が満足と答えた。ただし小規模・単一都市・自己評価のみ・追跡なしで、主解析が完了者に限られる点に注意が要る。

## 2. Figure・Tableの解説

### Figure 1：参加者の割り付け・評価・解析の流れ（CONSORTフロー図、本文5ページ）

臨床試験で「何人が入り、何人が脱落し、何人が解析されたか」を示す流れ図。図自体は画像のため、本文と表の数値から整理すると次の通り。①登録84人を無作為に分け、ICBT群40人、待機リスト対照（WLC）群44人。②ICBT群は全7モジュールを終えた「完了者」が31人、治療後評価に応じた人が計37人。③WLC群は治療後評価を終えた43人。④解析は二本立てで、完了者のみの「PPS（per-protocol set：計画どおり実施した人の集合）」31人対43人を主解析、評価を受けた全員の「FAS（full analysis set）」37人対43人を感度分析（結果の頑健さの確認）に使った。無作為化された84人全員を解析する厳密なITT（intention-to-treat）解析ではない点が要注意である。

### Table 1：参加者のベースライン特性（本文6〜7ページ）

介入前の両群の比較表。①全体の平均年齢は30.8歳、女性74%、漢族95%、大卒71%、就労者75%と、若く高学歴な集団である。②抗うつ薬の服用者は57%。③小児期の虐待経験（CTQという質問紙で判定）70%、家庭機能不全の経験79%と、逆境体験の割合が高い。④症状面ではPHQ-9平均12.87点（中等度）、GAD-7（不安）9.71点、K-10（心理的苦痛）28.64点、SF-6D（健康関連QOLの効用値、0＝死亡〜1＝完全な健康）0.67。⑤群間に有意差のある項目はなく、無作為化はおおむね機能している。ただし自己効力感（GSES）はICBT群がやや高く（21.05対18.95、P=.09）、また「最近の有害ライフイベント」の行では全体列（1〜3件：19人、4件以上：58人）と各群の合計（1〜3件：26＋32＝58人、4件以上：12＋7＝19人）が入れ替わっており、表の記載ミスと考えられる。

### Figure 2：PHQ-9得点の時間推移（(A) PPS、(B) FAS、本文8ページ）

うつ症状の自己評価尺度PHQ-9（0〜27点、高いほど重い）の、ベースラインから治療後への変化を群別に描いたグラフ。図は画像で直接の数値は読み取れないため、表の値で補うと次の通り。①ICBT群は開始時13.10点（無作為化された40人の平均）から、治療後はPPSで6.19点、FASで6.68点へと、ほぼ半減した。②WLC群は12.66点から10.88点へと、わずかな低下にとどまる。③(A)と(B)で線の形がほとんど変わらないことが、「完了者に限らなくても結論は同じ」という著者の主張の視覚的な根拠になっている。④測定は2時点のみで、途中経過や治療後の持続は描かれていない。

### Table 2：治療後評価における各アウトカムの結果（本文9ページ）

年齢、性別、喫煙、飲酒、抗うつ薬、小児期虐待、家庭機能不全、ライフイベント、試験中に受けた精神保健サービス、ベースライン得点を調整した重回帰分析（多数の要因を同時に考慮して群の差を推定する方法）の結果。β（回帰係数）は「WLC群と比べたICBT群の得点差」を表す。①PPSでのPHQ-9はβ＝−4.827（95%信頼区間−7.033〜−2.621、P<.001）。②GAD-7はβ＝−2.784（P=.01）、K-10はβ＝−4.688（P=.02）、GSESはβ＝＋3.262（P=.01）で、いずれもICBT群が良好。③個人的スティグマ、知覚されたスティグマ（「世間はこう思っている」という認識）、SDS（仕事・社会生活・家庭生活の支障度）、SF-6Dは有意差なし。④FASでもほぼ同じで、PHQ-9はβ＝−4.662（P<.001）、GAD-7はβ＝−2.907（P=.006）だった。

### Table 3：ICBT群内での完了者と非完了者の比較（本文10ページ）

ICBT群の中で、全モジュールをやり遂げた31人と途中でやめた6人（治療後評価に応じた人のみ）を、ベースライン得点を調整した共分散分析（ANCOVA：開始時の差をならしてから比べる方法）で比べた表。①PHQ-9の調整後平均は完了者6.24点、非完了者8.94点で、非完了者の方が約2.7点高いが、F＝1.752、P=.19で有意ではない。②GAD-7、K-10、GSES、スティグマ、SDS、SF-6Dもすべて有意差なし。③著者は「非完了者の多くは気分が良くなって自らやめた」と解釈する。ただし非完了者はわずか6人で、差を検出する力（検出力）が極端に低く、「差がない」ことの証明にはならない。

### Table 4：うつ症状の反応率と寛解率（本文11ページ）

反応（PHQ-9がベースラインから50%以上低下）と寛解（治療後のPHQ-9が5点未満）の割合を、カイ二乗検定で比べた表。①PPSでは反応率がICBT群58%（18/31）対WLC群16%（7/43）（χ²＝14.060、P<.001）、寛解率が55%（17/31）対9%（4/43）（χ²＝18.377、P<.001）。②FASではICBT群の反応率51%（19/37）、寛解率46%（17/37）とやや下がるが、それでも有意差は保たれる（P=.001、P<.001）。③ICBT群で反応者と寛解者の人数がほぼ同じという点は、開始時の症状が中等度で「半減すれば5点未満に届く」人が多かったことを反映していると考えられる。④共変量を調整しない単純な比較である点に留意する。

### Table 5：全モジュール完了者31人による受講態度と満足度（本文11ページ）

ICBTプログラムの受け入れやすさを5段階評価で尋ねた表。①「どれだけ真剣に取り組んだか」は「半分」39%、「大部分」26%、「全部」13%で、半分以上に真剣に取り組んだ人は計78%（24人）。一方「ほんの一部」も22%いた。②「感じた効果」は「大いに」29%、「非常に大きい」13%で計42%。「中程度」が39%で最多だった。③「満足度」は「満足」48%、「非常に満足」23%で計71%、不満はゼロ。④本文では、家族や友人に勧めたいと答えた人が90%（28人）と報告されている。ただし回答は完了者のみで、途中でやめた9人の評価が含まれないため、満足度は実際より高めに出ている可能性がある。

## 3. 内容の評価（8項目）

> 本論文は原著研究（ランダム化比較試験）のため、8項目は一次研究向けの基準でそのまま評価する。

### ① 研究デザイン

事前に中国臨床試験登録（ChiCTR2100046425）された2群のランダム化比較試験で、コンピュータで割り付けを行っており、ICBTの効果を検証する骨格としては妥当である。一方、問題点も大きい。①対照が待機リスト（通常治療のみ）なので、「アプリで学ぶ」「定期的に声をかけられる」「治療を受けているという期待」といった非特異的効果とCBTそのものの効果を切り分けられない。②介入の性質上、参加者も研究者も盲検化されていない。③評価時期が群間で異なり、WLC群は8週時点で固定なのに対し、ICBT群は「全モジュール終了の1週間後」で、受講を遅らせた人は評価が後ろにずれる。

### ② サンプルサイズと選択基準

MDDの診断はDSM-5に基づき、構造化面接MINIで確認しており、対象の同定は丁寧である。抗うつ薬は4週以上用量が安定している人に限り、薬の変更による交絡を減らしている。しかし、①総数84人と小規模で、本文中にサンプルサイズ（必要な人数）の設計根拠が示されていない。②深圳の2施設のみで、平均30.8歳、女性74%、大卒71%と、若くスマートフォンに慣れた高学歴層に偏っている。③中等度以上の自殺リスク、精神病性障害、双極性障害、物質使用障害を除外しており、重症例や併存症の多い実臨床の患者への一般化には限界がある。

### ③ 方法論の適切性

介入は認知再構成（考え方の癖を見直す技法）、問題解決、再発予防を含む7モジュールで、前のモジュール終了から7日後に次が開く設計により、一気に詰め込むことを防いでいる。支援者には「心理療法は一切行わない」ことを訓練しており、非専門職による支援の実装可能性を示す試みとして筋が通っている。尺度はPHQ-9（α＝.88）など信頼性の確認されたものを使っている。問題点としては、①著者自身が認める通り7週間は推奨される12〜16週より短い。②小児期虐待の尺度CTQはα＝.62と信頼性が低い。③スティグマの軽減を狙いながら、それを直接扱う要素（家族の関与など）が乏しい。④受講の忠実度（どの程度内容を実践したか）の客観的な記録がない。

### ④ 統計分析の妥当性

ベースライン得点を含む共変量で調整した重回帰は、小規模試験での精度を高める手法として妥当である。ただし問題が多い。①主解析を完了者に限ったPPSとしており、「脱落しにくい、効果を感じやすい人」だけを比べるバイアスが入る。著者は「ITT解析は効果を過小評価しうる」と正当化するが、ランダム化の利点を損なう選択である。②FASもICBT群の3人とWLC群の1人を除外し、欠測値の補完もしていないため、真のITT解析ではない。③約74〜80人に対して10個以上の共変量を投入しており、過剰適合（モデルが偶然のばらつきまで拾うこと）のおそれがある。④副次アウトカム7項目で多重比較の補正がない。⑤標準化効果量（Cohen's dなど）が報告されず、他の研究との比較がしにくい。

### ⑤ 結果の信頼性と再現性

PPSとFASでPHQ-9の差（β＝−4.83と−4.66）や反応・寛解率の優位性が一貫しており、少なくとも短期的な症状改善の方向性は頑健である。一方、①信頼区間が−7.0〜−2.6点と広く、効果の大きさの推定は不安定である。②反応率58%対16%、寛解率55%対9%という差は、ICBTの個人データメタ解析（Karyotakiら、2021年）で示される効果より大きく見え、待機リスト対照による過大評価の可能性がある。③アウトカムがすべてオンラインの自己記入式で、評価者による面接評価がない。④Table 1の合計列の数値の入れ替わりなど表の誤記がある。⑤データは倫理上の理由で公開されず「合理的な要請があれば提供」にとどまり、第三者による再解析は容易ではない。

### ⑥ 結論の妥当性

結論の本文は「選ばれたMDD患者において、待機リスト対照と比べ短期的な改善を示した」と限定を付けており、データの範囲に概ね沿っている。しかし最後の一文で「効果的でスケーラブル（大規模に展開可能）な治療選択肢として実装を支持する」とまで述べている点は言い過ぎである。①追跡調査がなく、効果の持続は不明である。②費用対効果や、実際に大規模展開した場合の検証は行っていない。③社会機能と生活の質には差がなかった。また、COVID-19の局地的流行が「結果に影響しなかった」とする判断や、「非完了者は良くなったからやめた」という解釈は、少人数の比較や推測に基づくもので、断定は難しい。

### ⑦ 新規性

中国のMDD患者を対象としたICBT研究は、これまでオーストラリア製プログラムMoodGYMの中国語翻訳版を用いた単群パイロット研究がほぼ唯一だった。本研究は、中国語で一から開発し、インストール不要のWeChatミニプログラムで配信するICBTを、診断の確定した外来患者でランダム化比較試験により検証した点に新規性がある。さらに、専門家ではなく非専門職が受講を促す支援モデルを採用し、うつ症状だけでなく自己効力感とスティグマをアウトカムに含めた点も新しい。一方、ICBTが待機リスト対照より有効であること自体は既に多くのメタ解析で確立しており、有効性に関する知見の新しさは限られる。

### ⑧ 臨床的意義

日本でもCBTを提供できる専門家は限られ、「薬物療法は受けているが心理療法には手が届かない」患者は多い。本研究は、日常的に使うメッセージアプリ上のプログラムと、専門家ではないスタッフによる受講の声かけだけで、軽症〜中等症のMDDの症状を短期的に改善しうることを示唆しており、LINEミニアプリのような国内の類似基盤での展開を考えるヒントになる。完了率78%は、専門家が内容面を支援するガイド付きICBTの平均（76%）に並ぶ。ただし、①自殺リスクの高い人や重症例は対象外で、専門家によるフォローの受け皿が前提になる。②社会機能やQOLは改善しておらず、対面治療の代替ではなく補助と位置づけるべきである。③SNS基盤で健康情報を扱う際のプライバシー保護も、実装の課題として残る。
