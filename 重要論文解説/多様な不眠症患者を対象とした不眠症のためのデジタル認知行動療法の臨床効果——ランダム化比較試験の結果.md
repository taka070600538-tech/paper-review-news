# 多様な不眠症患者を対象とした不眠症のためのデジタル認知行動療法の臨床効果——ランダム化比較試験の結果 精読ノート

## 1. 概要

不眠症は成人の6〜10%がかかる身近な病気です。治療の第一選択は「不眠症のための認知行動療法（CBT-I）」ですが、対面で行える専門家が少なく、多くの患者は受けられていません。そこで期待されているのが、スマホやウェブで受けられるデジタル版（dCBT-I）です。ドイツでは2020年から、こうしたアプリを医師が処方できる制度（DiGA）が始まりました。

この研究では、除外条件をできるだけ減らし、身体や心の病気を併せ持つ人も含めた238人を集めました。参加者は、8週間アプリ「somnio」を使う群と、順番待ちの群（待機リスト群）にくじ引きで分けられました。どちらの群も通常の治療は続けています。

8週後、不眠の重さを表すISIという点数は、アプリ群で待機群より7.6点下がりました。効果量（差の大きさの目安）はd＝−2.08と非常に大きい値です。改善した人（反応者）は63.6%対5.8%、ほぼ治った人（寛解者）は40.7%対1.7%でした。疲労感、うつ、不安、幸福感も改善しました。一方、夢や悪夢の頻度は変わりませんでした。アプリ群の改善は12か月後も続いていました。ただし、対照群が順番待ちで、参加者が自分の群を知っていたことは、効果を大きく見せた可能性があります。

## 2. FigureとTableの解説

本論文には、Graphical Abstract（図解要約）1点、Figure 3点、Table 5点があります（Table 5は2ページにまたがります）。

### Graphical Abstract：研究全体の図解要約

左上には研究の背景が書かれています。「推奨される不眠治療を受けられる人は少なく、デジタルCBT-Iが需要と供給の橋渡しになり得る」という問題意識です。中央は研究デザインの流れ図です。238人を1対1で2群に分け、介入群は8週間のdCBT-Iを受けます。両群とも通常の診療は受け続けます。介入群だけは、事後評価の後に6か月と12か月の追跡評価があります。下段は結果のまとめです。ISIの推移グラフ、反応率63.6%対5.8%、寛解率40.7%対1.7%、日中の機能と生活の質の改善が示されています。結論は「通常診療でデジタル治療アプリを使うことを支持する」です。

### Figure 1：参加者の流れ図（フローチャート）

参加者がどう選ばれ、途中で抜けていったかを示す図です。まず449人がオンラインのふるい分け（スクリーニング）を受けました。このうち152人が除外されています。主な理由は、連絡先を書かなかった（62人）、同意しなかった（35人）、不眠の診断基準を満たさなかった（24人）などです。残る297人に電話で診断面接を行い、さらに47人が除外されて250人が適格となりました。ベースライン（開始時）調査を終えた238人が、アプリ群118人と待機群120人に割り付けられました。8週後の評価に答えたのは、アプリ群106人、待機群111人です。アプリ群の追跡回答者は、6か月後94人、12か月後83人でした。左側の欄にはモジュール完了者数も載っています。1モジュール目は106人、10モジュールすべてを終えたのは72人でした。分析は全員を割り付けどおりに扱う方式（ITT解析＝途中で抜けた人も含めて元の群で分析する方法）で行われています。

### Table 1：dCBT-Iアプリ「somnio」のモジュール構成

アプリの中身を一覧にした表です。モジュールは「導入」「睡眠日誌」「睡眠の知識」から始まります。続いて「不眠の悪循環」の説明があり、自分の不眠がどう続いているかを図で示します。中心となるのは第6モジュールの睡眠制限療法です。これは、寝床にいる時間をあえて短くして眠りを濃くする方法です。直近7日間の平均睡眠時間から「睡眠の窓」を決めます（最低6時間）。睡眠効率（寝床にいる時間のうち実際に眠った割合）が85%以上なら15分延ばし、80%以下なら15分縮めます。双極性障害のある人はこのモジュールを飛ばします。そのほか、筋弛緩法（体の力を抜く練習）、刺激制御法（眠くなってから寝床に入る、などの決まり事）、睡眠衛生、考え方の見直し、安全行動の扱い、まとめのクイズ、再発予防（アフターケア）があります。表には12項目が並んでいますが、本文では「コア10モジュール」と書かれています。この数え方の違いについて説明はありません。

### Table 2：参加者の開始時の特徴

両群の特徴を比べた表です。平均年齢は43.7歳で、女性が67.6%でした。不眠が続いている期間は平均7.6年と長く、慢性の人が多いことがわかります。睡眠薬を使っている人は39.1%いました。何らかの併存疾患（ほかに抱えている病気）がある人は73.1%で、身体疾患は40.8%、現在精神疾患の診断がある人は11.3%でした。歯ぎしり（20.6%）や閉塞性睡眠時無呼吸（4.6%）を持つ人も含まれています。開始時のISIは平均17.3点で、中等度の不眠にあたります。全体として両群はよく似ていました。ただし、不眠の持続期間（8.9年対6.2年）と過去の心理療法の経験（26.3%対43.3%）には差があります。

### Figure 2：主要評価項目（ISI）の推移

不眠の重さ（ISI、0〜28点）の平均値とばらつき（±標準偏差）を時点ごとに示した折れ線グラフです。開始時は、両群とも17点前後でした。8週後、待機群は約16点とほぼ横ばいでしたが、アプリ群は約8.6点まで下がりました。アプリ群のその後は、6か月後9.4点、12か月後9.1点です。わずかに戻ってはいますが、低い水準を保っています。ただし、待機群は8週後にアプリを使い始めたため、6か月以降のグラフはアプリ群だけです。追跡期間に比べる相手がいない点に注意が必要です。

### Table 3：8週後の群間比較（全評価項目）

各評価項目について、アプリ群と待機群の差を示した表です。差は「開始時の値をそろえて比べる方法（ANCOVA＝共分散分析）」で求めています。ISIの差は−7.60点（d＝−2.08）でした。同様に、疲労（FSS）d＝−1.02、睡眠についての思い込み（DBAS-16）d＝−1.17、うつ症状（ADS-K）d＝−0.80、不安傾向（STAI-T）d＝−0.56で大きな改善がみられました。幸福感（WHO-5）d＝0.68と、生活の質の身体面d＝0.66は中程度の改善です。日中の眠気（ESS）d＝−0.26と生活の質の心理面d＝0.19は小さな改善でした。生活の質の「人間関係」と「環境」の領域、夢を思い出す頻度、悪夢の頻度には差がありませんでした。なお、生活の質の心理面のp値は表では.016ですが、本文では0.164と書かれており、食い違っています。

### Figure 3：副次評価項目の推移

4つの副次評価項目の推移を、Figure 2と同じ形式で示した図です。（A）うつ症状、（B）不安症状、（C）幸福感、（D）睡眠についての非機能的な思い込みです。どの項目でも、8週後にアプリ群だけが改善しています。うつは15.4点から10.2点へ、不安は45.3点から39.8点へ、幸福感は10.3点から13.7点へ、思い込みは5.4点から3.9点へ変化しました。その後48週まで、ほぼ同じ水準が保たれています。待機群は8週間でほとんど変わらないか、わずかに悪化しました。幸福感は改善したものの、一般人口の平均には届いていません。

### Table 4：睡眠日誌で見た睡眠の変化（アプリ群のみ）

アプリに付いている睡眠日誌のデータを、1週目と8週目で比べた表です。両時点のデータがそろった95人が対象です。分析には、同じ人を繰り返し測る構造を考慮した統計モデル（線形混合モデル）を使っています。寝つくまでの時間（SOL）は49分から16分へ、約28分短くなりました。夜中に目覚めている時間（WASO）は112分から45分へ、約64分減りました。総睡眠時間（TST）は約25分増えています。睡眠効率（SE）は68.8%から86.1%へ、約16ポイント上がりました。効果量は、睡眠効率でd＝2.08、中途覚醒でd＝−1.78です。ただしこれは群内の前後比較で、対照群がありません。また、1週目がすでに介入開始後である点にも注意が必要です。

### Table 5：介入群の長期効果（2・6・12か月）

アプリ群だけを対象に、開始時と2・6・12か月後を比べた表です。ISIは、開始時17.6点に対して2か月後8.6点（d＝−1.68）、6か月後9.4点（d＝−1.39）、12か月後9.1点（d＝−1.26）でした。改善がおおむね保たれています。疲労、思い込み、幸福感、うつ、不安、生活の質の身体面と心理面も、12か月後まで改善が続いていました。人間関係、環境、夢、悪夢には変化がありませんでした。一つ気になる数値があります。日中の眠気（ESS）は12か月後に3.27点（d＝−1.65）と急に下がっていますが、6か月後は6.93点でした。この急な変化について、著者らは「効果が時間とともに増す可能性」と解釈しています。ただし、入力ミスやコロナ禍の行動制限解除の影響も否定できません。

## 3. 8項目評価

### ①研究デザイン

2群並行の非盲検ランダム化比較試験です。事前登録もされており（DRKS00024477）、因果関係を推定するための基本的な形は整っています。現実の医療に近い条件で行われ、通常の診療に上乗せした効果を調べた「実用的（プラグマティック）」な設計である点も長所です。一方で、対照群は「順番待ち」でした。参加者は自分の群を知っており、そのうえで自己記入式の質問票に答えています。このため、期待による効果（プラセボ的な効果）や、順番待ちの人が自分で改善の努力をしなくなる影響を区別できません。長期追跡は介入群だけで、対照群との比較がない点も大きな限界です。

### ②サンプルサイズと選択基準

当初の検出力計算（試験に必要な人数の計算）では124人でした。その後、解析方法をANCOVAに変え、脱落率28%を見込んで220人に計算し直しています。最終的には238人を割り付けており、人数は十分です。除外基準は、多量飲酒・薬物、最近の自殺念慮、てんかん、統合失調症・急性精神病の4つだけでした。睡眠薬の使用や交代勤務も認めており、外的妥当性（実際の患者に当てはまる程度）は高いといえます。ただし、募集の中心は公的保険会社のメール配信とネット広告でした。参加者の57%は大卒で、ネットに慣れた高学歴層に偏っています。また、診断面接は修士課程直前の学生が担当していました。

### ③方法論の適切性

不眠の診断は、DSM-5に基づく構造化面接（DIPS-OA）で確認しています。評価には、ISI、FSS、ESS、DBAS-16、WHO-5、WHOQOL-BREF、ADS-K、STAI-Tなど、妥当性が確かめられた尺度を使っています。割り付けは、ベースライン調査を終えた順に、事前に作った割り付け表に従って行いました。解析前にはデータの群名を伏せています。一方で、問題もあります。評価はすべて自己記入で、睡眠ポリグラフ（睡眠中の脳波などの客観的な測定）は行っていません。睡眠日誌のデータは介入群にしかありません。アドヒアランス（指示どおり使ったか）も、本人の自己申告で測っています。有害事象は介入群にしか尋ねておらず、両群を比べることができません。

### ④統計分析の妥当性

ITT解析を行い、多重代入法（欠けたデータを統計的に推定して補う方法）を使い、ANCOVAで開始時の値をそろえて比べています。現在推奨されている手法です。ただし、問題点がいくつかあります。第一に、効果量dの分母に「開始時の両群をまとめた標準偏差」を使っています。ISIは不眠のある人だけを集めたため、開始時のばらつきが小さく（SD約3.7）、dが大きく出やすくなります（d＝−2.08）。第二に、F検定の分母自由度が3090や9074など不自然な値になっています。代入データを統合した結果と考えられますが、説明がありません。第三に、生活の質の心理面のp値が本文と表で食い違っています。第四に、副次評価項目が13個ありますが、多重比較の補正（たくさん検定すると偶然の「有意」が出やすくなるのを防ぐ調整）を行っていません。

### ⑤結果の信頼性と再現性

主要評価項目の効果は非常に大きく、信頼区間（−8.67〜−6.54）も狭いため、方向性は確かだといえます。過去のdCBT-I研究のメタアナリシス（複数研究の統合解析）とも一致しています。しかし、効果の大きさは他の研究より明らかに大きい値です。その背景には、待機対照・非盲検・自己記入という、効果を大きく見せやすい条件が重なっています。追跡期間の回答者は、12か月後には83人（70%）まで減っています。続けて回答した人ほど改善していた可能性があります。12か月後のESSが急に低下している点も検証が必要です。研究が行われたのはコロナ禍のロックダウン期間で、時期による影響も無視できません。

### ⑥結論の妥当性

「多様な不眠症患者でもdCBT-Iは不眠と日中の機能を改善し、効果は長期に続く」という結論は、少なくとも8週時点のデータでは支持されます。ただし、長期の持続性は対照群なしの前後比較による結論です。「効果が時間とともに増す」という解釈は推測の域を出ません。「ドイツの不眠症患者全体に一般化できる」という主張も、ネット募集・高学歴という偏りを考えると言い過ぎです。さらに、アプリを開発・販売する企業の社員が著者の大半を占めています。オープンアクセス費用も企業が負担しています。利益相反（研究結果が著者の利害と関わること）を考えると、独立したグループによる追試が必要です。

### ⑦新規性

dCBT-Iの有効性そのものは、すでに多くの研究で示されています。この研究の新しさは、ドイツのDiGA制度（処方できるデジタル治療）の下で、除外基準をできるだけ減らした実際の患者に近い集団を扱った点にあります。併存疾患を持つ人が7割を超えるサンプルで、大きな効果を示しました。同じアプリを均質な集団で調べた以前の研究より、反応率が高かったことも報告しています。さらに、夢・悪夢の頻度を評価項目に含めた点は独自です（ただし結果は効果なし）。一方、実薬対照（対面CBT-Iや睡眠衛生指導などの比較相手）は置いていないため、「ほかの方法より優れているか」という問いには答えていません。

### ⑧臨床的意義

精神科の臨床では、うつや不安に不眠が伴う患者は多く、睡眠薬に頼りがちです。この研究は、睡眠薬を使っている人（39%）や併存疾患のある人を含む集団でも、アプリによるCBT-Iが不眠とうつ・不安を改善し得ることを示しました。対面CBT-Iを行える専門家の不足を補う手段として、実用的な意味があります。また、16%の人が睡眠制限療法のモジュールで脱落していました。このことから、睡眠制限の段階での支援やリマインダー（通知機能）が実際の運用で重要だとわかります。ただし、日本ではDiGAのような保険償還の仕組みがまだ限られています。重い精神疾患や自殺念慮のある人は対象外だったため、そうした患者への適用には慎重さが必要です。
