# 精神医学における大規模言語モデルの機会とリスク 精読ノート

## 1. 概要(500字以内)

ChatGPT のような大規模言語モデル(LLM:大量の文章から「次に来る言葉」を予測するよう学習したAI)が、精神医療と精神医学研究に何をもたらすかを整理した総説である。まず LLM の仕組みを、人工ニューラルネットワーク、機械学習、トランスフォーマー(文章を並列にすばやく処理できる構造)から平易に説明する。次に社会全体への影響として、①専門向けに調整した LLM を使えるかどうかの格差、②病院の経営判断の自動化、③労働の置き換えによる失業と、心地よい会話が人間同士の交流の代わりになる危険を論じ、AI医療機器の安全性を多面的に評価する BPES フレームワーク(図1)を紹介する。精神医療での機会としては、重症度評価、治療用チャットボット(LUMEN など)、診療記録の要約、自殺リスク予測、抗うつ薬選択の支援、研究仮説の生成を挙げる。リスクとしては、もっともらしい誤り(存在しない文献の生成など)、仕組みが分からないこと、価値観のずれ、臨床医の依存、データ漏えいと格差を挙げる。最後に、精神科の専門家と当事者を加えたレッドチーミング(攻撃役になって弱点を探す試験)などの安全策づくりを提言する。

## 3. 8項目の評価

> 本論文は総説(叙述的レビュー)であり、新しいデータを集めた原著研究ではない。そのため、②「サンプルサイズと選択基準」は「文献の検索・選択の方法」に、④「統計分析の妥当性」は「引用した研究の数値をどう扱ったか」に読み替えて評価する。

### ① 研究デザイン
LLM の仕組み、社会への影響、精神医療での機会、リスク、安全策(責任あるAIとレッドチーミング)という流れで構成された叙述的レビューで、精神科医・計算社会科学者・医療政策研究者・企業の研究者が共著している。幅広い論点を一つの見取り図にまとめた点は有用である。問題点は、系統的レビューではなく、論点の選び方が著者らの関心(とくに自分たちの研究)に寄っている可能性を排除できないこと。どの論点を採り、どれを省いたかの基準は示されていない。

### ② サンプルサイズと選択基準(→文献の検索・選択方法)
引用文献は74本で、医学・計算機科学・経済学にまたがる。ただし検索データベース、検索語、採用基準は示されていない。プレプリント(査読前の論文、arXiv や medRxiv)が多く含まれ、Galatzer-Levy らの機能評価研究、Perlis の抗うつ薬選択研究、Rollwage らの会話AI研究などは、少なくとも引用時点では査読前の段階で示されている。重要な主張の一部が査読前の知見に支えられている点は、読者が割り引いて読むべき限界である。

### ③ 方法論の適切性(→論の組み立て)
機会とリスクを対にして論じ、最後に具体策(レッドチーミング、BPES フレームワーク、専門家・当事者の参加)へつなげる構成は、総説として妥当でバランスが取れている。著者ら自身の LUMEN 研究を取り上げ、小規模で軽症〜中等症に限られると自ら限界を書いている点も誠実である。一方で、LUMEN を ChatGPT-4 で1時間以内に再現したという記述は著者らの逸話で、評価データを伴わない。また、BPES フレームワークは共著者 Khan の提案であり、自分たちの枠組みを推す利益相反的な面がある。

### ④ 統計分析の妥当性(→引用研究の数値の扱い)
数値はいくつか紹介される。GPT-4 による抗うつ薬の次の一手の選択で最適薬が約4分の3で選ばれたが、ほぼ半数の症例で禁忌または不適切な選択肢も挙がったこと、指針を組み込んだモデルで専門家の選択が2倍になり、不適切な選択肢が約10例に1例に減ったこと、MART 法で安全違反が最大85%減ったこと、などである。どれも元研究の数値をそのまま引いており、信頼区間、症例数、比較対象の詳細は示されない。効果の大きさと不確かさを読者が判断できる情報は十分でない。

### ⑤ 結果の信頼性と再現性(→主張の頑健さ)
「LLM はもっともらしい誤りを出す」「プロンプトの小さな違いで出力が変わる」「バイアスを含む」という指摘は、その後の多くの研究でも繰り返し確認されており頑健である。一方、「LLM の会話が人間同士の交流の代わりになり、精神的健康を損なう」という懸念は、Facebook の研究やSNSと抑うつの研究からの類推で、LLM 自体の直接の証拠は示されていない。著者らも、これは実証で確かめるべき問いだと明記している。執筆は2024年前半で、技術の進歩が速いため、個々のモデルの性能に関する記述は古くなりやすい。

### ⑥ 結論の妥当性
「LLM の精神医療への応用はまだ始まったばかりで、可能性は大きいが、予測できない出力、仕組みの不透明さ、誤情報、価値観のずれ、バイアスといった壁がある。分野横断の対話と、安全策の確立、臨床医の指導による調整、社会全体への影響の研究が必要」という結論は、本文の議論とよく対応しており妥当である。ただし、提言は方向性の提示が中心で、誰が、どの基準で、どの段階で安全を判定するのかという具体的な手順(たとえばレッドチーミングの評価項目)は示されていない。

### ⑦ 新規性
LLM の医療応用を論じる総説は多いが、本論文の新しさは、①精神医学に特化し、②個々の患者への応用だけでなく、失業や孤独といった「集団の精神的健康」への影響まで視野に入れ、③AI のレッドチーミングに精神医学特有の懸念が抜け落ちていると指摘して、臨床医・当事者・家族・政策立案者の参加を求めた点にある。新薬開発の第1〜4相をまねた段階的評価を精神科AIに当てはめる提案も、実務に結びつきやすい。

### ⑧ 臨床的意義
臨床医にとっての実用的な示唆は、①LLM は診療記録の要約や情報整理には役立ちうるが、薬の選択などの判断では禁忌の選択肢も混じるため、必ず専門家が確認する、②希死念慮のような緊急の訴えを LLM が見落とす危険があり、監視の仕組みなしに患者対応を任せない、③患者が LLM との会話に依存していないかを尋ねる視点を持つ、ということである。限界として、臨床での有効性を示す大規模な試験はまだなく、本論文は「使い方の注意書き」と「研究の課題リスト」として読むのが適切である。
