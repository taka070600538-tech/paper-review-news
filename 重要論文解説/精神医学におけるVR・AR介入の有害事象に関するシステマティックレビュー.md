# 精神医学におけるVR・AR介入の有害事象に関するシステマティックレビュー 精読ノート

## 概要（500字以内）

本研究は、精神疾患治療に用いられるVR（バーチャルリアリティ）・AR（拡張現実）介入について、有害事象がどの程度報告されているかを検証したシステマティックレビューである。PubMed・PsycINFO・EmbaseをPRISMA準拠で検索し、ヘッドマウントディスプレイ（HMD）を用い特定の精神疾患を対象とした73件の研究を選定した。結果、45件（62%）は有害事象に一切言及せず、21件は「有害事象なし」と報告しながらもサイバーシックネス等の兆候が本文の記述中に確認され、有害事象を明確に報告していたのはわずか7件にとどまった。介入の主体は曝露療法（71%）で、対象疾患は恐怖症・PTSD・不安症が中心であった。著者らは、標準化された有害事象評価ツールの導入と報告基準の整備が急務であると結論づけている。

## Figure・Tableの解説

### Figure 1：PRISMA文献選定フローチャート（3ページ）
データベース検索で424件がヒットし、重複84件を除去後340件をスクリーニング。抄録スクリーニングで229件（非精神科112件、HMD未使用80件、非臨床集団37件）を除外し、全文評価対象111件のうち49件（HMD未使用42件、非英語4件、非臨床3件）をさらに除外。参考文献リストの追跡調査で11件を追加し、最終的に73件が定性的統合（研究特性の記述的まとめ）に組み込まれたことを示すPRISMA準拠のフロー図。

### Table 1：対象精神疾患別の研究数（4ページ）
73件の研究がどの精神疾患を対象としたかを一覧化した表。恐怖症（30件）が最多で、PTSD（17件）、不安症（10件）、精神病（7件）、摂食障害（6件）、ストレス（3件）と続き、認知機能障害・自殺念慮・攻撃性・依存症・うつ病は各1件にとどまる。曝露療法が適用しやすい不安関連疾患に研究が集中している実態が読み取れる。

### Table 2：「有害事象なし」と報告されたが実際には兆候が確認された研究（4ページ）
Pot-Kolder等（2018）のサイバーシックネスによる脱落（n=1）や機器の不快感による脱落（n=2）、Pericot-Valverde等（2015）の喫煙渇望の増加（n=4）など5件の研究を提示。著者らが本文中で「有害事象なし」と結論づけていたにもかかわらず、記述を精査するとサイバーシックネス等の兆候が実際には存在していたことを示す表で、本レビューの核心的な問題提起を裏付けている。

### Table 3：有害事象を明示的に報告した7件の研究（5ページ）
Maltby等（2002）のサイバーシックネスによる脱落、Reger等（2016）のPTSD症状悪化、Botella等（2016）の疲労・めまい・腰痛によるハードウェア変更、Levy等（2016）の転倒リスク上昇等、具体的な有害事象の内容を一覧化した表。いずれも記述は簡潔で、頻度・重症度の定量的評価が乏しいことが本文で指摘されている。

## 8項目評価

**※本論文は原著研究ではなく総説（システマティックレビュー）であるため、「サンプルサイズと選択基準」は「文献検索・選択基準の透明性」に、「統計分析の妥当性」は「異質な研究間の統合方法」に読み替えて評価する。**

**①研究デザイン**：PRISMAガイドラインに準拠したシステマティックレビューとして明確に設計されており、3つの主要データベース（PubMed、PsycINFO、Embase）を用いた包括的検索、2名の独立評価者（YY、RL）によるスクリーニング、参考文献リストからの追加同定など標準的な手続きを踏んでいる。ただしメタ解析は実施されておらず、有害事象発生率等の定量的統合は行われていない点は、Figure1中の「定量的統合（meta-analysis）」という表記とやや齟齬がある。

**②文献検索・選択基準の透明性（サンプルサイズと選択基準に代えて）**：検索式（VR/AR関連語×精神疾患関連語）はMethodsに具体的に記載されており再現性は高い。包含基準はHMD使用と特定の精神疾患診断の2条件に限定され明確である。一方、除外基準の適用は2名の合議によるとのみ記載され、評価者間の一致率（κ係数等）は報告されておらず、選定プロセスの客観性を検証する手段が限られる。

**③方法論の適切性**：HMDに限定し非没入型VR（画面型・CAVE等）を除外した判断は研究対象を明確化する上で妥当である。有害事象の定義（患者・臨床医・家族が不快・有害と認識するもの）も明示されており分析の枠組みは適切といえる。ただし、対象疾患・介入内容が多様な73研究を単一の枠組みで比較しているため、疾患特異的な有害事象の差異（例：摂食障害における身体イメージの歪みと恐怖症における転倒リスク）が埋没しやすい構成になっている。

**④異質な研究間の統合（統計分析の妥当性に代えて）**：本研究は統計的メタ解析を行わず、有害事象報告の有無を件数・比率で記述する定性的統合にとどまる。異なる疾患・介入・評価尺度を持つ73研究を「有害事象への言及の有無」という単一軸で並列に扱っており、研究間の異質性（heterogeneity）を統計的に評価する手続きは取られていない。これは著者らの目的（報告の質そのものの評価）には合致するが、有害事象の実際の発生率を定量的に見積もる上では限界となる。

**⑤結果の信頼性と再現性**：Table2・3に提示された個別事例は原著論文の記述に基づいており追跡可能である。一方、「有害事象への言及なし」と分類した45件について、実際に有害事象が発生しなかったのか単に報告されなかっただけなのかを区別する術がなく、この分類自体の限界が本文でも認められている。また、英語論文限定・HMD限定という選定基準により、対象範囲外の研究に存在しうる有害事象情報は反映されていない。

**⑥結論の妥当性**：「有害事象の検出・報告のための標準化されたスクリーニングツールが必要」という結論は、73件中45件が有害事象に無言及、21件が「なし」と報告しながら実際には兆候が見られたという主要な発見と直接的に整合しており、過度な一般化もなく妥当である。

**⑦新規性**：精神科領域におけるVR/AR治療そのものの有効性を扱ったレビューは既に複数存在するが、有害事象の報告状況そのものに焦点を当てたレビューは著者ら自身が指摘する通り希少であり、「効果」に偏りがちな既存文献に対する重要な補完的視点を提供している点に新規性がある。

**⑧臨床的意義**：VR/AR曝露療法を臨床導入する際に、サイバーシックネスや解離症状等の副作用を系統的にモニタリングする必要性を臨床家に喚起する実務的価値が高い。特に摂食障害治療におけるアバターを用いた身体イメージ提示のように、副作用が治療機序と表裏一体になりうる領域への注意喚起は臨床的に重要である。一方、具体的な評価尺度（SSQ、Virtual Reality Neuroscience Questionnaire等）の使い分けや導入手順までは踏み込んでおらず、実装のための具体的なガイダンスとしてはやや抽象度が高い。
