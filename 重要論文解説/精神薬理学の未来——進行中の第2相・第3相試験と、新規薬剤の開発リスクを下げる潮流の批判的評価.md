# 精神薬理学の未来——進行中の第2相・第3相試験と、新規薬剤の開発リスクを下げる潮流の批判的評価 精読ノート

> 役割：日本トップクラスのサイエンスコミュニケーターとしての精読プロンプトに基づく分析結果
> 論文の性質：**総説（レビュー）論文**。臨床試験登録データベース（clinicaltrials.gov と clinicaltrialsregister.eu＝EudraCT）を系統的に検索した「試験プログラムの俯瞰」と、臨床試験方法論に関する専門家による批判的論評を組み合わせた、World Psychiatry誌のフォーラム論文である。オリジナルの患者データを新たに取得した原著研究ではない。

## 1. 概要（500字以内）

過去70年の薬物療法の進歩にもかかわらず、多くの精神疾患は依然として十分に治療できていない。本論文はまず、統合失調症・双極性障害・うつ病・不安症/心的外傷関連症・物質使用症・認知症について、新規の作用機序（メカニズム）をもち第2相・第3相試験が進行中の薬剤を、公的な臨床試験登録データベースの系統的検索によって網羅的に整理する。同定された試験は統合失調症176件、双極性障害38件、うつ病177件、不安症/心的外傷関連症98件、物質使用症185件、認知症265件にのぼるが、主要評価項目でプラセボに勝った薬剤はごく一部にとどまる。有望な標的として、統合失調症ではM1/M4ムスカリン受容体作動とTAAR-1作動、うつ病ではNMDA受容体調節・GABA-A受容体正アロステリック調節・サイケデリクス、認知症では興奮症状に対するシグマ1/NMDA系などが挙げられる一方、強迫症では有望薬が皆無、双極性障害の躁病・維持期はそもそも開発対象になっていない。後半では、なぜ多くの開発が「死の谷」を越えられないのかを、適応的（アダプティブ）試験デザイン、増大し続けるプラセボ反応、試験参加者の代表性、評価者の信頼性、そして統計解析（多重性・共変量・欠測値補完）の観点から批判的に論じ、新規薬剤の試験プログラムの失敗リスクを下げるための実践的な指針を提示している。

本論文には**Figureは1点も存在せず、Tableが6点**（Table 1〜6）ある。いずれも「第2相または第3相のランダム化比較試験（RCT）でプラセボ等の対照に勝った薬剤」を疾患ごとに一覧化した表であり、薬剤名・作用機序・対照・試験期間・相・試験登録番号（NCT/EudraCT）・進捗状況・結果の8列で構成される。本文中では別途「補足資料（supplementary information）」に、結果が未公表の試験を含む全試験リストが収載されていると繰り返し言及されているが、補足資料そのものはPDF本体には含まれていない。

### Table 1：統合失調症で陽性結果を示した薬剤（本文50-52ページ）

同定された176件の第2/3相試験のうち、12分子・42試験が検討され、13試験のみが主要評価項目でプラセボに勝った。表にはBI 425809（グリシントランスポーター1阻害薬、認知機能で優越）、ブリラロキサジン、カンナビジオール、エストラジオール、グリコピロレート（唾液漏＝よだれの副作用を改善）、メラトニン、ピマバンセリン、ラロキシフェン、ロルペリドン、TV-46000（皮下注リスペリドン）、ウロタロント（TAAR-1/5-HT1A作動薬）、KarXT（ムスカリンM1/M4作動薬キサノメリン＋末梢性抗コリン薬トロスピウムの合剤）が並ぶ。同じ薬剤でも「PANSS総得点で優越」の試験と「プラセボに劣った」試験（ラロキシフェンのNCT01280305）が併記され、結果の不安定さが一目でわかる構成になっている。

表の後半は、現在最も注目される2剤に紙面が割かれている。ウロタロントは第2相NCT02969382でPANSS総得点においてプラセボに優越したが、続く第3相4試験（NCT04115319、NCT04825860、NCT04072354、NCT04092686）はいずれも結果未公表である。KarXTは第2相NCT03697252（効果量0.75）と第3相NCT04659161（効果量0.61）で総得点の優越が確認され、残る2試験が進行中とされる。注記には「統計学的有意性の情報がない結果はすべて『結果なし』に分類した」という判定基準が明示されており、著者らが陽性判定を保守的に行っていることを示している。

同定された38試験のうち、わずか6分子・11試験が検討され、陽性は6試験のみ。N-アセチルシステイン（グルタチオン前駆体）＋アセチルサリチル酸、非ラセミ体アミスルプリド（ドパミン/5-HT7拮抗）、アルモダフィニル（3試験中1試験のみ陽性で2試験は差なし）、D-シクロセリン＋ルラシドン、インフリキシマブ（TNF-α阻害薬）、ケタミン（希死念慮に対して優越）が並ぶ。特筆すべきは、**急性躁病と双極性障害の維持療法については陽性RCTが1件も同定されなかった**点であり、有望とされる薬剤がすべて他疾患からの「リパーパシング（適応の転用）」である点も表から読み取れる。

### Table 3：うつ病で陽性結果を示した薬剤（本文54-55ページ）

177試験のうち19分子・43試験が検討され、19試験が陽性という、6疾患中で最も層の厚い領域である。アヤワスカ、A型ボツリヌス毒素、ブプレノルフィン＋サミドルファン（第2相と第3相1試験で陽性、他の第3相3試験で差なし）、AXS-05（デキストロメトルファン＋低用量ブプロピオン、2022年8月にFDA承認）、カリプラジン、エスメサドン、エストラジオール＋プロゲステロン、エゾガビン、レボミルナシプランER、ルラシドン、メトホルミン＋フルオキセチン、ナルトレキソン、亜酸化窒素（笑気）が掲載されている。同一薬剤で陽性・陰性が混在する行が非常に多いことが、この領域の再現性の低さを視覚的に物語る。

### Table 3（続き）：サイケデリクスとズラノロンの試験群（本文55ページ）

続きの表ではシロシビンの10試験が列挙されるが、結果が出ているのは待機リスト対照で優越したNCT03181529と、エスシタロプラムと差がなかったNCT03429075の2件のみで、残る8試験はすべて進行中である。ラパスチネル（NMDA部分作動薬）は第2相単回投与で5-10mgが陽性だったにもかかわらず、第3相3試験がすべて差なしに終わった典型的な「相間の失敗」例として並ぶ。ズラノロン（GABA-A受容体正アロステリック調節薬）は用量別に整理され、30mg/日と50mg/日は15日目のHAM-Dで優越したが、20mg/30mgを比較した試験は高いプラセボ反応のために陰性、抗うつ薬併用試験は3日目のみ有意で15日目には有意差が消えたことが示されている。

98試験のうち9分子・31試験が検討され、18試験が陽性。表は疾患別に区切られ、PTSD（経鼻オキシトシン、MDMA）、パニック症（D-シクロセリン）、社交不安症（D-シクロセリン）、全般不安症（ABIO 08/01、アゴメラチン、プレガバリン、クエチアピンフマル酸塩、SR58611A、ボルチオキセチン）が並ぶ。MDMAは第2相4試験と第3相1試験で一貫して陽性だが、NCT01793610では「per-protocol解析では優越だがintention-to-treat解析では有意でない」と注記されている。本文では**強迫症（OCD）については有望な治療薬が1つも同定されなかった**と明記されている。

185試験のうち10分子・17試験が検討され、12試験が陽性。アルコール使用症ではバクロフェン、ガバペンチン、イブジラスト（元は喘息治療薬のホスホジエステラーゼ4阻害薬／TLR-4拮抗薬）、ケタミン。覚醒剤（アンフェタミン/メタンフェタミン）使用症ではミルタザピン、ナルトレキソン＋ブプロピオンER、徐放性メチルフェニデート。コカイン使用症ではAFQ056、ケタミン、ゾニサミド。ニコチン使用症ではゾニサミド＋バレニクリン（自己報告の喫煙量は減ったが生化学的に確認された喫煙では差なし）。オピオイド使用症ではコルチゾール（1日のヘロイン使用量が少ない者に限り渇望を軽減）。**陽性となった薬剤のほとんどが他疾患ですでに承認済みの薬の転用**であることが、この表の最大のメッセージである。

265試験という最大規模の試験群のうち、14分子・27試験が検討され、15試験が陽性。前半は認知機能・疾患修飾マーカーを狙った薬剤（アシトレチン、インスリングルリジン、ネフラマピモド、ORM-12741、ラサギリン、サルグラモスチム）、後半は行動・精神症状（BPSD）を狙った薬剤（AVP-786、AXS-05、ブレクスピプラゾール、デキストロメトルファン/キニジン、レンボレキサント、ナビロン、ピマバンセリン、スボレキサント）である。ブレクスピプラゾールやAVP-786のように、同じ薬剤・同じ設計の第3相2試験で結果が割れている例が目立つ。本文では、**抗アミロイド薬・抗タウ薬の第2/3相試験は主要評価項目ではすべて統計学的有意性を示せておらず**、アデュカヌマブの承認はサブ解析に基づく「議論を呼ぶ承認」だったと厳しく評価されている。

## 3. 内容の評価（8項目）

> **注記：本論文は総説であるため**、以下の評価では「サンプルサイズ」「統計解析の妥当性」等の項目を、一次研究の基準ではなく、レビューの文脈（文献・試験の検索と選択基準、既存試験間の異質性の扱い、著者らが論じている統計論の妥当性）に読み替えて評価する。

### ①研究デザイン

前半は臨床試験登録データベース（clinicaltrials.gov、EudraCT）の系統的検索に基づく試験の棚卸し、後半は臨床試験方法論に関する専門家の批判的論評という、二部構成の「ハイブリッド型総説」である。査読誌の登録データではなく試験登録簿を一次情報源とした点は、公表バイアス（陰性結果が論文化されない偏り）を回避するうえで優れている。一方で、PRISMA等の系統的レビューの報告ガイドラインには準拠しておらず、検索式・検索日・スクリーニングのフロー図・複数レビュアーによる独立抽出の有無が本文に明示されていない。「網羅的」を標榜しながら再現手順が示されていないため、厳密には系統的レビューではなく「構造化されたナラティブレビュー」と位置づけるべきである。

### ②サンプルサイズと選択基準（＝対象試験の規模と選択基準）

対象は成人の主要6疾患群、第2相・第3相、計939試験（統合失調症176、双極性障害38、うつ病177、不安症/心的外傷関連症98、物質使用症185、認知症265）と大規模であり、この領域の全体像を掴むには十分な規模である。しかし選択基準には明確な弱点がある。第一に、米国とEUの登録簿に限定したため、日本・中国などアジアの試験登録簿にある薬剤が体系的に漏れている（著者ら自身も限界として認めている）。第二に、小児・青年を対象とした試験が除外されており、児童精神科領域の開発動向は本論から抜け落ちている。第三に、他疾患で承認済みの薬剤を新規適応で試す試験が「第4相」に分類されて見落とされた可能性が明記されており、リパーパシング薬の網羅性は不完全である。

### ③方法論の適切性

「主要評価項目でプラセボ等の対照に統計学的に有意に勝った試験のみを陽性とし、有意性の情報がないものはすべて『結果なし』に分類する」という保守的な判定基準は明快で、都合の良い二次解析を陽性に数え上げる誘惑を排している点で適切である。作用機序を受容体・トランスポーター単位で分類し直した作業も、神経科学に基づく命名法（NbN）の趣旨に沿った有益な整理である。ただし、著者ら自身が「一部の薬剤は機序の情報が不十分で分類できなかった、あるいは誤って分類した可能性がある」と述べているとおり、多受容体に作用する薬剤（カンナビジオール、クエチアピン、AXS-05など）を単一の「機序」として表に落とし込む作業には本質的な恣意性が残る。また、陽性・陰性の判定を誰が何人で行ったかが記載されておらず、判定の信頼性が検証できない。

### ④統計分析の妥当性（＝論じられている統計論の妥当性）

本論文自体はメタ解析を行わず統合推定値を算出していないため、統計手法の誤用リスクは低い。むしろ本論文の価値は、後半で展開される統計方法論の議論そのものにある。主要評価項目を1つに絞るべき理由（独立した主要評価項目が2つなら偽陽性率は10%、3つなら14%に上昇する）、順序尺度の二値化（例：50%以上の改善を「反応」とする）が招く誤分類と検出力の激減、根拠なく共変量を「念のため」投入することが交互作用を無視して効果量を解釈不能にする問題、MMRM（反復測定混合モデル）がプラセボ効果を過大評価しうる可能性、そして欠測が「ランダムでない」場合に選択モデルやパターン混合モデルへ切り替える必要性——いずれも臨床試験統計学の標準的知見と整合し、記述は妥当である。ただし各主張の根拠となる引用が限定的で、たとえば「MMRMが近年のプラセボ効果増大の一因かもしれない」という示唆は仮説の域を出ておらず、実証データが示されていない。

### ⑤結果の信頼性と再現性

表に収載された試験番号・相・期間・結果は登録簿の記載に忠実であり、読者がNCT番号から一次情報にたどり着けるため、検証可能性は高い。一方で再現性には重大な制約がある。著者ら自身が認めるとおり、臨床試験登録簿の更新は自主的なものであるため、中止された試験や公表済みの結果が反映されていない場合がある。実際、「結果なし」に分類された試験の中には、すでに結果が論文化されているものが含まれている可能性が否定できない。さらに、検索実施日が本文に明記されていないため、他の研究者が同じ時点のスナップショットを再現することができない。精神薬理学の開発動向は流動的であり、2023年発表の本論文の一覧は2026年現在すでに相当程度更新が必要な状態にあると考えるべきである。

### ⑥結論の妥当性

「多くの新規機序薬は第2相から第3相への『死の谷』を越えられない」「陽性結果の多くは既存薬のリパーパシングである」「プラセボ反応の増大が最大の障壁である」という三つの主結論は、提示された表のデータから素直に導かれており妥当である。特に、統合失調症176試験のうち陽性はわずか13試験、双極性障害では躁病・維持期の陽性RCTがゼロ、認知症265試験のうち陽性は15試験という数字は、結論を強く支持する。ただし「最も有望な標的」の選定は、著者らが「プラセボに対する優越の記録、効果量の大きさ、安全性・忍容性の要件」を基準にしたと述べるのみで、重み付けの手続きが定式化されていない。臨床試験デザインを論じる論文が、自らの結論導出プロセスについては明示的な基準を示していないのは方法論上の非対称である。また著者の多くが製薬企業との広範な関係を持つ領域のオピニオンリーダーであり、「有望」の判断に構造的な偏りが入りうる点は読者が留意すべきである。

### ⑦新規性

個々の薬剤情報自体は公開データベースから得られるもので新規ではない。本論文の新規性は、(1)6疾患・939試験を横断的に同一の基準で判定し一望させたこと、(2)その俯瞰図を臨床試験方法論の批判的論評と直結させ、「なぜ失敗するのか」への回答として提示したことにある。特に、適応的デザイン（用量の逐次再評価法、共変量適応ランダム化、標本サイズ再設定、エンリッチメント、シームレスデザイン、無益中止）を実際の試験例（ウロタロントの40歳以下・入院2回以下という絞り込み、BI 425809の事後解析による反応予測因子）と結びつけて論じた部分は、教科書的記述にとどまらない実践的価値をもつ。一方で、プラセボ反応増大や単盲検プラセボ導入期の無効性については先行するメタ解析の知見の再整理であり、この部分の独自性は限定的である。

### ⑧臨床的意義

臨床医にとっての意義は大きく三つある。第一に、「いま何が来るのか」を疾患別に把握できる。統合失調症のKarXT（本論文発表後の2024年にFDA承認）やウロタロント、うつ病のAXS-05やズラノロン、認知症興奮症状のブレクスピプラゾールなど、実際に処方選択肢となりつつある薬剤の根拠試験を追跡できる。第二に、「何が来ないのか」を知ることができる。強迫症には有望薬がなく、双極性障害の躁病・維持期は開発の対象ですらなく、抗アミロイド薬の主要評価項目は軒並み未達である——この空白の指摘は、患者・家族への説明において誠実な期待値設定を可能にする。第三に、試験参加者の代表性の低さ（実臨床の統合失調症患者5人に1人しか試験に組み入れ可能でない）という指摘は、承認薬のエビデンスを目の前の併存症の多い患者にどこまで外挿できるかという、日々の臨床判断に直結する。ただし本論文は薬剤の相対的な有効性・安全性を比較する情報を提供しないため、これ単独では具体的な処方選択の指針にはならない。また第4相試験の標準化を規制当局に求める提言は、実現の具体的道筋が示されておらず、政策的インパクトは限定的である。
