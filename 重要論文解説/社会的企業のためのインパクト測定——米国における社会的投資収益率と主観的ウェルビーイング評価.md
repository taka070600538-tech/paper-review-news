# 社会的企業のためのインパクト測定——米国における社会的投資収益率と主観的ウェルビーイング評価 精読ノート

> 役割：日本トップクラスのサイエンスコミュニケーターとしての精読プロンプトに基づく分析結果

## 0. 論文の性質

本論文は既存研究のレビューではなく**原著研究**である。米国の全米代表標本データ（MIDUS Refresher 1）を用いた横断的な計量経済学的分析により、独自の「米国版WELLBY（ウェルビーイング調整生存年）」を算出したオリジナル研究であるため、以下の8項目評価は原著研究の基準（研究デザイン・サンプル・統計解析の妥当性など）をそのまま適用する。

## 1. 概要（500字以内）

米国の社会的企業（SE）は、自信の向上や近隣住民への信頼など、金銭化しにくい「主観的ウェルビーイング」の変化を社会的インパクトとして示すのに苦労してきた。英国・豪州・デンマークにはHACTなどの「ウェルビーイング価値バンク」があり、SROI（社会的投資収益率）分析の基盤として使われているが、米国には相当する標準化手法がなかった。本研究は全米代表標本のMIDUS Refresher 1調査データ（有効N=2,140）を用い、生活満足度（LS）を従属変数とする重回帰モデルで、自信・人生のコントロール感・近隣への信頼・畏敬の念という4つのウェルビーイング次元がLSに与える影響を推定した。さらにQALY（質調整生存年）に基づくWELLBYフレームワークで効果を金銭価値に換算し、米国初のWELLBYおよび主観的ウェルビーイング評価（SWV）の試案を提示した。自信の向上は1.8万〜2.7万ドル相当と算出された。

## 2. Table解説（すべて。Figureは本文中に存在しない）

### Table 1：候補データセットのレビューと選定基準
米国内の8つの候補データセット（American Community Survey、BLS縦断調査、GSS、PSID、Urban Institute調査、MIDUS 3、MIDUS Refresher 1など）を「全米代表性」「尺度化されたLS」「所得・人口統計」「LSの決定要因」「ウェルビーイング関連アウトカム」の5基準で比較した表。MIDUS Refresher 1のみが全基準を満たし、かつ新規コホート（25〜70歳）であることから採用された。

### Table 2：生活満足度（LS）の決定要因（統制変数）の処理方法
年齢・年齢の2乗（曲線関係を捉えるため）・性別・婚姻状況・教育・所得（世帯規模で均等化した対数値）・雇用形態・身体的健康・精神的健康・世帯人数・健康保険加入・民族（ヒスパニック系か否か）・人種の計13変数について、モデルでの扱い方（二値化・カテゴリ化等）を一覧化した表。全モデル共通の統制変数として使われる。

### Table 3：MIDUS Refresher 1データに対応づけたウェルビーイングの4次元
独立変数となる4つの主観的ウェルビーイング項目と、対応するMIDUS調査コードおよび原文の質問文を示す表。「自分に自信があり前向きだと感じる」（自信）、「人生全般をどの程度コントロールできているか」（コントロール感）、「近隣の人々は互いに信頼し合っている」（近隣信頼）、「人生の美しさに深く心動かされる感覚を日々経験するか」（畏敬の念）の4項目で、いずれも順序尺度から二値（有無）に変換して使用された。

### Table 4：自信（confidence）の回帰結果
モデル要約（R²=.353、調整済みR²=.346）、ANOVA（F=52.447、p<.001）、係数表からなる。統制変数（年齢・性別・健康状態・婚姻状況など）を投入した上でも、自信の有無はLSに対しb=.803（最も強い効果）で有意な正の関連を示した。年齢は負、年齢の2乗は正で、U字型（中年期に底を打つ）の関係が示唆される。

### Table 5：人生のコントロール感（control）の回帰結果
R²=.314、調整済みR²=.307、F=44.134（p<.001）。コントロール感の有無はLSに対しb=.627で有意（4次元中2番目に強い効果）。精神的健康（b=−.277）や婚姻状況（既婚でb=.380）も強い関連を示す。

### Table 6：近隣への信頼（trust in neighbors）の回帰結果
R²=.298、調整済みR²=.291、F=40.834（p<.001）。近隣信頼の有無はb=.229で、4次元の中では最も効果量が小さいが統計的には有意。精神的健康（b=−.302）が本モデルで最も強い統制変数となっている。

### Table 7：畏敬の念（awe：人生の美しさに深く心動かされる感覚）の回帰結果
R²=.325、調整済みR²=.318、F=46.423（p<.001）。畏敬の念の有無はb=.527で有意（4次元中3番目）。教育年数がここでのみ他モデルよりやや強い負の関連（b=−.024）を示している。

### Table 8：米国版WELLBY
QALY（1年間・完全な健康状態で生存することの金銭価値。米国では10万〜15万ドルが一般的な推定幅）と、LS尺度（7点尺度／11点尺度）の組み合わせごとに算出した米国版WELLBYの一覧。7点尺度では10万ドルQALYで22,449ドル、15万ドルQALYで33,673ドルとなる。

### Table 9：ウェルビーイング各次元の金銭評価（本論文の中心的な結果表）
Table4〜7で得られた回帰係数（b）に、Table8のWELLBY（7点尺度・10万/15万ドルQALY）を掛け合わせて算出した、各ウェルビーイング次元の金銭価値の一覧。自信の向上：18,036〜27,053ドル、コントロール感の向上：14,064〜21,096ドル、近隣信頼の向上：5,136〜7,704ドル、畏敬の念の向上：11,834〜17,750ドル。これが社会的企業がSROI分析等に活用できる「価値バンク」の中核データとなる。

## 3. 8項目評価

**①研究デザイン**
単一時点（MIDUS Refresher 1、2011〜2014年収集）の横断データを用いた計量経済学的value-transfer研究であり、縦断・介入研究ではない。「ウェルビーイングの次元の有無」による群間の生活満足度差を回帰係数として推定しているに過ぎず、因果関係（自信が上がるとLSが上がる、の方向）を担保する設計にはなっていない。逆因果（LSが高い人ほど自信を「ある」と回答しやすい）の可能性は本文でも明示的には検討されていない。

**②サンプルサイズと選択基準**
MIDUS Refresher 1は全米代表標本（25〜74歳）だが、実際の分析対象は有効回答N=2,140とやや小規模である。年齢範囲外の層（74歳超・25歳未満）は対象外であり、他国のSWV研究（英国のUnderstanding Societyなど、より大規模なパネル調査）と比べてサンプルサイズの見劣りは否めない。

**③方法論の適切性**
英国HACT/Fujiwara法の枠組み（LS尺度の変換、順序変数の二値化、WELLBYによる金銭化）を米国データに忠実に移植した点は方法論的に一貫している。ただし、4つの独立変数（自信・コントロール感・信頼・畏敬）はいずれも単一項目・単一時点の自己報告を強制的に二値（有る/無い）に落とし込んだものであり、測定の粒度・信頼性という点で明確な限界がある。

**④統計分析の妥当性**
OLS回帰＋HC3頑健標準誤差、ANOVAで全4モデルが有意（p<.001）という点は妥当な手続きである。しかし各モデルの調整済みR²は0.29〜0.35程度にとどまり、22個の統制変数を投入してもLSの分散の6〜7割は説明できていない。4つの独立したモデルを別々に走らせているにもかかわらず多重比較の補正には言及がなく、統計的解釈にはやや慎重さが必要である。

**⑤結果の信頼性と再現性**
4次元すべてが方向性・有意性の点で先行研究（Clark et al., 2018；Graham, 2017など）と整合的である点は結果の妥当性を支持する。一方、単一データセット・単一時点の分析であり、他データでの再現や感度分析（頑健性チェック）は行われていない。著者ら自身も「米国データには頑健な所得係数がなく」、WELLBY算出にQALYの外部推定値（10万〜15万ドル）を借用せざるを得なかったと明記しており、金銭評価そのものの精度には限界がある。

**⑥結論の妥当性**
「自信の向上は米国で1.8万〜2.7万ドルの価値がある」といった結論は、あくまでWELLBY理論枠組みの下での試算であり、著者らも考察部で「これらの数値が金額で表現されているからといって絶対的・客観的真実になるわけではない」と繰り返し釘を刺している点は誠実である。ただし全体の論調は、SEの実務担当者に向けてこの価値バンクの活用を推奨する方向にやや前のめりな印象もある。

**⑦新規性**
「米国初のWELLBYを用いた研究」であることを著者ら自身が明言しており、英国HACT Social Value Bankに相当する米国版価値バンクの土台を初めて構築した点に明確な新規性がある。米国におけるウェルビーイング関連の全国調査データの乏しさという政策的課題を可視化した点も貢献といえる。

**⑧臨床的意義**
本研究は精神科臨床への直接応用を意図したものではなく、社会的企業のインパクト測定・SROI実務への応用を主眼とする。ただし、自己効力感（自信）・統制感・社会的信頼・畏敬の念といった、精神医学領域でもポジティブ心理学的介入の標的となりうる要因を、政策・資金提供の意思決定に組み込むための「共通言語（金銭単位）」を提示した点では、地域精神保健プログラムの費用対効果評価などに間接的な示唆を持ちうる。
