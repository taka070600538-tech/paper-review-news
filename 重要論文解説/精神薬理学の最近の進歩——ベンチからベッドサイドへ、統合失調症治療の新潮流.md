# 精神薬理学の最近の進歩——ベンチからベッドサイドへ、統合失調症治療の新潮流 精読ノート

> 役割：日本トップクラスのサイエンスコミュニケーターとしての精読プロンプトに基づく分析結果

## 1. 概要（500字以内）

統合失調症（SCZ）は世界で2,100万人が罹患し、平均余命を15年短縮する重篤な疾患である。従来の抗精神病薬はドパミンD2受容体遮断を基本とし、幻覚・妄想などの陽性症状には効くが、感情表出の減少・意欲低下・社会的引きこもりといった**陰性症状**と、記憶・注意・実行機能の障害である**認知症状**にはほとんど効かず、加えて体重増加などの代謝系副作用が問題となる。本論文は米国ベイラー医科大学のShahとIqbalによるスコーピングレビュー（ある領域の研究状況を広く見渡して地図を描く総説）で、この限界を突破すべく開発中の新規化合物を受容体標的別に整理する。1952年のクロルプロマジン上市に始まる精神薬理学史と、前臨床から第1〜4相試験に至る新薬開発の流れを概観したうえで、①ドパミン系（カリプラジン、ブレクスピプラゾール、ブリラロキサジンなど）、②セロトニン系（ロルペリドン、ルマテペロン、ピマバンセリンなど）、③ホスホジエステラーゼ阻害薬（BI 409306、MK-8189、ロフルミラスト）、④グルタミン酸系（BI 425809、ソディウムベンゾエート、エベナミド、メマンチンなど）、⑤微量アミン関連受容体TAAR1作動薬（**ウロタロント**、ラルミタロント）、⑥オランザピン＋サミドルファン配合剤の6群に分けて臨床試験成績を表にまとめている。さらにムスカリン作動薬ザノメリン、GPCR139作動薬TAK-041、デクスメデトミジンにも触れる。結論として、ドパミン受容体に結合しない作用機序の探索と、遺伝情報を用いて治験の失敗リスクを下げる**ファーマコゲノミクス**の活用が今後の鍵であると述べる。

## 2. Figure・Tableの解説

本論文に**Figureは1点も存在しない**（模式図・グラフは掲載されていない）。**Table 6点**がすべての図表であり、いずれも「化合物名／受容体標的／被験者数／用量／対照／相／試験デザイン／主要評価項目／結果」の9列で構成された臨床試験一覧表である。以下、順に解説する。

### Table 1：ドパミン系を主に修飾する薬剤（5〜7ページ）

カリプラジン、ブレクスピプラゾール、F-17464、ブリラロキサジン（RP5063）、Lu AF35700を収載する。**カリプラジン**はD2およびD3受容体の部分作動薬（受容体を弱く刺激する薬）で、D3への親和性がD2の7倍高く、この性質が陰性・認知症状への効果につながると期待される。第2相試験（732例）では1.5／3.0／4.5 mgの全用量でPANSS（陽性・陰性症状評価尺度、統合失調症の症状の重さを点数化する標準的な尺度）が有意に低下した（最小二乗平均差 −7.6／−8.8／−10.4、p<0.001）。第3相（604例）でも3 mg・6 mgでプラセボに優った。**ブレクスピプラゾール**は674例の第3相で4 mgのみ有意（−6.47、p=0.0022）で1 mg・2 mgは有意差なし。**F-17464**はD3拮抗＋5-HT1A部分作動で、134例の第2相で43日目のPANSSに有意差（p=0.014）。小児・思春期を対象とするカリプラジンの第3相（330例、13〜17歳）は2025年4月完了予定で組み入れ中である。

### Table 2：セロトニン受容体を主に修飾する薬剤（9ページ）

ロルペリドン（MIN-101）、ビフェプルノックス、AVN-211、SB-773812、イダロピルジン、ルマテペロン（ITI-007）、ピマバンセリンを収載する。本文の記述と合わせると要点は次の通り。**ロルペリドン**は5-HT2Aとシグマ2受容体の拮抗薬で、ある第2相ではプラセボに優らなかったが、別の第2相では32 mg・64 mgで12週時のPANSS総得点と陰性症状が改善し、64 mgでは言語記憶を中心に認知機能も改善した。**ルマテペロン**は5-HT2AへのD2の60倍の親和性を持ち、2019年12月にCAPLYTAとしてFDA承認。第2相で42 mgがプラセボに有意（p=0.017、効果量0.42）だったが**84 mgでは有意差が消え**、陰性症状下位尺度ではどの群も差がなかった。錐体外路症状は6.7%とプラセボ6.3%と同等であった。**ピマバンセリン**は5-HT2A部分逆作動薬で、大規模第2相ではPANSS総得点に効果はなかったが安定期患者の陰性症状は改善した。

### Table 3：ホスホジエステラーゼ（PDE）修飾薬（11ページ）

BI 409306、MK-8189、ロフルミラストの3剤。**BI 409306**はPDE9A阻害薬で脳内cGMPを増やし、げっ歯類ではエピソード記憶と作業記憶を高めたが、ヒト450例の第2相では12週時のCANTAB（コンピュータ化された認知機能検査バッテリー）でもMCCB（統合失調症認知機能の標準評価バッテリー）でもプラセボと差がなかった。**MK-8189**はPDE10A阻害薬で576例の第2b相が2024年6月完了予定として組み入れ中。**ロフルミラスト**はPDE4阻害薬で、わずか18例のクロスオーバー第1相ながら250 µg上乗せでミスマッチ陰性電位に関連するシータ波振幅（p=0.04）と作業記憶（p=0.02）を改善した。ただし他の認知指標には効果がなく、症例数も極小である。

### Table 4：グルタミン酸神経伝達の修飾薬（14〜15ページ）

本レビューで最も分量の多い表である。NMDA受容体（記憶・学習の中核をなす興奮性受容体）の機能低下がSCZの陰性・認知症状の基盤にあるという仮説に基づく薬剤群を収載する。共作動物質であるD-セリン（低用量では無効、60 mg/kg＝約4 g/日で陰性・認知症状の改善）、グリシントランスポーター1（GlyT-1）阻害薬**BI 425809**（第1相で髄液グリシンが用量依存性に上昇、第2相で10 mg・25 mgが認知機能を小さな効果量ながら有意に改善、2021年5月にFDA画期的治療薬指定、第3相CONNEX-1〜3が進行中）、D-アミノ酸酸化酵素（DAAO）阻害薬のソディウムベンゾエートとルバダキシスタット、AMPA受容体正のアロステリック修飾薬BIIB-104、NMDA受容体正のアロステリック修飾薬CAD-9303、グルタチオン前駆体N-アセチルシステイン、メマンチン、AVP-786、そして電位依存性ナトリウムチャネル遮断によりグルタミン酸放出を抑える**エベナミド（NW-3509）**などが並ぶ。BI 425809は貧血（ヘモグロビン低下）が副作用として挙げられている。

### Table 5：TAAR受容体修飾薬（17ページ）

**ウロタロント（SEP-363856）**とラルミタロント（RO6889450）を収載する。ウロタロントはTAAR1（微量アミン関連受容体1）作動薬で、**D2受容体にほとんど結合しない**点が画期的である。245例の第2相（4週）でPANSSの平均変化がウロタロント群−17.2点対プラセボ群−9.7点（最小二乗平均差 −7.5、95%信頼区間 −11.9〜−3.0、p=0.001）と有意。続く26週非盲検延長試験では156例が参加し、94.1%が継続、26週完遂率67%であった。第3相が複数走っており、クエチアピン徐放錠を実対照とする56週の長期安全性試験も含まれる。ラルミタロントはTAAR1部分作動薬で、2試験のうち1つは主要評価項目未達により**早期中止**となった。

### Table 6：サミドルファン・オランザピン配合剤（18ページ）

代謝系副作用対策の表である。オランザピンにオピオイド受容体拮抗薬**サミドルファン**を組み合わせ、抗精神病効果を保ったまま体重増加を抑える戦略で、2021年にLybalviとしてFDA承認された。ALK3831-302（第2相、309例）では全用量でPANSS改善がオランザピン単剤と同等（平均差0.6点、95%CI −1.2〜2.5）でありながら、12週時の平均体重増加が**37%低い**（p=0.006）。ENLIGHTEN-1（第3相、403例、4週）ではPANSS総得点が−6.4±1.8（p≤0.001）と改善。ENLIGHTEN-2（第3相、561例、24週）では体重増加率が配合剤群4.2%対オランザピン単剤群6.6%、10%以上の体重増加を来した患者が17.8%対29.8%と有意に少なかった。52週の非盲検延長でも忍容性は良好であった。

### ① 研究デザイン

開発中化合物を「主に作用する受容体系」で6群に整理し、各群を本文の記述と表の対応で示す構成は、この領域に不慣れな読者にも見取り図を与える。ベンチ（前臨床）からベッドサイド（臨床応用）までの開発工程を第1〜4相の通過率（第1相70%、第2相33%、第3相25〜30%）とともに冒頭で説明したことで、後段の「多くが第2相で止まっている」という現実が実感しやすい。**問題点**は、スコーピングレビューを名乗りながら、その標準的な報告指針であるPRISMA-ScR（スコーピングレビュー用のPRISMA拡張版）に準拠していないことである。研究の問い（リサーチクエスチョン）が明文化されず、チャート作成の手順も示されないため、体系性は名目にとどまる。

### ③ 方法論の適切性

複数の受容体系にまたがる膨大な開発パイプラインを、表という統一フォーマットで横並びに比較可能にした点は評価できる。各表に主要評価項目と結果の双方を載せ、否定的な結果（BI 409306の認知機能改善failure、ラルミタロントの早期中止、Lu AF35700の非優越）も省かず記載している姿勢は誠実である。**問題点**として、評価者は誰か、選定と抽出を独立に複数名で行ったか、意見不一致をどう解決したかという手続きが一切書かれていない。また、収載薬剤の網羅性についても基準がなく、たとえばクロザピンの位置づけや、既に第3相で失敗した化合物の扱いが体系的でない。表と本文の間で情報量に差があり、本文で詳述された薬剤（ザノメリン、TAK-041、デクスメデトミジン）が**どの表にも収載されていない**という構造上の不整合もある。

### ④ 統計分析の妥当性（→ 成績提示の妥当性）

引用した試験の効果量、最小二乗平均差、95%信頼区間、p値を可能な範囲で表に転記しており、単に「有効だった」と書き流さない点は良い。カリプラジンやウロタロントのように差の大きさが読み取れる記述もある。**問題点**は三つ。第一に、レビュー自身は一切の統合解析を行っておらず、異なるデザイン・異なる患者集団の試験結果を並置するのみで、薬剤間比較の根拠にはならない。第二に、p値のみを示して効果量や信頼区間を欠く記載が多数あり（Table 3・Table 6の一部）、臨床的意義の判断ができない。第三に、Table 1のカリプラジン第2相では「1.5 mg/日・3.0 mg/日・4.5 mg/日」の3用量に対し括弧内の平均差が3値示されるが、行のレイアウトが崩れており対応関係が読み取りづらい。テキスト抽出上の問題ではなく、PDF原文の組版の問題である。

### ⑤ 結果の信頼性と再現性

引用文献番号が本文と表に一貫して付されており、個々の記述の出所は追跡可能である。ClinicalTrials.govの登録番号相当の情報を引くことで、進行中試験の完了予定時期まで示している点は有用である。**問題点**として、検索の再現性がない（②参照）ことに加え、本レビューが**2023年2月時点のスナップショット**である点が挙げられる。実際、本ノート作成時点（2026年）から振り返ると記述の陳腐化は著しい。ウロタロントの第3相DIAMOND 1・2は2023年に主要評価項目未達で失敗し、ザノメリン・トロスピウム配合剤（KarXT／Cobenfy）は2024年9月にFDA承認されるなど、本論文が「今後の期待」として並べた化合物の運命は既に大きく分岐している。総説の宿命ではあるが、読者は発表時点を強く意識して読む必要がある。

### ⑥ 結論の妥当性

「陰性・認知症状に対する有効な治療は依然として存在せず、ドパミン以外の標的探索とファーマコゲノミクスの活用が必要である」という結論は、提示されたデータと矛盾しない穏当なものである。ほとんどの新規化合物が第2相にとどまり、認知機能を主要評価項目とした試験の多くが失敗している事実を、著者は隠さずに記述している。**問題点**として、結論部にファーマコゲノミクスへの期待が大きく置かれているが、本文第4章の記述は新薬開発コスト（1990年以降3倍の264億ドル、CNS領域の第3相は患者1人あたり8,000〜12,000ドル）と一般論に終始し、**統合失調症治療における具体的な薬理遺伝学的バイオマーカーの成功例が一つも示されていない**。CYP450多型による代謝差という古典的な例に触れるのみで、章のタイトルが約束する内容を満たしていない。

### ⑦ 新規性

2023年初頭時点で開発中の統合失調症治療薬を受容体標的別に一覧化した点に実用的な価値はあるが、**方法論的・概念的な新規性は乏しい**。著者自身が繰り返し引用するLoboらのナラティブレビュー［文献6］をはじめ、同趣旨の総説はこの時期に複数存在する。TAAR1作動薬とムスカリン作動薬という「非D2」の2系統を明確に取り上げた点は当時としては先見的だったが、独自の分析枠組みや、パイプライン全体の成功率・失敗要因に関する定量的考察は加えられていない。表という形式で情報を整理した編集上の貢献にとどまる。

### ⑧ 臨床的意義

精神科臨床医にとって、本レビューの実用的価値は明確である。第一に、既承認薬であるカリプラジン、ブレクスピプラゾール、ルマテペロン、ピマバンセリンについて、承認根拠となった試験の用量・対照・効果量が一覧で確認でき、**「なぜこの用量なのか」を根拠に遡って理解できる**。第二に、Lybalvi（オランザピン＋サミドルファン）のデータは、体重増加を理由にオランザピンを避けてきた実務に対して具体的な代替案を提示する。第三に、ルマテペロン84 mgが42 mgに劣ったという「用量反応が単調でない」事実は、増量一辺倒の処方習慣への警鐘となる。**問題点**は、本邦未承認の薬剤が大半を占め、そのまま日本の処方に持ち込めないこと、また⑤で述べた通り情報が2023年2月で止まっており、**本論文を現時点の意思決定の根拠に用いてはならない**ことである。開発の歴史的経緯と受容体薬理の見取り図を得る教材として読むのが適切である。
