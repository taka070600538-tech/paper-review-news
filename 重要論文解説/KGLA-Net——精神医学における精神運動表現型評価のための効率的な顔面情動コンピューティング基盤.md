# KGLA-Net——精神医学における精神運動表現型評価のための効率的な顔面情動コンピューティング基盤 精読ノート

> 役割：日本トップクラスのサイエンスコミュニケーターとしての精読プロンプト（デフォルトフォーマット）に基づく分析結果

## 1. 概要（500字以内）

顔表情認識（FER: Facial Expression Recognition）は、精神疾患にしばしば伴う精神運動の異常（表情の乏しさや動きの変化）を客観的に測る手段として、計算論的精神医学で注目されている。ただし長期モニタリング用の機器に載せるには、認識精度と計算コストの両立が必要である。既存の二流路（顔画像と顔の特徴点＝ランドマークを並行処理する）ネットワークは、両者を突き合わせる際に画像全体どうしを総当たりで比較する「グローバル・クロスアテンション」に依存し、計算量が画素数の二乗で増えるという難点があった。著者らはKGLA-Netを提案する。ランドマーク側の特徴を精製モジュール（FRM）で雑音除去し、3段階の解像度をまとめて単一の「構造的事前情報」を作り、これを案内役（Query）として、画像特徴を8×8・4×4・2×2と縮む局所窓の中だけで統合する（KGLAモジュール）。これにより計算量が線形に落ちる。RAF-DB 92.43%、AffectNet 7クラス67.83%、8クラス64.01%、CAER-S 93.20%と既報を上回り、31.2Mパラメータ・7.2G FLOPs・1枚7.9msを達成した。ただし検証は公開表情データセットのみで、精神科患者データは一切用いられていない。

## 2. Figure・Tableの解説

本論文に登場する図は Figure 1〜4 の計4点、表は Table 1〜12 の計12点である（補足資料に別表はなく、Data availability statementでも「本文／補足資料に含まれる」と述べられるのみ）。

### Figure 1：KGLA-Net全体アーキテクチャ（p.4）

ネットワーク全体の設計図。入力の顔画像は、顔の目鼻口などの点の位置を捉える「ランドマークバックボーン」と、見た目の質感を捉える「イメージバックボーン」に並行して入力される。両者からStage 1〜3の3段階の特徴が取り出され、Projected Moduleで全てチャネル数256に揃えられる。ランドマーク側は精製・プーリングを経て「マルチスケール精製キーポイント特徴」という1つの構造的事前情報にまとめられ、これが案内役となって、8×8→4×4→2×2と縮む局所窓の中でMulti-Head Cross Attention（複数の視点から2種類の情報を突き合わせる注意機構）により画像特徴を統合する。最後にキーポイント特徴の自己注意と、全要素ゼロで初期化した「初期クエリ」を用いる積層アテンションブロックが感情クラスを予測する。

### Figure 2：特徴精製モジュール（FRM）の詳細（p.5）

ランドマーク特徴には、表情と無関係な個人差（顔立ち）や背景の雑音が混ざる。FRMはそれを削ぎ落とす仕組みである。入力された各位置の特徴ベクトルと、学習で得られる共有の「重みベクトル（構造的アンカー）」を、それぞれL2正規化（長さを1に揃える操作）してから内積をとり、コサイン類似度を得る。これにガウス型の活性化関数（式2、スケールaと分散σも学習パラメータ）を当てて0〜1の空間スコア地図を作り、元の特徴に要素ごとに掛け算する。すなわち「表情らしい場所は残し、そうでない場所は暗くする」マスク処理を、重い線形変換を使わず軽量な類似度計算だけで実現している点が売りである。

### Figure 3：キーポイント誘導局所統合（KGLA）モジュールの構造（p.5）

本論文の中核部品。精製済みキーポイント特徴と画像特徴を、空間的に対応する重なりのない局所窓に分割する。各窓の中で、キーポイント特徴が「何を探すか」を示すQuery、画像特徴が参照される側のKeyとValueとなり、局所的なMulti-Head Cross Attentionが計算される。顔の表情は眉・目・口といった局所の筋活動で決まるため、遠く離れた領域どうしを突き合わせる必要はない、という解剖学的な直感が設計根拠になっている。窓内に計算を閉じることで、本来トークン数の二乗で増える計算量が線形になる。前段の統合出力が次段のQueryになる縦続（カスケード）構造である。

### Figure 4：RAF-DBデータセットの代表サンプル（p.7）

評価に用いたRAF-DB（実世界で収集された表情画像データベース）から、surprise（驚き）、fear（恐怖）、disgust（嫌悪）、happy（喜び）、sad（悲しみ）、anger（怒り）、neutral（中立）の7基本感情の代表例を並べた図。照明・角度・年齢・人種がばらついた「実世界（in-the-wild）」画像であることを示す意図がある。精神科の視点で重要なのは、この7分類がEkmanの基本6感情＋中立という一般心理学の枠組みであり、平板化した感情表出や情動鈍麻といった臨床概念とは直接対応しないという点である。

### Table 1：データセット別の学習設定（p.7）

RAF-DB、AffectNet（7クラス）、AffectNet（8クラス）、CAER-Sの4条件それぞれのハイパーパラメータ一覧。最適化アルゴリズムはAdam、エポック数200、バッチサイズ128、重み減衰1e-4、学習率の指数減衰γ=0.98、DropPath（学習中に経路を確率的に落とす正則化）0→0.5は共通で、基礎学習率のみRAF-DBとCAER-Sが1e-5、AffectNetが1e-6と変えている。データ拡張は左右反転とランダム消去で、消去の強さもデータセットごとに調整されている。裏を返せばデータセットごとに手調整が入っており、調整の探索手順や検証セットの使い方は記載されていない。

### Table 2：RAF-DBとAffectNetにおける最先端手法との比較（p.8）

2020年のPSRから2026年のMambaerまで28手法と本手法を並べた主表。KGLA-NetはRAF-DBで92.43±0.11%、AffectNet 7クラスで67.83±0.09%、8クラスで64.01±0.08%と、いずれも最高値を示した。代表的な比較対象はPOSTER（92.05 / 67.31 / 63.34）、POSTER++（92.21 / 67.49 / 63.77）、HAM（91.92 / 66.97 / 63.82）、Mamba系のFERMam（92.13 / 66.38 / 61.45）など。ただし優越幅はRAF-DBで0.22ポイント、AffectNet 7クラスで0.34ポイントと極めて小さく、比較対象は原著の公表値の転記であって、同一条件で再学習した値ではない。

### Table 3：CAER-Sデータセットでの比較（p.9）

文脈込みの感情認識データから静止画を抜き出したCAER-Sでの比較表。2018年のDSN（75.19%）から始まり、EfficientFace 85.87%、MA-Net 88.42%、GLAMOR-Net 89.88%、POSTER 92.73%、HAM 92.86%、POSTER++ 93.00%と並び、KGLA-Netが93.20±0.13%で最高値となる。ここでも差は0.20ポイントで、標準偏差0.13と同程度のスケールである。なお比較手法側の標準偏差は不明であり、差が偶然の範囲かどうかは本表からは判断できない。

### Table 4：5回の独立実行に基づく統計的不確実性（p.9）

乱数シードを変えた5回の実行について、平均±標準偏差と95%信頼区間（Studentのt分布による）を示した表。RAF-DB 92.43±0.11［92.29, 92.57］、AffectNet 7クラス 67.83±0.09［67.72, 67.94］、8クラス 64.01±0.08［63.91, 64.11］、CAER-S 93.20±0.13［93.04, 93.36］。信頼区間が狭いことを「安定性」の根拠としているが、これは自モデルの初期値依存性を評価したにすぎず、比較手法との差の有意性検定（t検定や順位検定）は一切行われていない。

### Table 5：計算効率と精度の比較（p.10）

パラメータ数、FLOPs（浮動小数点演算回数＝計算量の指標）、推論時間、精度の4軸比較。KGLA-Netは31.2M・7.2G・7.9ms・RAF-DB 92.48% / AffectNet 67.87%で、POSTER++（43.7M・8.4G）、POSTER（71.8M・15.7G）、TransFER（65.2M・15.3G）より軽量かつ高精度と主張する。推論時間が記載されているのは本手法のみで、比較手法は「–」である。またここでの精度92.48 / 67.87はTable 2の平均値92.43 / 67.83と一致せず、単一実行のベスト値と平均値が混在している。

### Table 6：主要コンポーネントのアブレーション実験（p.10）

アブレーション（部品をわざと外して寄与を測る実験）の中核表。二流路の特徴を単純加算するだけのベースラインが88.52%、そこにFRM（特徴精製）を足すと89.65%（+1.13）、さらに単純加算をKGLAに置き換えると91.83%（+2.18）、最後にプーリング型分類器をクエリ型分類ヘッドに替えると92.48%（+0.65）と段階的に上がる。KGLAの寄与が最大であることが示されており、論文の主張と整合する。ただし各行は1回の実行値とみられ、繰り返し実行のばらつきが付されていない。

### Table 7：KGLAを適用する段階の組み合わせ（p.11）

3つのStageのどこにKGLAを効かせるかを網羅した表。単独ではStage 1が90.25%、Stage 2が90.68%、Stage 3が91.10%と、深い段階ほど良い。2つの組み合わせではStage 1+3が91.44%、Stage 2+3が91.95%、そして3段階すべてを縦続させたとき最高の92.48%となる。低い段階はしわや微細な表情変化、高い段階は粗い構造的意味を捉えるため、多スケールの統合が不可欠だという主張を裏づける。一方で組み合わせ間の差は0.5〜1ポイント台で、単一実行値である点に注意が必要である。

### Table 8：分類ヘッド設計の比較（p.11）

最終段で特徴をどう1本のベクトルにまとめるかの比較。グローバル最大プーリング（最も強い反応だけ拾う）が91.35%、グローバル平均プーリング（全体を平均する）が91.70%、提案するクエリ型デコーディングヘッド（学習可能な問い合わせベクトルが特徴と繰り返し対話して情報を吸い上げる方式）が92.48%。差は約0.8〜1.1ポイントで、著者は「高次の識別的意味を抽出できる」と解釈している。ただし3手法ともパラメータ数が揃っているかは示されておらず、単なる容量増加の効果を否定できない。

### Table 9：クエリ初期化戦略のアブレーション（p.11）

初期クエリベクトル（1×256）をゼロで初期化する提案手法と、Xavier乱数初期化（5種のシード：10、42、100、512、2026）を比較した表。乱数版は91.92、92.15、92.30、92.37、92.51%とばらつき、ゼロ初期化は92.48%。5件中4件はゼロ初期化を下回るが1件（シード2026）は92.51%とわずかに上回る。著者は「ゼロ初期化でも最適化は不安定化せず、決定論的で再現しやすい」と穏当に結論しており、ここは誇張のない記述である。同時に、シード違いだけで0.6ポイント動くという事実は、Table 2での0.2ポイント差の意味を相対化する。

### Table 10：異なる効率化クロスアテンション戦略の比較（p.11）

他の構成要素を固定したうえで、突き合わせ方式だけを入れ替えた比較。グローバル・クロスアテンション（全体総当たり）が92.06%、PVT由来のSpatial Reduction Cross Attention（画像特徴を先に平均プーリングで縮めてから突き合わせる）が91.44%、提案のKGLAが92.48%。全体総当たりより局所限定の方が精度が高いという結果は、余計な遠距離の対応づけが雑音として働くという著者の仮説を支持する。ただしこれも単一実行の比較であり、差の大部分（0.42ポイント）は前述のシード揺らぎの幅に収まる。

### Table 11：ランドマーク品質を劣化させたときの頑健性（p.12）

入力画像の一部を正方形パッチでランダムに黒塗りしてからランドマーク側にだけ入力し、部分的な顔の隠れや特徴点検出の失敗を模擬した実験（5回実行の平均±SD）。マスク率0%で92.43±0.11、10%で92.16±0.15、20%で91.58±0.20、30%で90.47±0.28、40%で88.21±0.37、50%で85.36±0.51と、なだらかに低下する。軽度の欠損には強いが、30%を超えると急速に劣化する。臨床現場ではマスク着用や眼鏡、うつむき姿勢が日常的であり、この表は実運用上の弱点を率直に示した有用なデータである。

### Table 12：RAF-DBとAffectNet間のクロスデータセット評価（p.12）

本論文で唯一の外部（データセット横断）検証。RAF-DBで学習しAffectNet 7クラスでテストすると56.82±0.34%、逆向きでは74.35±0.27%。同一データセット内評価（92.43%、67.83%）と比べて大幅に低下しており、著者もドメインギャップの大きさを認めている。AffectNet→RAF-DBの方が良いのは学習データ量と多様性が大きいためと説明される。57%前後という値は、精神科の縦断モニタリングのように撮影環境も対象者も学習時と異なる状況では、そのままでは使えないことを示唆する重要な結果である。

## 3. 8項目評価

### ① 研究デザイン

コンピュータビジョンの標準的な手法開発研究として、提案手法の設計→公開ベンチマーク3種での比較→アブレーション→効率測定→頑健性・クロスデータセット検証という流れは妥当に構成されている。しかし「精神医学における精神運動表現型評価」を標題と導入・結論に掲げながら、デザインの中に精神科的要素が一切組み込まれていない。臨床応用を検証する仮説も、精神症状との対応関係を調べる設計もなく、精神科への言及は引用文献を介した文脈づけにとどまる。デザインとタイトルの乖離が最大の問題である。

### ② サンプルサイズと選択基準

用いたのは公開データセットRAF-DB、AffectNet（7／8クラス）、CAER-Sのみ。本文には各データセットの画像枚数、訓練／検証／テストの分割数、被験者の年齢・性別・人種構成が一切明記されておらず、「標準的な学習プロトコル」と書かれるだけで再現に必要な情報が欠けている。精神疾患患者のサンプルはゼロであり、抗精神病薬による表情の減少、緊張病、うつ病の精神運動制止といった、論文が標的と称する現象を含むデータは1例も検証されていない。選択基準は「広く使われているから」という慣行以上の根拠を欠く。

### ③ 方法論の適切性

FRM→統一構造的事前情報→局所窓クロスアテンション→クエリ型ヘッドという構成は、先行のPOSTER／POSTER++の弱点（繰り返しの全体総当たり融合）に対する合理的な改良であり、式(5)〜(7)による計算量の理論的導出も明示されている。一方で、静止画1枚から基本感情を当てる枠組みは、時間的な動きの遅さ・乏しさを本質とする精神運動症状の評価とは原理的にかみ合わない。動画・時系列モデリングは扱われず、Action Unit（表情筋単位）のような臨床解釈可能な中間表現も用いていない。また第4.5.2節・第4.6.1節で「可視化した」と詳述されるヒートマップと注意分布の図が、本文中に図として収載されていない（本PDFの埋め込み画像はFigure 1〜4に対応する3ページ分のみ）。検証不能な定性的主張が残っている点は方法論上の欠落である。

### ④ 統計分析の妥当性

乱数シードを変えた5回の実行から平均・標準偏差・95%信頼区間を報告した点（Table 4）は、単発の最高値のみを載せる同種の論文より一段良心的である。しかし決定的な欠陥として、比較手法との差についての統計的検定が皆無である。RAF-DBでの0.22ポイント、CAER-Sでの0.20ポイントという優越幅は、自モデルのシード間変動（Table 9では91.92〜92.51%と0.6ポイント幅）より小さく、「最高精度」という主張を支える統計的根拠は示されていない。加えて交差検証（k-fold）は行われておらず、アブレーション各表（Table 6〜8、10）は単一実行値とみられ、ばらつきが併記されていない。

### ⑤ 結果の信頼性と再現性

学習設定はTable 1に整理され、バックボーン（Ms-Celeb-1Mで事前学習したIR-50、重み固定のMobileFaceNet）、使用GPU（RTX 4090単体）まで記述されており、この点は再現性に資する。しかしコード・学習済み重みの公開に関する記載はなく（Data availability statementは「本文と補足資料に含まれる」のみ）、第三者による再現は事実上困難である。さらにTable 2の平均値（92.43 / 67.83）とTable 5・各アブレーション表の値（92.48 / 67.87）が混在しており、どの数字が主要結果なのかが読者に委ねられている。本文中でも「92.43±0.11」と「92.48」が節ごとに使い分けられており、論文内の数値提示に一貫性を欠く。

### ⑥ 結論の妥当性

「効率と精度を両立した」という限定的な結論は、Table 5（31.2M／7.2G／7.9ms）とTable 2〜3の範囲でおおむね支持される。ただし効率の主張には誇張がある。KGLAによる49倍削減はアテンション計算部分（103.26M→2.11M FLOPs）に限った話で、線形射影を含めても0.681G→0.580Gにすぎず、モデル全体の7.2G FLOPsに対する寄与は約1.4%にとどまる。また7.9msはハイエンドGPU（RTX 4090）上の測定値であり、論文が繰り返し訴える「資源制約のある端末」での実測は一切行われていない。「計算論的精神医学の軽量な基盤を提供する」という結論部の主張は、実証を伴わない展望にすぎない。

### ⑦ 新規性

構造的事前情報を一度だけ構築して再利用し、縮小する局所窓内でクロスアテンションを行うという着想は、POSTER++の段階ごとの反復融合に対する明確な差分であり、Swin Transformerの局所自己注意やPVTの空間縮約とも異なる「局所クロスモーダル統合」として位置づけられている。Table 10でSRAとの直接比較を示したことも誠実である。一方で、構成要素（局所窓注意、学習可能クエリによるデコード、類似度マスク）はいずれも既存技術の組み合わせであり、精度向上は0.2ポイント台。精神医学的な新規性に至っては、既存FER手法を精神科の文脈で語り直した以上のものはない。

### ⑧ 臨床的意義

現時点での臨床的意義はほぼゼロに近いと評価せざるを得ない。検証は一般公衆の実世界表情データ（RAF-DB、AffectNet、CAER-S）のみで行われ、精神疾患患者のデータでの検証は一切ない。したがって、統合失調症の情動鈍麻、うつ病の精神運動制止、薬剤性のパーキンソニズムによる仮面様顔貌を本モデルが検出・定量できるという証拠は存在しない。出力が7〜8種の基本感情ラベルである点も、臨床で必要な表出の量・速度・変動性という連続指標とずれる。さらにクロスデータセット精度56.82%（Table 12）とマスク30%以上での急落（Table 11）は、撮影条件の変わる臨床環境での安定性に強い疑念を投げかける。人種・年齢・性別ごとの公平性評価、顔画像という機微情報の取り扱い、患者の同意といった実装上の倫理的論点も未検討である。精神科医としては「将来この方向の基盤技術になりうる」という程度に受け止め、臨床判断への利用には現段階で根拠がないと理解すべきである。
