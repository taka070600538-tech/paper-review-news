# 全般性インターネット使用障害とソーシャルメディア過剰使用のエピジェネティクス - SLC6A4・NR3C1・OXT遺伝子に注目して

## 概要

ネットやSNSの使いすぎ(インターネット使用障害、IUD)が「体の中で何と結びついているのか」を、遺伝子のスイッチの入り具合=**DNAメチル化**(DNAに目印の化学基が付き、遺伝子の働きを弱める仕組み)から調べた探索的研究です。ドイツ・ウルム大学で、うつ病入院患者83人と、年齢・性別・飲酒量をそろえた健常者83人を比較し、入院時と2週間後に採血しました。対象はセロトニントランスポーター(SLC6A4、SSRIの標的)、ストレスホルモンの受け手であるグルココルチコイド受容体(NR3C1)、絆のホルモンであるオキシトシン(OXT)の3遺伝子です。結果、うつ病群ではSNS依存傾向・ネット依存傾向・渇望が強いほどNR3C1の1か所(CpG 9)のメチル化が高く(r = <b style="color:#dc2626">0.33〜0.40</b>)、健常群では社会的支援が多いほどOXTの1か所のメチル化が高い(r = <b style="color:#dc2626">0.30</b>)という関係が見つかりました。SLC6A4とネット依存傾向の関連はありませんでした。SNS依存傾向が強いほど2週間のOXTメチル化の変化が小さい傾向もありましたが、ブートストラップ信頼区間はゼロをまたぎ、効果は小さいものでした。著者自身「予備的な手がかり」と位置づけています。

## FigureとTableの解説

本文で言及されるのは **Figure 1点(Fig. 1)と Table 3点(Table 1〜3)** です。このほか補足資料に Table S1〜S12(全変数の群比較、全相関係数表、残り8モデルの信頼区間)がありますが、PDF本体には含まれないため内容は本文の記述からのみ把握しています。

### Table 1:うつ病入院患者が受けていた治療

入院時(T0)と2週間後(T1)の薬物療法の内訳です。抗うつ薬ではSSRI(選択的セロトニン再取り込み阻害薬)が最多で、T0で46人(55.4%)、T1で29人(51.8%)。続いてSNRI 16人(19.3%)、三環系18人(21.7%)、四環系13人(15.7%)、その他の非定型6人(7.2%)。抗精神病薬は第2世代が21人(25.3%)でした。1人が複数薬を使うため合計は100%を超え、T1の割合は脱落者を除いた人数で計算されています。表の注にECT(電気けいれん療法)・BLT(高照度光療法)・CBT(認知行動療法)の略語があり、これらの治療も記載されていたと考えられますが、テキスト抽出では該当行を確認できませんでした。重要なのは、患者の半数以上がまさにSLC6A4の産物を標的にする薬を飲んでいた点で、これが後のSLC6A4結果の解釈に効いてきます。

### Table 2:2群の背景と質問紙得点の比較

健常群(HC)とうつ病群(MDD)はいずれも男性35人・女性48人。マッチングにより年齢(40.3歳 vs 42.2歳)、飲酒量に差はありません。一方、喫煙本数はMDDで多く(1.4本 vs 6.0本/日、p < 0.001、d = <b style="color:#dc2626">0.71</b>)、BMIもやや高めでした(p = 0.067)。社会的ネットワークの大きさと質(3.28 vs 1.90、d = <b style="color:#2563eb">-1.91</b>)とFERUS社会的支援得点(44.0 vs 35.8、d = <b style="color:#2563eb">-0.88</b>)はMDDで大きく低く、SNS使用時間は週8.5時間 vs 18.1時間でMDDが倍以上(p = 0.033)。ところが、ネット依存傾向(s-IAT合計 21.7 vs 23.1)、SNS依存傾向(BSMAS 9.5 vs 10.7)、渇望下位尺度には有意差がありませんでした。つまり「うつ病患者は使う時間は長いが、依存的と自覚する程度は健常者と大差ない」という構図です。p値はFDR(偽発見率、多重比較による偶然の当たりを抑える補正)で調整済みです。

### Table 3:OXTメチル化の変化量を予測するモデル

2週間でのOXTメチル化の変化量(t1−t0)を目的変数にした線形混合モデル(個人差やCpG部位差を「ランダム効果」として吸収する回帰)の係数表です。好中球・リンパ球数、うつ重症度、抗うつ薬用量、BMI、喫煙は、いずれも有意な予測因子ではありませんでした。BSMAS(SNS依存傾向)の係数は β = <b style="color:#2563eb">-0.0271</b>、p = 0.009 と有意でしたが、5000回のブートストラップ(データを繰り返し再抽出して推定のぶれを見る方法)による信頼区間は −0.0698〜0.0126 でゼロを含みます。群の主効果(β = −0.0012)とBSMAS×群の交互作用(β = 0.0186、p = 0.245)は有意でなく、「効果は群によらない」と解釈されています。固定効果で説明できる分散(周辺R²)は0.06にとどまり、ランダム効果込みでも0.34です。

### Figure 1:SNS依存傾向とOXTメチル化変化量の関係(群別)

横軸にBSMAS得点、縦軸にOXTメチル化の差(t1−t0)をとり、MDD群とHC群それぞれの予測直線を描いた図です。どちらの群でも右下がりで、SNS依存傾向が強い人ほど2週間でのOXTメチル化の変化が小さい(あるいは減る方向)ことを示します。2本の直線の傾きはほぼ同じで、交互作用が有意でなかったことと一致します。ただし Table 3 のとおり信頼区間はゼロをまたぎ、固定効果の説明力も6%程度なので、図の傾きは「その方向の傾向がうっすら見える」程度に読むのが妥当です。図に信頼帯がどう描かれているかは、テキスト抽出のため確認できていません。

## 8項目評価

本論文は一次データを扱う原著研究(症例対照+2時点縦断)なので、8項目を一次研究の基準でそのまま評価します。

### ①研究デザイン

うつ病入院患者と健常者を傾向スコアでマッチングし、2時点で採血する症例対照・縦断デザインです。事前登録(OSF)があり、解析計画が後出しでない点は評価できます。IUDの正式診断を持つ患者を集めるのが難しい中で、IUDと併存しやすいうつ病患者を使う工夫も理にかなっています。問題点は、IUD傾向が初回のみの測定で、メチル化だけが2回測られている非対称な設計であることです。「依存傾向が変わるとメチル化も変わるか」は問えず、因果の方向も判別できません。データは事前登録より前に収集・保存されており、一部は既報(Sanwald 2024)と重複しています。

### ②サンプルサイズと選択基準

最終解析は各群83人(MDD 99人から16人除外、HC 169人から43人除外の後マッチング)。SCID-IVによる診断、Mini-DIPSとSCID-5-PDで健常者の精神疾患を除外するなど、選択基準は丁寧です。しかし候補遺伝子のメチル化研究として83人はかなり小さく、著者も「小さな効果を検出するにははるかに大きなサンプルが必要」と認めています。さらにSNS使用時間はMDDで57〜58人分しかなく、BSMASも各群77人と欠測があります。2週後の脱落も相応にあり(SSRI使用者46→29人)、脱落の偏りは検討されていません。不安症併存例を除外したため、実臨床のうつ病像より「純粋な」集団に偏っている点も一般化を制限します。

### ③方法論の適切性

メチル化測定はSequenom EpiTYPER MassARRAY(質量分析で部位ごとのメチル化率を定量する方法)、mRNAはqPCRと、確立した手法を外部ラボで行っています。血球組成(好中球・リンパ球)を共変量に入れたのも、血液メチル化研究の基本を押さえています。問題点として、IUD・SNS依存は自己記入式の質問紙のみで、内省の不正確さや社会的望ましさの偏りを免れません。採血の時刻や空腹状態は統制されておらず(著者も限界に記載)、メチル化の日内変動の影響を排除できません。mRNAはt0のみで、変化量の機能的意味は検証不能です。抗精神病薬用量は「モデルの簡潔さのため」除外されています。

### ④統計分析の妥当性

相関はFDR補正、LMMは参加者とCpG部位のランダム切片を入れ、さらにブートストラップで信頼区間を求めるなど、多重比較への配慮は一定水準です。しかしTable 3でBSMASが p = 0.009 なのに、ブートストラップ信頼区間がゼロを含むという食い違いがあり、本文はこれを「慎重に解釈」とするだけで、どちらを主たる判断基準にするのかが明確ではありません。三元交互作用で設計行列がランク落ちしたため差分(t1−t0)モデルに切り替えた点は合理的ですが、差分は測定誤差を増幅しやすい指標です。うつ重症度の群×時間交互作用は F = 13.72, p < 0.001 なのに η² = 0.01 と効果量が小さく報告されており、数値の整合性にやや疑問が残ります。

### ⑤結果の信頼性と再現性

有意だったのは、NR3C1の1か所、OXTの1か所という「多数の部位のうち単一部位」の相関です。著者自身、NR3C1・OXTの大多数の部位は有意でなく、NR3C1 CpG 9はmRNA量と関連しなかったと述べています。FDR補正後もp値は0.02〜0.05前後で、境界的な結果が多いといえます。データは倫理委員会の判断で公開されておらず、第三者による再解析は請求ベースに限られます。SLC6A4について先行研究(Annunzi 2023)と部位を対応づけて比較している点は誠実ですが、その比較でも結果は一致しておらず、再現性の確認は今後の課題です。

### ⑥結論の妥当性

著者は「NR3C1とOXTがSNSの過剰使用に関与する可能性の、最初の予備的な手がかり」と控えめに結論しており、全体としては妥当です。一方、Discussion末尾で「NR3C1の1部位のメチル化はネット・SNS問題使用と頑健に正に関連した」と書いている点は、単一部位・mRNAとの関連なし・r = 0.33〜0.40というデータからすると「頑健」は言い過ぎです。また要旨の「両群でOXTメチル化の変化が小さくなった」は信頼区間がゼロを含む結果で、要旨を読むだけでは実際より強い印象を与えかねません。IUD傾向が治療反応に関わるという当初の仮説は支持されなかったと明記している点は評価できます。

### ⑦新規性

IUD・SNS依存とDNAメチル化を縦断的に調べた研究は、著者の知る限り初めてとされます。分子レベルのIUD研究自体が少なく、エピジェネティクス研究はDAT1遺伝子やOXTR・SLC6A4を調べた横断研究が数本ある程度です。うつ病という併存症の文脈で、ストレス系(NR3C1)と社会的絆の系(OXT)をIUDに結びつけた視点は新しいといえます。ただ、候補遺伝子アプローチ自体は、効果が小さく再現しにくいことが知られた古典的手法です。ゲノム全体のメチル化を網羅する解析(EWAS)と比べると発見の幅は限られ、「新規性」は主に対象テーマの新しさによるものです。

### ⑧臨床的意義

現時点で診療を変えるものではありません。ただ、うつ病患者でSNS依存傾向とストレス応答遺伝子の目印が結びつく可能性は、「うつ病のSNS過剰使用をストレス対処の失敗(不適応的な代償行動)として扱う」という臨床的な見立てと整合します。健常者で社会的支援とOXTメチル化が関連した点も、対人関係の質を生物学的に捉える手がかりになり得ます。限界として、末梢血のメチル化が脳内の状態をどこまで反映するかは、SLC6A4以外では不明です。SSRI服用がSLC6A4のメチル化を「汚染」している可能性も著者自身が指摘しており、薬物療法中の患者で得たバイオマーカーを未治療者に当てはめることはできません。
