# 精神医学へのニューロフィラメント軽鎖測定の導入——現在のエビデンス・機会・落とし穴 精読ノート

## 概要

ニューロフィラメント軽鎖（NfL）は、神経細胞の軸索（情報を伝える長い突起）を支える骨組みタンパク質で、軸索が傷つくと脳脊髄液（CSF）や血液に漏れ出す。第4世代の超高感度測定法（SIMOA、ELLA）の登場で血液中の微量なNfLも正確に測れるようになり、神経内科では「脳のトロポニン」（心筋梗塞の血液マーカーになぞらえた呼び名）として、病気の種類を問わず「いま脳が傷んでいる量」を示す指標になりつつある。本総説はチューリッヒ大学のグループが、NfLの生物学・測定上の注意点を解説した上で、PubMedを系統的に検索して精神疾患のNfL研究48本を整理したものである。うつ病、双極性障害、精神病性障害、神経性やせ症、物質使用障害で、健常者よりおおむね1.2〜2.5倍高い血中NfLが報告されたが、病期・亜群で大きくばらつき、疾患特異性はない。著者らは、診断よりも「状態の指標」として、神経変性疾患の除外、薬物の脳毒性評価、治療反応の経時モニタリングに活用する道を提案している。

## Figure・Tableの解説

本論文にはFigureが5点（Fig. 1〜5）、Tableが5点（Table 1〜5）ある。補足資料（Supplementary）は本文中に言及がない。

### Fig. 1 NfLの細胞外液への放出

1. 左側に神経細胞が描かれ、軸索を青いミエリン（髄鞘：電線の被覆のような絶縁体）が包んでいる。
2. ステップ1「神経軸索の病理」：炎症、外傷、虚血（血流不足）、加齢、物質（薬物・アルコール）が軸索を傷つける。
3. ステップ2「微細構造の変化」：拡大図で、軸索内の微小管（黄色）やNF重合体（灰色の線）が崩れ、NfLの断片（灰色の点）が散らばる様子が示される。ニューロフィラメントの安定性が下がり、細胞障害やアポトーシス（細胞の計画的な死）が起きる。
4. ステップ3「NfL放出」：断片がCSFと血液へ流れ出し、濃度が上がる。
つまり「血中NfLの上昇＝原因を問わず軸索がいま壊れている」という本総説全体の前提を1枚で示した図である。

### Fig. 2 血中NfL測定の主な交絡因子

交絡因子とは、病気そのもの以外で測定値を動かしてしまう要因のこと。図は3列に分かれる。
1. 「上昇させる因子」：年齢（成人期で年1〜2%、高齢期で4〜5%上昇）、物質使用、心血管リスク因子（HbA1c、収縮期血圧、喫煙、脂質異常）、頭部への衝撃（スポーツ脳震盪など）、妊娠。
2. 「上げも下げもする因子」：測定技術（第何世代の測定法か）、生体試料（血漿は血清より約20%低い）、個人差そのもの。
3. 「低下させる因子」：BMI（体格指数）と循環血液量。体が大きく血液量が多いほどNfLが薄まるためである。
精神疾患患者は体重・喫煙・物質使用などが健常者と異なるため、これらの補正が特に重要だというメッセージにつながる。

### Fig. 3 系統的レビューのフローチャート

PRISMA（系統的レビューの報告手順）に沿った文献選択の流れ。
1. 同定：PubMed検索で848件がヒット（2023年8月11日まで）。
2. 選択基準（ヒト研究、血液またはCSFのNfL測定、精神疾患集団）を満たさない795件を除外し、題名・要旨のスクリーニングで53件が残る。
3. 全文を読んで内容が合わない5件を除外し、48件を採用。
4. 診断別内訳：うつ病16、双極性障害10、精神病性障害9、物質使用障害8、その他14（9本は複数診断を扱うため合計は48を超える）。
なお本文では「n=47件を採用」と書かれており、図の48件と1件食い違っている。

### Fig. 4 精神医学におけるNfL利用の主要エビデンス・機会・落とし穴

3列の表形式の図。
1. 主要エビデンス：①気分障害でのNfL上昇（病期に依存）、②物質使用障害（コカイン、ケタミン、アルコール）での上昇、③統合失調症の早期・一部亜群での上昇、④上昇幅は神経変性疾患より小さい。
2. 機会：①神経疾患（認知症、二次性精神病）との鑑別、②微細な脳病理の重症度の定量（状態依存）、③薬物の神経毒性評価、④治療反応の経時モニタリング。
3. 落とし穴：①個人差が大きいので十分なサンプルと交絡因子の定義が必要、②NfL放出の神経生物学的意味が未解明で解釈が難しい、③NfLと画像上の脳変化の関係が不明確。
本総説の「機会と落とし穴」の章を一望できる要約図である。

### Fig. 5 精神医学でのNfL測定の使い方（入門）

研究計画と交絡因子の2段構成の実践ガイド。
1. 研究課題と計画：①横断研究は個人差が大きいので中〜大規模サンプルが必要、②単一疾患への特異性はない、③状態依存的に変わるので、急性期／慢性期／寛解期、治療中／未治療などの臨床状態を区別して記録する（状態 vs 特性）、④重症度の定量、予後評価、治療反応の経時モニタリングを主な臨床応用として検証する。
2. 交絡因子：人口統計学的（年齢↑、BMI↓、妊娠↑）、臨床的（併存疾患↑、物質使用↑）、分析的（測定法・試料で↑↓）。⑤これらの考慮、⑥第4世代測定法（ELLA・SIMOA）の使用、⑦CSF・血清・血漿は相関が高いが絶対値が異なること、⑧採血後の取り扱いには頑健であること、が明記されている。

### Table 1 うつ病患者のNfL研究

うつ病（MDD）関連の17研究を、臨床特徴、試料（血清・血漿・CSF）、測定法、人数、平均年齢、健常者との比較（↑上昇／≈差なし）、補正した交絡因子で一覧化している。
1. 現在うつ病エピソード中の成人では、血清・血漿で上昇（↑）とする研究が多い（24〜94人、1.3〜2.8倍）。
2. NfLが高いほど処理速度や実行機能（段取りや切り替えの力）が悪い、白質（神経線維の束）の変化が大きいという相関も報告。
3. 高齢者の小規模研究や電気けいれん療法（ECT）前後の研究では差なし（≈）。ECTで上がらないことは安全性の傍証とされる。
4. ケタミン点滴の治療反応をNfLが予測した研究もある。
一方、ELISA系の旧世代測定法の研究が混在し、交絡補正も「部分的」が少なくない点に注意が必要である。

### Table 2 双極性障害患者のNfL研究

双極性障害（BD）の10研究を同じ形式でまとめる。
1. 成人・思春期のBDでは、CSF・血漿・血清のいずれでも健常者より上昇とする研究が多い（25〜133人、1.2〜2.5倍）。
2. 抗精神病薬治療との正の関連（Jakobssonら）、記憶・言語機能低下との関連（Rolstadら）、白質変化との相関（Aggioら）、作業記憶課題成績との逆相関（Baiら）。
3. 一方、寛解（安定）期のBDを1年追跡したKnorrらでは、CSFに差がなく、血漿も基準時に軽度上昇傾向（1.19倍）のみで追跡時には消えた。
4. 高齢BDの小規模研究では健常者並みで、前頭側頭型認知症（FTD）より明確に低い。
躁・うつ・寛解などの病相が研究ごとにばらばらで、病相とNfLの関係は結論が出ていない。

### Table 3 精神病性障害患者のNfL研究

統合失調症（SZ）・初回エピソード精神病（FEP）の9研究。
1. 高齢の慢性SZや一般成人の慢性SZでは、平均値では健常者と差がない（≈）研究が多い。
2. ただしBavatoらは個人差が非常に大きく、年齢別基準の95・99パーセンタイルを超える患者の割合が多いこと、一部の個人では4倍に達することを示した。クロザピン治療中の亜群で高いという報告もある。
3. 早期段階では、FEPで1.39倍（Guaspら）、早発性SZで2.67倍（Ceylanら）の上昇。
4. 抗NMDA受容体脳炎（自己抗体が脳を攻撃し精神病症状を起こす病気）はFEPの3.87倍で、15 pg/mLの基準値でFEPの96%、脳炎の85%を正しく分類できた。
「平均では差がなくても、高値の個人を拾う」使い方を示唆する表である。

### Table 4 物質使用障害患者のNfL研究

物質使用障害（SUD）の8研究。
1. ケタミン依存：健常者の2.07倍。うつ病を併存すると、さらに高い（Liuら、Huangら）。
2. コカイン慢性使用：基準時1.39倍、4か月後1.54倍。毛髪中コカイン濃度という客観的指標と相関し、使用量の増減がNfLの増減を予測した（用量反応関係）。
3. MDMA（エクスタシー）慢性使用：差なし。拡散テンソル画像（白質の状態をみるMRI）でも白質障害なし。
4. アルコール：依存症で2.53倍、認知機能（MoCA）や白質量と負の関連。入院初日の重症アルコール使用障害は3か月以上断酒者の1.59倍で、離脱そのものの影響が示唆される。
5. 多剤使用のSUDでも上昇し、認知機能障害と関連。
物質ごとに結果が異なり、毒性比較の道具としての可能性が示されている。

### Table 5 その他の一次性精神疾患のNfL研究

13研究を収載。
1. 自閉スペクトラム症（ASD）の子ども：2研究で上昇（1.44倍、1.93倍）、旧世代測定法の1研究では差なし。重症度との正の相関も報告。
2. 神経性やせ症（AN）：急性期・低体重で上昇（1.95倍、1.68倍）し、体重回復で正常化。皮質の薄さとも関連。発症30年後でも1.46倍という報告がある一方、長期回復者では差なしとの報告もある。ただし低BMIそのものがNfLを上げる点に注意。
3. ストレス関連の消耗症（疲弊障害）：150人の研究で1.1倍上昇し7〜12年後に正常化、31人・旧世代法の研究では差なし。
4. PTSD：退役軍人478人で、AIM2遺伝子のメチル化を介した間接的関連。
5. 混合精神疾患群：FTDなど神経変性疾患より低い。

## 8項目評価

本論文は原著研究ではなく総説（系統的文献検索を伴うナラティブレビュー）である。そのため、①〜⑤は一次研究向けの基準をそのまま当てはめず、「文献検索・選択の設計」「収載研究の規模と選択基準」「整理・統合の方法」「異質性の扱い（メタ解析の有無）」「結論の再現性」に読み替えて評価する。

### ①研究デザイン

前半でNfLの構造、測定法の世代、血液とCSFの関係、半減期、交絡因子を解説し、後半でPRISMAに準拠した系統的検索の結果を診断別に整理する。最後に「機会と落とし穴」をまとめる三部構成は、入門書（primer）という目的によく合っている。問題点は、PRISMAを掲げながら検索がPubMed単一で、プロトコル事前登録（PROSPEROなど）もないことである。採用研究の質評価（バイアスのリスク評価）も行われていない。系統的レビューとナラティブレビューの中間的な位置づけで、網羅性の保証は限定的である。

### ②サンプルサイズと選択基準（→収載文献の規模と選択基準）

848件から48件を選び、診断別に表で全研究の人数・年齢・測定法を開示している点は透明性が高い。二次性の精神症状（神経疾患・遺伝性・全身疾患に伴うもの）を除外し、一次性精神疾患に絞った基準も明確である。一方で、個々の研究は9〜11人程度の極小規模が多く、最大でも478人（PTSD）にとどまる。英語論文・ヒト研究のみという制限もある。さらに、本文の「47件」とFig. 3の「48件」、Fig. 3の「うつ病16件」とTable 1の17行が一致しないなど、集計に小さな不整合がある。

### ③方法論の適切性（→文献の整理方法）

各表で「試料」「測定法」「交絡補正の有無」を列として明示しているため、読者が研究の質を自分で判断できる。旧世代のELISA系測定法と第4世代SIMOA・ELLAを区別して論じ、矛盾した結果の一部を測定法の違いで説明しようとする姿勢も適切である。問題点として、交絡補正は「Yes／Partially／No」の粗い3段階でしか評価されていない。また、健常者との比較を「↑／≈」の記号で示すだけで、効果量や信頼区間は統一的に抽出されていない。そのため、研究間の強弱を比べにくい。

### ④統計分析の妥当性（→異質性の扱い・統合方法）

本総説はメタ解析を行っておらず、「1.3〜2.8倍」「1.2〜2.5倍」といった倍率の範囲を記述的に示すにとどまる。異質性については、病期（急性・寛解）、年齢層、測定法、交絡補正の違いを言葉で丁寧に指摘している。しかし、統計的な異質性の指標（I²など）や、出版バイアス（陽性結果ほど論文になりやすい偏り）の評価はない。結論にある「1.2〜2.5倍」は、出所の異なる倍率を寄せ集めた目安にすぎない。そのため、加齢による年1.01〜1.05倍との比較も、厳密な比較ではなく概念的な対比として読むべきである。

### ⑤結果の信頼性と再現性

物質使用障害（特にコカインの用量反応関係、アルコール断酒後の正常化）とANの体重回復後の正常化は、縦断データがあり比較的再現性が高い。MDDの現在エピソード中の上昇も複数研究で一致している。一方、統合失調症では平均値の差がない研究が多く、ASD、疲弊障害、PTSDは研究数が少なく結果も割れている。著者自身の研究（Bavatoら）が複数の表に含まれ、解釈に影響している可能性がある。また、利益相反欄は「全著者に利益相反なし」としながら、Zetterbergの多数の企業顧問歴やバイオマーカー企業の共同創業が謝辞欄に記載されている。開示の一貫性に疑問が残る。

### ⑥結論の妥当性

「NfLは精神疾患で変化するが疾患特異性はない。したがって診断よりも状態の指標として使うべき」という結論は、収載データとよく整合しており、過大評価を避けた慎重な結論である。特定の基準値を超えたら神経疾患（FTD、パーキンソン病、自己免疫性精神病）を疑う、という提案も根拠研究に支えられている。ただし、治療反応モニタリングや薬物の脳毒性評価という応用は、現時点では小規模・単発の研究に基づく仮説段階である。また、NfL上昇の神経生物学的意味（真の軸索障害か、炎症か、血液脳関門の透過性変化か）が未解明なままなので、「状態依存マーカー」としての臨床的解釈には飛躍が残る。

### ⑦新規性

神経内科で確立しつつあるNfLを精神医学に体系的に持ち込み、うつ病から摂食障害、物質使用障害、ASDまで横断的に整理した点は新しい。単なる文献一覧ではなく、「鑑別」「重症度」「毒性」「モニタリング」という応用の枠組みと、研究計画上のチェックリスト（Fig. 5）を示した点に独自性がある。一方、NfLを精神疾患と神経変性疾患の鑑別に使う発想自体は先行研究（Eratneら、Al Shweikiら）で既に示されている。そのため、エビデンスとしての新規性は乏しく、概念整理と提言が主な貢献である。

### ⑧臨床的意義

精神科臨床医にとって最も実用的なのは、「若年でもNfLが年齢基準を大きく超えるなら、FTDや抗NMDA受容体脳炎などの器質疾患を疑い、MRI・髄液検査へ進む」という鑑別スクリーニングの使い方である。物質使用障害では、断薬・減量による正常化を患者にフィードバックする動機づけの道具にもなりうる。ただし、日本の日常診療で血中NfLを保険で測定できる体制は整っていない。また、年齢・BMI・腎機能・喫煙などで値が大きく動き、個人差も大きいため、単回測定の解釈は難しい。現時点では研究用指標であり、臨床判断に直接使うには基準値の整備と前向き検証が必要である。
