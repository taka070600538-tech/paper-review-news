# パキスタンの精神科医におけるデジタル精神医学の知識・認識・導入意欲——多施設横断研究 精読ノート

> 役割：日本トップクラスのサイエンスコミュニケーターとしての精読プロンプト（デフォルトフォーマット）に基づく分析結果

## 1. 概要（500字以内）

パキスタンは不安・うつの有病率が南アジアで最も高い水準（約34％）にある一方、精神科医は人口10万人あたり0.19人、精神保健予算は総医療費の0.04％にすぎない。こうした人手と資金の不足を補う手段として期待されるのが「デジタル精神医学」、すなわち遠隔精神医療（ビデオ診察など）、AI（人工知能）、メンタルヘルスアプリ、VR（仮想現実）である。本研究は2023年1〜6月、同国の公立18病院の精神科で働く医師200人（研修医54％、30歳以下56％）に48項目のオンライン質問紙を実施し、各技術の知識・受け止め方・導入意欲と、導入の障壁を調べた。遠隔精神医療は68.5％が知っており75.5％が有用と考えたが、既存の診療体制への組み込みには53.5％が反対した。AIの研修を受けた人は39.5％、アプリを知らない人は62％、VRを知る人は32.5％にとどまった。自由記述からは「設備・資源の不足」（44.5％）と「教育・認知の不足」（21.5％）が主な障壁として浮かんだ。著者らは研修・インフラ・制度整備が急務と結論している。ただし本文内で数値の食い違いが多く、解釈には注意を要する。

## 2. FigureとTableの解説

本論文にFigureはなく、本文中のTableは4つ（Table 1〜4）である。加えて、各技術の質問項目別の回答分布を示す補足Table S1〜S4が本文から参照されている（補足資料は出版社サイトの別PDFで、本PDFには含まれないため、本文の記述から内容を再構成して解説する）。

### Table 1：回答者の属性（デモグラフィック）

step 1：回答者は200人で、男性55.5％、女性44.5％。step 2：年齢は20〜30歳が56.0％、31〜40歳が36.0％と若手中心で、51歳以上は2.0％のみ。step 3：職位は研修医（レジデント）54.0％、コンサルタント（専門医）22.5％、医務官（精神科専門研修を受けていない一般医）17.0％、レジストラー6.5％。step 4：勤務先は公立病院95.5％、担当する患者は郊外・農村が60.5％。step 5：経験年数5年未満が68.0％。各行にp値（0.001〜0.330）が付くが、何の検定かの説明がなく、「公立病院191人対その他9人」でp=0.330となるなど、数値として解釈できない点に注意。

### Table 2：信頼性分析（各領域の内的一貫性）

step 1：4つの領域それぞれで、質問項目が同じものを一貫して測れているかをクロンバックのα（アルファ係数：0〜1で、0.7以上ならおおむね良好とされる「質問同士のまとまり」の指標）で評価した。step 2：遠隔精神医療0.847、VR 0.866と高く、AI 0.756はまずまず、アプリ（MHA）は0.614とやや低い。step 3：各領域の「平均値」（遠隔精神医療58.18、AI 60.55など）も示されるが、何点満点の尺度か、どう合計したのかは記載がなく、意味づけができない。step 4：方法の章では「αは0.78〜0.87」と書かれており、この表の0.614・0.756と食い違っている。

### Table 3：4領域間の相関分析

step 1：4つの技術に対する回答スコアが互いに連動するかを相関係数（−1〜1、1に近いほど「一方が高い人はもう一方も高い」）で調べた。step 2：正規分布に従わない変数にはスピアマンのρ（順位にもとづく相関）、従う変数にはピアソンのr（通常の相関）を使い分けた。step 3：遠隔精神医療とAI 0.493、AIとアプリ0.497、遠隔精神医療とアプリ0.429、VRとの相関は0.293〜0.392で、すべてp<0.01の中程度の正の相関。step 4：「デジタル技術全般に前向きな人は、どの技術にも前向き」という傾向を示すが、著者らの「相乗的な可能性」という解釈は相関からは言えず、回答者の一般的な技術志向を反映しているだけとも考えられる。

### Table 4：自由記述の主題分析（障壁のテーマ）

step 1：「導入の課題」についての自由記述を、2人の独立した分析者がデータから帰納的にコード化し、主題（テーマ）にまとめた（反省的主題分析：分析者自身の立場を意識しながら意味のまとまりを見出す質的研究の手法）。step 2：分析者間の一致度はコーエンのκ（偶然の一致を除いた一致度）0.84と高い。step 3：テーマは「設備・資源の不足」44.5％、「教育・認知の不足」21.5％、「変化への抵抗」14.0％、「技術の複雑さ」9.0％、「守秘義務・倫理の懸念」6.5％、回答なし4.5％。step 4：合計がちょうど200人＝100％になるため、1人1テーマに振り分けたことになり、複数の障壁を挙げた回答をどう扱ったかは不明である。

### Table S1（補足）：遠隔精神医療の項目別回答

本文によれば、基本的に知っている68.5％、実際の応用を理解42.0％、正式な研修を受けていない67％、職場で関連会議がない47.5％。時間効率がよい72.5％、診療の選択肢として有効75.5％、大規模な遠隔精神医療センターとの連携に前向き79.0％、ECT（電気けいれん療法）の遠隔見学に前向き64.0％。一方で既存サービスへの統合には53.5％が反対し、賛成は37.0％だった。回帰分析では「研修を受けた人ほど応用を知る（β=0.408）」「国のデジタル基盤を評価する人ほど使う意欲が高い（β=0.657）」との関連が示された。

### Table S2（補足）：AIの項目別回答

本文によれば、精神医療でのAIの応用を知らない68.5％、所属施設でAI研修を受けていない60.5％（何らかの研修経験あり39.5％）。AIの有用性については中立46.5％、費用・時間節約の効果には77.5％が否定的、AIが従来の精神医療に取って代わることには53.5％が否定的。AIアルゴリズムの結果を理解できない63.5％。それでもAIと精神医療の共同開発には55.0％が関心を示し、臨床医とAIの間の信頼構築が重要とする人は43.5％だった。「知らないが、関わってはみたい」という姿勢がうかがえる。

### Table S3（補足）：メンタルヘルスアプリ（MHA）の項目別回答

本文によれば、臨床でのアプリ利用を知らない62.0％、臨床的な有用性に否定的40.5％、時間・費用の節約に「強く反対」53.0％。患者にどのアプリを勧めればよいか知っているのは30.0％、診療に取り入れる意欲は35.5％にとどまった。新しいアプリについて学ぶことには53.0％が関心を示したが、パキスタンの精神医療体制への統合が可能と考えるのは24.5％だった。考察では、アプリの多くが欧米のデータで作られ、現地の言語・文化に合わせていないことが受け入れの低さの一因と論じている。

### Table S4（補足）：VRの項目別回答

本文によれば、VRを知る32.5％、施設での研修経験25.0％、時間・費用を節約できると考える27.0％。デジタル基盤が不十分とする人は79.5％に達した。対面診療の代わりにはならないとする人51.0％、統合に反対37.5％。VRについて学ぶ意欲は55.5％と過半数にのぼる一方、実際に診療で使う意欲には85.0％が否定的で、ECTのVR見学にも40.5％が消極的だった。「興味はあるが、使える環境も準備もない」という、関心と実行可能性のギャップが最も大きい領域である。

## 3. 8項目評価

### ① 研究デザイン

KAP（知識・態度・実践）型の横断的質問紙調査に、自由記述の質的分析を組み合わせた混合研究法である。4種の技術を同じ枠組みで比べ、障壁を当事者の言葉で拾った点は、政策立案の基礎資料として合理的な設計といえる。問題点として、横断研究のため「研修を受けたから知識が増えた」などの因果関係は言えない。また公立病院のみが対象で、私立・軍病院の精神科医は含まれない。データ収集が2023年前半で、生成AIが急速に普及する前後の時期にあたり、AIに関する認識は公表時点（2026年）にはすでに変わっている可能性が高い。

### ② サンプルサイズと選択基準

全国の公立精神科医を約400人と見積もり、誤差5％・信頼度95％から必要数200人を算出し、ちょうど200人を集めた。ただし母集団400人は病院への聞き取りによる推定で、登録簿にもとづかない。便宜的サンプリング（ソーシャルメディアやボランティア経由）で、配布数・回答率が報告されておらず、デジタル技術に関心のある人ほど回答した可能性（自己選択バイアス）がある。39施設中18施設、バロチスタン州は1施設のみと地域の偏りもある。さらに除外基準で「精神科以外の医師」を除くとしながら、精神科研修を受けていない医務官（17％）を含めている点は選択基準と矛盾する。

### ③ 方法論の適切性

48項目の質問紙を専門家による内部検討、23人のパイロット調査、4人の外部専門家による内容妥当性確認で作成しており、手順は丁寧である。一方で、項目の全文、回答尺度（何段階のリッカート尺度か）、得点化の方法が本文に示されず、読者が再現・比較できない。質問紙は英語のみで、理解度に差が出た可能性を著者自身も認めている。質的分析のソフトウェアを「NVivo 15」と「Quirkos 3」の両方で記載しており、どちらを使ったのか不明確である。倫理声明では「出版への同意を得た」と「出版への同意は該当なし」が並んでおり、記載の精度にも疑問が残る。

### ④ 統計分析の妥当性

正規性をシャピロ・ウィルク検定で確認してスピアマン相関とピアソン相関を使い分け、多重共線性（説明変数同士が似すぎる問題）もVIFで確認するなど、手順自体は教科書的である。しかし問題が多い。「多重ロジスティック回帰」を行ったとしながら、結果はβ値とp値が3つ示されるのみで、目的変数、調整変数、オッズ比、信頼区間、モデルの適合度が一切ない。Table 1のp値は何の検定か不明で解釈不能である。KMOとバートレット検定で因子分析の適性を示しながら、実際の因子構造は報告されていない。内的一貫性の値も方法（0.78〜0.87）と結果（0.614〜0.866）で食い違う。

### ⑤ 結果の信頼性と再現性

最大の問題は、同じ項目の数値が要旨・結果・考察で食い違うことである。例：遠隔精神医療の研修を受けていない人が結果では67％（受けた人は33％）なのに考察では「受けたのは16.5％」、アプリを「知らない」62％に対し考察では「知っているのは4.0％」、AIの応用を「知らない」68.5％に対し考察では「知っているのは11.0％」、VRを使う意欲は「否定85.0％」と「準備ができている12.5％」が並ぶ。要旨の「68.5％が遠隔精神医療の応用を理解」も、結果では「基本的に知っている」の数値で、応用の理解は42.0％である。補足表を見ないと質問の違いか誤記かを判別できず、生データは「要請に応じて提供」にとどまるため、第三者による再現は難しい。

### ⑥ 結論の妥当性

「関心はあるが、知識・研修・インフラが不足している」という結論の大筋は、量的結果と自由記述の両方から支持されており妥当である。しかし要旨の「デジタル精神医学リテラシーを調べた初めての横断研究」という主張は、本文で引用されるパキスタンの先行調査（遠隔精神医療に関する精神科医調査、研修医のAI知識調査）を考えると言い過ぎの可能性がある。また、自己申告のみで実際の技能を測っていないため「能力の欠如」を断定することはできない。相関分析から「技術間の相乗効果」を読み取る解釈も、データの範囲を超えている。数値の不整合が多いため、個々の割合を政策判断の根拠とする際は慎重さが要る。

### ⑦ 新規性

遠隔精神医療、AI、アプリ、VRの4技術を一つの調査票で同時に扱い、パキスタンの公立病院精神科医を全州にまたがって調べた点は新しい。低中所得国の精神科医の「デジタル対応の準備状態」を、量的データと当事者の生の声（「Wi-Fiさえ贅沢」「停電が続く中でハイテクは非現実的」など）の両面から描いた点は、類似研究の少ない地域の記録として価値がある。ただし、手法そのものは既存のKAP調査の枠組みの踏襲であり、方法論的な新しさは乏しい。サウジアラビアやアジア太平洋地域の先行研究とほぼ同じ構図の結果で、知見の意外性は大きくない。

### ⑧ 臨床的意義

精神科医が極端に少ない国で、デジタル技術を導入する際に「技術を配れば使われる」わけではなく、電気・ネットワークといった基盤整備、研修カリキュラムへの組み込み、データ保護の法制度が前提になることを示した点は、実務的な示唆がある。日本の精神科臨床にとっても、オンライン診療やアプリ（治療用アプリ）の普及において、医師側の研修不足や守秘への不安が障壁になる構図は共通している。ただし、この研究は医師の意識調査であり、デジタル介入が患者の転帰を改善するかどうかは検証していない。数値の食い違いも多いため、具体的な割合を引用するよりは、障壁の種類を把握する資料として使うのが適切である。
