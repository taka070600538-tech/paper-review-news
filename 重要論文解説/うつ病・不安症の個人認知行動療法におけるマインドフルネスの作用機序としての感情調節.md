# うつ病・不安症の個人認知行動療法におけるマインドフルネスの作用機序としての感情調節 精読ノート

> 役割：日本トップクラスのサイエンスコミュニケーターとしての精読プロンプトに基づく分析結果

## 1. 概要（500字以内）

マインドフルネス（今この瞬間の体験に、評価を加えず注意を向ける心の構え）はうつ病や不安症に有効とされるが、なぜ効くのかは十分わかっていない。本研究はドイツの外来施設で個人認知行動療法（CBT）を受けた162名を対象に、治療前・第5回・第15回・第25回セッションの4時点で、マインドフルネス、6種類の感情調節方略、抑うつ（BDI-II）、不安（BAI）を測定し、多層構造方程式モデリングで媒介分析を行った。患者は各セッション冒頭に「5分間のマインドフルネス」「漸進的筋弛緩法」「導入なし」の3群へ無作為に割り付けられていた。その結果、個人内でマインドフルネスが高まると、**反すうの減少と、再評価・受容の増加を介して抑うつが軽減**し、**不安の軽減には回避の減少が媒介**していた。抑うつと不安では改善の経路が異なることが示唆される。一方、冒頭5分のマインドフルネスを加えてもこれらの経路は変わらず、問題解決がわずかに増えただけだった。**ただし媒介は同時点の変化どうしで推定されており、因果の順序は確定できない。**

### Figure 1：反すう・回避・抑制を媒介とした抑うつのモデル

「マインドフルネス→感情調節方略（a経路）→抑うつ（b経路）」を、上段が個人間（レベル2）、下段が個人内（レベル1）で示した図。個人内では、総効果 b = −11.52、直接効果 −10.10。反すうはa = −0.86、b = 1.26で**間接効果 −1.09（p = .002）が有意**。回避（間接効果 −0.06, p = .803）と抑制（−0.27, p = .142）は有意でない。個人間では反すう（間接効果 −2.81, p = .007）と抑制（−2.48, p = .011）が有意で、回避は有意でない。媒介は「部分媒介」であり、**総効果の大半（個人内で約88%）は直接効果として残っている**点に注意したい。

### Figure 2：再評価・受容・問題解決を媒介とした抑うつのモデル

個人内では総効果 −11.53、直接効果 −10.31。**再評価（a = 0.73, b = −1.00, 間接効果 −0.73, p = .028）と受容（a = 0.77, b = −0.90, 間接効果 −0.70, p = .035）が有意**で、問題解決（間接効果 0.21, p = .310）は有意でない。認知的再評価とは「状況の見方を変えて気持ちを変える」方略、受容とは「変えられない感情や状況をそのまま認める」方略である。個人間では再評価のみ有意（間接効果 −0.84, p = .036）、受容（−0.59, p = .120）と問題解決（0.19, p = .452）は有意でない。**本ノート作成時の照合では、個人間の直接効果（−10.45）と3つの間接効果の和が −11.69となり、図中の総効果 −15.37と一致しなかった。** 他の3図では和が総効果と一致するため、この図の個人間部分には数値の誤りがある可能性がある（テキスト抽出に基づく照合）。

### Figure 3：反すう・回避・抑制を媒介とした不安のモデル

個人内では総効果 −7.25、直接効果 −6.07。**回避のみが有意な媒介（a = −0.65, b = 0.91, 間接効果 −0.60, p = .045）**で、反すう（−0.66, p = .074）と抑制（0.07, p = .689）は有意でない。つまり治療中にマインドフルネスが高まった時期に「嫌な感情を避ける傾向」が弱まり、それが不安の軽減と連動していた。個人間では反すうが有意（間接効果 −3.05, p = .006）で、直接効果は −3.49（p = .100）と有意でなくなる。**本文では個人内の回避のb経路が「−0.91, 95% CI [0.10, 1.72]」と記載されているが、図では b = 0.91であり、本文の負号は誤植と考えられる。** また回避の間接効果のp = .045は境界的である。

### Figure 4：再評価・受容・問題解決を媒介とした不安のモデル

個人内では総効果 −7.25、直接効果 −5.96で、**再評価（間接効果 −0.61, p = .083）、受容（−0.57, p = .111）、問題解決（−0.11, p = .617）のいずれも有意な媒介ではなかった**。一方、個人間では受容が大きな間接効果（a = 0.79, b = −7.74, 間接効果 −6.12, p < .001）を示し、直接効果は −3.07（p = .205）と有意でなくなった。著者らはこれを「不安では受容は時期によって変動する状態というより、その人の特性（trait、持続的な傾向）として効いている」と解釈している。個人内と個人間で結果が逆転するこの図は、**「人と人の違い」と「同じ人の変化」を分けて考える必要性**をよく示している。

## 3. 8項目評価

> **注記**：本論文は、既存の無作為化比較試験（RCT）で収集された一次データを用いた原著研究（作用機序の二次解析）であるため、8項目評価は一次研究の基準をそのまま適用する。ただし、主たる媒介分析は「無作為化された介入」ではなく「治療中に自然に生じたマインドフルネスの変化」を予測変数としている点で、観察研究的な性格を持つことに留意して評価する。

### ① 研究デザイン

治療前・第5回・第15回・第25回の4時点を反復測定した縦断デザインは、横断研究しかなかった先行研究から一歩進んでいる。加えて、個人内と個人間の効果を分けて推定できる設計は、心理療法の作用機序研究として適切である。**しかし重大な限界がある。** 第一に、媒介分析の予測変数である「マインドフルネスの変化」は無作為に操作されたものではなく、治療中に自然に生じた変化であるため、因果推論はRCTの強みを引き継いでいない。第二に、**マインドフルネス・感情調節・症状は同じ時点で同時に測定され、同時点の変化どうしで媒介を推定している**（時間差をつけたラグモデルではない）。そのため「マインドフルネスが先に上がり→感情調節が変わり→症状が下がる」という時間的順序は検証されておらず、症状の改善がマインドフルネスや感情調節を高めたという逆方向の説明も排除できない。著者ら自身も、未測定の交絡がないという媒介分析の前提を限界として挙げている。

### ② サンプルサイズと選択基準

162名（3群×54名）、4時点で648観測という規模は、臨床サンプルの縦断媒介研究としては中規模である。選択基準は18〜65歳でSCID-5（構造化面接）によりうつ病性障害または不安症と診断された者と広く、評定者間一致率もκ = 0.93と高い。実臨床に近い患者像で、外的妥当性に配慮している。**問題点として、サンプルサイズの根拠となった検出力分析は元のRCTの主要アウトカム（小さな効果、Cohen's f = 0.12）に対するものであり、本研究の多層媒介分析や「群による媒介効果の違い」を検出するために設計されたものではない。** 群間で経路が変わらなかったという結論は、検出力不足の可能性を残す。また、脱落や欠測の状況・扱いが本論文では記述されておらず（フロー図は先行論文に委ねられている）、648がちょうど162×4であることの意味（欠測がなかったのか、補完したのか）が不明である。併存症（43.8%）や薬物療法（47.5%）の多さも解釈を複雑にするが、薬物療法は共変量として検討されていない。

### ③ 方法論の適切性

測定には、マインドフルネスにKIMS（39項目）、感情調節にHFERST（28項目、6方略）、症状にBDI-IIとBAIという妥当性が確立した尺度を用い、本サンプルでの内的一貫性（α）も0.79〜0.95と良好で、報告も丁寧である。介入条件は音声で標準化され、アドヒアランスも高いとされる。**一方で、すべての指標が自己記入式であり、共通方法分散（同じ人が同じ形式で答えることで相関が膨らむ現象）の影響を受ける。** 著者らも、メタ認知的な状態を自己報告で正確に捉えられるかに限界があると認めている。また**対照群（TAU、TAU+PMR）でも治療者はマインドフルネス技法を自由に取り入れることができ、その使用は測定されていない**ため、群間差が出にくい構造になっている。さらに「冒頭5分」という介入量はきわめて小さく、「マインドフルネスを加えても機序は変わらない」という結論を、本格的なマインドフルネス介入にまで一般化することはできない。

### ④ 統計分析の妥当性

多層構造方程式モデリング（lavaan）、ロバスト最尤推定、個人内・個人間の分離、適合度指標（RMSEA ≤ 0.044、CFI ≥ 0.990など）の報告、成長モデルでの時間効果の検討、効果量と信頼区間の提示は、いずれも現代的で妥当である。**しかし問題点も多い。** 第一に、**2アウトカム×2レベル×6方略という多数の間接効果を検定しながら多重比較の補正がなく**、有意とされた間接効果の多くがp = .028〜.045と境界的である（不安の回避p = .045、抑うつの受容p = .035など）。第二に、6方略を「減るはずの3方略」「増えるはずの3方略」の2モデルに分けて推定しており、6方略を同時に投入した場合に各媒介が独立に残るかはわからない。第三に、報告上の不整合がある——本文の方法で**間接効果を「c経路とb経路の積」と書いているが、正しくはa経路とb経路の積**である。回避のb経路の負号の誤植、Figure 2個人間での効果の和の不一致、Table 3の信頼区間と有意記号の食い違い、補足表S7の一覧漏れも、査読・校正の甘さを示す。

### ⑤ 結果の信頼性と再現性

抑うつにおける反すうの媒介は、個人内（p = .002）と個人間（p = .007）の両方で一貫して有意であり、先行研究とも整合するため、本研究でもっとも信頼できる知見である。**一方、再評価・受容（抑うつ）や回避（不安）の個人内媒介は境界的なp値で、1回の研究では偶然の可能性を否定しきれない。** 媒介の割合も小さく、総効果の大部分は直接効果として残っている。つまり「感情調節で説明できる部分」は限定的である。再現性の面では、データはOpen Science Framework（osf.io/syk25）経由で、データ共有契約を結べば入手可能とされ、一定の透明性がある。ただし補足表は本PDFに含まれず、解析コードの公開への言及もない。ドイツの単一外来施設のデータであることも、一般化の制約として著者自身が挙げている。

### ⑥ 結論の妥当性

「感情調節方略がマインドフルネスと症状変化の媒介として働き、抑うつと不安では異なる経路がある」という結論は、データの向きとは整合する。著者らが限界の節で「縦断的媒介が示されても、因果的な変化の機序とは言い切れない」と明言している点は誠実である。**しかし抄録や考察では「reductions in avoidance explained the association」「changes in emotion regulation strategies are not just consequential but are mediating」など、同時点測定のデータが支えられる以上に機序的・因果的な言い回しが用いられている。** また「マインドフルネス介入を加えても経路は変わらなかった」という点は、介入量の小ささ、対照群への技法の混入、検出力不足を考えると、「差を検出できなかった」と控えめに述べるべきである。抑うつでは受容が個人内で、不安では個人間で効くという「状態と特性」の解釈も、事後的な説明の域を出ない。

### ⑦ 新規性

マインドフルネスと感情調節の関連は横断研究や非臨床サンプルで多数報告されてきたが、**臨床サンプルの個人CBTという実臨床の文脈で、4時点の縦断データを多層媒介モデルで解析し、個人内と個人間を分けて検討した**点は新しい。多くの先行研究がMBCTやMBSRなどマニュアル化された集団プログラムを対象としていたのに対し、個人精神療法の中でマインドフルネスがどう働くかを扱った点にも価値がある。さらに、抑うつ（反すう・再評価・受容）と不安（回避）で経路が分かれるという差別化は、臨床的に示唆に富む。**ただし、反すうが抑うつの媒介になることや回避が不安に関わることは既に理論・実証の蓄積があり、個々の知見そのものは予想の範囲内である。** 元のRCT（Mander et al., 2019）の二次解析であり、新たなデータ収集ではない点も踏まえる必要がある。

### ⑧ 臨床的意義

精神科医・CBT実践者にとっての示唆は明快である。**うつ病の患者では反すうを減らし、再評価や受容を育てること、不安症の患者では体験の回避を減らすことが、マインドフルネスの効果を症状改善につなぐ鍵になりうる**。症状ごとに「どの感情調節方略を標的にするか」を意識した個別化（プロセスに基づく治療）の根拠の一つとなる。また、明示的なマインドフルネス介入がなくても、通常のCBT全体でマインドフルネスが中程度に向上し（d = 0.61）、BDI-IIが約10点低下したことは、標準的CBTの多面的な効果を示す。**一方で、セッション冒頭に5分のマインドフルネスを入れる実践は、機序の面で追加の利益がほとんど示されなかった**ため、「とりあえず冒頭に呼吸法を入れる」ことの効果を過大視すべきではない。媒介の割合が小さく因果の向きも未確定なため、本研究だけで治療方針を大きく変えることは推奨できない。なお最終著者（JM）はマインドフルネス関連書籍の印税とワークショップ謝礼を受けていることが開示されている。

## 4. 整合性の最終チェック
