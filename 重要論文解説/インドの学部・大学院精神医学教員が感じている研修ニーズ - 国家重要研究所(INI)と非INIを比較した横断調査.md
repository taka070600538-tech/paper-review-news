# インドの学部・大学院精神医学教員が感じている研修ニーズ - 国家重要研究所(INI)と非INIを比較した横断調査 精読ノート

> [!info] この論文について
> インドで医学生(学部、UG)と精神科専攻医(大学院、PG)に精神医学を教えている教員とシニアレジデント214人に、オンラインで「教え方の研修が必要か」「国の新カリキュラムに沿って教えているか」「どんな教え方をしているか」を尋ねた調査。国が特別な自治権を与えた国家重要研究所(INI、AIIMS など)と、それ以外の医科大学(非INI)を比べている。治療や病態の研究ではなく、精神医学「教育」の実態調査である。

## 1. 概要(500字以内)

インドでは国家医学委員会(NMC)が、知識・技能・態度を段階的に評価するコンピテンシー基盤型医学教育(CBME:到達目標の「できること」を軸に組んだ教育課程)を導入した。一方、AIIMS などの国家重要研究所(INI)は独自の法律で運営され、CBME に従う義務がない。著者らは2025年7〜12月、全国の精神医学教員にGoogleフォームの調査票を配り、招待635人中214人(回答率33.7%)から回答を得た。INI所属は128人(59.8%)、シニアレジデント(専門医取得後の若手指導医)が47%を占めた。UG教育で83%、PG教育で82%が「教え方の研修が必要」と答えた。NMCカリキュラムを厳格に守っていると答えたのはUG担当の64%、PG担当の54%。医学教育の正式な研修を受けたのは全体の33%で、教員(65.4%)とシニアレジデント(12.8%)の差が大きかった。INIと非INIの差は「PGを教えているか」(非INI 93%対INI 66%)以外に見られなかった。著者らは、両方の施設で、特にシニアレジデント向けの体系的な教員研修が必要だと結論している。

## 2. Figure と Table の解説

本論文に Figure(図)は無く、本文の Table 1〜3 と補足資料の Supplementary Table 1〜4、計7つの表がある(補足資料には調査票そのものも載っているが、表ではないので末尾で触れる)。

### Table 1 回答者の基本属性(n=214)

回答者の平均年齢は35.7歳(標準偏差7.3)、精神医学の教育歴の中央値は4年(四分位範囲 2〜8.15年。中央値=真ん中の人の値、四分位範囲=真ん中半分の人が収まる幅)。シニアレジデント101人(47.2%)、助教以上の教員113人(52.8%)。最高学位は MD/DNB/DPM(インドの精神科専門資格)が80.4%、さらに上の亜専門資格 DM が13.1%。INI勤務は128人(59.8%)。UGを教えている人は157人(73.4%)、PGを教えている人は165人(77.1%)。若く、教育経験の浅い層が中心の標本であることがわかる。

### Table 2 全回答の記述集計(n=214)

UG教育の研修が必要と答えたのは131人(83.4%)、PG教育では135人(81.8%)。NMCカリキュラムを「厳格に守っている」に同意したのはUG担当で100人(63.7%)、PG担当で89人(53.9%)。教員になってから医学教育の正式な研修を受けたのは71人(33.2%)で、その内訳は基礎コース(BCME、昇進要件にもなっているNMCの必修研修)が58.6%、上級コース(ACME)が4.3%。研修したい領域は「理論と臨床の両方」が66.4%。研修への関心は76.2%、日程の希望は週末のまとまった枠が27.8%で最多、費用を自己負担してよいは45.3%。

### Table 3 INIと非INIの比較(カイ二乗検定)

カイ二乗検定(χ²:2つの集団で回答の分布が偶然以上に違うかを調べる方法)で比較した。有意差があったのは「PGを教えている」だけで、INI 66.4%に対し非INI 93.0%(χ²=20.642、P<0.001)。職位構成、UG担当の割合、NMC遵守、研修ニーズ、受講歴(INI 42.2%、非INI 38.4%)、研修への関心、形式(ハイブリッドかオンラインか)、日程、時間、自己負担の意思には差がなかった。著者らは、多くの非INIは昔からPG課程を持つ一方、新しいINIは2012年以降に本格稼働したためと説明している。なお表中の割合はグループ全体(128人、86人)を分母にしており、Table 2 の割合とは分母が違う。

### Supplementary Table 1 回答者の地域分布

回答者の州・連邦直轄地の内訳。デリー首都圏が82人(38.3%)と突出し、次いでウッタル・プラデーシュ州18人(8.4%)、タミル・ナードゥ州9人(4.2%)と続く。25の州・地域から回答があったが、多くは数人以下で、州を書かなかった人も16人(7.5%)いた。著者らの多くがデリーの施設に所属し、デリー精神医学会を通じて配布したことと整合する偏りで、「全国調査」と言っても実態はデリー中心の標本であることを示す重要な表である。

### Supplementary Table 2 シニアレジデントと教員の比較

教育歴はレジデント2.4年、教員10.15年(t検定、P<0.001)。UGを教えている割合は教員81.4%、レジデント64.3%(P<0.005)。最大の差は医学教育の受講歴で、教員74人(65.4%)に対しレジデント13人(12.8%)(χ²=61.195、P<0.001)。日程の希望(教員は丸1日の枠を好む、24.8%対6.9%、P=0.010)と自己負担の意思(教員53.1%対レジデント36.6%、P=0.023)にも差があった。研修ニーズやNMC遵守、研修への関心には差がなかった。

### Supplementary Table 3 PG教育で使っている教え方(職位別)

PGで最も使われていたのは症例基盤型学習(CBL:実際の症例を題材に考える学習、74.3%)、セミナー・シンポジウム(72.9%)、ジャーナルクラブ(論文を批判的に読み合う会、70.6%)。教員の方が有意に多く使っていたのは、セミナー、ジャーナルクラブ、ロールプレイ(19.8%対36.3%)、対話型の教え方、多職種セミナー(26.7%対49.6%)などで、CBL も P=0.021 と報告されている。模擬患者(18.2%)や客観的臨床能力試験(OSCE:標準化した場面で臨床技能を評価する試験、34.1%)は少なかった。

### Supplementary Table 4 UG教育で使っている教え方(職位別)

UGでは講義(61.2%)、症例基盤型学習(54.2%)、少人数討論(50.0%)が上位で、PGに比べて講義中心である。教員はレジデントより講義(74.3%対46.5%、P=0.002)とブレンド学習(対面とオンラインの組み合わせ、14.2%対4.0%、P=0.038)を多く使うと報告されている。ジャーナルクラブ(9.3%)、ブレンド学習(9.3%)、模擬患者(11.2%)はまれだった。CBME が重んじる実技的な教え方がUGではまだ少ないことがうかがえる。

### 補足資料:調査票(Googleフォーム全26問)

補足資料には調査票が丸ごと載っている。同意、年齢、職位、勤務先、学位、教育歴のあと、UG担当者向けの問(NMC遵守の5段階評価、使っている教え方12種類、研修の必要性、自由記述)、PG担当者向けの同様の問、全員向けの問(受講歴、研修の形式・時間・日程・自己負担、自由記述)と続く。最初の問でメールアドレスを必須にしている点、自由記述3問(研修したい具体的な領域など)の結果が本文に全く報告されていない点は、評価で触れる。

## 3. 8項目の評価

### ① 研究デザイン

横断的なオンライン質問紙調査で、CHERRIES(ネット調査の報告指針)に沿って報告しており、倫理審査・電子同意・重複回答の防止(1人1回答の設定)も明記されている。「感じているニーズ」を広く把握する目的には合った設計である。問題点は、自己申告だけに頼っていること。「NMCカリキュラムを厳格に守っている」は実際の授業を観察したものではなく、社会的に望ましい答えに寄りやすい。また比較の主軸であるINI対非INIは、施設の歴史・規模・所在地(デリー集中)と重なっており、施設の種類そのものの違いを切り分けられない。

### ② サンプルサイズと選択基準

対象は過去6か月以上UGかPGを教えている教員とシニアレジデントで、明確である。ただ、事前の標本数計算は無い。インドには約6000人の精神医学教員がいると本文で述べながら、回答は214人(約3.6%)にとどまる。さらに回答率33.7%の分母「招待した635人」が、一斉メール・WhatsApp・個人的な連絡で広めた方法とどう対応するのか説明がなく、実際に届いた人数は不明である。INIが6割、デリー首都圏が38%と大きく偏り、私立医科大学の割合も示されていないため、全国の代表標本とは言えない。著者らも限界として認めている。

### ③ 方法論の適切性

調査票は4部構成で、選択式・5段階評価・自由記述を組み合わせ、経験豊富な精神科医による表面妥当性(質問が見た目に妥当かの確認)を得たとされる。しかし予備調査、信頼性(同じ人が答え直して同じ結果になるか)、内容妥当性の体系的な検討は報告がない。「研修が必要か」の問いは「何の研修か」を決めずに尋ねており、回答の意味が人により違い得る。自由記述3問は分析されず、本来もっとも具体的な「ニーズ」の中身が失われている。メールアドレスを必須にしたため匿名性が弱まり、正直な回答を妨げた可能性もある。

### ④ 統計分析の妥当性

SPSSで記述統計とカイ二乗検定・t検定を行った単純な分析で、多重比較の補正(多数の検定で偶然の有意差が出るのを防ぐ調整)も、職位や施設を同時に考慮する多変量解析も無い。さらに表の数値に不整合が目立つ。Table 3 のPGのNMC遵守は χ²=0.760、自由度2なら P≈0.68 のはずが 0.963 と記載。Supplementary Table 3 では CBL の割合がほぼ同じ(75.2%対73.5%)なのに P=0.021、Supplementary Table 4 では差のある CBL(47.5%対60.2%)で χ²=0.000 と、表の割合と検定統計量が対応していない。受講歴も Table 2 は71人、Table 3 と Supplementary Table 2 は87人で食い違う。

### ⑤ 結果の信頼性と再現性

研修ニーズ約8割、受講歴約3割という主要な数字は、カルナータカ州の先行調査(87%)やINI対象の Pal らの調査(UG 92%、PG 69%、受講歴38%)と近く、方向性は一貫している。ただし著者の一部は両先行研究の著者でもあり、同じネットワーク・同じ調査票の系統で集めた結果が似るのは当然とも言える。④で述べた数値の不一致(本文の「83.5%(n=113)」と Table 2 の「131人(83.4%)」、UGの研修ニーズ回答の合計154人が UG担当157人と合わない等)があり、再分析しないと結果をそのまま信頼しにくい。データは合理的な求めがあれば提供するとされ、再検証の道は残っている。

### ⑥ 結論の妥当性

「INIと非INIの双方に体系的な教員研修の未充足のニーズがある」「特にシニアレジデント向けの研修が必要」という結論は、記述統計の範囲では支持される。受講歴の教員65%対レジデント13%は、検定の細かな問題を差し引いても大きな差である。一方、「研修への参加意欲はあるのに実際の参加は限られている」「その理由は保護された時間の欠如など」という考察は、本調査で測っていない推測である。また NMC 遵守率が6割前後なのに「CBME を実施しても研修ニーズは消えない」と因果を示唆するのは言い過ぎで、両者の関連は解析されていない。INIと州レベルの協働の提案も、データから直接導かれたものではない。

### ⑦ 新規性

先行研究は一つの州(カルナータカ)か INI だけに限られ、多くは教員だけを対象にしていた。本研究は INI と非INIを並べて比べ、教育の現場で大きな役割を担うシニアレジデントを含めた点が新しい。教員とレジデントで受講歴に大きな差があるという知見は、インドの精神医学教育でまだ十分に示されていなかった。ただし質問項目は Pal ら(2024)の調査とほぼ同じ枠組みで、方法の新しさは乏しく、「施設の種類で差がない」という主な比較結果も、目新しい発見というよりは確認にとどまる。

### ⑧ 臨床的意義

直接の臨床研究ではないが、インドでは精神科医が少なく、一般医や若手医師の精神医学教育の質が、治療の空白を埋めるうえで重要になる。その教育を担う人のうち、半数近くを占めるシニアレジデントが教え方の研修をほとんど受けていない、という指摘は、医学教育政策にとって実用的な意味がある。4〜8時間程度の短い、週末やオンラインでも受けられる研修が好まれるという結果も、研修設計の参考になる。ただし、研修を受けた教員が教えると学生の能力や患者の転帰が良くなるかは示されておらず、日本など制度の違う国にそのまま当てはめることはできない。
