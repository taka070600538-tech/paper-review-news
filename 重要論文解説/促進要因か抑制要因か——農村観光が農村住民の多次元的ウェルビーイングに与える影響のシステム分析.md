# 促進要因か抑制要因か——農村観光が農村住民の多次元的ウェルビーイングに与える影響のシステム分析 精読ノート

## 1. 概要

中国では「農村振興戦略」のもとで、農村観光（農家民宿、農業体験、景観観光など）が国策として推し進められています。しかし、観光開発は環境への負担や利益の偏りを生むこともあります。本当に村人を幸せにしているのでしょうか。本研究は、中国社会科学院の全国調査「中国農村振興調査（CRRS）2020」を使い、10省・300村・約15,000人のデータで「村に農村観光があるか」と住民のウェルビーイングの関係を分析しました。

ウェルビーイングは2つに分けて測っています。「物質的ウェルビーイング」は、所得・健康・教育・年金加入・就労の5項目のうち、いくつ満たしているか（0〜5点）です。「精神的ウェルビーイング」は、生活満足度（1〜5点）です。

分析の結果、観光のある村では、物質面で最上位になる確率が7%、生活に「とても満足」する確率が5.3%高くなっていました。この関係は、操作変数法や傾向スコアマッチング（似た条件の村どうしを比べる手法）でも確かめられています。効果は、東部地域、丘陵地、党書記と村長を1人が兼ねる村、学歴の低い人、40歳以上の人で大きくみられました。

仕組み（媒介経路）としては、融資・電子商取引、非農業就労・技能研修、ごみ処理・トイレ整備、村民会議・WeChatでの交流が挙げられています。一方、住宅・所得・治安の満足度は改善せず、観光には「抑制要因」の側面もあると結論づけています。

ただし、この研究は2020年の1時点のデータで因果関係を推定しています。また、表の重複や本文と表の食い違いが複数あり、数値の読み取りには注意が必要です。

## 2. FigureとTableの解説

本文には**Figure 1点**、**Table 13点（Table 1〜13）**があります。以下、専門用語はかっこ内で言い換えます。

### Figure 1：概念的枠組み

左の「農村観光」から4つの経路を通って、右の「ウェルビーイング（物質的・精神的）」につながる図です。
- ①**デジタル金融の推進**（借入制約、電子商取引の発展）
- ②**エンパワーメント改革**（非農業就労、技能研修）
- ③**要素の再編**（インフラ整備、生態環境）
- ④**ガバナンスのてこ**（村民会議、住民参加）

矢印にはすべて「＋」が付いていて、正の効果を想定しています。**注意点**：タイトルは「促進要因か抑制要因か」なのに、この図には抑制の経路（資源の奪い合い、統治の遅れ）が描かれていません。

### Table 1：ウェルビーイングの次元・指標・基準値

物質的ウェルビーイングの5つの指標は、それぞれ条件を満たせば1点です。
- **所得**：世帯1人あたりの所得がサンプルの中央値の50%を超える。平均0.721。
- **健康**：慢性疾患がない。平均0.617。
- **教育**：教育年数が9年以上。平均0.580。
- **年金加入**：何らかの年金保険に加入している。平均0.816。
- **就労**：現在働いている。平均0.908。

精神的ウェルビーイングは、「今の生活にどのくらい満足していますか」の1〜5点で、平均は4.056点です。脚注によると、中国の新型農村年金には「高齢の親が年金を受け取るには、成人した子ども全員が加入していなければならない」という家族単位の仕組みがあります。物質面の5項目は、アルカイア＝フォスター法（多次元的な貧困を測る代表的な手法）で、各項目を同じ重みとして合計しています。

### Table 2：記述統計

物質的ウェルビーイングは7,435人分（平均3.729点）、精神的ウェルビーイングは14,993人分（平均4.056点）です。対象者の平均年齢は40.3歳（0〜103歳）で、男性51.3%、既婚65.4%、漢族86.3%、共産党員10.2%、世帯人数は平均4.65人です。過去3年間に自然災害を受けた村が55.3%、郷の役所までの距離は平均5.5km、工業汚染のある村が9%、集団資産の財産権改革を行った村が63.1%でした。**注意点**：年齢が0歳から含まれています。子どもの「生活満足度」や「就労」をどう扱ったのかは説明されていません。

### Table 3：ベースライン推定結果

順序プロビット・モデル（順位のついた結果を分析する手法）と、OLS（通常の重回帰）の8つのモデルです。県の固定効果（県ごとの違いを取り除く処理）を入れたモデルで、観光の係数は、物質面で0.070（p<0.05）、精神面で0.053（p<0.05）でした。OLSでは0.055（p<0.1）と0.037（p<0.05）です。

共変量（一緒に調整した要因）を見ると、年齢と生活満足度はU字型の関係でした。共産党員であることは両面で強くプラス（物質0.391、精神0.169）、高齢者との同居は物質面でマイナス（−0.231）です。**注意点**：本文では「Table 2で示した」と書かれていますが、実際はTable 3です（表番号の誤り）。

### Table 4：頑健性チェック

分析方法を変えても結果が変わらないかを確かめています。ウェルビーイングを「5項目中4項目以上なら1」という二値にした場合（0.118）、順序ロジット・モデルに変えた場合（0.129）、寧夏回族自治区を除いた場合（0.107）、非農家を除いた場合（0.065）です。いずれも観光の係数はプラスでした。**注意点**：かっこ内の数値が標準誤差ではなく、p値のように見えます（例：0.065のかっこ内が0.069で、星印は10%水準）。また、精神面の観測数が15,109で、全サンプル15,108を超えています。

### Table 5：操作変数法（IV）による内生性の検討

「観光のある村の人が幸せ」なのか、「幸せな村だから観光が発達した」のか、という逆の因果関係に対処するため、操作変数（結果には直接影響せず、原因にだけ影響する変数）を使っています。操作変数は、「同じ省内で1人あたりGDPが近い隣接3都市の農村観光シェアの平均」です。

第1段階の係数は0.743〜0.779（p<0.001）、第2段階の観光の効果は、物質面0.178、精神面（1〜5点）0.295、精神面（0/1）0.752でした。F値は39.00（10を超えるので弱い操作変数ではない）、Waldは51.96です。**注意点**：隣の都市の観光が、地域の経済圏や交通網を通じて、観光以外の経路からも住民の幸福に影響する可能性（除外制約の違反）は否定しきれません。

### Table 6：傾向スコアマッチング（PSM）の結果

本文では、6種類のマッチング手法（1対1、k近傍、半径、カーネル、局所回帰、マハラノビス距離）で、観光の効果（ATT：観光のある村の住民への平均効果）が物質面0.054〜0.075、精神面0.074〜0.093と述べています。**重大な問題点**：ところが、掲載されているTable 6の中身は、学歴別・年齢別の結果で、**Table 7と一字一句同じ**です。PSMの結果表そのものが載っておらず、本文の数値を表で確かめることができません。

### Table 7：人的資本と世代による違い

学歴が低い人では、物質面0.073（p<0.1）、精神面0.074（p<0.05）で効果がありましたが、学歴が高い人では有意ではありませんでした。年齢で分けると、40歳以上で物質面0.098、精神面0.076（いずれもp<0.05）と有意、40歳未満では有意ではありませんでした。著者らは、資源が少ない人ほど観光から得るものが大きく、高齢者はコミュニティとのつながりを通じて恩恵を受ける、と解釈しています。

### Table 8：村の特徴による違い

丘陵地の村では、物質面0.204、精神面0.149と有意でしたが、丘陵地以外では0.023で有意ではありませんでした。党書記と村長の兼任がある村では、物質面0.169、精神面0.172（p<0.001）と有意で、兼任していない村では有意ではありませんでした。**注意点**：結論の節では「丘陵地は山地・半山地より効果が大きい」と書かれていますが、実際の比較は「丘陵地とそれ以外」です。また、兼任の有無は村の統治能力や党の資源とも関連している可能性があります（交絡）。

### Table 9：地域による違い

東部では物質面0.140、精神面0.273（p<0.01）と有意でした。中部では物質面0.234（p<0.001）が有意、精神面は−0.017で有意ではありませんでした。西部はどちらも有意ではありませんでした。**問題点**：本文では「中部は農業中心の経済で、労働力や土地の奪い合いが起き、ウェルビーイングの向上は見られなかった」と書かれています。しかし表では、中部の物質面は東部より大きな効果（0.234）が有意に出ており、本文と表が食い違っています。

### Table 10：媒介変数への観光の効果（仕組みの検証 第1段階）

観光があると、次の8つの媒介変数がすべて有意に改善していました。借入制約の緩和0.087、電子商取引0.608、非農業就労0.113、技能研修0.175、村民会議0.088、住民参加0.089、ごみ処理0.280、トイレ整備0.095です。**注意点**：3章では、インフラの指標を「下水道管」、環境の指標を「農業用フィルム・農薬容器の回収所」と定義していますが、表では「ごみ処理」「トイレ整備」に変わっています。また、表の見出しでは、「要素の再編」の列に村民会議と住民参加が、「ガバナンス」の列にごみとトイレが置かれ、入れ替わっています。

### Table 11・12：媒介変数と物質的・精神的ウェルビーイングの関係（第2段階）

8つの媒介変数は、いずれも物質面（非農業就労0.321、技能研修0.302、住民参加0.270など）とも、精神面（ごみ処理0.324、技能研修0.252、トイレ0.212など）とも、有意なプラスの関係がありました。著者らはこれをもって仮説2（4経路による媒介）が確かめられたとしています。**注意点**：これは「観光→媒介」と「媒介→幸福」を別々に回帰しただけです（逐次的な手法）。媒介効果の大きさ（間接効果）の推定や、ブートストラップ検定（データを何度も再抽出して誤差を見積もる方法）は行われていません。媒介変数と幸福の間にも交絡があり得るので、因果的な媒介の証拠としては弱いです。

### Table 13：多次元の満足度

観光があると、道路の満足度0.226、生活環境0.116、村委員会の仕事ぶり0.101が有意にプラスでした。一方、住宅は−0.073（p<0.05）、所得は−0.071（p<0.05）、治安は−0.066（有意でない）でした。**重大な問題点**：本文では「住宅・所得・治安の満足度は統計的に有意ではない」と書かれています。しかし表では、住宅と所得が**有意なマイナス**になっています。つまり、観光は住宅と所得の満足度を「改善しない」のではなく、「下げている」可能性があります。これは著者らの「抑制要因」仮説をむしろ強く支持する結果で、本文の記述が表を過小に伝えています。さらに、「観光の発展の可能性が1%上がると道路満足度が22.6%上がる」という言い方は、二値変数（観光あり/なし）の係数の解釈として誤っています。

## 3. 8項目評価

**①研究デザイン**
全国規模の横断調査（1時点のデータ）の二次分析です。「村に観光があるか」を処理変数（原因側の変数）とし、県の固定効果、操作変数法、傾向スコアマッチングを組み合わせて、因果関係に近づこうとしています。観察研究としては手堅い道具立てです。しかし、2020年の1時点だけのデータ（しかもコロナ禍で観光が落ち込んだ年）なので、観光が始まる前と後の変化は追えません。村単位の処理変数を個人単位で分析しているため、同じ村の住民どうしの相関（クラスタリング）を補正したかどうかも明記されていません。

**②サンプルサイズと選択基準**
10省・50県・156郷・300村・3,800世帯以上・15,000人以上を、多段階の層別無作為抽出で集めた、大規模で代表性の高いデータです。一方で、分析に使われた人数はモデルごとに大きく異なります（物質面7,280人、精神面14,695人）。物質面では約半数が欠けていますが、欠損の理由とそれによる偏りは検討されていません。年齢0歳から含まれていて、子どもの生活満足度をどう扱ったのかも不明です。欠損値の処理は、単純に除外する方法（リストワイズ除外）だけです。

**③方法論の適切性**
物質面の指標をアルカイア＝フォスター法で等しい重みで合計することや、順序プロビットとOLSを並べて示すことは、この分野で標準的なやり方です。しかし、精神的ウェルビーイングを生活満足度1問だけで測っている点は、タイトルの「多次元的ウェルビーイング」と比べて貧弱です。心理的ウェルビーイング（人生の意味、自律性など）や、抑うつ・不安といった精神的健康の指標は含まれていません。媒介変数の定義が3章と表とで変わっていることも、事前に計画した分析かどうかを疑わせます。

**④統計分析の妥当性**
操作変数のF値は39で、「弱い操作変数」の問題はありません。しかし、除外制約（隣の都市の観光が、観光以外の経路で住民の幸福に影響しないこと）は説明で主張されているだけで、検定されていません。媒介分析は係数の符号を並べる古典的な逐次法で、間接効果の推定がありません。Table 4のかっこ内の数値はp値のように見え、標準誤差のクラスタリングの有無も不明です。サブグループ間の差（たとえば丘陵地とそれ以外）を直接比べる交互作用の検定も行われていません。

**⑤結果の信頼性と再現性**
表の不備が多く、信頼性に深刻な疑問があります。
- Table 6（PSM）とTable 7（人的資本と世代）が完全に同じ内容
- Table 9の中部の物質面（0.234***）と、本文の「向上なし」が食い違う
- Table 13の住宅・所得（有意なマイナス）と、本文の「有意でない」が食い違う
- 本文で表番号を取り違えている（Table 2とTable 3）
- 観測数がサンプル全体を超えている

データは申請すれば入手できるとされていますが、公開はされておらず、第三者がすぐに再現することはできません。

**⑥結論の妥当性**
「農村観光は物質的・精神的ウェルビーイングを高める」という主な結論は、複数の手法で一貫しており、ある程度支持されます。ただし、効果の大きさは小さく（最上位カテゴリーに入る確率が5〜7%上がる程度）、横断データでは逆の因果関係や、村ごとの観測されない違いを完全には除けません。一方、「抑制要因」の側面について、本文は「有意でない」と控えめに書いていますが、実際の表はより強い負の効果を示しています。政策提言の中の「党書記と村長の兼任を制度として推進する」は、交絡の可能性がある異質性分析の結果から導いたもので、踏み込みすぎです。

**⑦新規性**
大規模な全国データで、観光に直接関わらない住民も含めた「波及効果」を分析した点は、観光地の事業者だけを対象にした先行研究を補うものです。デジタル金融（融資の枠、電子商取引）を媒介経路として組み込んだ点も新しいといえます。ただし、内生的発展論・社会生態システム論・複雑適応系・エンパワーメント論・新制度派経済学と多くの理論を並べているわりに、実証的な検証はどれも同じ形の回帰分析です。理論が上乗せされているだけで、中身と十分にかみ合っていません。

**⑧臨床的意義**
精神医学や臨床心理学との直接の接点はほとんどありません。精神的ウェルビーイングは生活満足度1問のみで、抑うつや不安などの精神的健康の指標は扱われていません。それでも、ウェルビーイング研究の視点からは、次の3点が参考になります。
- 地域の開発は、住民全員に同じように幸福をもたらすわけではありません（高齢者や学歴の低い人に効きやすい一方、住宅や所得の満足度は下がり得る）。
- 共産党員であることや高齢者との同居（介護の負担）が、ウェルビーイングの強い予測因子になっています。
- 生活満足度が年齢とU字型の関係にあることは、先進国のデータとも一致しています。

地域精神保健や社会的処方（医療が趣味・地域活動などの社会資源につなぐ取り組み）を考えるうえでの背景知識にとどまります。
