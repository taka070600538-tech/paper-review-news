# 出産恐怖症へのデジタル介入——エジプトの妊婦の出産恐怖と自己効力感に対するインターネット認知行動療法のランダム化比較試験 精読ノート

> [!info] 論文の性質
> エジプト・ダマンフールの妊婦96名を、WhatsAppで配信する6週間のインターネット認知行動療法(ICBT)群と通常の妊婦健診のみの群に**ランダムに振り分けた臨床試験(RCT)**です。評価は介入前(T1)と6週後(T2)の2時点だけで、出産そのものの転帰(帝王切開率など)は測っていません。

## 1. 概要

出産への強い恐怖(トコフォビア)は妊婦の最大14%にみられ、医学的理由のない帝王切開の希望にもつながります。エジプトは帝王切開率が5割を超える国の一つで、著者らは恐怖がその一因と考えました。本研究では、中等度〜重度の出産恐怖をもつ妊娠28週以降の女性96名を、ICBT群48名と対照群48名に割り付けました。ICBTは週1回・全6回のモジュールをWhatsAppグループで配信し、考え方のくせを見直す「認知再構成」、怖い場面に少しずつ慣れる「曝露」、呼吸法・漸進的筋弛緩・マインドフルネス、出産の正しい知識の提供を組み合わせ、バンデューラの自己効力感理論(「自分ならできる」という見込みが行動を左右するという理論)を土台にしています。最後まで残った76名(ICBT 36名、対照40名)の分析で、ICBT群は出産恐怖(CAQ)が47.35→33.03点に下がり、出産の自己効力感(CBSEI)は227.0→265.3点に上がりました。対照群はほぼ変化しませんでした。ただし脱落者を除いた解析、表の数値の不整合、短い追跡期間など、結果を割り引いて読むべき点も多くあります。

## 2. FigureとTableの解説

本文で言及されるのは **Figure 3点(Fig. 1〜3)、Table 5点(Table 1〜5)** です。補足資料の表はありません。

### Figure 1:概念モデル(理論的枠組みと仮説)
バンデューラの自己効力感理論と認知行動療法の2つが「インターネットCBT介入」を形づくり、その介入が①出産恐怖を減らす(仮説H1)、②母親の自己効力感を高める(仮説H2)、という矢印でつないだ図です。ここでの「自己効力感」は、陣痛や分娩に自分でうまく対処できるという自信を指します。図そのものは模式図で、データは含まれていません。なお本文は、恐怖の軽減が帝王切開の減少や産後うつの予防につながると期待を述べますが、それらは本研究では検証されていない「先の話」です。

### Figure 2:参加者の流れ図(フローチャート)
CONSORT(臨床試験の報告ルール)に沿った流れ図です。第1段階の横断調査で中等度〜重度の恐怖をもつ169名が見つかり、そのうち適格基準を満たして同意した96名を48名ずつに割り付けました。最終的な分析対象はICBT群36名(75%)、対照群40名(83%)で、ICBT群12名・対照群8名が脱落しています。脱落の条件には「2回続けて反応しない」「課題を出さない」が含まれ、介入に乗れなかった人ほど除かれやすい仕組みでした(図は画像のため、人数はTable 3と本文から確認)。

### Figure 3:出産恐怖と自己効力感の推移(折れ線グラフ)
上段が出産恐怖、下段が自己効力感の、T1→T2の平均値の折れ線です。両群とも出発点はほぼ同じで、ICBT群は恐怖が大きく下がり、自己効力感は上向きます。一方、対照群の恐怖はほぼ横ばい、自己効力感はわずかに下がっています。グラフは平均だけで、ばらつき(誤差棒)は本文の説明からは確認できません。T1は96名全員、T2は残った76名の値なので、同じ人の変化を厳密に追った図ではない点に注意が必要です。

### Table 1:ICBTプログラム6モジュールの内容
第1回は導入と恐怖の評価、呼吸法。第2回は認知再構成で、出産にまつわる否定的な考えや「認知の歪み」(物事を極端に悲観的に受け取るくせ)を見つけ、分娩室の動画を見て、恐怖日記を宿題にします。第3回は曝露療法で、怖いものを弱い順に並べて段階的に向き合います。第4回は心理教育(分娩の段階、陣痛開始のサイン、胎動の観察)と漸進的筋弛緩法。第5回は陣痛の痛みへの薬を使わない対処法といきみ方。第6回はふり返りと全体のまとめです。CBTの定石をひととおり押さえた構成です。

### Table 2:参加者の属性(n=96)
平均年齢25.8歳、大卒以上61.5%、専業主婦67.7%、平均妊娠週数31.4週、初産43.8%、計画妊娠91.7%、妊婦健診を定期受診77.1%でした。年齢・学歴・職業・妊娠週数・出産経験・計画妊娠・健診受診のいずれも、両群の間に統計的な差はありません(すべてp>0.05)。ただし、選択基準は「18〜34歳」なのに、表には「35歳以上」が9名(対照3名、ICBT 6名)いて、基準と食い違っています。また妊娠週数は対照群32.0±1.06週に対しICBT群30.92±2.80週で、p=0.089とわずかに偏りが残っています。

### Table 3:出産恐怖と自己効力感の群間比較(主要結果)
出産恐怖(CAQ、16〜64点、高いほど怖い)は、介入前が対照47.08点・ICBT 47.35点で差なし。介入後は対照47.10点・ICBT 33.03点で大差がつきました(p<0.001)。ICBT群は平均14.32点下がり(30.2%改善)、群内の効果量η²(結果のばらつきのうち変化で説明される割合)は0.876です。自己効力感(CBSEI、32〜320点)は介入後に対照233.5点・ICBT 265.3点(p=0.011)で、ICBT群は38.3点上昇(16.9%、η²=0.600)。問題点として、①η²は群間差ではなく「ICBT群の前後差」の効果量、②対照群の自己効力感は240.7→233.5点と下がっているのに表では「+7.2(3.0%改善)」と記載、③対照群の恐怖は平均差0.02でt=0.801という組み合わせが、変化のばらつきがほぼゼロでないと成り立たない、という不整合があります。

### Table 4:属性別にみた介入前の出産恐怖(論文は「二元配置分散分析」と表記)
介入前の恐怖の点数を属性ごとに比べた表です。若い(18〜25歳)49.11点、高校以下49.09点、妊娠30週以上49.09点、初産49.07点が、それぞれ比較相手より有意に高く(年齢F=4.095、学歴F=6.792、妊娠週数F=11.202、出産経験F=9.554)、職業と健診受診では差がありませんでした。著者は「若さ・低学歴・妊娠後期・初産が恐怖を強める」と解釈します。ただし表題は「二元配置分散分析」「交互作用」なのに、中身は属性ごとの単純な比較に見えます。また上記4グループの標準偏差が0.26〜0.32と極端に小さく、選択基準(40〜64点)の幅を考えると不自然です。

### Table 5:単回帰分析による介入効果
介入後の点数を、介入の有無・年齢・学歴・妊娠週数・出産経験のそれぞれ1つずつで説明した単回帰(説明変数が1つだけの回帰)です。出産恐怖では介入の標準化係数β=−0.902(95%CI −15.63〜−12.51点、R²=0.813)、自己効力感ではβ=0.292(7.66〜56.06点、R²=0.085)で、どちらも有意でした。年齢などの属性はいずれも有意ではありません。本文は「交絡因子を調整しても効果は頑健」と述べますが、変数を1つずつ入れた単回帰なので、実際には何も調整していません。ここが本文と表の最も大きな食い違いです。

## 3. 8項目評価

> [!note] 評価の前提
> 本論文は原著研究(ランダム化比較試験)なので、8項目は一次研究の基準どおりに当てはめています。

### ① 研究デザイン
並行群間RCTで、コンピュータで作った乱数表による割り付けと、評価者・解析者の盲検化をうたっており、因果を問う設計としては適切です。対照群にも別のWhatsAppグループで一般的なサポートをし、試験後に同じプログラムを提供した点も倫理的に配慮されています。一方で、参加者も介入者も割り付けを知っており、結果は自己記入式の質問紙なので、「期待されている答え」に寄る偏りを防げません。対照群は「注意を向けられる量」でICBT群に釣り合わず、効果がCBTの中身によるのか、6週間手厚く関わったことによるのかを区別できません。さらに試験は2023年8〜12月に行われたのに、ClinicalTrials.govへの登録は2024年10月15日で、事後登録です。

### ② サンプルサイズと選択基準
効果量d=0.5・有意水準5%・検出力80%で「1群43名、計86名」と算出したと書かれています。しかし、この条件で2群の平均を比べるのに必要な人数は通常1群約64名で、43名では足りません(43名はd≈0.6前後を想定した数に相当)。脱落見込みを10%としましたが実際の脱落は21%(20/96)で、想定を大きく上回りました。選択基準では18〜34歳としながら35歳以上が9名含まれ、基準の運用に疑問が残ります。不安症やうつ病の診断がある人を除外するとしつつ、限界の節では「評価尺度でのスクリーニングはしていない」と述べており、除外の精度も不明です。1都市4施設・スマホを持つ識字のある女性に限られ、一般化の範囲は狭いです。

### ③ 方法論の適切性
介入はCBTの標準的な要素(認知再構成・曝露・リラクセーション・心理教育)を6回に整理し、専門家5名の審査と15名のパイロットで手直ししており、内容の筋は通っています。尺度はアラビア語版CAQ(α=0.893)とCBSEI(α=0.880)という検証済みのものを使いました。問題は、介入の「忠実度」(計画どおり実施されたか)や参加率、宿題の実施状況が報告されていないこと、介入者が誰で何人いたかが曖昧なこと、そして評価が介入直後の1回だけで、出産時の恐怖や分娩方式・産後の状態といった本来の目的に近い転帰を測っていないことです。課題を出さない人を脱落扱いにする規則は、効果を過大に見せる方向に働きます。

### ④ 統計分析の妥当性
解析は介入を最後まで受けた76名だけで行われ、割り付けた全員を含めるITT解析(脱落者も含めて元の群で比べる方法)がありません。脱落はICBT群に多く(12名対8名)、残った人は「うまくいった人」に偏りやすいです。群間比較は介入後の平均のt検定で、介入前の値で補正するANCOVAのような標準的手法を使っていません。報告されたη²は群内の前後差の効果量で、群間効果としては過大な印象を与えます。Table 3の対照群の数値(平均差0.02でt=0.801、自己効力感の低下を「+7.2」と記載)、Table 4の不自然に小さい標準偏差、Table 5を「調整済み」と呼ぶ記述など、計算や表記の誤りが複数あります。

### ⑤ 結果の信頼性と再現性
ICBT群の恐怖14.32点減少・自己効力感38.3点増加は、群内の数値(平均差と対応のあるt値から逆算した変化のばらつき)とは整合しており、ICBT群で点数が改善したこと自体は信頼してよさそうです。一方、対照群の恐怖の変化量のばらつきがほぼゼロという計算結果は、現実の質問紙データとしては考えにくく、データの処理や記載に誤りがある可能性を示します。データは「求めに応じて提供」で公開されておらず、第三者が検証できません。単一地域・76名・直後評価のみで、効果の持続や別の集団での再現は未確認です。

### ⑥ 結論の妥当性
「ICBTは出産恐怖を減らし自己効力感を高めた」という結論は、介入直後の自己記入式の点数については支持されます。しかし要旨と提言にある「費用対効果がある」「不要な帝王切開を減らしうる」「追加の医療資源なしで効果」は、費用も分娩方式も測っていないので本研究の結果からは言えません。恐怖の効果量η²=0.876も群内の前後差なので、「大きな効果」という印象はそのまま受け取らないほうがよいです。提言5で著者自身が「対面CBTと比べるべきだった」と認めているように、インターネットという形式の優位性も示されていません。

### ⑦ 新規性
出産恐怖へのインターネットCBT自体は、オーストラリアのLoughnanら(2018)や中国・欧州の試験など先行研究があり、手法としての新しさは限られます。新しい点は、アラビア語圏・エジプトという研究が少ない地域で、文化に合わせた内容を、専用アプリではなく広く普及したWhatsAppで届けたことです。帝王切開率が非常に高い国で、低コストの配信手段を試したという「実装の文脈」に価値があります。ただし文化的な適応の具体的な中身(何をどう変えたか)が十分書かれておらず、他地域が参考にしにくい点は残念です。

### ⑧ 臨床的意義
妊娠後期の女性に、通院の負担なく、身近なメッセージアプリでCBTの要素を届けられる可能性を示した点は、精神科医療が届きにくい地域の周産期ケアにとって意味があります。日本でも出産恐怖は無痛分娩や帝王切開の希望、産後うつと関わるため、助産師外来などでの応用は考えられます。ただし今回の効果は直後の点数の変化にとどまり、出産体験・分娩方式・産後の母子の転帰が改善するかは不明です。グループチャットでのプライバシー確保、重い不安やうつを見落とさない仕組み、脱落しやすい人への対応も、導入前に詰める必要があります。現時点では「有望な予備的結果」と位置づけるのが妥当です。

## 4. 整合性の最終チェック

Readツールの直接読み込みはpopplerが無く失敗したため、スキル同梱の`extract_pdf_text.py`(pdfplumber)で全15ページのテキストを抽出し、本文(1〜13ページ)と著者情報・文献リスト(14〜15ページ)まですべて読みました。Figure 1(概念モデル)とFigure 2(流れ図)は画像のため中身の文字は取れず、本文の説明とTable 3の人数から内容を確認しています。Figure 3もグラフ画像のため本文の説明に基づきます。Figure 3点・Table 5点をすべて解説しました。

ノート中の数値(96名・48名ずつ・分析76名、Table 2の属性、Table 3の平均値・t値・η²・改善率、Table 4のF値、Table 5のβ・95%CI・R²、αの値、登録番号NCT06640608と登録日)は抽出テキストと照合済みです。論文側の不整合として、①選択基準18〜34歳に対し35歳以上が9名、②必要サンプル数の計算(d=0.5で1群43名)が通常の計算(約64名)と合わない、③対照群の自己効力感が240.7→233.5点と低下しているのに「+7.2・3.0%改善」と表記、④対照群の恐怖の平均差0.02とt=0.801の組み合わせが不自然、⑤Table 4の一部の標準偏差が極端に小さい、⑥Table 5は単回帰なのに本文で「交絡を調整」と記述、⑦Table 3の群間t=17.40とTable 5の回帰t=−17.962の不一致、⑧試験終了から約10か月後の事後登録、⑨著者貢献欄に著者一覧にないイニシャル(A.H.H.、N.E.K.、M.S.、N.I.M.B.など)がある、を確認しました。これらはノートでは論文の記載どおりに引用したうえで、評価①②④⑤で指摘しています。
