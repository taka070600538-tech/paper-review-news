# ニュートラシューティカルとフィトシューティカルによる精神疾患治療の臨床医向けガイドライン——WFSBPとCANMATのタスクフォース 精読ノート

## 概要(500字以内)

サプリメントやハーブを精神疾患の治療に使う人は多いのに、国際的な臨床ガイドラインは2015年ごろから更新されていませんでした。世界生物学的精神医学会連合(WFSBP)とカナダ気分・不安治療ネットワーク(CANMAT)は、15か国31名のタスクフォースを作り、栄養素由来の「ニュートラシューティカル」と植物由来の「フィトシューティカル」について、メタ分析または2本以上のランダム化比較試験(RCT)がある「グレードA」のエビデンスだけを評価しました。15種のニュートラシューティカルと10種のフィトシューティカルが対象になり、効果の向きも加えて「推奨(+++)」から「非推奨(−)」の5段階で格付けしました。最も強い「推奨」は、うつ病へのオメガ3脂肪酸(EPA 1〜2 g、抗うつ薬への併用)と、軽症〜中等症うつ病へのセントジョーンズワート(単剤)の2つだけです。プロバイオティクス、亜鉛、メチル葉酸、サフラン、クルクミン、アシュワガンダ、ラベンダー、統合失調症の陰性症状へのNACとメチル葉酸などは「暫定的推奨」です。葉酸、イノシトール、マグネシウム、カバ(全般不安症)などは「非推奨」でした。重い精神疾患では、通常治療への併用に限るよう強調しています。

## Figure・Tableの解説

本文に Figure はなく、Table 1〜7 の7点です。Table 4〜7 は横向き(90度回転)に組まれた大きな表で、薬剤ごとの推奨度・用量・安全性・臨床上の助言をまとめています。

### Table 1: 推奨度の格付け(WFSBPの格付け体系を改変)

推奨の5段階と、それぞれに必要なエビデンスの条件を定めた表です。「推奨(+++)」は、良質のメタ分析(複数の研究結果を統計的にまとめた解析)などで強く肯定的なデータがあり、安全性が「頑健・許容・まずまず」のいずれか。「暫定的推奨(++)」は、主に肯定的だが、小さな標本や単一地域の研究、製品の品質のばらつきが気になる場合。「弱い推奨(+)」は肯定と否定が混じるものの肯定寄り。「現時点では推奨しない(±)」は結果が混在して向きが決められない場合。「非推奨(−)」は否定的データが頑健、または安全性が「不良」の場合です。従来のガイドラインがエビデンスの「量」だけを格付けしていたのに対し、効果の「向き」まで判定した点が新しいところです。

### Table 2: 文献検索の検索語

対象者(うつ病、不安、強迫、ADHD、双極性障害、精神病、統合失調症、PTSDなど)、介入(ビタミン、ミネラル、オメガ3、アミノ酸、SAMe、クレアチン、NAC、プロバイオティクス、各種ビタミンB群、葉酸、亜鉛、セントジョーンズワート、カバ、サフラン、クルクミン、イチョウ、ロディオラ、ラベンダー、アシュワガンダなど50種以上)、比較対照(プラセボ、対照、併用)、研究の型(メタ分析、RCT、系統的レビュー)の4群の語を組み合わせた検索式です。英語のデータベースに加え、日本語(医中誌)、ドイツ語、中国語、スペイン語、ポルトガル語、アフリカの言語のデータベースも検索したと本文に記されています。

### Table 3: 介入の種類と対象疾患の一覧

格付けの対象になった25種を、疾患ごとに並べた表です。ニュートラシューティカルは、気分障害にオメガ3(特にEPA)、ビタミンD、NAC(N-アセチルシステイン、抗酸化作用のあるアミノ酸誘導体)、プロバイオティクス(腸内の善玉菌製剤)、亜鉛、葉酸系化合物、SAMe(S-アデノシルメチオニン、体内のメチル基の供給源)、ビタミンC、トリプトファンと5-HTP(セロトニンの原料)、クレアチン、イノシトール、マグネシウム。不安症にNAC、精神病性障害にオメガ3、ビタミンD、NAC、葉酸系、ADHDにビタミンD、亜鉛、葉酸系、オメガ3とオメガ9、広域微量栄養素、アセチルLカルニチン。フィトシューティカルは、気分障害にセントジョーンズワート、サフラン、クルクミン、ロディオラ、ラベンダー、不安症にラベンダー、カバ、アシュワガンダ、ガルフィミア、カモミール、精神病性障害とADHDにイチョウです。

### Table 4: 気分障害(単極性・双極性うつ病)の推奨

最大の表で、2ページにまたがります。うつ病への併用オメガ3(EPA 1〜2 g/日、+++、メタ分析+RCT5本)、単剤オメガ3(±)、双極性うつ病へのオメガ3(+)、ビタミンD(1500〜4000 IU/日、+)、プロバイオティクス(10億〜100億個/日、併用++)、亜鉛(25 mg/日以下、併用++)、メチル葉酸(15 mg、++)と葉酸(−)、SAMe(単剤800 mgは±、併用1600〜3200 mgは+)、ビタミンC・トリプトファン/5-HTP・クレアチン(±)、イノシトール・マグネシウム(−)、双極性障害へのNAC(±)が並びます。植物ではセントジョーンズワート(600〜1800 mg、単剤+++)、サフラン(30 mg、++)、クルクミン(500〜1000 mg、++)、ロディオラ(±)、ラベンダー(表では++、本文では+)です。安全性の欄では、オメガ3と血液をサラサラにする薬の併用、セントジョーンズワートとSSRI/SNRIの併用によるセロトニン症候群、肝臓の代謝酵素を誘導して他の薬の血中濃度を下げる作用などが注意点として書かれています。

### Table 5: 不安症の推奨

ニュートラシューティカルは NAC だけで、強迫症への併用(2〜3 g/日、+、メタ分析)と抜毛症(±)。植物では、カバ(カバラクトン60〜250 mg、全般不安症に−)、アシュワガンダ(300〜600 mg、ウィタノリド5%に標準化、++)、ガルフィミア(350〜700 mg、+、主に南米で使われ入手が問題になり得る)、カモミール(220〜1500 mg、±、安全性は頑健)、ラベンダー(80〜160 mgの精油カプセル、++)です。カバの欄には、肝障害がある人やアルコール・ベンゾジアゼピンとの併用を避けること、「ノーブル」と呼ばれる品種の根茎だけを使うことが書かれています。

### Table 6: 統合失調症の推奨

オメガ3(EPA 1〜2 g、−。肥満や炎症がある人では効く可能性、抗精神病薬による代謝の問題に役立つかもしれない)、ビタミンD(1500〜4000 IU、−)、NAC(1〜3 g、併用++)、メチル葉酸(1〜15 mg、併用++)、イチョウ(120〜360 mg、ギンコフラボン2〜3%、併用+)です。NAC、メチル葉酸、イチョウはいずれも主に陰性症状(意欲の低下、感情の平板化など)への効果として格付けされています。イチョウは遅発性ジスキネジア(薬の副作用で起きる不随意運動)や認知機能への効果も期待されると書かれていますが、元データが単一地域に偏っている点が弱みです。

### Table 7: ADHDの推奨

対象は主に子どもです。オメガ3(120〜1200 mg、±。メタ分析は肯定的でも、その後のRCT4本が否定的)、オメガ9(月見草油、2〜3 g、−)、広域微量栄養素(ビタミン13種とミネラル15種の配合、8〜12カプセル/日、単剤+、子どもと大人)、ビタミンD(1500〜4000 IU、併用+)、アセチルLカルニチン(1〜3 g、−)、亜鉛(15〜40 mg、±)、イチョウ(80〜120 mg、±)です。用量は年齢と体重に合わせると注記されています。植物でADHDに有効と判定されたものはありませんでした。

## 8項目評価

本論文は新しいデータを集めた原著研究ではなく、既存のメタ分析とRCTをまとめて推奨を作る「臨床ガイドライン」です。そのため②「サンプルサイズと選択基準」は文献の採否基準と元データの規模に、④「統計分析の妥当性」はエビデンスの統合と格付けの手続きに読み替えて評価します。

### ① 研究デザイン

著者らの2本のメタレビュー(メタ分析を集めて再評価する研究。ニュートラシューティカル2019年、フィトシューティカル2020年)を土台に、2020年5〜9月の追加検索でRCTを補い、15か国31名のタスクフォースが3回のオンライン投票(80%以上の賛成で採択)で推奨を決めました。最後にCANMATの外部審査も受けています。手順は明快ですが、評価対象をグレードAに限ったため、RCTが1本しかない薬剤や新しい薬剤は最初から外れます。著者ら自身も「データがないことは効果がないことを意味しない」と書いており、表に載っていないことを「効かない」と読む誤解を招きやすい設計です。系統的レビューで使われるGRADE(エビデンスの確実性を評価する国際標準の方法)ではなく、WFSBPの格付けを改変して使っている点も、他のガイドラインと比べにくくしています。

### ② サンプルサイズと選択基準(文献の採否基準と元データの規模に読み替え)

採否基準はPICO(対象・介入・比較・結果)で整理され、標本の75%以上が精神疾患と確認されていること、プラセボか既存の治療薬との比較、2週間以上の投与、1群10人以上を条件としました。認知症、自閉スペクトラム症、睡眠障害、大麻成分、漢方などの伝統的な複合処方は除外です。問題は元データの規模の差が非常に大きいことです。セントジョーンズワート(35試験、6993人)やビタミンD(27試験、7651人)に対し、亜鉛(3試験、124人)、マグネシウム(2試験、49人)、クレアチン(2試験、64人)などはごく小さく、2本のRCTで「グレードA」と呼べてしまいます。小さな試験2本でも同じグレードAに入る仕組みは、「A」という言葉の印象より根拠がかなり弱い場合があることを意味します。

### ③ 方法論の適切性

推奨を作る前に、効果の向き、安全性(頑健・許容・まずまず・不良の4段階)、費用、実用性まで評価し、用量は臨床試験、教科書、規制当局のデータ、臨床家の意見を合わせて決めています。英語以外のデータベースまで検索した点も、この分野では大事な配慮です。一方で、複数のメタ分析が重なったときに「新しいものが古いものの75%以上の試験を含めば新しい方を使う」というルールは実用的ですが、どのメタ分析を選んだかで結論が変わり得ます。投票した委員の中には、評価対象の製品を作る企業から研究費や謝礼を受けた人が多く含まれます(利益相反の開示は詳しい)。その影響をどう管理したか、たとえば利益相反のある委員を該当薬剤の投票から外したか、は書かれていません。

### ④ 統計分析の妥当性(エビデンスの統合と格付けの手続きに読み替え)

有意水準はp<0.05、効果の大きさを示す標準化平均差(SMD)は0.2未満を無視できる、0.2〜0.4を小、0.4〜0.8を中、0.8超を大と区分し、出版バイアス(否定的な結果が論文にならない偏り)の補正値があればそれを主な結果としました。元のメタレビューではAMSTAR(メタ分析の質を評価する道具)も使っています。しかし本文の推奨文には試験数と人数は書かれているのに、効果量や異質性(試験ごとの結果のばらつき)の数値がほとんど示されず、読者は「+++」と「++」の差が統計的に何を意味するのか確かめられません。格付けは数値の基準ではなく、最終的に委員の合意で決まるため、同じデータから別の格付けになる余地が残ります。

### ⑤ 結果の信頼性と再現性

著者ら自身が、元の研究の多くに小さな標本、ばらばらな用量、盲検化の説明不足、有効成分の標準化不足があると認めています。植物製剤では製品ごとの成分差が大きく、たとえばセントジョーンズワートの良い結果は高度に標準化された抽出物(WS 5570など)のもので、市販の別の製品に当てはまるとは限りません。イチョウの統合失調症データは単一地域のものだけです。さらに本文の内部にも不整合があります。統合失調症へのビタミンDは本文とTable 6では「非推奨(−)」なのに、要旨では「+」、結論では「弱い推奨」とされています。うつ病へのラベンダーはTable 4で「++」、本文では「+」です。要旨と結論はうつ病へのNACに触れていますが、本文で評価したのは双極性障害へのNACです。

### ⑥ 結論の妥当性

「推奨」をうつ病への併用オメガ3と単剤セントジョーンズワートの2つに絞り、多くを「暫定的推奨」や「弱い推奨」にとどめ、重い疾患では通常治療への併用に限るとした結論は、データの強さに見合った慎重なものです。ただし「最も包括的なガイドライン」「世界の治療手順に取り入れられる」という締めくくりは、⑤で見た元データの質の低さや本文内の不整合を考えると、やや言い過ぎです。研究期間の多くが4〜12週で、長期の効果や再発予防のデータがほとんどないことも、著者ら自身が認める限界です。

### ⑦ 新規性

CANMATの2009年・2016年版を更新し、精神科の主要な疾患(うつ病、双極性障害、不安症、統合失調症、ADHD)を横断して、サプリメントとハーブだけに焦点を当てた国際ガイドラインとして初めて、効果の「向き」まで判定して5段階の推奨を出した点が新しいところです。さらに、薬剤ごとに用量、標準化の目安、安全性、どんな患者に向くか(炎症や肥満のある人、栄養欠乏のある人など)まで1枚の表にまとめています。一方、評価の土台は著者らが以前に出した2本のメタレビューで、新しく加わったのは主に追加のRCTと格付けの作業です。データそのものの新しさは限られます。

### ⑧ 臨床的意義

日常の診療では、患者がすでにサプリメントやハーブを使っていることが多く、医師が知らないこともあります。このガイドラインは「どれに根拠があり、どれにないか」「どの薬と併用すると危ないか」を短時間で確かめる早見表として役立ちます。特に、セントジョーンズワートと SSRI/SNRI・経口避妊薬・ワルファリンなどとの相互作用、カバと肝障害、オメガ3・イチョウと抗凝固薬の注意は、処方する医師が必ず知っておくべき情報です。ただし、日本では多くの製品が医薬品ではなく食品として売られ、試験で使われた標準化抽出物と同じ品質かどうか確かめにくい点、推奨の多くが「暫定的」以下である点を踏まえ、標準治療の代わりではなく補助として、患者と相談しながら使うのが妥当です。
