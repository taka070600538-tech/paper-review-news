# 当事者経験をもつピアが届けるテクノロジー支援型の周産期うつ病認知行動療法——クラスター無作為化非劣性試験 精読ノート

## 1. 概要

低・中所得国では、妊娠中から産後の女性の4人に1人が周産期うつ病を経験します。WHOの「Thinking Healthy Programme（THP）」は、地域の保健師が認知行動療法（CBT：考え方と行動のくせを整える心理療法）を届ける方法で、効果が実証されています。しかし、忙しい医療現場で広げようとすると、質が落ちてしまうことが課題でした。

そこで著者らは、子育て経験のある地域の一般女性（ピア）が、アニメのキャラクター（アバター）が物語でCBTを伝えるタブレットアプリを使って届ける版（THP-TAP）を作りました。そして、従来の保健師版（WHO-THP）と比べました。

パキスタン農村部の70村を無作為に割り付け、大うつ病エピソードと診断された妊婦980人が参加しました。産後3か月の寛解率は、THP-TAPが92.3%、WHO-THPが83.5%でした。差は8.91ポイントで、あらかじめ決めた「−10ポイントより悪くない」という基準を大きく上回り、非劣性（劣っていないこと）が示されました。PHQ-9の抑うつ症状もTHP-TAPのほうが軽くなりましたが、産後6か月では両群の差はなくなりました。

## 2. FigureとTableの解説

本文には**Figure 1点（Fig. 1）**と**Table 5点（Table 1〜5）**があります。Extended Dataはありません。本文では補足資料（Supplementary Fig. 1〜3、Supplementary Table 1〜15）にも言及していますが、補足資料はこのPDFに含まれていません。そのため最後に、本文の記述から分かる範囲でまとめて紹介します。

### Figure 1：試験の流れ（CONSORTフロー図）

CONSORT（臨床試験の報告ルール）に沿って、参加者がどう集まり、どう追跡されたかを示す図です。70村を35村ずつに無作為に割り付け、THP-TAP群では1,464人、WHO-THP群では1,397人の妊婦に声をかけました。そのうち大半（911人と850人）は、構造化面接SCID（決まった質問で診断する面接）で大うつ病エピソードに当てはまりませんでした。最終的に487人と493人が登録されました。産後3か月の評価を受けたのは428人（87.8%）と418人（84.7%）です。脱落の主な理由は乳児の死亡（31人と47人）と転居でした。産後6か月の評価は421人と410人でした。

### Table 1：参加者の背景（ITT集団）

ITT集団（割り付けられた全員を解析する集団）の特徴です。平均年齢は約27歳で、97%が専業主婦でした。子どもの数は平均約2人、夫の94%が就業しています。PHQ-9（抑うつ症状の9項目質問票、27点満点）は16.7点と16.2点で、中等度〜やや重いうつ状態でした。不安の尺度GAD-7と、生活の支障度WHO-DASも両群でほぼ同じです。学歴は、初等教育卒がTHP-TAP群で13.8%、WHO-THP群で8.3%と少し偏りがあります。なお「流産・死産の既往」の欄は平均1.61という値で、何を数えたのか単位があいまいです。

### Table 2：寛解（主要評価項目）の集計

主要評価項目は、産後3か月にSCIDで大うつ病エピソードから抜け出しているか（寛解）です。ITTの単純解析では92.3%対83.5%で、リスク差（割合の差）は8.91ポイント（95%信頼区間4.25〜13.56）でした。下限の4.25が非劣性マージン−10を大きく上回っています。背景をそろえた調整解析（差9.22）、欠測を多重代入法（欠けたデータを統計的に補う方法）で補った解析（差8.88）、プロトコル遵守集団の解析でも、結果は同じでした。産後6か月では差は約2〜3ポイントに縮まり、有意ではありませんでした。

### Table 3：連続量の副次評価項目（ITT）

混合効果モデル（村や個人の違いを考慮する回帰分析）で比べた、症状の点数です。PHQ-9は産後3か月で3.25点対4.33点、差は−1.13点（P=0.0071）で、THP-TAPのほうが低くなりました。ただし6か月では差がなくなりました（−0.31、P=0.46）。不安の尺度GAD-7は、3か月・6か月とも差がありませんでした。生活の支障度WHO-DASは、3か月でTHP-TAPが低い傾向（P=0.09）でしたが、有意ではありませんでした。どちらの群も、ベースラインの16点台から大きく改善しています。

### Table 4：二値の副次評価項目（PHQ-9が10点以上）

PHQ-9が10点以上（中等度以上のうつ状態）の人の割合です。産後3か月では、THP-TAP群が9.1%（39/428）、WHO-THP群が17.5%（73/418）でした。オッズ比は0.45（調整後0.38）で、THP-TAP群はうつ状態が残るリスクが約半分でした。6か月では9.0%対10.7%（オッズ比0.81、有意でない）となり、WHO-THP群が追いついています。一般化線形混合モデル（GLMM：二値の結果を、村や個人のばらつきを考えて分析する方法）で解析しています。

### Table 5：主要評価項目のサブグループ解析

事前に決めた4つの因子で参加者を分け、効果の違いを見ました。ベースラインのPHQ-9が17点を超える重い人では、差が13.36ポイント（78.7%対92.2%）でした。27歳を超える人では14.04ポイント、経産婦（出産経験のある人）では10.56ポイントと、差が大きくなっています。一方、軽めの人、若い人、初産婦では差が小さく、信頼区間が0をまたいでいました。世帯収入による違いはありませんでした。著者ら自身も、サブグループで非劣性を検証するだけの検出力はないと断っています。探索的な結果として読むべきです。

## 3. 8項目評価

**①研究デザイン**
村単位のクラスター無作為化・非劣性試験です。村ごとに割り付けたのは、同じ村の中で介入が混ざる「汚染」を防ぐためです。村の割り付けは、参加者を集める前に、独立した統計家がブロック無作為化（一定の人数ごとに両群を同数にそろえる方法）で行いました。評価者は割り付けを知らされていません。実効性のある既存治療を奪わない、という倫理的な理由で非劣性デザインを選んだ点も妥当です。
問題点は、無治療の対照群がないことです。そのため、両方の治療が本当に効いたのか（アッセイ感度）を、この試験の中だけでは確かめられません。また、村を割り付けた後に登録しているため、登録時の偏りが入り得ます。

**②サンプルサイズと選択基準**
検出力の計算では、両群の寛解率を75%、非劣性マージンを−10%、クラスター内相関（同じ村の人どうしの似かより）を0.005、脱落を20%と仮定しました。その結果、980人で検出力は87.2%とされています。
しかし実際のクラスター内相関は0.0109で、仮定の2倍でした。寛解率も92%前後と、仮定の75%を大きく上回っています。非劣性はそれでも余裕をもって示されましたが、前提が大きくずれていたことは記録しておくべきです。選択基準は、SCIDで大うつ病エピソードと診断された18歳以上の妊娠中期・後期の女性で、臨床的に明確です。一方で、重症で入院が必要な人は除かれています。

**③方法論の適切性**
診断に、自記式の質問票ではなく、文化に合わせて訳したSCID面接を使っています。これは大きな長所です。アプリは当事者と一緒に作られ、オフラインでも動き、対象の女性が自分で端末を持たなくてよい設計です。デジタル格差への配慮として優れています。
問題点もあります。
- 介入の内容と実施者（ピアかLHW〔Lady Health Worker：パキスタンの女性保健員〕か）が同時に違うため、どちらの要素が効いたのか区別できません。
- 同じ地域で過去にもTHP試験が行われています。
- 参加者を盲検化できないため（単盲検）、期待効果やホーソン効果（見られていると頑張る効果）が入り得ます。
- EQ-5D（生活の質の尺度）や子どもの成長など、事前に計画した評価項目が別の論文に回されています。

**④統計分析の妥当性**
主要解析には、村のまとまりを考慮したGEE（一般化推定方程式）を使っています。調整解析では、事前に決めた共変量（年齢、出産回数、収入、ベースラインのPHQ-9）で重みづけをしました（逆確率重みづけ）。欠測は多重代入法で補い、プロトコル遵守解析も行っています。複数の感度分析で結論が一貫している点は評価できます。
一方で、次の問題があります。
- Methodsでは「単純解析」のモデルにもベースラインのPHQ-9が共変量として入っていると書かれており、「単純」「調整」の区別があいまいです。
- 副次評価項目が多数あるのに、多重比較（何度も検定すると偶然の有意差が出やすくなる問題）の補正がありません。
- PHQ-9のカットオフが、Methodsでは「≤10」、結果では「≥10」と表記が揺れています。

**⑤結果の信頼性と再現性**
主要な数値（登録数、脱落数、寛解の分子と分母）は、図と表と本文でほぼ一致していて、流れの計算も合っています。
ただし、Table 2には転記ミスとみられる箇所があります。ITT単純解析の6か月の行は「389/421（92.0）対375/410（89.7）、差2.91」となっています。しかし389/421は92.4%、375/410は91.5%です。しかも、この行はプロトコル遵守集団の多重代入の行と数値が完全に同じです。また、脱落の理由として乳児の死亡がWHO-THP群で多く（47人対31人）、脱落の割合に群間差（12.1%対15.2%）があります。データは申請制で、すぐには再現できません。

**⑥結論の妥当性**
「THP-TAPはWHO-THPに劣らない」という主要な結論は、信頼区間の下限が+4.25で、十分に支持されます。産後3か月でTHP-TAPのほうが改善が大きい点は、副次評価項目の優越性検定として示されています。ただし、6か月では差が消えています。「早く回復すること自体に意味がある」という議論はもっともです。しかし、子どもへの影響などのデータはまだ示されていません。
両群とも寛解率が9割前後と高く、自然に回復する分（無治療でも3〜6か月で4分の1〜3分の1が寛解）を差し引いた真の効果は分かりません。費用は、試験の実績では1人あたりTHP-TAPが69ドル、WHO-THPが59ドルで、THP-TAPのほうが高くなっています。「より安い」とする主張は、最適化シナリオの推計（24ドル対44ドル）に頼っています。

**⑦新規性**
新しさは、次の3つを組み合わせた点にあります。
- 医療経験のない当事者のピアが実施者になること
- アバターと物語による「ナラティブCBT」（物語を通じて伝える認知行動療法）をアプリで自動化すること
- 研修とスーパービジョン（専門家による指導・監督）をピアどうしの段階的な仕組みで行うこと

こうしたデジタル支援型のピア介入を、WHO標準の治療と直接比べた大規模な無作為化試験は、他に例がありません。
ただし、ピア版THPの有効性（Vanobberghen 2020）や、アプリ開発の経緯（Atif 2022）は、同じ研究グループがすでに報告しています。今回の新しさは、それらを実際に近い環境で組み合わせて検証したことにあります。

**⑧臨床的意義**
専門職が足りない地域で、一般の女性とアプリを「共同セラピスト」にしてCBTを届けられることを示しました。タスクシェアリング（専門家の仕事を、訓練を受けた非専門家と分担すること）の実装モデルとして、意義は大きいです。日本でも、産後うつの支援、ピアサポーターの活用、デジタルCBTの設計（人との関わりを残しつつ中身を自動化する）に応用できる考え方です。
ただし、次の点は割り引いて考える必要があります。
- パキスタン農村部の、専業主婦が97%という集団で行われた試験です。
- 1回限りのアプリ開発費（約14.8万ドル）がかかります。
- NGOの管理体制や、ピアへの報酬の仕組みが前提になっています。
- DV（家庭内暴力）のスクリーニングは行われていません。

そのまま他の地域に当てはめられるとは限りません。

- 9〜13ページ：Methods、参考文献27〜42、謝辞、著者の貢献、利益相反

本文で言及されている図表のうち、Fig. 1とTable 1〜5はすべて解説しました。Supplementary Fig. 1〜3とSupplementary Table 1〜15は、PDFに含まれていないため、本文の記述から内容を推定して紹介するにとどめています。Extended Dataはありません。
