# レイパーソン支援によるウェブ配信型認知行動療法——高齢者うつ病に対するランダム化比較試験 精読ノート

## 概要（500字以内）

米国ミシガン大学の研究チームが、高齢者向けに開発したウェブ配信型認知行動療法(wCBT)プログラム「Empower@Home」の有効性を検証したランダム化比較試験(RCT)である。60歳以上でうつ症状のある70名を、9回のウェブセッション＋訓練を受けた非専門家(レイパーソン)コーチによる週1回の電話コーチングを10週間受ける介入群と、週1回の親しみやすい電話(friendly call)とうつ症状モニタリングを受ける待機群に1:1で無作為割付した。主要評価項目はPHQ-9によるうつ症状。結果、介入群は9セッションの完遂率89%と高い治療エンゲージメントを示し、群内効果量は大(Cohen d=1.22)、対照群に対する群間効果量は中(Cohen d=0.72、P=.004)であった。不安・怒り・社会的孤立・不眠・疼痛などの副次アウトカムも介入群でのみ有意に改善した。媒介分析では、CBTスキル獲得・行動活性化・基本的心理欲求(自律性・有能感・関係性)の充足の3つが治療効果を部分的に媒介していた。専門的な精神保健訓練を持たないレイパーソンによる支援でも、高齢者向けデジタルCBTが有効に機能しうることを示した研究である。

## Figure・Tableの解説

### Figure 1：参加者のフロー図（CONSORT図）（3ページ）
適格性評価を受けた382名のうち243名が不適格(年齢不足、認知症疑い、うつ症状が軽度すぎる、他の心理療法を受けている、自殺リスクありなど)、7名が辞退、62名が別研究に回されて除外され、70名がベースライン評価を完了して介入群35名・対照群35名に無作為割付された。介入群は35名全員が介入を開始し(9セッション完遂31名)、対照群は33名がフレンドリーコールを開始した。最終的に介入群35名、対照群33名が解析対象となった。

### Table 1：研究サンプルのベースライン特性（6〜8ページ）
年齢、性別、人種、教育歴、世帯収入、居住形態、婚姻状況、慢性疾患数、身体可動性制限指数、機器所有状況、うつ病診断歴、抗うつ薬服用状況、PHQ-9スコアを両群で比較した表。参加者の多くが女性(81%)・非ヒスパニック系白人(80%)・大卒以上(57%)で、ほぼ全員(97%)が何らかの下肢可動性の困難を訴えていた。すべての項目で群間に統計学的有意差はなく(すべてP>.05)、無作為化が適切に機能していたことが示されている。

### Table 2：PHQ-9スコアを予測する線形混合モデル（8ページ）
時間の主効果(b=-0.49、95%CI -0.73〜-0.26、P<.001)と、群×時間の交互作用(b=-0.68、95%CI -1.00〜-0.35、P<.001)を示した表。交互作用が有意であったことは、介入群が対照群よりも評価時点ごとに速くPHQ-9スコアが低下したことを意味する。両効果を合わせると、介入群では2週ごとに1.17点の低下が見込まれる計算となる。

### Table 3：副次アウトカムおよび媒介変数の群内・群間差（9〜10ページ）
不安(GAD-7)、怒り(PROMIS-anger)、社会的孤立(PROMIS-social isolation)、不眠重症度(Insomnia Severity Index)、疼痛(PEG)、健康関連QOL(EQ-5D-5L)、CBTスキル獲得(CBTSQ)、行動活性化(BADS-SF)、基本的心理欲求充足(BNSG-S)について、群ごとのベースライン〜事後評価の平均値・群内変化量(Cohen d)・群間差(Cohen d、95%CI)を一覧した表。介入群はほぼすべての項目で有意な群内改善を示した一方、対照群では有意な変化はほぼ見られなかった。ただし群間差が統計学的に有意であったのはCBTSQと BNSG-Sのみで、その他の項目はサンプルサイズ不足のため有意水準に達しなかった。

### Table 4：うつ症状に対する媒介分析による間接・直接効果（11ページ）
CBTスキル獲得、行動活性化、基本的欲求充足の3つの媒介変数それぞれについて、自然間接効果・自然直接効果・媒介割合(%)を示した表。3つすべての媒介変数で間接効果が統計学的に有意であり、媒介割合はCBTスキル獲得が62.9%と最も大きく、次いで基本的欲求充足46.8%、行動活性化34.5%であった。

## 内容の評価

### ①研究デザイン
並行群間デザインの無作為化比較試験であり、対照群を単なる待機群ではなく「アテンションコントロール(週1回の親しみやすい電話＋症状モニタリング)」とすることで、人的交流そのものの効果とwCBTプログラム固有の効果を分離しようとした点は方法論的に優れている。ただし介入の性質上、参加者を治療条件に盲検化することは不可能であり、盲検化されたのは事後評価を行う研究スタッフのみである点は限界として認識すべきである。

### ②サンプルサイズと選択基準
主要アウトカムのために計画されたサンプルサイズ(N=70)は、線形混合モデルによる中程度の効果検出には十分であったとされるが、副次アウトカムの2標本t検定では検出力不足であったことを著者ら自身がpost-hoc検出力分析で認めている(効果量0.35を80%検出力で検出するには204名が必要と算出)。除外基準(認知症疑い、精神病性障害、自殺高リスク、末期疾患、物質使用障害、心理療法受療中など)は倫理的・安全性の観点から妥当だが、参加者の学歴・機器所有率が全米平均を大きく上回っており、対象集団の代表性には限界がある。

### ③方法論の適切性
無作為化手順(コンピュータ生成のランダム配列、割付管理者と評価者の分離)や盲検化された事後評価者の設定は適切である。コーチは臨床経験のない学部生・修士課程学生などのレイパーソンで統一されており、「専門的訓練を持たない支援者でも機能するか」という研究目的に対応する設計になっている。一方、コーチングコールの長さや内容(独立完了か同席完了か)には参加者間でばらつきがあり、介入の均質性という点では課題が残る。

### ④統計分析の妥当性
主要アウトカムには線形混合モデルを用い、繰り返し測定データを適切に扱っている。群内・群間比較にはCohen dを付した2標本・対応のあるt検定を用い、効果量とP値を併記する透明性の高い報告がなされている。うつ症状の解析ではLOCF(last observation carried forward)によるIntention-to-treat解析を行った一方、副次アウトカムと媒介変数の解析は欠測データを補完せず完全ケース解析としている点は一貫性を欠くが、欠測が少数であったことと探索的位置づけであることを理由に挙げており、限定的ながら妥当な判断といえる。媒介分析では複数の交絡因子(年齢、性別、教育、収入、居住形態、慢性疾患数)を調整しており、方法論的に丁寧である。

### ⑤結果の信頼性と再現性
主要アウトカムの群間効果(Cohen d=0.72)は統計学的に有意で、著者らの先行する非対照試験の知見(中〜大の効果量)とも整合しており、一定の信頼性がある。しかし副次アウトカムのほとんどは95%信頼区間が0をまたいでおり、真の効果の有無・大きさについては不確実性が大きい。単一州(ミシガン州)・単一プログラム・単一研究チームによる結果であり、他地域・他プログラムでの再現性は今後の課題である。

### ⑥結論の妥当性
著者らは「対照群と比較して抑うつ症状の軽減に有効であった」という結論を、有意な主要アウトカムの結果に基づいて述べており、過度な一般化は避けている。限界(サンプルサイズ、長期追跡の欠如、参加者の代表性の偏り)についても具体的な数値とともに率直に記載しており、結論の妥当性は高い。ただし、副次アウトカムに関する「介入群でのみ有意な群内改善」という記述は、群間差が有意でない以上、対照群との比較においては慎重な解釈が必要である。

### ⑦新規性
高齢者に特化して設計されたwCBTプログラムをアテンションコントロール群と比較したRCTは希少であり、かつコーチをすべて専門的訓練のないレイパーソンで構成した点、さらにCBTスキル獲得・行動活性化・基本的心理欲求充足という3つの媒介変数を同時に検証した媒介分析を行っている点に新規性がある。特に自己決定理論に基づく「基本的心理欲求充足」を治療効果の媒介変数として明示的に検証した点はCBT研究の中でも独自性が高い。

### ⑧臨床的意義
専門的な精神保健人材が不足している高齢者ケアの現場において、非専門家によるコーチングを組み合わせたデジタルCBTが実行可能かつ有効な選択肢となりうることを示した点で臨床的意義が大きい。特にケースマネージャーやプライマリケア医など、精神保健の専門訓練を持たない医療従事者が高齢者のメンタルヘルスケアを補完する手段としての活用可能性を示唆している。一方で、著者ら自身が強調する通り、wCBTは専門的な心理療法の代替ではなく補完的なツールと位置づけるべきであり、実装にあたっては対象患者の選定や技術アクセスの支援体制の整備が課題として残る。
