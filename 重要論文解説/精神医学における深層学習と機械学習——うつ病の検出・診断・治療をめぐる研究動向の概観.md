# 精神医学における深層学習と機械学習——うつ病の検出・診断・治療をめぐる研究動向の概観 精読ノート

> 役割：日本トップクラスのサイエンスコミュニケーターとしての精読プロンプトに基づく分析結果

## 1. 概要（500字以内）

本論文はオーストラリア南クイーンズランド大学のSquiresらによる総説で、うつ病の「検出（detection）」「診断（diagnosis）」「治療反応予測（treatment response prediction）」という3つの局面に、機械学習と深層学習がどこまで入り込んでいるかを整理している。検出ではSNS投稿などのテキストが主役で、LIWC辞書やbag-of-wordsといった手作りの特徴量から、BERTのような文脈依存の埋め込み表現へと移行しつつある。診断では教師なし学習が既存のカテゴリ診断を解体しつつあり、Drysdaleらが安静時fMRIの結合パターンから4つの生物学的サブタイプ（バイオタイプ）を見出した研究が象徴例として扱われる。治療反応予測はrTMS（反復経頭蓋磁気刺激）と薬物療法に大別され、脳波やfMRIを入力とするSVMが依然として中心である。著者らの結論は辛口で、報告される高い精度の大半は内部検証にとどまり、独立データでの外部検証は2件、無作為化比較試験は皆無、患者アウトカムの改善を実証した研究は一つもない、と断じる。小標本、用語定義の不統一、不確実性の定量化の欠如、公開データセットの不足を主要な障壁に挙げ、次の一歩は臨床試験による実証だと主張する。

### Table 1：検出システムとその特徴量（本文5ページ）

深層学習を除く**古典的機械学習**によるうつ病検出研究9件を、研究者・手法・特徴量・データセット・F1スコアの5列で並べた表である。SVM（サポートベクターマシン＝データを最もよく分ける境界面を引く手法）が最多で、特徴量はLIWC（心理測定的に語をグループ化した辞書型テキスト解析ソフト）、LDA（文章の背後にある話題を統計的に推定する手法）、n-gram／bag-of-words（語の出現頻度で文章を数値化する初歩的手法）が中心である。数値のばらつきは大きく、Tadesseら0.91、Deshpande＆Rao 0.83、Hassanら0.81、Islamら0.71、De Choudhuryら0.68、Reeceら0.61、Tsugawaら0.46。この表の要点は成績の高低そのものではなく、**うつ病かどうかのラベルをどう決めたか**で成績が大きく変わる点にあり、著者らは自己申告に依拠した研究ほど見かけの成績が高くなる傾向を指摘している。

### Table 2：深層学習・ニューラルネットワーク（本文7ページ）

**深層学習**によるうつ病検出研究14件を、アーキテクチャ・特徴量・データセット・F1スコアで整理した表である。CNN（画像処理由来の畳み込みネットワーク）、LSTM／BiLSTM（時系列や文章の前後関係を扱う再帰型ネットワーク）、BERT（文脈を考慮した最新の言語表現モデル）が並ぶ。Waniら0.99、Rosaら0.92、Zoganら0.91、Tadesseら（MLP）0.91、Wanら（EEGNet、脳波）0.95、Ansariら0.77、Alhanaiら（音声＋テキスト）0.77、Tasnim＆Stroulia 0.61、Congら0.60。表から読み取れる潮流は2つで、①データ型としてテキストへの偏重が著しいこと、②特徴量が手作りの辞書から神経的な単語埋め込み（Word2Vec、GloVe、BERT）へ移行していることである。ただし0.99という値は、データセットの作り方に由来する過度に楽観的な数字である可能性が高い。

### Table 3：rTMS治療反応予測（本文9ページ）

反復経頭蓋磁気刺激（rTMS）に反応する患者としない患者を、治療前のデータから見分けようとした研究11件の一覧である。著者・対象疾患・特徴量・アルゴリズムの4列構成。特徴量は脳波（EEG）が5件（Baileyら2件、Hasanzadehら、Zandvakiliら、Erguzelら）、安静時MRI／fMRIが4件（Chenら、Hopmanら、Fanら、Drysdaleら）で、アルゴリズムは線形SVMが圧倒的多数を占める。深層学習は**Erguzelらの人工ニューラルネットワーク1件のみ**で、検出領域と比べて技術的に一世代遅れている構図が可視化される。対象疾患もうつ病中心だが、Koutsourelisらの統合失調症、Rostamiらの単極性・双極性うつ病、Zandvakiliらのうつ病＋PTSD併存例が含まれ、応用範囲の広がりも示されている。

### Table 4：脳波（EEG）特徴量のまとめ（本文9ページ）

治療反応予測モデルに投入される脳波指標を、非専門読者向けに1行ずつ定義した5行の用語表である。①**コーダンス（cordance）**：ある周波数帯の絶対パワーと相対パワーをz変換して足し合わせた指標。②**コヒーレンス（coherence）**：2つの信号間の相関を測る指標で、文脈上は脳領域間の機能的結合の強さを表す。③**パワー（power）**：ある周波数帯における活動量の大きさ。④**シータ・ガンマ結合（theta gamma coupling）**：遅い波と速い波の位相・振幅の関係で、ワーキングメモリの障害と関連することが示されている。⑤**重み付き位相遅れ指数（wPLI）**：機能的結合の別の測り方。精神科医にとっては、次章の各研究が何を測っているかを解読するための必須の索引になる。

### Table 5：薬物治療反応予測（本文13ページ）

抗うつ薬などの薬物治療への反応を予測した研究11件を、特徴量・アルゴリズム・**検証方法**の3列で並べた表である。この表の白眉は検証列で、大半が「10分割交差検証」「一つ抜き交差検証（LOOCV）」といった**内部検証**にとどまることが一望できる。独立データでの外部検証を行ったのはBrowningらとChekroudらの2件のみ。手法は線形SVM（Peiら、Tianら）、木構造モデル（Jaworskaらのランダムフォレスト、Patelらの交互決定木、Chekroudらの勾配ブースティング）、ロジスティック回帰（Mumtazら）が中心で、深層学習はLinらの多層順伝播ネットワークとChangらのARPNetの2件である。特徴量は脳波、MRI／fMRI、遺伝マーカー（SNP）、音声、質問票・社会人口統計と多様である。

### Table 6：薬物治療反応予測研究の標本サイズ一覧（本文13ページ）

本総説で最も批判的な意味を持つ表で、著者・標本サイズ・「反応」の定義の3列からなる7行の表である。標本サイズはJaworskaら51例、Peiら98例、Linら421例、Changら121例、Carrilloら17例、Mumtazら34例、Khodayari-Rostamabadら22例。**Linらを除きすべて150例未満**であり、深層学習を語るには極端に小さい。もう一つの論点は反応の定義の不統一で、多くは「評価尺度の50%以上の低下」を採るものの、用いる尺度がMADRS、HDRS、HAM-D、QIDS、BDI-IIとばらばらであり、Khodayari-Rostamabadらに至っては「30%以上の低下」を採用している。定義が違えば数字は比較できない、という主張を1枚で示した表である。

## 3. 内容の評価（8項目）

**評価にあたっての前提**：本論文は原著研究ではなく総説（サーベイ）である。したがって「②サンプルサイズと選択基準」は**文献検索・文献選択の基準**として、「④統計分析の妥当性」は**研究間の異質性をどう統合したか**として読み替えて評価する。

### ① 研究デザイン

「検出（第2章）→ 診断カテゴリの再編（第2.3節）→ 治療反応予測（第3章）→ 課題と展望（第4章）」という構成は、臨床の時間軸（見つける・診断する・治療を選ぶ）に沿っており、精神科医と情報科学者の双方が同じ地図を共有できる設計になっている点は優れている。治療反応予測をrTMSと薬物療法に分けた点、および脳波指標の用語表（Table 4）を挟んだ点は、学際的読者への配慮として実効的である。**問題点**として、本稿は自らを「survey」と呼びながら、方法論のセクションを一切持たない。検索データベース、検索式、対象期間、組み入れ・除外基準、スクリーニング手続きのいずれも記載がなく、PRISMA等の報告指針にも準拠していない。結論部で「すべての論文を含められた保証はない」と正直に断ってはいるが、それは手順を記録しない理由にはならない。

### ② 文献検索・選択基準（一次研究の「サンプルサイズと選択基準」に相当）

引用文献は128報で、De Choudhuryらの2013年頃の初期テキスト解析から2022年のDeepCausalityまで約10年をカバーし、Nature Medicine級の代表的研究（Drysdaleらのバイオタイプ研究）から個別の工学系報告まで幅を持たせている。Table 1・2・3・5に整理された研究は計45件前後で、サーベイとしての射程は妥当である。**問題点**は選択の透明性がゼロに近いことである。どの検索語で何件がヒットし、何件を除外したのかが不明なため、著者の主張（外部検証が足りない・標本が小さい）を支持する研究が優先的に拾われた可能性を排除できない。また対象は事実上うつ病に限定されているのに、表題と本文はしばしば「精神疾患（mental health conditions）」と一般化して語られ、統合失調症の研究が1件だけ紛れ込むなど、範囲の設定がやや緩い。

### ③ 方法論の適切性

個々の研究の記述は具体的で、単に成績を並べるのではなく「なぜその数字が出たか」に踏み込んでいる点が本稿の美点である。たとえばHopmanらについて、訓練時精度約97%が保留テストセットでは平均約87%（95%信頼区間は100%〜約70%）に落ちることを明記し、Koutsourelisらの統合失調症研究では単施設のバランス精度85%が「一施設抜き」検証で71%に低下することを示す。Tianらでも79.41%が69〜71%に落ちる。こうした**汎化性能の崩れ方**を繰り返し提示する編集方針は、読者に正しい懐疑を植え付ける。**問題点**は、評価尺度の扱いが不揃いなことで、ある研究はF1スコア、別の研究は精度、また別の研究はAUCやバランス精度で語られ、著者らはそれらを同じ表・同じ段落に並べてしまう。特にTable 1・2のF1スコアは、クラス不均衡や検証設計が異なる研究間で直接比較できないにもかかわらず、並置によって比較可能に見えてしまう危険がある。

### ④ 研究間の異質性の統合（一次研究の「統計分析の妥当性」に相当）

本稿はメタ解析ではなく、統合値を算出していない。その代わり著者らは、異質性そのものを論点化する戦略を採る。具体的には「うつ病というラベルの決め方」（臨床評価・心理尺度・自己申告）で検出成績が系統的に変わること、「治療反応」の定義（尺度の種類と閾値50%か30%か、寛解か反応か）が研究ごとに異なり比較を不能にしていること、を繰り返し指摘する。Fried＆Nesseが STAR*D の3703例から**1030通りの症状プロファイル**を同定したという数字を引き、カテゴリ診断そのものの不均質性を統合不能の根源に位置づける論法も説得的である。**問題点**は、その指摘が定性的な記述にとどまることである。たとえば「自己申告ラベルの研究は成績が高い」という主張は、Table 1を見れば示唆的ではあるが、群別の平均F1や検定は一切示されていない。異質性を語りながら、異質性を測っていない。

### ⑤ 結果の信頼性と再現性

本稿が最も強く踏み込んだのがこの論点で、著者らは「調査した論文のうち、**患者アウトカムの改善を実証したものは一つもない**」と明言する。検証階層についてもHarrellの序列（最良反復値の報告 < k分割交差検証 < 反復k分割交差検証 < 外部検証 < 独立チームによる検証）を援用し、多施設データを用いたのは2件（Koutsourelisら、Tianら）、独立データで外部検証したのは2件（Browningら、Chekroudら）、無作為化比較試験は0件と数え上げる。Browningらでは精度約80%が独立データで60%へ、Chekroudらでは64.6%が59.6%へ低下した。**問題点**は、著者ら自身の集計も検証可能な形では提示されていないことで、45件前後の研究のうち何件がどの検証段階にあるかの一覧表は作られていない。再現性を論じる論文が、自らの数え上げの再現手順を示していないのは惜しい。

### ⑥ 結論の妥当性

「AIは精神科医療に入ってくるが、現時点で臨床導入に足る証拠はなく、次の一歩は無作為化比較試験である」という結論は、提示された証拠から素直に導かれ、過剰な一般化を避けている。Frölichらの「頑健な内部検証 → 独立データでの外部検証 → 臨床試験による実証」という3段階の道筋を引用して具体的な処方箋を示した点も実務的である。小標本が過学習と性能の誇張を招くこと（Buttonらの神経科学における検出力不足の議論、Widgeらの出版バイアスの指摘）を根拠に、公表文献は「現在の有効性の理論的上限」にすぎないと述べる一節は、本稿で最も価値のある警句である。**問題点**は、この慎重な結論と、本文各所での前向きな言い回し（「有望」「革命的」）との温度差である。また「臨床導入されていない」ことの理由を検証設計と標本サイズにほぼ帰し、規制、償還、実装科学、臨床ワークフローへの適合といった非技術的障壁への言及が乏しい。

### ⑦ 新規性

先行するレビューの多くが「検出」か「治療反応予測」のどちらかに閉じるのに対し、本稿は検出・診断（教師なし学習によるカテゴリ再編）・治療反応予測を一本の流れとして接続し、さらに検出系と予測系で技術の世代が食い違っている（前者はBERT等の最先端、後者はいまだSVM中心）という**分野内の非対称性**を明示した点に独自性がある。EEG特徴量の用語表（Table 4）や、特徴抽出に使える公開ソフトウェア（LIWC、COVAREP、openSMILE、Facial Action Units）の紹介も、実務的な付加価値である。**問題点**として、公開年（2023年3月受理）の時点でも大規模言語モデルの臨床応用の議論は始まっており、本稿の言語モデルの記述はBERTで止まっている。また因果AI、ベイジアンニューラルネットワークによる不確実性定量化、脳マッピングという将来展望の3本柱は、いずれも1〜2の事例（DeepCausalityによる薬物性肝障害の20因子同定など）に依拠しており、提案としてはやや薄い。

### ⑧ 臨床的意義

精神科医にとって本稿の実践的な価値は、「AIうつ病診断」を掲げる商用サービスや論文を評価するための**チェックリスト**として使える点にある。すなわち、①正解ラベルは臨床診断か自己申告か、②標本は何例か（150例未満なら警戒）、③検証は内部か外部か多施設か、④「反応」の定義は何の尺度の何%低下か、⑤モデルは予測の確信度を出力するか、の5点である。rTMSの反応率が約30%〜46%、寛解率が約19%〜30%にとどまるという数値と、抗うつ薬の初回寛解率25〜33%・複数試行後67%という数値も、患者説明にそのまま使える。**問題点**は、実際の外来でこれらのモデルを使う道筋が示されていないことである。脳波やfMRIの前処理を要する予測器は日常診療の資源制約と噛み合わず、費用対効果、説明可能性の欠如による説明責任、誤分類が患者に与える不利益（偽陽性による不要な治療）といった臨床倫理上の論点はほとんど扱われていない。

## 4. 整合性の最終チェック
