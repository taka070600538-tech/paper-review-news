# 気分障害治療における精神薬理学と精神療法の統合——併用療法と単独療法の比較分析 精読ノート

> 役割：日本トップクラスのサイエンスコミュニケーターとしての精読プロンプト（デフォルトフォーマット）に基づく分析結果

## 1. 概要（500字以内）

うつ病（大うつ病性障害、MDD）と双極性障害の治療では、薬（抗うつ薬・気分安定薬・抗精神病薬）と精神療法（CBT、対人関係療法IPT、弁証法的行動療法DBT）のどちらを使うか、あるいは両方を組み合わせるかが長く議論されてきた。本研究はパキスタン・カラチのジンナー大学院医療センター（JPMC）などに通う18〜65歳の気分障害患者600名を、薬物療法単独・精神療法単独・併用の3群（各200名）に「ランダムに分けた」とし、12週間の治療後に抑うつ尺度HAM-Dの推移、6か月間の再発率、治療継続率、副作用、満足度、費用を比べた。12週時点のHAM-Dは併用群6.8で、薬物群11.7・精神療法群10.5より低く、再発しなかった人は併用群74%（薬物52%、精神療法46%）、治療完遂率も併用群87%（69%、72%）と最良だった。一方で6か月の費用は併用群が2,000ドルと最も高い。著者らは併用療法の優越性と、費用・アクセスの壁を下げる政策の必要性を主張する。ただし割付方法、統計検定の結果、診断別の内訳などの記載がほぼなく、数値の内部矛盾も多いため、結論は慎重に受け止める必要がある。

3群（各200名）の年齢・性別・学歴・就労・婚姻状況を並べた表。平均年齢は薬物群42.3歳（SD 10.5）、精神療法群40.7歳（9.8）、併用群41.5歳（10.2）、男性は55%・50%・52%。学歴は高卒約3割・学士約半数・修士約4分の1、就労約6割、既婚5割強と3群はよく似ている。ただし割合はすべて整数の概数で、検定結果（群間差のp値）は示されていない。最も重要な「MDDと双極性障害の人数比」や服薬歴・罹病期間はこの表に含まれず、背景の比較可能性を十分に確かめられない。

### Figure 1：治療群別の年齢分布

3群の年齢を色分けした重ね合わせのヒストグラム（度数分布の棒グラフ）。横軸は年齢（おおむね20〜70歳）、縦軸は人数で、いずれの群も40歳前後を頂点とする山型の分布を示す。本文は「正規分布で外れ値はない」と述べるが、組み入れ基準は18〜65歳であるのに70歳を超える位置に棒が見える点は、基準との整合性に疑問を残す。3色が重なって読み取りにくく、この図が研究の結論に与える情報はほとんどない。

### Table 2：参加者の治療前の臨床的特徴

治療開始前の症状の重さを比べた表。HAM-D（ハミルトンうつ病評価尺度、医師が面接で付ける抑うつの重症度スコア）は21.4±5.2／20.8±4.9／21.2±5.0、YMRS（ヤング躁病評価尺度）は14.7／13.9／14.2、BAI（ベック不安尺度）は19.3／18.7／19.1、入院歴は40%／38%／39%、気分障害の家族歴は55%／53%／54%。3群はよく揃っている。ただしYMRSは双極性障害の参加者のみで測ったと本文にあるのに対象人数が示されず、本文ではYMRS併用群を「14」と書くなど表（14.2）と細かな食い違いもある。

### Figure 2：治療前の抑うつ重症度（HAM-D）

Table 2のHAM-D平均値を3本の棒で示した棒グラフ。3群ともおよそ21点前後で、見た目にも差はない。HAM-Dで21点前後は一般に「中等症〜重症」の境目にあたり、ある程度しっかりした抑うつを持つ集団であることがわかる。ただし誤差棒（ばらつきの幅）が描かれていないため、群間差がないことを図だけから判断することはできず、情報量はTable 2と同じである。本文ではこの図の説明文が「2群の比較」と書かれており、3群比較との記述の不一致もある。

### Table 3：時間経過による症状の軽減（HAM-D平均値）

治療前・6週・12週のHAM-D平均値。薬物群21.4→14.8→11.7、精神療法群20.8→13.9→10.5、併用群21.2→11.2→6.8。併用群は12週で約14点下がり、寛解の目安とされることの多い「7点以下」に平均値が入っている点が本研究の目玉である。ただし各時点の標準偏差、信頼区間、群間比較の検定結果（ANOVAを行ったと方法に書かれているのにF値・p値）が一切示されていない。また抑うつ症状の尺度を双極性障害の参加者にどう適用したのか、脱落者をどう扱ったのかも不明である。

### Figure 3：時間経過による症状の軽減（HAM-D）

Table 3の数値を折れ線グラフにしたもの。3本の線は開始時にほぼ同じ位置（約21点）から始まり、6週・12週と右下がりに進むが、併用群（緑の破線）だけが傾きが大きく、12週で約7点まで下がる。薬物群（青）と精神療法群（赤）はほぼ平行に推移し、12週で10〜12点に留まる。3時点しかない点を直線で結んでいるため、途中経過の形は推測にすぎない。ばらつきを示す誤差棒がなく、差の大きさが統計的に意味のあるものかは図から読み取れない。

### Table 4：6か月追跡期間中の再発率

「3か月以内の再発」が18%／20%／8%、「6か月以内の再発」が30%／34%／18%、「再発なし」が52%／46%／74%。各列を足すとちょうど100%になるため、「6か月以内」は実際には「3〜6か月の間の再発」と読むしかなく、累積の再発率は薬物48%・精神療法54%・併用26%となる。ところが本文とFigure 4は6か月再発率を30%／34%／18%として扱っており、表の構造と本文の解釈が一致しない。さらに本文はこの節で「アルコールの再発」「断酒を維持した割合」と書いており、気分障害の再発とは別物の言葉が混入している。

### Figure 4：6か月間の再発率

3群の6か月再発率を棒グラフで示したもの。薬物群30%、精神療法群34%、併用群18%で、併用群の棒が明らかに低い。Table 4の「6か月以内の再発」の行だけを抜き出して描いていると考えられ、3か月以内の再発を含む累積値（48%／54%／26%）ではない可能性が高い。どちらの読み方でも「併用が最も低い」という順位は変わらないが、実際の数値の大きさは読み手の解釈によって大きく変わる。再発の定義（HAM-Dの何点以上か、入院か）も示されていない。

### Table 5：群別のアドヒアランス（治療継続）

治療完遂は69%／72%／87%、1〜2回欠席は15%／12%／8%、3回以上欠席は10%／9%／3%、治療中断は6%／7%／2%（各列の合計は100%）。アドヒアランス（患者が治療を指示どおり続けること）は併用群が最も良い。考察では併用群の87%に「p<0.05」と付されているが、どの検定で何と比べたのかは書かれていない。また薬物単独群は精神療法のセッションを受けないはずなのに「セッション欠席」の割合が示されており、何を数えたのかが不明である。

### Figure 5：群別のアドヒアランス率

Table 5の「治療完遂」の割合を棒グラフにしたもの。薬物群約69%、精神療法群約72%、併用群約87%で、併用群の棒が最も高い。単独療法の2群の差は小さく、併用群だけが15ポイント以上抜きん出ている。一般に併用群のほうが通院や面接の回数が多く負担が大きいはずであり、完遂率が最も高いという結果はそれ自体興味深いが、割付の偏りや自己選択の影響（治療に熱心な人ほど併用を選ぶ）で説明できる可能性がある。誤差棒や信頼区間は描かれていない。

### Table 6：薬物療法群と併用群で報告された副作用

薬物群／併用群の順に、体重増加32%／28%、性機能障害25%／22%、胃腸症状18%／14%、眠気20%／17%、感情の平板化（emotional numbness）15%／12%。精神療法単独群は薬を使わないため「N/A」。併用群のほうが3〜4ポイントずつ少ないが、検定は示されていない。同じ方針の薬を使っているのに副作用が少ない理由として、著者は精神療法が副作用の「感じ方」を和らげる可能性を挙げる。ただし副作用の評価方法（自己申告か、評価尺度か）は不明で、本文では感情の平板化を「emotional drudgery」と別の言葉で書いている。

### Figure 6：治療群別に報告された副作用

Table 6の5種類の副作用を、薬物群（青）と併用群（緑）の2本の棒で並べた棒グラフ。すべての項目で青の棒が緑の棒をわずかに上回る。最も多いのは体重増加（約3割）で、抗うつ薬や気分安定薬、非定型抗精神病薬に典型的な副作用である。差はどれも数ポイントと小さく、200名規模の比較では偶然の範囲に収まる可能性が高い。本来は薬の種類・用量ごとの内訳が必要だが、図にも表にもそれはない。

### Table 7：患者満足度スコア（1〜10点）

薬物群／精神療法群／併用群の順に、総合満足度6.5／7.2／8.9、効果の実感6.2／7.0／9.0、他者への推奨意向6.0／6.9／8.7、アドヒアランスの容易さ5.8／7.1／9.1。すべての項目で併用群が最も高く、薬物群が最も低い。本文は差を「有意に高い」とするが、検定結果もばらつきも示されていない。特に、面接と服薬の両方が必要な併用群で「続けやすさ」が9.1と最高になっている点は直感に反し、盲検化されていない自己評価の偏りが入りやすい指標であることに注意が要る。

### Figure 7：治療群別の患者満足度

Table 7の「総合満足度」を3本の棒で示した棒グラフ。薬物群約6.5、精神療法群約7.2、併用群約8.9と、右肩上がりに並ぶ。薬物群が最も低い理由として著者は副作用を挙げるが、それを直接検証した分析はない。満足度の質問票がどのような妥当性の確認された尺度なのか（独自の質問なのか）は記載されておらず、方法の章に書かれた質的インタビュー（各群20名＋専門家10名）の結果もどこにも報告されていない。

### Table 8：6か月間の治療費（米ドル）

薬剤費は薬物群800ドル・併用群800ドル、面接（セッション）費は精神療法群1,200ドル・併用群1,200ドル、総額は800／1,200／2,000ドル。併用群は単純に両方を足した額である。ところが本文の同じ節では、薬物単独を「1,800ドル」、精神療法単独を「2,100ドル」と文章で書いており、表と大きく食い違っている（考察では表と同じ800／1,200ドル）。費用の算出根拠（誰の負担か、どの価格表か）も示されず、効果1単位あたりの費用（費用対効果）の分析は行われていない。

### Figure 8：6か月間の治療費

Table 8の総費用を棒グラフで示したもの。薬物群約800ドル、精神療法群約1,200ドル、併用群約2,000ドルと階段状に高くなる。併用療法は最も効果が高い一方で最も高価であり、薬物単独の約2.5倍の費用がかかることが一目でわかる。本文は「効果と費用の対比を示す」と述べるが、図に効果の指標は含まれておらず、費用対効果比（例：再発1件を防ぐのに必要な追加費用）は計算されていない。パキスタンの所得水準を考えると、この額の負担感についての議論も必要である。

## 3. 8項目評価

本論文は著者が「比較研究（ランダム割付）」と位置づける原著研究であるため、一次研究の基準で評価する。

### ① 研究デザイン

薬物単独・精神療法単独・併用の3群を並行して比べ、12週の治療効果と6か月の再発まで追う構成は、臨床的な問いに素直に答える設計である。しかし記述が自己矛盾している。方法では「横断的サンプル600名を3群にランダムに分けた」とあり、横断研究（1時点の調査）と前向き介入試験が混同されている。さらに組み入れ基準は「すでに薬物療法・精神療法・併用を受けていた人」であり、限界の章では「精神療法を選ぶ人は薬だけを選ぶ人と異なる可能性」を認めている。実態は患者の選択に基づく観察研究の可能性が高く、ランダム化の方法、割付の隠蔽、評価者の盲検化も記載がない。

### ② サンプルサイズと選択基準

各群200名、計600名という規模は、単施設の精神科臨床研究としては大きい。18〜65歳、DSM-5でMDDまたは双極性障害と診断、統合失調症や物質使用の合併を除外という基準も一般的である。問題は、600名の根拠となる検出力計算（必要な人数の見積もり）がないこと、MDDと双極性障害の人数比が一切報告されていないことである。うつ病と双極性障害では薬も経過もまったく異なるため、両者を混ぜたまま1本のHAM-Dで比べると、群ごとの診断構成の違いだけで結果が変わり得る。募集期間、スクリーニング数、除外数を示す流れ図もない。

### ③ 方法論の適切性

HAM-D、BDI-II、YMRS、BAIという標準的な尺度を使い、治療前・6週・12週に評価した点は妥当である。しかし、薬は「SSRIかSNRI」「リチウムかバルプロ酸」「必要に応じ抗精神病薬」、精神療法は「CBT・IPT・DBTを患者と治療者の判断で」と、介入の中身が群内でばらばらで、用量や治療者の資格、治療の忠実度（マニュアルどおりに行われたか）の確認もない。主要評価項目としたBDI-IIの結果は一度も報告されず、方法に書かれた回帰分析と質的インタビューの結果も欠落している。再発の定義も示されていない。

### ④ 統計分析の妥当性

方法ではANOVA（3群以上の平均の比較）、対応のあるt検定（同じ人の前後比較）、重回帰分析を行ったと書かれているが、結果の章にはF値・t値・p値・効果量・信頼区間が一つも示されない。唯一の検定表記は考察の「87%, p<0.05」だけで、何と何を比べたのかも不明である。さらにHAM-Dの経時変化には本来、反復測定分析や混合効果モデルが適しており、脱落者の扱い（ITT解析か完遂者のみか）も記載がない。再発率のような割合の比較にはカイ二乗検定や生存時間分析が必要だが、それも行われていない。

### ⑤ 結果の信頼性と再現性

数値の内部矛盾が多く、信頼性には重大な疑問がある。費用は本文で1,800ドル・2,100ドル、表で800ドル・1,200ドルと食い違い、再発率はTable 4の構造上累積なら48%／54%／26%のはずなのに本文は30%／34%／18%として扱う。再発の節には「アルコールの再発」「断酒の維持」という、別の研究から流用されたような表現が混入し、文献レビューにも「乳がん」という無関係な語が現れる。本文中の引用（Keller 2018、Sambetti 2017、Linehan 2017など）の多くが参考文献リストに存在しない。割合はすべてきれいな整数で、元データや試験登録も公開されておらず、第三者による検証はできない。

### ⑥ 結論の妥当性

「併用療法は単独療法より症状軽減・再発予防・アドヒアランス・満足度のすべてで優れる」という結論は、既存のメタ解析（Cuijpersらの研究など）とも方向性は一致する。しかし本研究のデータからその結論を導くには、ランダム化の実在性、検定結果、診断別の解析がいずれも欠けている。自己選択の可能性を著者自身が認めている以上、「併用だから良かった」のか「治療に意欲的な人が併用を選んだ」のかは区別できない。副作用が併用群で少ない理由を「精神療法が副作用の知覚を減らすため」とする説明も、検証されていない推測にとどまる。

### ⑦ 新規性

併用療法が単独療法を上回るという知見自体は、欧米の多数のランダム化比較試験とメタ解析ですでに確立しており、新しい主張ではない。本研究の独自性は、南アジア（パキスタン）の臨床現場で、症状・再発・アドヒアランス・副作用・満足度・費用を一つの研究で同時に比べた点にある。低中所得国のデータは不足しているため、その意味では価値がありうる。ただし、双極性障害とうつ病を分けて解析していないこと、費用対効果の分析をしていないことから、既存知見に新たに加わる情報は限られる。

### ⑧ 臨床的意義

「薬だけ」「カウンセリングだけ」に頼らず、両方を組み合わせることで再発や治療中断を減らせる可能性を示した点は、臨床の直感と合致し、患者説明の材料にもなりうる。費用が薬物単独の約2.5倍になるという提示も、医療政策上の議論（精神療法への公的補助、遠隔医療による提供など）につながる。しかし本研究単独を根拠に治療方針を変えるべきではない。方法と統計の記載不足、数値の矛盾、著者の専門分野（潜水医学・法医学・薬理学）が精神医療と離れていることを踏まえ、併用療法の推奨はCANMATなどのガイドラインや質の高いメタ解析に基づいて判断するのが妥当である。
