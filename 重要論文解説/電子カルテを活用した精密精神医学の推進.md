# 電子カルテを活用した精密精神医学の推進 精読ノート

## 概要

精密精神医学(precision psychiatry)とは、データにもとづいて一人ひとりに合った精神科医療を届けようとする考え方で、その道具が「個人ごとのリスクを数字で示す臨床予測モデル」である。本総説は、日常診療で自然にたまる電子カルテ(EHR)のデータが、このモデルを作る・確かめる・現場で使う土台になると主張する。

著者らは、ケアの流れの異なる段階を担う、外部検証(作った場所とは別の病院群のデータで性能を確かめること)を済ませた4つのモデルを紹介する。①二次精神科を受診した人から精神病の発症リスクを見つける「診断横断的リスク計算機」、②早期介入サービス(EIP)終了後12か月以内の入院を予測するモデル、③初回エピソード精神病(FEP)の若者のメタボリックシンドロームを予測する PsyMetRiC、④統合失調症・双極性障害の1年以内の自殺を予測する OxMIS である。外部検証での判別能(C統計量)は0.70〜0.85で、較正(予測と実際の一致)もおおむね保たれ、意思決定曲線分析などで臨床的有用性が示された。

一方で、EHR の相互運用性の欠如、情報ガバナンスの複雑さ、自然言語処理(NLP)の精度と言語の偏り、既存の医療格差がモデルに入り込む危険、グローバルサウスでの検証の欠如が課題として挙げられる。今後はメタ解析・研究データ・バイオマーカーを EHR と組み合わせることで性能を上げられると結んでいる。

## FigureとTableの解説

本論文には Figure はなく、本文中の囲み記事 Box 1・Box 2 と、Table 1 の計3つの図表がある。

### Box 1 臨床予測モデルに EHR データを使う長所と限界

長所は5つ。①実世界のデータ(研究の検査に来られるほど元気な人だけでなく、地域の全患者を反映)、②日常的に集まる(追加の手間や費用がなく、医師に特定の結果を記録させることで生じる「結果の汚染」も避けられる)、③詳細(構造化データに加え、NLP=コンピュータで文章を読み取る技術で診療録の自由記述から症状や物質使用を取り出せる)、④すぐ使えるビッグデータ(EU では90%が EHR を導入)、⑤数年単位の長い追跡。限界も5つ。①既存の偏りをそのまま映す(米国の医療費予測モデルが黒人患者を系統的に不利に扱った例)、②記録が標準化されておらず欠損が多い、③病気の仕組みではなく臨床情報を記録するためのもの、④経済的に恵まれない人ほど EHR にアクセスできず格差を広げうる、⑤情報漏えいが偏見・保険料・就職に響くリスク。

### Box 2 予測モデルの性能を評価する3つの観点

①判別能(discrimination):結果が起きる人と起きない人をどれだけ見分けられるか。Harrell の C(無作為に選んだ「起きた人」が「起きなかった人」より高いリスク点を取る確率)で測る。0.5ならコイン投げと同じで、どれだけあれば十分かは場面と代替手段しだいで、固定の基準はない。②較正(calibration):予測した確率と実際の発生割合の一致度。判別がよくても絶対リスクがずれていれば、患者に誤った数字を伝えたり、不要な介入(過大評価)や必要な治療の見落とし(過小評価)を招く。③臨床的有用性(clinical utility):正味の利益(net benefit)で測り、「全員に介入」「誰にも介入しない」「現行の標準」と比べる。検査必要数(NNT:number needed to test)が10なら「見逃し1回は不要な介入の9倍悪い」と見なす前提で、その幅を変えながら得失を比べる(意思決定曲線分析)。

### Table 1 4つの事例の背景・性能・実装状況のまとめ

4事例を、対象集団・目的・版・検証地域・判別能・較正・NNT・実装・既存の代替モデルの列で一覧にしている。事例1(精神病リスク):基本版は英米で C=0.73–0.79(米国で民族の欄が欠け補完した場合は0.68)、NNT 1–99、1年間の前向き実装研究で臨床医の対応率77%。NLP 版は英国で C=0.85、較正に大きな問題なし。事例2(EIP 退所後の入院):英国で C=0.70、低〜中リスク帯で過小・過大評価、NNT 2–5、実装はまだ。事例3(PsyMetRiC):完全版 C=0.72–0.75、血液検査なしの部分版 C=0.66–0.71(英・西・スイス)、高リスク帯でやや較正ずれ、NNT 5–35。事例4(OxMIS):フィンランド・スウェーデンで C=0.70–0.71、予測5%超で過大評価(標本の1.3%)、臨床医の93%が実用的と回答。右端の列は、比べられる外部検証済みの代替モデルがほとんどないことを示す。

## 8項目評価

本論文は総説(新しいデータを集めないナラティブレビュー)なので、一次研究向けの基準は「事例の選び方」「引用した性能指標の扱い方」などレビューの文脈に読み替えて評価する。

### ①研究デザイン(→総説の組み立てに読み替え)

「問題→アプローチ→実装の利点と課題」という同じ型で4事例を並べ、Box と Table で横断的に比べられるようにした構成はわかりやすい。精神病の発見、再入院、身体合併症、自殺と、ケアの流れの異なる段階を選んだ点も、EHR の守備範囲の広さを示すのに効果的である。ただし体系的レビューではなく、文献検索の方法や選択基準が示されていない。事例は「外部検証で良い成績を示し、実装に向いていそうなもの」として著者が選んでおり、成功例だけを見せる構成になっている。

### ②サンプルサイズと選択基準(→事例の選び方に読み替え)

紹介された事例の標本規模は、事例1の開発33,820人・米国検証243万人から、事例2の開発831人(79件)、事例3の開発651人(109件)まで大きく幅がある。事例2・3は事象数が少なく、著者自身も事例2の過学習の可能性を認めている。最大の問題は事例の選び方で、4モデルはいずれも著者自身が開発に加わったもの(事例1は Fusar-Poli・Stahl・McGuire、事例2は Whiting、事例3は Perry・Osimo、事例4は Fazel が原著の著者)であり、Fazel は利益相反の欄で OxMIS の開発者であると開示している。自分たちのモデルを中心に選んだ点は、評価の中立性に疑問を残す。

### ③方法論の適切性(→紹介したモデルの作り方の妥当性に読み替え)

4モデルとも文献にもとづいて予測因子を事前に選び、Cox 回帰・ロジスティック回帰・罰則付きロジスティック回帰といった透明性の高い手法を使い、外部検証まで行っている点は方法論的に堅実である。TRIPOD などの報告ガイドラインに沿うかは本文では触れられていない。事例1では「民族」「性別」のような代理指標を予測因子に含めており、Box 1 で自ら警告した「代理指標による偏り」と緊張関係にあるが、その点の検討はない。NLP 版や再帰型ニューラルネットワークによる動的更新版は、性能が上がる一方で解釈しにくくなる問題を、本文の最後で一般論として触れるにとどまる。

### ④統計分析の妥当性(→引用した数値の扱い方に読み替え)

判別・較正・臨床的有用性の3点を一貫して報告しており、C統計量だけで性能を語りがちな分野の中では評価の枠組みが適切である。ただし較正は「おおむね良好」「一部ずれ」といった言葉での要約が多く、較正の傾きや切片といった数値は示されていない。NNT の範囲も事例ごとに前もって選んだ上限(Table 1 の注 a)があり、事例間で単純に比べられない。また Table 1 の文献番号(88–94、106、107)は文献リスト(105番まで)と対応しておらず、107番は存在しない。本文での事例の出典確認がしにくい、編集上の誤りである。

### ⑤結果の信頼性と再現性(→紹介した結果の頑健さに読み替え)

事例1は英国の複数地域と米国の保険データ、事例3は英国・スイス・スペイン、事例4はスウェーデン・フィンランドで外部検証され、別の場所でも性能が保たれる「持ち運べる性能」の証拠がある。3モデルがウェブ上で無料公開されており、第三者が試せる点も再現性に寄与する。一方、事例2は英国内の1施設での検証しかなく、NLP 版事例1も同じ SLaM 内での検証にとどまる。全モデルがグローバルサウスで未検証であることは著者自身も認めており、欧州の国民皆保険制度に偏った証拠である。

### ⑥結論の妥当性

「EHR は予測モデルの開発・検証・実装の便利な土台であり、すでに実装に近いモデルがある」という結論は、紹介した事例の範囲では支持される。しかし、実際に前向きの実装研究まで進んだのは事例1だけで、事例4は臨床医への意見調査(実際の自殺データは取っていない)、事例2・3は実装未着手である。「患者の転帰が改善した」という証拠はどの事例にもなく、費用削減額も別研究からの推計である。「近い将来の実装に好位置」という表現は、証拠の段階に比べてやや楽観的である。

### ⑦新規性

個々のモデルはすでに発表済みで、新しい知見はない。新しさは、精神科領域で外部検証まで済んだ EHR ベースのモデルを、ケアの流れに沿った4つの使い道として並べ、判別・較正・有用性という同じ物差しで比べた点にある。臨床試験の参加者選び(リスクの高い人を集めて必要標本数を減らす)や脱落者の追跡に EHR を使うという提案、PETRUSHKA 試験のようにメタ解析と EHR を組み合わせる方向性の紹介は、研究者にとって示唆的である。

### ⑧臨床的意義

精神科医にとっての実用的な価値は大きい。精神病の発症リスク、EIP 終了後の入院、抗精神病薬に伴う代謝異常、自殺のいずれも日常診療で判断を迫られる場面であり、PsyMetRiC や OxMIS はウェブで無料で使える。特に、一般人口向けの心血管リスク計算が精神病の若者のリスクを大きく過小評価するという指摘は、身体管理の見直しに直結する。ただし、日本のように EHR が施設ごとに異なり、診療情報の二次利用の仕組みが英国や北欧ほど整っていない環境では、そのまま導入するのは難しい。英国人中心のデータで作ったモデルを日本人に当てはめる前に、再較正と検証が必要である。
