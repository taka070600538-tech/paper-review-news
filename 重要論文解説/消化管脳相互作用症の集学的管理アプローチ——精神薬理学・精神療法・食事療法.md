# 消化管脳相互作用症の集学的管理アプローチ——精神薬理学・精神療法・食事療法 精読ノート

## 概要(500字以内)

本総説は、腸脳相互作用異常症(DGBI；過敏性腸症候群や機能性ディスペプシアを含む慢性消化器症候群)の病態生理、精神科的併存疾患、および治療選択肢(薬物療法・精神療法・食事療法)を統合的にまとめたナラティブレビューである。DGBI患者の約半数に不安症などの精神科的併存疾患を認め、島皮質・扁桃体・前頭前野を含む情動・認知回路の機能異常が症状の中核病態とされる。薬物療法では三環系抗うつ薬(TCA)やSSRI/SNRIなどの「神経調節薬」が中等度の有効性を示し、認知行動療法(CBT)や消化管指向催眠療法などの脳腸行動療法(BGBT)は薬物療法に匹敵する有効性(NNT4〜5)を持つ。低FODMAP食などの食事療法も症状軽減に寄与するが、過度な除去食は回避・制限性食物摂取症(ARFID)のリスクを高めうる。著者らはKeeferらの枠組みに基づき、患者の主症状(消化器症状・精神症状・疾患特異的不安)に応じて治療モダリティを組み合わせる集学的アプローチを提案している。

## Figure・Tableの解説

### Figure 1(9ページ)：腸脳軸調節因子の概念図
中心に「腸脳軸調節因子(Gut-brain axis regulators)」を置き、周囲に心理的要因・精神療法・遺伝要因・社会的要因・食事・薬理学・マイクロバイオームの7領域を円環状に配置した概念図。心理的要因、食事、マイクロバイオームなど「比較的介入しやすい因子」と、遺伝要因のように介入が困難な因子を区別しつつ、薬理学的治療と精神療法を腸脳軸に直接作用する2つの治療戦略として位置づけている。BioRenderで作成された図であることが明記されている。

### Table 1(5ページ)：DGBIに対する薬理学的介入(神経調節薬)を検討した主要研究9件の一覧
プラセボ対照二重盲検RCTを中心に、アミトリプチリン・イミプラミン・シタロプラム・エスシタロプラム・デュロキセチン・ブスピロン・ガバペンチン・新規α2δリガンドなど多様な薬剤のIBSまたは機能性ディスペプシアに対する有効性を対比した表である。三環系抗うつ薬(アミトリプチリン・イミプラミン)はプラセボに比べ有意な症状改善を示した試験が複数ある一方、SSRIのシタロプラムや新規α2δリガンドはプラセボと有意差を認めなかった試験もあり、薬剤クラス・個別薬剤間で効果に一貫性がないことを示す一覧となっている。

### Table 2(7ページ)：DGBIに対する精神療法的介入を検討した主要研究6件の一覧
消化管指向催眠療法、標準的CBT/簡易接触型CBT、情動認識表出訓練(EAET)、電話/ウェブ配信型CBTなど、IBSまたは炎症性腸疾患寛解期のIBS型症状を対象としたRCTが並ぶ。多くの研究で介入群が対照群(支持療法・待機リスト・通常ケア)に比べ有意な症状改善を示した一方、Hoekmanら(2021)の炎症性腸疾患寛解期患者を対象とした研究では催眠療法と標準治療の間に主要評価項目で有意差が認められず、疾患背景によって精神療法の効果に差が生じうることを示している。

## 内容についての8項目評価

本論文は新規データを収集した原著研究ではなく、既存文献を著者の専門性に基づいて統合したナラティブレビューである。そのため以下の評価では、「サンプルサイズ」「統計分析の妥当性」といった一次研究向けの基準を、「文献検索・選択基準の質」「既存エビデンスの定性的統合の妥当性」という観点に読み替えて評価する。

**①研究デザイン(文献検索・選択基準の質に読み替え)**：著者らは5つの構造化されたPubMed検索式(神経生理学的機序・心理的併存疾患・薬物療法・精神療法・食事療法の5領域)を用いたと明記しており、検索の枠組み自体は体系的である。しかし最終的な文献選択は「著者の臨床経験と研究専門性に基づく」と明記されており、PRISMAに準拠した系統的レビューではなく、著者の主観的判断を伴うナラティブレビューである点は限界として認識すべきである。

**②サンプルサイズと選択基準(採用文献の質と代表性に読み替え)**：Table1・2に示された個別研究のサンプルサイズは17例(ブスピロンのクロスオーバー試験)から558例(電話/ウェブ配信CBT試験)まで幅があり、多くのプラセボ対照RCTは50〜300例程度の中規模試験である。全体としてRCTを中心に引用されている点は妥当だが、新興治療(低用量ナルトレキソン・経皮的迷走神経刺激・便微生物移植)については単一のオープンラベル試験や動物実験に基づく記述もあり、エビデンスレベルに大きな差がある。

**③方法論の適切性**：脳腸軸の神経生理学的機序、精神科的併存疾患の疫学、薬物療法・精神療法・食事療法という4つの異なる領域を単一のレビューに統合する構成は、DGBIの生物心理社会モデルを反映した適切な設計である。ただし、系統的レビューにおける文献検索式・除外基準・スクリーニングプロセスの詳細(PRISMAフローチャート等)は本文中に示されておらず、再現性の検証は困難である。

**④統計分析の妥当性(エビデンス統合の妥当性に読み替え)**：本稿自体は独自のメタ解析を行っておらず、既存のメタ解析・システマティックレビューの結果(オッズ比・相対危険度・NNTなど)を引用する形で統合している。引用された効果量(TCAの相対危険度0.66〜0.70、CBTのNNT≈4等)は出典が明記されており検証可能だが、異なるメタ解析間の異質性(対象疾患・アウトカム指標の違い)については十分な議論がなされていない。

**⑤結果の信頼性と再現性**：TCA・SSRI・CBT・消化管指向催眠療法の有効性については複数の独立したメタ解析・大規模RCT(Ford 2023のATLANTIS試験n=463等)で一貫した結果が得られており、再現性は比較的高い。一方、新興治療(低用量ナルトレキソン、経皮的迷走神経刺激、便微生物移植)は単一の小規模試験に基づく記述が多く、再現性の検証は今後の課題として本文中でも明記されている。

**⑥結論の妥当性**：DGBIを生物心理社会的疾患と捉え、薬物療法・精神療法・食事療法を症状の性質に応じて組み合わせるべきという結論は、引用されたエビデンスの範囲内で妥当である。Keeferらの治療振り分けアルゴリズム(主症状に基づく紹介先の選択)を採用している点も、臨床実装上合理的である。

**⑦新規性**：個々の治療モダリティ(神経調節薬、CBT、催眠療法、FODMAP食)自体は既に確立された知見であり、本稿の新規性は個別の発見にあるのではなく、これらを統合し、症状表現型に応じた治療振り分けの実践的枠組みとして提示した点にある。網羅性は高いが、独自の一次データは提示されていない。

**⑧臨床的意義**：精神科医・消化器内科医・栄養士が連携すべき具体的な場面(消化器症状優位例は神経調節薬を先行、精神症状優位例は精神科への早期紹介等)を示しており、実地臨床への応用可能性は高い。特に除去食によるARFIDリスクへの言及とNIASスクリーニングツールの紹介は、見落とされやすい実務上の注意点として有用である。ただし本稿で言及される研究の大半が欧米高所得国の集団に基づくものであり、非西洋圏や医療資源の限られた環境への一般化可能性には限界がある、と著者ら自身がLimitationsで認めている。
