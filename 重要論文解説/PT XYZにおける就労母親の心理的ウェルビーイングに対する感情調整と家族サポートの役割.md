# PT XYZにおける就労母親の心理的ウェルビーイングに対する感情調整と家族サポートの役割 精読ノート

## 概要（500字以内）

本論文は、インドネシアの一企業（PT XYZ）に勤務する就労母親41名を対象に、感情調整（Emotion Regulation Questionnaire）と家族サポート（MSPSS家族下位尺度）が心理的ウェルビーイング（Ryffの心理的ウェルビーイング尺度）に与える影響を重回帰分析で検証した原著研究である。結果、家族サポートは心理的ウェルビーイングに有意な正の効果を示した（β=0.702, p=0.046）一方、感情調整は有意な効果を示さなかった（β=−0.402, p=0.164）。両変数を同時投入したF検定も有意水準に届かず（F=2.989, p=0.062）、決定係数R²は0.136にとどまり、モデルの説明力は限定的であった。著者らはこれをRyffの多次元的ウェルビーイング理論に基づき、自己受容や人生の目的など他の要因の寄与が大きいためと解釈し、過度な一般化を避けて結論を控えめに述べている点は評価できる。ただし対象は単一企業・N=41という小規模サンプルであり、家族サポートの有意性（p=0.046）も0.05にわずかに届いた程度で頑健性には注意が必要である。

## Tableの解説

本文中にFigureは存在せず、Table1〜14の合計14個のTableで構成されている。

### Table 1：妥当性・信頼性検定結果（5ページ）
感情調整（X1・10項目）、家族サポート（X2・4項目）、心理的ウェルビーイング（Y・15項目）の各項目について、算出相関係数（r値）を臨界値（r表=0.361, 有意水準5%）と比較し、すべて妥当（Valid）と判定。クロンバックのα係数はX1=0.776、X2=0.915、Y=0.809で、いずれも信頼性基準（≧0.60）を満たす。

### Table 2：記述統計量（6ページ）
N=41の各変数の最小値・最大値・平均・標準偏差。感情調整（平均28.68, SD3.061）、家族サポート（平均12.27, SD2.550）、心理的ウェルビーイング（平均52.00, SD5.745）。

### Table 3：区間距離算出の公式（6ページ）
平均値±1標準偏差を基準に、各変数を「低・中・高」の3カテゴリーに分類するための計算式を示した表（データではなく分類基準の定義）。

### Table 4：感情調整の度数分布（6ページ）
低群6名（14.6%）、中群27名（65.9%）、高群8名（19.5%）。大多数が中程度の感情調整能力を持つ。

### Table 5：家族サポートの度数分布（6ページ）
低群5名（12.2%）、中群28名（68.3%）、高群8名（19.5%）。大多数が中程度の家族サポートを受けている。

### Table 6：心理的ウェルビーイングの度数分布（7ページ）
低群9名（22.0%）、中群23名（56.1%）、高群9名（22.0%）。中群が過半数を占める。

### Table 7：正規性検定（Kolmogorov-Smirnov検定）（7ページ）
残差の正規性を検定し、Asymp. Sig.（両側）=0.200（>0.05）で残差は正規分布に従うと判定。

### Table 8：多重共線性検定（8ページ）
X1・X2ともにVIF=1.003（<10）、許容度=0.997（>0.1）で、多重共線性は認められないと判定。

### Table 9：不均一分散検定（8ページ）
残差絶対値を従属変数とした回帰でX1（Sig.=0.154）、X2（Sig.=0.165）ともに非有意であり、不均一分散は認められないと判定。

### Table 10：自己相関検定（8ページ）
Durbin-Watson値=2.132（許容範囲1.5〜2.5内）で、自己相関は認められないと判定。

### Table 11：重回帰分析結果（9ページ）
回帰式 Y = 54.906 − 0.402X1 + 0.702X2 を提示。定数項は有意（p<0.001）、X1（感情調整）の係数は−0.402（p=0.164、非有意）、X2（家族サポート）の係数は0.702（p=0.046、有意）。

### Table 12：t検定（9ページ）
Table11とほぼ同一の回帰係数をt値・有意確率とともに再掲した表。X1：t=−1.418, p=0.164（非有意）、X2：t=2.064, p=0.046（有意）。同一の回帰結果を異なる見出し（「重回帰分析結果」と「t検定」）の下で2回提示しており、構成上やや冗長である。

### Table 13：F検定（分散分析表）（10ページ）
モデル全体の説明力を検定。F=2.989, Sig.=0.062（>0.05）で、感情調整と家族サポートを同時投入したモデル全体は有意ではないと判定。

### Table 14：決定係数検定（10ページ）
R=0.369, R²=0.136, 調整済みR²=0.090。感情調整と家族サポートの2変数で心理的ウェルビーイングの分散の13.6%しか説明できず、モデルの説明力は弱いと明記されている。

## 内容の評価

### ①研究デザイン
単一時点の質問紙調査に基づく横断的相関研究であり、重回帰分析により変数間の関連を検証する設計自体は妥当である。ただし横断デザインのため因果関係は特定できず、単一企業（PT XYZ）の従業員のみを対象としているため、他業種・他企業への一般化は困難である。著者ら自身もこの限界を明記している点は誠実である。

### ②サンプルサイズと選択基準
母集団70名（PT XYZの就労母親全員）からSlovinの公式（許容誤差10%）でN=41を算出しているが、10%という誤差許容は心理学研究としては緩めの基準であり、著者ら自身も「緩い基準では効果量が小さくても有意になりやすい」と本文中で言及している。2つの予測変数に対しN=41は検出力の観点で心もとなく、境界的な有意水準（p=0.046）の頑健性には注意が必要である。

### ③方法論の適切性
ERQ（Gross & John, 2003）、MSPSS家族下位尺度（Zimet et al., 1988）、Ryffの心理的ウェルビーイング尺度という確立された尺度を使用しており、この点は妥当である。ただし心理的ウェルビーイング尺度は予備調査で一部項目が基準（r>0.361）を満たさず削除・修正されたと記述されているが、具体的にどの項目がどう変更されたかは開示されておらず、構成概念の透明性にやや欠ける。

### ④統計分析の妥当性
正規性・多重共線性・不均一分散・自己相関という回帰分析の前提条件を一通り検証しており、手続き自体は丁寧である。一方でTable11とTable12が同一の回帰係数を異なる見出しで重複提示しており、報告の整理という点でやや冗長である。またTable4本文の記述で「27名（65.6%）」とあるが、Table4自体の数値は65.9%であり、本文とTableの間に軽微な数値の不一致がある。

### ⑤結果の信頼性と再現性
各尺度の信頼性係数（α=0.776〜0.915）は良好である。ただし前述の通りサンプルサイズが小さく、家族サポートの有意性（p=0.046）は0.05をわずかに下回る境界的な値であり、追試での再現性は不確実である。感情調整が非有意（かつ負の方向）という結果は、著者らが引用する先行研究（Hapsari et al., 2022）とも整合しており、その点では一定の一貫性がある。

### ⑥結論の妥当性
著者らは「感情調整と家族サポートだけでは心理的ウェルビーイングの複雑さを説明しきれない」と、決定係数13.6%という低い説明力を踏まえて結論を控えめに述べており、過度な一般化を避けている点は評価できる。ただし「家族サポートが心理的ウェルビーイングを有意に向上させる」という結論は、境界的なp値と小サンプルに基づく単一研究の結果であることを踏まえると、より慎重な留保をつけて提示すべきであった。

### ⑦新規性
家族サポートが就労母親の心理的ウェルビーイングと正の関連を持ち、感情調整単独では有意な予測因子とならないという知見は、著者らが引用するインドネシアの先行研究（Hapsari et al., 2022; Kosasih & Rahmawati, 2022）と概ね一致しており、学術的な新規性は限定的である。新規性の主眼は特定企業（PT XYZ）というケーススタディの文脈にとどまる。

### ⑧臨床的意義
家族サポートを高める職場・家庭内介入が就労母親のメンタルヘルス支援に寄与しうるという示唆は実務的に有用である。ただし説明率13.6%という低さから、家族サポートの強化のみでは心理的ウェルビーイング向上効果は限定的と考えられ、著者らも今後は職場環境・組織的サポートを含めたより包括的なモデルの必要性を提言している。
