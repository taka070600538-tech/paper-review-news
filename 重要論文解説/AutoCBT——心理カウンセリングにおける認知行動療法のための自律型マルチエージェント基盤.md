# AutoCBT——心理カウンセリングにおける認知行動療法のための自律型マルチエージェント基盤 精読ノート

> 役割：日本トップクラスのサイエンスコミュニケーターとしての精読プロンプトに基づく分析結果

## 概要（500字以内）

対面の心理カウンセリングは恥の感覚から受診をためらう人には届きにくく、オンラインの自動カウンセリングがその受け皿になりうる。本研究は、認知行動療法（CBT：思考の歪みを見つけて修正する心理療法）の枠組みを大規模言語モデル（LLM）に実装した自律型マルチエージェント基盤「AutoCBT」を提案した。従来のLLM式CBT（CBT-LLM、CoCoAなど）はエージェント構造が固定されており自己最適化ができず、定型的で中身の薄い助言になりやすいという弱点があった。AutoCBTは、利用者と接する1体の「カウンセラーエージェント」と、CBTの中核5原則（共感と承認／中核信念の同定／挑戦と内省の促し／方略の提示／励ましと見通し）をそれぞれ担当する5体の「スーパーバイザーエージェント」を配置し、短期・長期記憶機構と、5種の動的ルーティング（LOOPBACK／UNICAST／MULTICAST／BROADCAST／ENDCAST）を組み合わせる。カウンセラーはまず下書き回答を作り、助言が必要かを自ら判断してスーパーバイザーに照会し、助言を学習して再びルーティング判断に戻る。中国語（PsyQA）・英語（TherapistQA）各100件の二言語データセットで、Qwen-2.5-72BとLlama-3.1-70Bを用い、GPT-4o-miniによる6指標自動評価と心理職による人手評価を実施。AutoCBTは素の生成（Generation）およびPromptCBTを上回り、人手評価では全問題の70%超で最良回答と判定された。

## Figure・Tableの解説

本論文には図2点（Figure 1、Figure 2〈a・b の2パネル〉）と表9点（Table 1〜9）が登場する。以下、本文の言及順に解説する。

### Figure 1：AutoCBTの全体像とエージェント・トポロジー

左側に処理手順、右側にエージェント間の接続図を配した概念図。①利用者が初回の相談文（例：「ここ最近ほとんど毎日、言葉にできない絶望感を感じる。人生から喜びが失われたようだ」）を送る、②カウンセラーが動的ルーティングでスーパーバイザーに相談するか直接返答するかを決める、③相談する場合は下書き回答を送って助言を求める、④助言を受け取って学習し再びルーティング判断へ戻る、⑤直接返答を選んだ時点で最終回答が利用者に届く、という5ステップを示す。右側の接続図には5種のルーティング標識（LOOPBACK＝自分に戻す、UNICAST＝1体に送る、MULTICAST＝複数に送る、BROADCAST＝全員に送る、ENDCAST＝通信終了）が並び、カウンセラーが中心ハブとして利用者と複数スーパーバイザーの双方に接続する構造が読み取れる。

### Table 1：二言語データセットの構成と質問応答の実例

英語100件・中国語100件、計200件からなるデータセットの内訳と実例を示した表。英語例は「義理の妹と同時に妊娠中で、婚約者の家族が赤ちゃんを競争扱いすることに落ち込んでいる」という相談と、それに対する「まず婚約者と何が起きているのか話すべき」という回答。中国語例は「友人関係でいつも自分の立場を低くしてしまい、相手が怒るとひたすら謝ってしまう」という長文の相談と、「姉の立場からあなたに私の話をさせてほしい」と自己開示から入る回答。実際の相談サイト由来のため質問が長大で背景情報が豊富なこと、回答も長文の自由記述であることが分かる。

### Table 2：CBT中核原則に基づく6つの自動評価指標と採点基準

自動評価に用いる6観点（Empathy＝共感、Identification＝認知の歪みの同定、Reflection＝内省の促し、Strategy＝方略、Encouragement＝励まし、Relevance＝関連性）を、それぞれ3つの下位基準とともに定義し、各7点満点とした表。たとえばEmpathyは「1.1 相談者の意図を正しく理解したか」「1.2 不安や苦痛に敬意・理解・共感を示したか」「1.3 感情を表現できる安全な環境を作ったか」の3項目からなる。Identificationは「歪んだ信念を同定したか／掘り下げたか／認識し挑戦する手助けをしたか」で構成され、CBTの介入手順をそのまま採点軸に写している点が特徴である。

### Table 3：Qwen-2.5-72Bによる二言語データセット上の性能

中国語・英語それぞれで Generation／PromptCBT／AutoCBT の6指標得点と総合点を比較した表。中国語では総合点が Generation 32.300 → PromptCBT 36.460 → AutoCBT 37.460 と上昇し、英語でも 33.663 → 37.370 → 38.377 と同じ順序になった。CBT原則をプロンプトに入れるだけで大きく改善し（+4点前後）、そこに動的ルーティングと監督機構を加えるとさらに約1点上乗せされる、という二段構えの効果が読み取れる。中国語ではRelevanceのみPromptCBT（6.860）がAutoCBT（6.857）をわずかに上回り、6指標中5指標での勝利にとどまった。

### Table 4：Llama-3.1-70Bによる英語データセット上の性能

Llamaが回答を拒否した9問を除いた91問での比較表。総合点は Generation 34.810 → PromptCBT 36.722 → AutoCBT 37.333。ここでもAutoCBTが最上位だが、Strategy指標ではGeneration（6.059）がPromptCBT（5.879）・AutoCBT（5.908）を上回っており、CBT構造化がかえって方略の幅を狭める可能性を示唆する。Qwenの英語成績（38.377）と比べるとLlamaは全体に低い。

### Figure 2a：人手による全体評価（SOE）の二言語比較

心理職5名が全200問について3手法のうち最良回答を選んだ結果の棒グラフ。中国語・英語のいずれでもAutoCBTが70%超を占め、PromptCBT・Generationを大きく引き離す。自動評価では1点程度の僅差だった差が、人間の総合判断では明確な選好差として現れることを示す重要な図である。

### Figure 2b：詳細サンプリング評価（DSE）の7次元レーダーチャート

心理職6名がデータセットの10%（60回答）を7次元（Empathy、Identify-CD＝認知の歪みの同定、Challenge-CD＝認知の歪みへの挑戦、Strategy、Encouragement、Relevance、Presentation＝提示の総合的な質）で評価した結果を、中国語3手法・英語3手法の計6系列でレーダー表示した図。AutoCBTが全7次元でGenerationとPromptCBTを上回り、とくに認知の歪みの同定と挑戦で差が大きい。

### Table 5：下書き回答と最終回答の得点差の分解

AutoCBTの効果を「プロンプト由来の部分」と「監督機構由来の部分」に分けて検証した表。「Draft and PromptCBT Diff.」列（AutoCBTの下書き回答とPromptCBT回答の差）は中国語総合+0.177、英語+0.187と小さく、下書き段階は実質的にPromptCBTと同等であることを示す。一方「Final and Draft Diff.」列（最終回答と下書きの差）は中国語総合+1.177、英語+0.798と大きく、全指標でプラス。つまり性能向上の主因はプロンプト文言ではなく、スーパーバイザーによる助言と動的ルーティングそのものだと結論づけられる。

### Table 6：QwenとLlamaの回答拒否件数の比較

Qwenは中国語・英語とも拒否ゼロ。Llamaは英語でGeneration 3問、PromptCBT 3問、AutoCBT 8問を拒否し、和集合で9問の異なる質問を拒否した。ただしAutoCBTの改良（プロンプト修正）後は8問→2問に減少したと注記されている。未成年・性・自殺に関する相談が拒否対象であり、支援を求める人が「理解されない」と感じる副作用が指摘されている。

### Table 7：詳細サンプリング評価で自動評価と共通の4指標

Empathy、Strategy、Encouragement、Relevanceの4指標が自動評価と同一であることを示す短い一覧表。

### Table 8：詳細サンプリング評価の新規3指標

自動評価のIdentification／ReflectionをIdentify-CD／Challenge-CDに置き換え、さらにPresentationを追加した3指標の定義表（各7点）。Identify-CDは「認知の歪みを同定したか／利用者が歪んだ信念に気づく助けになったか／心理学的観点から説明したか」、Challenge-CDは4基準（挑戦の支援、深い思考を促す開かれた問い、心理カウンセリング技法の統合、想定される歪みとの対応）に細分化されている。Presentationは「カウンセラーらしい語り口か／情報が明確か／技法を柔軟に適用したか」を問う。

### Table 9：心理職6名による質的分析

4観点（共感と励まし／認知の歪み／方略の有用性）についての自由記述分析をまとめた表。要点は、(1) AutoCBTはPromptCBTと論理構成は似るがより温かく、語彙選択が柔軟で共感的トーンが一貫している、(2) 「安全な環境づくり」の表現が言語文化で異なり、中国語では敬意・傾聴を強調、英語では「非審判的な視点から見ます」と専門職としての境界を強調する、(3) PromptCBTは「破局的思考」のような専門用語を多用して利用者に「ラベルを貼られた」感覚と自己批判を生みやすいのに対し、AutoCBTはより平易で配慮ある言い換えを行う、(4) Generationは方略の幅は最も広いが具体性を欠き関連性が低い、というもの。臨床実務で専門用語を慎重に扱う実践知をAutoCBTがよく再現していると評価されている。

## 8項目評価

本論文は原著研究（システム提案＋評価実験）であり、臨床試験ではなく計算機科学の枠組みで実施されている。したがって以下の評価では、「サンプルサイズ」を評価用データセットの規模、「統計分析」を評価指標の設計と数値の扱いとして読み替えて論じる。

### ①研究デザイン

CBTの5原則を5体のスーパーバイザーエージェントに一対一で写像し、動的ルーティングで照会先を自律決定させるという設計は、心理療法のスーパービジョン構造をそのまま計算アーキテクチャに翻訳した点で明快である。さらにTable 5で「下書き＝PromptCBT相当」と「最終＝監督機構込み」を分離し、性能向上がどの機構に由来するかを切り分けたのはアブレーション実験として適切だ。問題点として、比較対象がGenerationとPromptCBTの2つのみで、先行手法であるCoCoA（記憶機構つき単一エージェント）との直接比較が行われていない。また単発（single-turn）の相談に限定されており、CBTの本質である複数セッションにわたる協働的経験主義や宿題は評価範囲外である。

### ②サンプルサイズと選択基準（＝評価データセットの規模）

PsyQA（中国語）とTherapistQA（英語）から、LLM（Qwen-72B、LLaMA-70B）を用いて10種類の認知の歪みに分類させ、各クラス10件ずつ無作為抽出して各言語100件、計200件を構成した。実際の相談サイト由来である点は生態学的妥当性が高い。しかし各言語100件は絶対数として小さく、6指標×3手法の比較で1点未満の差を論じるには心もとない。さらに致命的なのは、分類ラベル自体がLLMによって付与されており、人手検証の記述がないことである。「10種類の認知の歪み」の具体的内訳も本文で列挙されておらず（"discussed in previous section"とあるが該当箇所が明示されない）、再現性の観点で不十分である。

### ③方法論の適切性

自動評価と人手評価を併用し、後者をさらに全問題の最良回答選択（SOE、心理職5名）と10%サンプルの7次元詳細評価（DSE、心理職6名）に分けた設計は妥当である。とくにDSEでIdentification／ReflectionをIdentify-CD／Challenge-CDに置き換え、認知の歪みへの対応を厚く評価した点は、CBTの核心を突いている。一方、自動評価にGPT-4o-miniを用いる「LLM-as-a-judge」は、生成側もLLMであるため系統的なバイアス（冗長で丁寧な文章を高く評価する傾向など）を排除できていない。GPT-4o-miniの採点と人間評価の一致度（相関係数やκ係数）が一切報告されておらず、自動評価の妥当性そのものが検証されていない。人手評価者間の一致率も同様に未報告である。

### ④統計分析の妥当性（＝報告数値の扱い）

各回答を3回採点して平均する処理は、LLM出力の揺らぎ（temperature 0.98という高い値を設定）への対処として最低限のものである。しかし本論文には信頼区間も検定も一切なく、「AutoCBT 37.460 対 PromptCBT 36.460」といった差が偶然の範囲を超えるかを判断する材料がない。Table 5の差分も同様で、たとえば中国語Relevanceの+0.047やEmpathyの-0.030といった小さな値を、+1.177の総合差と同じ精度で語ることはできない。標準偏差やサンプルごとのばらつきが示されていないため、読者は効果量を評価できない。統計的検証の欠如は本論文の最大の弱点である。

### ⑤結果の信頼性と再現性

温度0.98という高いランダム性の設定、モデルの継続的な更新、プロンプトの詳細が付録にも完全には収録されていないことから、第三者による厳密な再現は難しい。3回平均は揺らぎを平滑化するが根本的な解決にはならない。加えて、著者ら自身が3つの技術的課題（同時ルーティングによる無限ループ、スーパーバイザーが助言でなく回答を生成してしまう役割混同、同一スーパーバイザーへの重複照会）を報告し、いずれもプロンプトの工夫や有向辺の削除といった対症療法で回避していると認めている。これはLLMの指示追従能力に依存した設計の脆さを示しており、モデルを替えれば挙動が変わりうる。他方、中英2言語・2モデルで一貫して同順位が得られた点は、結果の頑健性を支える材料である。

### ⑥結論の妥当性

「AutoCBTはより質の高い自動心理カウンセリングを提供できる」という結論は、提示されたデータの範囲内では概ね支持される。とくにTable 5による機構の切り分けと、人手評価で70%超が最良と判定された事実は説得力がある。ただし「質が高い」とされているのは回答テキストの評価得点であって、症状改善や実利用者の満足度ではない。実際の相談者を対象とした前向き研究は一切行われておらず、「臨床的に有効」と読み替えることはできない。また比較対象が弱いベースライン2種に限られる以上、「最良の手法である」とは言えず、「プロンプトのみの手法より優れる」に限定して読むべきである。

### ⑦新規性

LLMによるCBT支援の研究自体は既にCBT-LLM、CoCoA、Woebotなど蓄積があり、マルチエージェント構成も計算機科学では一般的な手法である。本論文の独自性は、①CBTの5原則を明示的に5体のスーパーバイザーへ一対一で割り当てたこと、②5種の動的ルーティングによりカウンセラー自身に「誰に何を聞くか」を判断させたこと、③下書きと最終回答の差分によって監督機構の寄与を定量化したこと、④Llamaの過剰な安全側応答（未成年・性・自殺に関する相談を拒否する現象）を心理支援の文脈で具体的に問題化したこと、にある。とくに④は、安全アライメントが支援を必要とする人を排除しうるという指摘であり、臨床応用を考える上で新規かつ重要である。技術的なブレークスルーというより、既存要素の臨床的に妥当な再編成と位置づけるのが正確だろう。

### ⑧臨床的意義

日本の精神科臨床の文脈で読むと、示唆は二方向にある。肯定的側面としては、恥の感覚から受診をためらう層への初期接触手段として、テキストベースの自動応答が「専門用語でラベルを貼らず、温かく、具体的な文脈に沿って」応答できると示した点に価値がある。Table 9で指摘された「破局的思考」といった用語の直接使用が自己批判を招くという知見は、対人臨床でも通用する実務的教訓である。他方で懸念は大きい。単発応答の質しか検証されておらず、危機介入（自殺念慮の評価、緊急対応への接続）の仕組みは設計に含まれていない。むしろLlamaの拒否行動が示すように、最も支援を要する相談ほど自動応答が機能しない可能性がある。またLLM特有の作話や不適切な助言に対する安全機構、責任の所在、個人情報の扱いについても本論文は論じていない。現時点では臨床導入の前段階にある技術であり、あくまで研究用の枠組みとして読むべきである。
