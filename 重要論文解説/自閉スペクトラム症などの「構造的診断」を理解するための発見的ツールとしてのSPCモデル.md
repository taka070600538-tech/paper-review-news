# 自閉スペクトラム症などの「構造的診断」を理解するための発見的ツールとしてのSPCモデル 精読ノート

## 1. 概要

成人の自閉スペクトラム症（ASD）の人が精神科を受診するとき、「自閉症だから困っている」と訴えることはまれです。多くの場合、うつ、職場や家庭での対人トラブル、ひきこもりなどを訴えて来院します。著者はドイツ・フライブルク大学で成人ASDの専門病棟を運営する精神科医です。このように入り組んだ訴えを整理するための「SPCモデル」を提案しています。

SPCモデルでは、目の前の現象を3種類に分けます。
- **S＝構造（Structure）**：身長や視力のように、その場で意志の力では変えられない、生まれ持った特性。ASDの中核特性（他者の心を読む力の弱さ、感覚過敏など）がここに入ります。治療目標は「受け入れて、補う工夫をする」ことです。
- **P＝問題・問題行動（Problems）**：いじめ、孤立、ひきこもり、うまくいかない話し方の癖など。構造から典型的に生じますが、変えられるものです。治療目標は「解決し、変える」ことです。
- **C＝状態（Conditions）**：うつ病エピソード、緊張、解離、精神病など、始まりと終わりがある一時的な心身の状態です。治療目標は「薬や心理療法で治す、または過ぎ去るまで耐える」ことです。

この区別を誤ると、治療がうまくいきません。たとえば、構造を「問題」と取り違えると「あなたのままではダメだ」という達成不可能な目標を押しつけることになります。逆に、うつ病による一時的な悪化を「自閉症が重くなった」と取り違えると、抗うつ治療の機会を逃します。本モデルはまだ実証的な検証を受けていない、臨床から生まれた「発見的ツール」（考えを整理するための道具）です。

## 2. FigureとTableの解説

本文には**Figure 2点（Figure 1・2）**、**Table 4点（Table 1〜4）**、そして**症例を紹介するBox 1点**があります。

### Box 1：高機能自閉症の症例（43歳の建築家M氏）

M氏は幼いころから視線が合わず、「小さな教授」と呼ばれていました。音に敏感で、決まった日課にこだわる人でした。建築家として才能を発揮し、営業担当の上司とペアを組んで受賞歴もあります。ところが上司が引退すると、顧客や職人とのやりとりがうまくいかず、会社は半年で倒産しました。M氏は強いストレスで話せなくなり、自宅に閉じこもり、うつ病と診断されます。入院した心身医療クリニックでは、薬の副作用、騒音、集団療法が合わず、2週間で自主退院しました。その後3年間ひきこもり、自殺も考えています。

評価では、中等度から重度のうつ病と、はっきりした自閉症表現型が見られました。ただし、それまでは本人がうまく適応していたため、DSM-5のD基準（苦痛や機能障害）を満たすかは議論の余地がある、としています。**構造（ASD特性）・問題（倒産、孤立）・状態（うつ病）が絡み合う典型例**として示されています。

### Figure 1：SPCモデルの概念図

「構造」「問題」「状態」の3つの円が互いに矢印でつながっています。
- **構造**（性格、自閉症、衝動性、注意、チックの素因、知能、才能、身長、視力）：意志による変化は「不可能」。治療方針は「受容と補償策の開発」。
- **問題**（誤解、いじめ、社会的排除、ひきこもり、借金、貧困、失業、不適切な自己像、低い自尊心、対立）：意志による変化は「おおむね可能」。治療方針は「変化・解決」。
- **状態**（うつ、精神病、不安、解離、緘黙、緊張と興奮、片頭痛、中毒、空腹、口渇）：意志による変化は「ほぼ不可能」。治療方針は「治療・治癒」。

矢印は、構造から問題が生まれ、問題が状態を引き起こし、状態が構造や問題を修飾する、という相互作用を表しています。**注意点**：本文とタイトルでは「C＝Conditions（状態）」なのに、図中の表記は「states」で、用語が統一されていません。

### Figure 2：現象の存在論的な位置づけを判定するフローチャート

目の前の現象（刺激への過敏さ、意欲の低下、視線回避、妄想的な考え方、ひきこもり、問題のある話し方など）について、4つの観点から分析します。
- **時間的経過**：いつ始まったか。はっきりした始まりと終わりがあるか。
- **発達的経過**：幼児期から、状況に関係なく存在していたか。
- **状況との結びつき**：特定の対立場面や人（上司、同僚、パートナーなど）のときにだけ起きるか。
- **行動としての組み立て**：怒りの爆発・ひきこもり・物質使用といった行動なのか、感覚過負荷などの知覚なのか、信念や世界観に根ざした習慣なのか。

分析結果に応じて、「構造」（静的構造：感覚過敏・知能・視力、動的構造：自己・アイデンティティ）、「問題・問題行動」（環境の問題、社会的問題、問題行動）、「状態」（身体の状態、精神の状態）に振り分け、それぞれの治療方針を示します。**注意点**：図の説明文では「状況的（変えられないが一時的）」という言葉が使われ、本文の「状態（condition）」と用語が一致していません。また、4つの観点がどう組み合わさって判定に至るのか、判定基準は示されていません。

### Table 1：構造的現象の特徴と治療方針

- **特徴**：その場では変えられない、身体に備わった運命的な性質です。
- **疾病分類上の位置づけ**：正常の範囲内のばらつきのこともあれば、病気の後遺症（障害）のこともあります。
- **精神医学の例**：自閉症、性格構造、知能、うつ病や精神病エピソードへのなりやすさ。
- **一般医学の例**：身長、視力、遠視・近視、片頭痛・けいれん・高血圧へのなりやすさ。
- **自己概念**：運命として認め、責任・罪・過ちとは結びつけない。
- **治療**：本人と周囲が受け入れること、補う戦略を立てること、自分に合う生態学的ニッチ（得意を生かせる居場所）を見つけること。

### Table 2：問題・問題行動の特徴と治療方針

- **特徴**：状況によって変わりうる現象で、環境や他者から押しつけられた問題や、身につけてしまった非機能的な行動パターンです。
- **位置づけ**：病気ではありません。
- **精神医学の例**：いじめ、社会的排除、剥奪、失業、劣悪な住居、貧困、ひきこもり、薬物乱用、攻撃行動、うまくいかない話し方。
- **一般医学の例**：貧困、衛生不良、環境毒への曝露、食習慣・飲酒・喫煙の習慣。
- **自己概念**：変えられるもので、個人の責任と自由意志の範囲にあります。
- **治療**：そのまま受け入れるべきではありません。解決を目指し、非機能的な行動は分析して、代わりの行動を練習します。

### Table 3：精神的・身体的な状態の特徴と治療方針

- **特徴**：始まりと終わりがある、周期的・一時的な現象で、身体の機能のモードを表します。その場ではなく、時間とともに変化します。
- **位置づけ**：生理的な反応や正常の範囲内のばらつきのこともあれば、病気の表れのこともあります。
- **精神医学の例**：うつ病エピソード、ストレスや不安のエピソード、感覚過負荷、精神病的な破綻、中毒、神経性やせ症、脳の炎症状態。
- **一般医学の例**：片頭痛発作、てんかん発作、自己免疫疾患の炎症、妊娠、飢餓。
- **自己概念**：意図して切り替えることはできませんが、薬物療法・心理療法・行動の変化によって間接的に元の状態に戻す手助けができます。
- **治療**：医学的・心理的な治療を試し、望ましい状態に戻すことを目指します。

### Table 4：学問分野ごとの「構造」概念

「構造」という言葉は分野によって意味が違います。表では次のように整理しています。
- **一般的な定義**：全体、部分、部分どうしの組織化された関係、全体は部分の総和以上のもの。
- **哲学**：存在論・認識論など。抽象的で実証が難しい。
- **精神分析**：口唇期〜性器期の発達段階、自我・エス・超自我。近年は自己発達や感情調整の能力を指します。
- **発達心理学**：知覚・運動・言語・心の理論など、測定できる能力。
- **社会学**：集団や社会の構造。
- **生物学**：分子・細胞・組織の構造。

そのうえで、**静的な生物学的構造**（身長、遠視、知能、ASDの感覚過敏や心の理論の弱さ）と、**動的な生物学的構造**（筋肉量、楽器演奏や読み書きの能力、衝動の抑制、世界観・中核信念・自己・アイデンティティ）を区別しています。動的な構造は、「構造」と「問題」の中間に位置づけられます。

## 3. 8項目評価

※本論文は、データを集めた実証研究ではなく、「仮説と理論（Hypothesis and Theory）」という種類の概念的な論文です。このため、「サンプルサイズ」「統計分析」などは、「論拠の選び方」「概念の定義と論理の一貫性」に読み替えて評価します。

**①研究デザイン**
成人ASDの専門外来と入院プログラム（FASTER-IP、2011年〜）での臨床経験から生まれたモデルを、1つの症例（Box 1）と図表で説明する論文です。著者自身も、「実証的な検証はまだ行われていない発見的ツールであり、現実そのものを記述したものではない」と明記しています。その限界の自覚は適切です。しかし、ケースシリーズ（複数症例の記録）や、臨床家どうしで判定が一致するかの予備的なデータすらなく、根拠は著者の臨床的な印象にとどまります。

**②サンプルサイズと選択基準（→論拠の選び方）**
参考文献は、ASDの有病率（CDCの「31人に1人」）、診断の低年齢化・軽症化を示す大規模な遺伝研究、併存症、女性の擬態（カモフラージュ）、広義の自閉症表現型、ストレス脆弱性モデルなど、標準的な文献を押さえています。ただし、モデルの中核は著者のドイツ語の書籍（文献21）と、Kohlhammer社の自著（文献3）に依拠しています。英語圏の読者が一次資料を確かめるのは難しいです。

**③方法論の適切性**
「その場で意志によって変えられるか」「時間的に始まりと終わりがあるか」という2つの軸で現象を分ける発想は明快です。臨床での説明（心理教育）にもそのまま使えます。一方で、実際にどう判定するかは曖昧です。フローチャート（Figure 2）の4つの観点について、判定の閾値や優先順位が定められていません。自己概念やアイデンティティのように、「その場では変えられないが、長期的には変わる」現象については、著者自身が「専門家でもすぐには判断できない」と認めています。

**④統計分析の妥当性（→概念の定義と論理の一貫性）**
統計解析はありません。用語がぶれている点が気になります。C（Conditions）が、図1では「states」、図2の説明文では「situational」と呼ばれています。また、Table 1では「うつ病へのなりやすさ」が構造に、Table 3では「うつ病エピソード」が状態に分類されています。素因と発症を分けるという意図は分かりますが、この点が明示されていないため、読者が混乱する可能性があります。静的構造と動的構造を区別した「修正」（Table 4）は、実質的には「S」と「P」の間に第4のカテゴリーを置くことにあたります。三分法の枠組みそのものが揺らいでいます。

**⑤結果の信頼性と再現性**
経験のある臨床家どうしで、S・P・Cの判定が一致するかどうか（評価者間信頼性）は検討されていません。今後の研究として、著者は質的研究（治療者と患者への聞き取り）から始めることを提案しています。しかし、治療成績や治療同盟（治療者と患者の協力関係）への効果を測る具体的な研究計画は示されていません。現時点では、モデルの有用性を再現可能な形で確かめる手段がありません。

**⑥結論の妥当性**
「構造は受け入れて補い、問題は解決し、状態は治療する」という結論は、臨床的な常識とよく合っていて、無理がありません。特に重要なのは次の2点です。1つは、ASDの人のうつ病が典型的な抑うつ気分としてではなく、「自閉症特性の一時的な悪化」（より硬直的になる、補う力が落ちる）として現れるという指摘です。もう1つは、シャットダウン（緘黙、固まる、解離）が境界性パーソナリティ障害と誤診されやすいという指摘です。いずれも臨床的に説得力があります。ただし、これらも系統的なデータで裏付けられてはいません。

**⑦新規性**
著者自身が、ストレス脆弱性モデル（素因＝構造、ストレス＝問題、発症＝状態）との類似を認めています。本モデルの新しさは、「構造」を病的なものとして扱わず、正常の範囲内のばらつきとして捉えた点にあります。これにより、閾値に達しない「広義の自閉症表現型」やADHDの傾向も扱えるようになります。また、各カテゴリーごとに治療方針（受容・解決・治療）を明確に対応させた点も新しいといえます。Uta Frithによる「自閉スペクトラム概念は広がりすぎて失敗した」という議論への回答を試みている点も、時宜にかなっています。

**⑧臨床的意義**
日本の成人精神科外来でも、「発達障害グレーゾーン」の人がうつ病や職場不適応で受診するケースはとても多いです。本モデルは、そうした場面で使える実践的な視点を与えてくれます。
- 本人と「どこは受け入れ、どこは変え、どこは治すか」を一緒に仕分ける心理教育の枠組みになります。
- 「自閉が悪化した」と見える場合にうつ病を見逃さず、薬物療法を検討するきっかけになります。
- 感覚過敏や心の理論の弱さを「治す」目標にしないことで、自尊心が傷つくのを防げます。

ただし、実証的な裏付けがないため、既存のCBTやASD向けの心理療法を置き換えるものではありません。考えを整理するための補助線として使うのが適切です。
