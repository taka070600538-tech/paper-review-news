# 旅の動機を超えて——満足度・エウダイモニア的ウェルビーイング・親密さが目的地ロイヤルティに及ぼす影響 精読ノート

## 概要(500字以内)

旅に出たい気持ち(旅行動機)は、旅先での満足感だけでなく、「自分が成長した」「生きる意味を感じた」というエウダイモニア的ウェルビーイング(EWB:快楽ではなく、意味や自己実現を伴う深い幸福)にもつながるのか。そしてそれが「また来たい・人に勧めたい」という目的地ロイヤルティ(DL)を生むのか。本研究は、刺激(Stimulus)→生体内の心理過程(Organism)→反応(Response)というSORモデルを枠組みに、2024年5〜9月にエジプトとUAEを訪れた観光客524人の質問紙データをPLS-SEM(多数の潜在変数の因果関係を同時に推定する統計手法)で分析しました。その結果、旅行動機はEWBを強く(β=0.76)、満足度を弱く(β=0.14)予測し、EWBは満足度を強く予測(β=0.68)、満足度とEWBはそれぞれロイヤルティを予測しました(β=0.44、0.42、説明率84%)。さらに目的地への「親密さ」(温かさ・居心地・理解されている感覚)が高いほど、満足度やEWBがロイヤルティに結びつく力が強まりました。エジプトとUAEで経路の強さが大きく異なることも示されています。

## Figure・Tableの解説

本論文のFigureは3点(Figure 1〜3)、Tableは5点(Table 1〜5)です。

### Figure 1: 研究の概念モデル
SORモデルに当てはめた仮説図です。刺激(S)が「旅行動機」、生体内の心理過程(O)が「観光客満足度(TS)」「エウダイモニア的ウェルビーイング(EWB)」、反応(R)が「目的地ロイヤルティ(DL)」に置かれます。矢印は H1(動機→満足度)、H2(動機→EWB)、H3(EWB→満足度)、H4(満足度→ロイヤルティ)、H5(EWB→ロイヤルティ)の5本で、さらに「親密さ」が H6(満足度→ロイヤルティ)と H7(EWB→ロイヤルティ)の矢印の強さを変える調整変数(モデレーター:関係の強弱を左右する第三の変数)として描かれています。

### Table 1: 回答者の属性
524人の内訳です。女性57.7%・男性42.3%、年齢は26〜35歳が38.2%で最多、独身65.6%。学歴は高卒49.1%・学士37.5%・大学院13.4%、年収2.5万ドル未満が43.6%と、若く比較的所得の低い層が中心です。旅行目的は文化・遺産訪問40.1%、レジャー37.7%、ビジネス12.3%、友人親族訪問9.9%。同行者は友人35.8%、一人28.2%、家族18.9%、団体ツアー17.1%。滞在日数は表では1〜2日6.3%、3〜4日11.9%、5〜6日33.1%、7日以上48.7%ですが、本文には年齢の数字と同じ値(38.2%など)が誤って書かれており、食い違いがあります。

### Table 2: 尺度の妥当性と信頼性
各概念を測る質問項目と因子負荷量(その項目が概念をどれだけよく反映しているか、0.7以上が目安)です。旅行動機6項目(「新しい場所を知るため」など、0.733〜0.847)、満足度5項目(0.805〜0.877)、EWB8項目(「自立と自己決定を育む」「個人として大きく成長する」など、0.732〜0.853)、ロイヤルティ3項目(好意的に話す・勧める・再訪する、0.823〜0.912)、親密さ5項目(0.886〜0.941)。合成信頼性(CR)0.908〜0.962、クロンバックα0.849〜0.951、AVE(平均分散抽出:項目が概念をまとめて説明する割合)0.623〜0.836といずれも基準を満たし、VIF(多重共線性=変数同士が似すぎる問題の指標)は1.314〜3.176でした。

### Table 3: AVEの平方根と概念間の相関
弁別妥当性(異なる概念が本当に別物として測れているか)の確認です。対角線上のAVE平方根(動機0.789、満足度0.860、EWB0.810、ロイヤルティ0.877、親密さ0.914)が、他の概念との相関を上回ることが基準(フォーネル・ラーカー基準)です。相関は動機–EWB 0.751、満足度–EWB 0.786、EWB–ロイヤルティ 0.792、満足度–ロイヤルティ 0.781と高めで、親密さは他の4概念と0.143〜0.189と弱い相関にとどまっていました。

### Table 4: HTMT比
もう一つの弁別妥当性指標であるHTMT(異なる概念間の相関の、同一概念内の相関に対する比。0.90未満なら別概念とみなす)です。動機–満足度0.730、動機–EWB0.839、満足度–EWB0.854、動機–ロイヤルティ0.800、満足度–ロイヤルティ0.871、EWB–ロイヤルティ0.868、親密さとの組み合わせは0.168〜0.191でした。全て0.90未満で基準は満たしますが、満足度・EWB・ロイヤルティの3者は0.85〜0.87とかなり境界に近く、概念が重なっている可能性も残ります。

### Figure 2: 構造モデル(推定結果)
仮説の矢印に推定された経路係数(β:影響の強さ)を載せた図です。動機→満足度 β=0.14、動機→EWB β=0.76(EWBの分散の57%を説明)、EWB→満足度 β=0.68(動機とEWBで満足度の63%を説明)、満足度→ロイヤルティ β=0.44、EWB→ロイヤルティ β=0.42(両者でロイヤルティの84%を説明)。親密さの調整効果は満足度→ロイヤルティで β=0.31、EWB→ロイヤルティで β=0.25。すべて p<0.01 で、H1〜H7がすべて支持されました。

### Figure 3: 調整効果のプロット
親密さが低い人と高い人で、満足度(またはEWB)とロイヤルティの関係線の傾きを比べた図です。親密さが高い観光客ほど線の傾きが急で、同じだけ満足しても、同じだけ意味深い体験をしても、ロイヤルティへの結びつきがより強くなることを視覚的に示しています。つまり「満足」や「意味ある体験」は、目的地への温かい親しみがあるときにこそ再訪・推奨に転化しやすい、という解釈です。

### Table 5: 訪問国別の多群比較(エジプト対UAE)
エジプト訪問者(320人)とUAE訪問者(204人)で経路係数を比べた結果です(左がエジプト、右がUAE)。動機→満足度 0.16対0.19、動機→EWB 0.73対0.77、EWB→満足度 0.66対0.72はほぼ同程度。一方、満足度→ロイヤルティは0.18対0.89、EWB→ロイヤルティは0.80対0.20と逆転し、エジプトでは「意味ある体験」が、UAEでは「満足」がロイヤルティを主に駆動していました。親密さの調整効果は両経路ともエジプトの方が強い(0.31対0.15、0.26対0.15)。著者らは遺産観光のエジプトと、娯楽・ラグジュアリー型のUAEという性格の違いで説明しています。

## 8項目評価

### ①研究デザイン
SORモデルに基づく横断的(一時点)質問紙調査と構造方程式モデリングで、観光研究では標準的な設計です。2つの文化的に異なる目的地を含め、多群比較を行った点は工夫といえます。しかし横断データでは「動機→EWB→満足度→ロイヤルティ」という時間的・因果的な順序を確かめられず、図の矢印は理論上の仮定にすぎません。旅行前の動機と旅行後の評価を同じ時点で尋ねており、回顧バイアス(今の気分で過去の動機を思い出す)も避けられません。縦断(旅行前後の追跡)設計が望まれます。

### ②サンプルサイズと選択基準
524人はPLS-SEMとしては十分な規模で、回収率もエジプト89%(320/360)、UAE82%(204/250)と高めです。ただし博物館・遺跡・ホテルなどで「友人・知人の協力を得て」集めた便宜的サンプリングで、著者自身も一般化可能性の限界を認めています。回答者は高卒49%・年収2.5万ドル未満44%と若く低所得寄りで、UAEの典型的な高消費観光客像と一致するか疑問です。国籍・初回訪問かリピーターかといった基本情報が示されず、オンラインとオフライン回答の比率も不明です。

### ③方法論の適切性
既存尺度を組み合わせ、アラビア語・英語の逆翻訳確認と50人の予備調査を行った点は丁寧です。しかし問題も多くあります。EWB項目は「EWBは私の自立を助ける」のように概念名そのものを主語にしており、回答者がEWBという専門語を理解したか疑問です。親密さ項目の「この目的地での体験を楽しんでいる」は満足度項目とほぼ同じ内容で、概念の重複が懸念されます。全変数を同一回答者・同一時点の自己報告で測っており、共通方法バイアス(同じ測り方による見かけの相関)の検討もありません。

### ④統計分析の妥当性
WarpPLSによるPLS-SEMで、AVE・CR・α・フォーネル・ラーカー基準・HTMTと定石の妥当性検証は行われています。ただしVIFが満足度3.169、EWB3.113、ロイヤルティ3.176と3を超えているのに本文は「すべて3未満」と記載しており不整合です。HTMTも満足度–EWB–ロイヤルティ間で0.85〜0.87と境界に近く、ロイヤルティの説明率84%は概念の重なりによって水増しされている可能性があります。多群比較の検定方法の詳細や、媒介効果(間接効果)の推定値・信頼区間も示されていません。

### ⑤結果の信頼性と再現性
質問項目と負荷量がTable 2に全文掲載されている点は再現に有利です。しかし本文内の数値の食い違いが目立ちます。考察ではEWB→ロイヤルティを β=0.25と書いていますが結果では0.42(0.25は調整効果の値)、結論では「親密さは満足度とEWBの関係、満足度とロイヤルティの関係を調整」と、検証していない経路に言及しています。滞在日数の割合も本文と表で異なり、方法論の節には投稿テンプレートの文言らしき一文が残っています。編集・校閲の甘さが結果全体の信頼性を下げています。

### ⑥結論の妥当性
「旅行動機がEWBと満足度を通じてロイヤルティを高め、親密さがそれを強める」という結論は、データの範囲内では一応支持されます。しかし動機→満足度の直接効果は β=0.14と小さく、実際には動機→EWB→満足度という間接的な経路が中心です。そのため「動機が満足度の主要な予測因子」とする要旨・結論の書き方はやや言い過ぎです。多群比較で満足度→ロイヤルティ(0.18対0.89)とEWB→ロイヤルティ(0.80対0.20)が国ごとに逆転している点は、全体モデルの一般性を揺るがす重要な結果ですが、文化差による事後的な説明にとどまっています。

### ⑦新規性
観光の文脈で、旅行動機・EWB・満足度・ロイヤルティを一つのモデルにまとめ、そこに「親密さ」を調整変数として加えた点、さらにエジプトとUAEという中東の2目的地を比べた点が新しいところです。特に、エジプトでは意味ある体験(EWB)が、UAEでは満足がロイヤルティを主に動かすという対比は興味深い発見です。ただし個々の経路(動機→満足度、満足度→ロイヤルティなど)は先行研究で繰り返し確認されたもので、理論的な新しさは主に組み合わせにあります。親密さが調整変数として働く理由の理論的な掘り下げも十分とはいえません。

### ⑧臨床的意義
観光マーケティング論文であり、直接の臨床的意義は限られます。ただしウェルビーイング研究の視点では、「意味・成長・自己決定といったエウダイモニア的な体験が満足感の土台になる」という結果は、快楽的な満足だけでなく意味のある活動がその後の行動(再訪・推奨)を左右するという、ポジティブ心理学の知見と整合的です。行動活性化療法などで「価値に沿った活動」を重視する考え方とも響き合います。ただしEWBの測定が粗く自己報告のみで、心理的な健康状態との関係も調べていないため、臨床応用への示唆はあくまで仮説段階にとどまります。
