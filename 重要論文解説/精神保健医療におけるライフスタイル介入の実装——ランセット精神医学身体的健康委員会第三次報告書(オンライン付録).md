# 精神保健医療におけるライフスタイル介入の実装——ランセット精神医学身体的健康委員会第三次報告書(オンライン付録) 精読ノート

## 概要（500字以内）

本PDFは、重症精神疾患を含む精神疾患を持つ人々に対する運動・栄養・禁煙・睡眠などの「ライフスタイル介入」を精神保健医療の中でどう実装・提供するかを扱った、Lancet Psychiatry Physical Health Commissionの第三次報告書の「オンライン付録（Supplemental Material）」である。論文本体（本文）は含まれておらず、本文を支える5つの補足セクションから成る。すなわち①2019年の第一次委員会報告の影響分析、②2018年以降の最新介入研究99件のスコーピングレビュー、③介入の効果的な提供方法に関する58件のメタ解析の精選レビュー、④実装・提供を阻む障壁と促進要因に関する38件の質的研究の統合、⑤医療従事者・グローバルサウス諮問グループ・当事者(生きた経験)アドバイザリーグループへのコンサルテーションに基づく提言策定、である。全体として「誰が・どこで・どのように介入を届けるか」という実装レベルの問いに焦点を当て、動機づけ理論に基づく設計、個別化と柔軟性、ピアワーカーの活用、そして当事者の自律性を尊重した関わり方の重要性を導いている。

## Figure・Tableの解説

本文書は査読論文というより大量の補足表・図から成る付録であるため、報告書の骨格を成す主要なもの（PRISMAフロー図3点、統合表・提言表）を中心に解説する。

### Figure S1：最新介入研究のPRISMAフロー図（8ページ）
2018年11月以降に発表されたライフスタイル介入研究をMEDLINE等4データベースで検索した結果、5,342件から重複除去・スクリーニングを経て、最終的に99件の報告・91種類のユニークな介入が統合対象として同定された過程を示す標準的なPRISMA図。除外理由（研究デザイン不適合184件、サンプルサイズ不足143件等）も内訳表示されている。

### Figure S2：メタ解析スコーピングレビューのPRISMAフロー図（64〜65ページ）
1,827件の候補から702件の重複を除去し、1,125件をスクリーニング。155件を全文評価し、最終的に76件が意図的サンプリング(purposive sampling)の対象となり、うち18件が統合に採用された過程を示す。運動関連メタ解析が多数(43件)を占めたため、量が質を損なわないよう「幅広い運動種目を扱う」「アウトカムの豊富さ」「診断群の広がり」という3段階の意図的サンプリング基準で絞り込んだ点が特徴的である。

### Figure S3：質的エビデンス統合のPRISMAフロー図（96ページ）
6,352件から1,744件の重複除去後、4,608件をタイトル・抄録スクリーニング。240件を全文評価し、最終的に38件の質的研究（実装・提供の障壁と促進要因を扱ったもの）が統合対象として採用された。データの豊かさ（5段階評価で3点以上）と地理的多様性（低・中所得国の研究を優先的に包含）を基準にした意図的サンプリングが行われている。

### Table S16：サンプル化されたメタ解析18件の主要知見一覧（76〜85ページ）
複数のライフスタイル要素を組み合わせた介入(5件)・運動単独(10件)・栄養(1件)・睡眠(2件)の各メタ解析から、「どのような提供方法がより効果的か」というサブグループ解析結果を抜粋した大規模表。例えば、統合失調症を対象とした運動介入では入院設定より外来設定の方が心理病理への効果が大きい(Gallardo-Gómez, 2023)、体重管理では個別セッションが集団セッションより効果的(Speyer, 2019)、思春期うつ病では週3回・45〜50分のセッションが最も効果的(Chen, 2024)など、頻度・強度・場・提供形態による効果の違いが具体的な効果量とともに整理されている。

### Table S28・S29：実装・提供を阻む障壁（医療者側・当事者側）の質的統合結果（115〜119ページ）
38件の質的研究から抽出された障壁を、マクロ（制度・政策）・メソ（組織）・ミクロ（個人）の3層構造で整理した表。医療者側では「資源不足（時間・人員・設備）」「トレーニング不足」「ライフスタイル介入への懐疑・優先度の低さ」が、当事者側では「症状による困難（気分の落ち込み・社会不安）」「資源へのアクセス不足（交通・費用・技術）」「介入内容が押し付けがましいと感じる経験」が主要テーマとして繰り返し報告された。

### Panel S1・Table S32：実装・提供のための推奨事項一覧（139〜148ページ）
2019年の第一次委員会報告をもとに作成された組織・スタッフ・介入の3層14項目の予備的推奨リストと、それをマクロ・メソ・ミクロレベルに再編し、根拠となった質的研究を引用しながら整理した最終提言表。「ピアワーカーの雇用」「運動・栄養専門職への精神保健トレーニングの提供」「動機づけ理論に基づく介入設計」「実施状況のモニタリング体制の構築」などが具体策として列挙されている。

### Table S33・S34：GRADE-CERQualによる確信度評価（125〜134ページ）
提言ごとに、根拠となった質的研究の方法論的限界・一貫性(coherence)・関連性(relevance)・データの十分性を4段階で評価し、「高い確信度」16件、「中程度の確信度」5件と判定した表。多くの提言で「関連性」への懸念（根拠となる研究の大半が高所得国由来）が共通の弱点として指摘されている。

### Table S35・S36：グローバルサウス諮問グループ・当事者アドバイザリーグループへの調査結果（141〜153ページ）
予備的推奨14項目それぞれについて、10か国のグローバルサウス専門家(平均関連性スコア7.6〜8.9/10)と、英国の当事者・介護者8名(平均関連性スコア6.6〜8.5/10)から自由記述付きで妥当性評価を受けた結果。低資源国では「専門職員の常設雇用」は財政的に非現実的で、既存スタッフの再教育・ピアワーカー活用の方が現実的といった具体的な文脈的制約が示されている。

## 内容の評価

本文書は原著研究ではなく、複数のレビュー手法（スコーピングレビュー、メタ解析の精選統合、質的エビデンス統合、ステークホルダー・コンサルテーション）を組み合わせた委員会報告の付録であるため、以下では「文献統合プロセスの透明性」「提言の実行可能性」という観点から評価する。なお本PDFには報告書本文（Discussion・Conclusion等の統合的な論述）が含まれておらず、付録データのみで評価している点に留意されたい。

①研究デザイン：介入研究レビュー・メタ解析レビュー・質的統合という3種類の系統的手法を、それぞれ独立した検索戦略（Tables S3, S12, S22）とPRISMA図で明示しており、透明性は高い。ただし、メタ解析78件から18件への絞り込みは著者らの主観的判断基準（多様性・豊富さ・診断群の広がり）に依拠しており、完全に再現可能とは言えない。

②サンプルサイズと選択基準：介入研究99件、メタ解析18件、質的研究38件という統合対象数は妥当な規模だが、質的研究の意図的サンプリングでは「データの豊かさスコア3点以上」という基準がやや主観的である。

③方法論の適切性：AMSTAR2によるメタ解析の質評価（Table S15）、GRADE-CERQualによる質的エビデンスの確信度評価（Table S33-34）を用いており、一次研究の統合というより二次・三次資料の統合における質保証の手続きとしては手堅い。ただし、AMSTAR2評価では18件中4件が「批判的に低品質(Critically Low Quality)」と判定されており、根拠として採用されたメタ解析自体の質にはばらつきがある。

④統計分析の妥当性：本付録自体は新規の統計解析を行わず、既存メタ解析の効果量・サブグループ解析結果を要約する形式である。個々のメタ解析における異質性(heterogeneity)や小規模研究バイアスの評価は元論文に依存しており、本報告書側での再検証はなされていない。

⑤結果の信頼性と再現性：GRADE-CERQual評価により、16件の提言が「高い確信度」、5件が「中程度の確信度」とされ、確信度の根拠が表形式で明示されている点は再現性・透明性の観点で優れている。一方、質的研究の大半が高所得国由来という「関連性」の限界がほぼ全ての提言で共通して指摘されており、非西洋圏・低資源国への一般化可能性には注意が必要である。

⑥結論の妥当性：グローバルサウス諮問グループおよび当事者アドバイザリーグループへの実際の調査結果を提示し、予備的提言に対する定量的な関連性スコア（0〜10点評価）と自由記述フィードバックを透明に示している点は、提言の妥当性検証として説得力がある。特に当事者フォーカスグループでは「lifestyle」の定義自体が狭すぎるという批判的意見（口腔ケアや人生の意味・目的の欠如）も率直に記録されており、報告書が自己の限界を認識している点は評価できる。

⑦新規性：2019年の第一次委員会報告が「なぜ身体的健康に介入すべきか」というエビデンスの提示に主眼を置いていたのに対し、本報告書（第三次）は「どう実装・提供すべきか」という実践知に焦点を移した点に新規性がある。特に質的研究の統合とGRADE-CERQual評価を組み合わせた実装科学的アプローチ、そして当事者・グローバルサウスの声を体系的に取り込むコ・プロダクションの手法は、従来のトップダウン的な臨床ガイドラインとは一線を画す。

⑧臨床的意義：運動セッションの頻度・強度・場（個別vs集団、入院vs外来）による効果の違いを具体的な効果量とともに整理しており、臨床現場での介入設計に直接応用可能な知見を提供している。一方で、提言の多くが「動機づけ理論に基づく」「柔軟な提供形態」といった原則レベルにとどまり、資源制約下（特に低・中所得国）での具体的な実装手順にまで踏み込んだ記述は限定的である。
