# 大規模言語モデルを用いた認知行動療法の応答生成 - ソクラテス式質問との比較研究 精読ノート

## 概要

メンタルヘルスアプリの対話システムは、これまで「決められた台本(シナリオ)どおりに質問する」方式が主流でした。安全で予測可能ですが、会話が浅いと言われます。本研究は、認知行動療法(CBT)の台本のうち、自動思考(ある場面で反射的に浮かぶ考え)を見直させる6回の「ソクラテス式質問」(根拠・反証・別の見方などを問いかける技法)の部分を、大規模言語モデル(LLM)の生成文に置き換えたり、生成文に台本の質問を付け足したりすると、ユーザーの評価がどう変わるかを調べました。LLM は、大阪府の SNS(LINE)相談データで追加学習した日本語対話モデル「OsakaED」(16億パラメータ)と GPT-4 の2種類で、計5条件を比較しました。クラウドワーカー(健常者)86人の有効回答では、OsakaED は台本だけの条件より良くならず、一貫性はむしろ下がりました。一方 GPT-4 は、気分の改善量、共感、信頼などが有意に向上しました。著者らは、実際のサービスで LLM の生成文を利用者に直接見せるのは安全面で問題があるとし、専門家が LLM と協力してあらかじめ応答例の辞書を作る「human-in-the-loop」方式を提案しています。

## FigureとTableの解説

本論文には **Figure はなく、Table が4つ**(Table 1〜4)あります。補足資料はありません。

### Table 1:台本どおりに話す条件(SQ)の対話シナリオ

全条件で共通する15発話の台本です。発話1〜7は CBT の基本モデル「ABC」(A:きっかけの出来事、B:考え・信念、C:結果としての気分)を聞く部分で、困っている状況→そのときの気分→気分の強さ(0〜100点)→浮かんだ考え→いちばん強い考えを「自動思考」として取り上げる、という流れです。発話8〜13がソクラテス式質問6問で、「自動思考が正しいならその根拠は」「間違っているならその証拠は」「ほかの見方は」「最悪の結果は」「最良の結果は」「最も現実的な結果は」と続きます。発話14で気分の強さを再び採点し、15で締めくくります。条件ごとに違うのは発話8〜13だけです。

### Table 2:比較した5つの対話システム

① SQ(台本のソクラテス式質問だけ)、② OsakaED(OsakaED の生成文だけ)、③ OsakaED+SQ(OsakaED の生成文の後に台本の質問を付ける)、④ GPT-4(GPT-4 の生成文だけ)、⑤ GPT-4+SQ(GPT-4 の生成文に台本の質問を付ける)の5条件です。OsakaED は、日本語の Transformer(現在の LLM の基本構造)対話モデルを、LINE 相談の 2,077 対話から取り出した約2.9万組の「文脈と相談員の発話」で追加学習(ファインチューニング)したもので、不適切な語(NG ワード)を含む候補を除いて応答を選びます。

### Table 3:GPT-4 に与えたシステムプロンプト

GPT-4 の振る舞いを決める指示文(システムプロンプト。会話の前提として最初に渡す役割設定)です。先行研究(Kumar ら)で評価が最も高かった「コーチ」という役割と「対人スキルが高い」という性格づけを採用し、「コーチは考え・気分・行動の関係を理解する手助けをし、否定的な考えをより現実的な信念に置き換える手助けをする」と書いています。GPT-4+SQ 条件では、後ろに台本の質問が付くので質問が重複しないよう「コーチは質問をしない」という1文を加えています。実験では日本語に訳して使いました。温度(生成のばらつき)は既定値の1です。

### Table 4:各システムの主観評価(平均と標準偏差)

主要指標は、気分変化(初めと終わりの気分の強さの差を初めの値で割ったもの。大きいほど改善)と CC-immediate(単回 CBT 直後の認知の変化を測る6問の尺度、0〜30点)、さらに対話の質15項目(自然さ、共感、信頼、一貫性など。0〜10点)です。GPT-4 は17項目中14項目で最高でした。気分変化は GPT-4+SQ 0.49、GPT-4 0.44 に対し SQ 0.28、OsakaED 0.22、OsakaED+SQ 0.19。CC-immediate は GPT-4 19.8、SQ 16.6 でした。一方「一貫性」は SQ 8.04 に対し OsakaED 5.79 と大きく下がり、「主導権(自分が会話をリードできた)」は OsakaED が 5.79 で最高でした。「また話したい(re-speak)」は条件間の差が小さい点も重要です。

## 8項目評価

本研究は一次データを集めた原著研究(ただし単回の対話を評価するユーザー実験で、臨床試験ではない)なので、一次研究向けの基準で評価します。

### ①研究デザイン

5条件を比べる並行群間の比較実験で、参加者はどの条件に当たったか知らされていません(参加者の盲検化)。「台本を LLM で置き換える」「台本に LLM を足す」「LLM に台本を足す」という3つの比較を組み、要因を分けて考えられる設計は工夫されています。問題点は、割り付けの方法(ランダム化の手順)が書かれていないこと、対照が「台本」だけで人間のカウンセラーがいないこと、評価が対話直後の1回だけで追跡がないことです。CBT の効果ではなく「1回の対話の印象」を測った研究と読むべきです。

### ②サンプルサイズと選択基準

クラウドソーシングで105人を集め、有効回答は86人、1条件あたり13〜24人と非常に少数です。事前の検出力計算(必要な人数の見積もり)はありません。対象は健常者で、心理的苦痛の尺度 K6 の平均は 7.60(SD 5.59)と、臨床群よりかなり低い水準です。19人が除外された理由の内訳は示されておらず、OsakaED では全候補に NG ワードが入るとエラーになりその回答を無効扱いにしたため、条件によって除外のされ方が偏った可能性があります。結果をうつ病・不安症の患者に当てはめることはできません。

### ③方法論の適切性

台本を共通にし、違いを発話8〜13だけに絞った点は比較として明快です。ただし重大な交絡(結果を左右する別の要因の混入)が2つあります。1つは応答速度で、台本条件は即座に返事が出るのに対し、GPT-4 は数秒以上かかりました。自由記述でも「即答で定型文だと感じた」「止まったかと心配した」との声があり、著者自身が限界として認めています。もう1つは文章の長さで、GPT-4 の応答は長く、OsakaED は短い共感文でした。「中身」の差なのか「長さ・待ち時間」の差なのか区別できません。また GPT-4 の生成文は全対話でソクラテス式質問を含んでおり、「質問をしない」という指示が守られていませんでした。

### ④統計分析の妥当性

2群ずつ Mann-Whitney の U 検定(順位にもとづく、正規分布を仮定しない検定)で比べています。しかし17項目×6通り程度の比較を、多重比較の補正なしで p<0.05 判定しており、偶然の「有意」が混ざる危険が大きいです。効果量(差の大きさの指標)や信頼区間は示されていません。気分変化は初めの点数で割る比率で、初めの値が小さい人では大きくぶれます。また本文の「GPT-4+SQ を加えると GPT-4 より14項目が下がった」は、Table 4 を数えると気分変化以外の16項目すべてが下がっており、記述と表が一致しません(表の 'p¡0.05' のような誤植も残っています)。

### ⑤結果の信頼性と再現性

GPT-4 の2条件がそろって気分変化・共感・信頼などで高い点を得ており、方向性には一貫性があります。しかし各群十数人という規模で、GPT-4 は温度1の確率的な生成であり、モデル自体も随時更新されるため、同じ結果が再現できる保証は弱いです。OsakaED と学習データ(大阪府の相談記録)は公開されておらず、第三者が追試できません。査読前のプレプリントである点も踏まえ、結論は「予備的な結果」として扱うのが妥当です。

### ⑥結論の妥当性

「OsakaED は台本より良くならない」「GPT-4 は対話の印象と気分の改善を高める」という結論は、データの範囲では支持されます。ただし要旨の「GPT-4 は高いカウンセリング能力を持つ」という表現は言い過ぎです。健常者の1回の対話、主観評価のみ、応答速度の交絡、多重比較の未補正を考えると、言えるのは「単回の対話で好印象を与えやすい」までです。一方、生成文を利用者に直接見せることの危険性(幻覚=もっともらしい誤情報、希死念慮のある人への予測不能な応答)を認め、human-in-the-loop を提案する慎重さは評価できます。

### ⑦新規性

CBT の台本型システムと LLM 生成型システムを、同じ台本の上で直接比べた研究は、著者らの知る限り初めてとされます。さらに、実際の相談記録で学習した専用モデルが、汎用の GPT-4 に及ばないどころか台本にも勝てなかったという結果は、「専門データで学習すれば良くなる」という素朴な期待に対する反証として価値があります。ただし比較した専用モデルは16億パラメータと小さく、モデルの規模の差と学習データの差が分けられていない点は新規性の主張を弱めます。

### ⑧臨床的意義

精神科・心理臨床の立場からは、「6問のソクラテス式質問を台本どおりに聞くだけでも、SNS 相談データで学習したモデルと互角だった」という点が示唆的です。CBT の構造そのものに一定の力があることを裏づけます。また GPT-4 は指示しなくても文脈に合ったソクラテス式質問を行えたことから、セラピストの訓練用の応答例づくりや、構造化された自習ツールへの応用が考えられます。ただし対象は健常者で、1回の気分変化しか測っておらず、症状の改善や安全性(危機対応)は検証されていません。臨床でそのまま使える根拠にはならず、大規模で長期のランダム化比較試験が必要です。
