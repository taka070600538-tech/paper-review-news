# インド精神医学雑誌の計量書誌学的評価——動向・影響力・共同研究(2009〜2024年) 精読ノート

> [!note] この論文の性質
> 誌面の見出しは「REVIEW ARTICLE(総説)」ですが、中身は既存研究の内容をまとめる総説ではなく、**論文の書誌データ(著者・所属・引用数・キーワードなど)を数えて分析する「計量書誌学(ビブリオメトリクス)」の研究**です。患者や実験のデータはありません。そのため下の8項目評価では、「サンプル」を「分析対象の論文データ」、「統計分析」を「指標の計算と集計」に読み替えて評価します。また、筆頭著者の Grover 氏はこの雑誌で最多の論文を出している著者本人(148本)であり、自分が深く関わる雑誌を評価している点にも注意が必要です。

## 1. 概要

*Indian Journal of Psychiatry*(IJP、インド精神医学雑誌)は、インド精神医学会の公式誌で、1949年創刊の歴史ある雑誌です。この研究は、論文データベース Scopus から、IJP が2009〜2024年の16年間に載せた **2,357本** の論文の書誌情報を取り出し、出版数・引用数・著者・所属機関・国・キーワードを集計しました。

主な結果は次のとおりです。

- 出版数は年平均 **9.16%** のペースで増え(2009年86本→2024年222本)、インパクトファクター(論文がどれだけ引用されるかの指標)は2010年の **0.384** から2022年に **3.1**(約8倍)まで上がりました。その後2023年1.7、2024年2.0です。
- 論文の **88.63%** にインド人著者が含まれ、NIMHANS(バンガロール)や PGIMER(チャンディーガル)などの一流機関が中心です。一方、スイス・ドイツ・カナダ・イタリアなどの著者を含む論文のほうが、1本あたりの引用数は多い傾向でした。
- 単著論文は 28.65%(2009〜12年)から 9.9%(2021〜24年)に減り、共同研究が主流になりました。
- テーマはうつ病・統合失調症などが中心で、COVID-19 にも素早く反応していました。

著者らは、国際共同研究を増やして世界での存在感を高めるべきだと結論しています。

## 2. Figure と Table の解説

本文で言及される図表は、Figure 1、Table 1〜3、補足資料の Supplementary Figure 1 と Supplementary Table 1〜9 の計14点です。以下、順に説明します。

### Supplementary Table 1:雑誌の評価指標の推移(2010〜2024年)

3つの指標を年ごとに並べた表です。**インパクトファクター(IF)**は「直近2年の論文が平均何回引用されたか」、**CiteScore** は Scopus 版の同様の指標で直近4年を使います。**SJR** は、有名な雑誌からの引用ほど重く数える指標です。IF は2010年0.384→2021年2.983→2022年3.1と急上昇し、2023年に1.7へ下がりました。CiteScore は2022・2023年の4.4が最高で2024年は2.2、SJR は2022年の0.771が最高です。2024年の SJR 区分は Q3(4段階の下から2番目)と表の注に書かれています。2021〜22年の急上昇は COVID-19 関連論文がよく引用された時期と重なります。

### Table 1:年ごとの出版数と引用数

各年の論文数(TP)、被引用数の合計(TC)、1本あたりの被引用数(CPP)、インド人著者・外国人著者を含む論文数を示します。合計2,357本、被引用26,726回、CPP は11.33です。前半(2009〜16年)の CPP は17.22、後半(2017〜24年)は7.93で、2024年の論文は1.51しかありません。これは質の低下ではなく、**新しい論文ほど引用される時間が短い**ためです。なお、インド(2,089本)と外国(471本)の合計は2,560本で総数を超えます。両国の著者がいる共同論文が両方に数えられているためで、表の読み方に注意が必要です。

### Supplementary Table 2:論文の種類別の内訳

原著論文が1,197本(50.78%)で最多、次いで編集者への手紙488本(20.70%)、総説409本(17.35%)、論説168本(7.13%)です。1本あたりの被引用数は、学会の受賞講演などにあたる「Conference Papers」が36.86回で最も高く、総説21.06回、原著12.10回、手紙2.57回でした。ただし Conference Papers は14本しかなく、平均値が少数の論文に大きく左右される点に注意が要ります。分類は雑誌独自のものではなく Scopus の分類を使ったと注記されています。

### Supplementary Table 3:被引用数の分布

論文を被引用数の幅ごとに分けた表です。1回以上引用された論文は1,918本(81.3%)、一度も引用されていない論文は439本です。1〜10回の論文が1,277本と最も多く、51〜100回は65本、101回以上は29本、240回を超える「代表的な論文」は6本だけでした。つまり、**ごく少数の論文が雑誌全体の評価を押し上げる「ロングテール型」(一部に極端に集中する分布)**です。これは多くの学術誌に共通する特徴でもあります。

### Supplementary Table 4:著者数のパターン

論文1本あたりの著者数を4年ごとに集計した表です。単著(著者1人)は2009〜12年の104本(28.65%)から、2021〜24年には72本(9.9%)へ減りました。反対に、著者5〜10人の論文は52本から219本へ、10人を超える論文は2本から36本へ増えています。精神医学研究が、1人で書く論文から、複数の機関が協力するチーム研究へ移っていることを示しています。

### Table 2:主な国別の貢献と引用

国ごとの論文数・被引用数・CPP・**RCI(相対被引用指数。雑誌全体の平均を1としたときの引用の多さ)**を並べています。インドは2,089本で CPP 11.60、英国96本(14.41)、米国95本(17.58)、カナダ38本(17.68)、ドイツ16本(17.68)、スイス11本(22.36、RCI 1.97)と続きます。トルコ(5.58)や中国(7.2)は平均を下回りました。ただし、スイスやイタリアは11本しかなく、数本のよく引用される論文で平均が大きく変わります。また、インドの CPP 11.60 は全体平均11.34より高いのに RCI が0.90になっており、計算が合いません(他国は CPP÷11.34 で RCI と一致します)。

### Supplementary Figure 1:国どうしの共同研究ネットワーク

上位13か国の著者がどの国の著者と一緒に論文を書いたかを、VOSviewer(論文データを網の目状の図にするソフト)で描いた図です。**TLS(総リンク強度。つながりの多さ・強さの合計)**は290で、5つのグループ(クラスター)に分かれました。インドが中心にあり、米国・英国と強く結ばれています。ほかに、オーストラリア・中国・ドイツのグループ(赤)、カナダ・イラン・米国のグループ(緑)、ネパール・トルコ・パキスタンの小さなグループがありました。図そのものはテキスト抽出では見えず、本文の記述に基づいて説明しています。

### Supplementary Table 5:論文数の多い上位25機関

2,571の機関の中で、上位25機関が論文の73.61%、被引用の92.35%を占めます。最多は NIMHANS(国立精神保健神経科学研究所、バンガロール)428本、次いで PGIMER(チャンディーガル)223本、AIIMS ニューデリー153本、JSS 医科大学(マイソール)148本、KGMU(ラクナウ)99本です。CPP が高いのは Gautam 病院(33.58)、Fortis Healthcare(27.83)などでした。ICP は国際共同論文の数、TLS は他機関とのつながりの強さです。NIMHANS と PGIMER の結びつき(TLS 518)が最も強いと本文で述べられています。

Gautam(30.41)が高い値でした。上位25人の論文数は合計1,117本で、表では総数の47.39%とされていますが、本文では「44.68%」と書かれており、食い違っています(44.68は1人あたりの平均本数1,117÷25と同じ値です)。

### Supplementary Table 6:疾患・分野ごとの論文数

論文がどの病気・分野を扱っているかを、前半(2009〜16年)と後半(2017〜24年)で比べた表です。多い順に、不安症(817)、うつ病(702)、精神病性障害(580、統合失調症422を含む)、精神保健(449)、物質使用(290)、気分障害(290、双極性障害212)、自殺(212)が並びます。後半には不安・ストレス・睡眠・神経発達症(自閉スペクトラム症、ADHD など)が大きく増えました。ただし、「Anxiety」の行に前半の値が欠けている、妄想型統合失調症の合計(14+4=18のはずが22)が合わないなど、細かな転記の誤りが見られます。

## 3. 8項目の評価

### ① 研究デザイン

1つの雑誌の書誌データを、期間を区切って集計する記述的な計量書誌学研究です。分析ソフト(Excel、VOSviewer、bibliometrix)や検索式が明記され、他の人が同じ手順をたどれる形になっている点は良いところです。一方で、比較対象となる他の精神医学雑誌や、インドの他の医学雑誌との比較がなく、「IJP の伸びが特別に大きいのか、分野全体の伸びと同じなのか」が判断できません。また、筆頭著者が最多寄稿者であり、雑誌の内部者による自己評価という利益相反に近い構造があるのに、利益相反は「なし」とされています。

### ② サンプルサイズと選択基準(=分析対象データ)

Scopus で3,131件がヒットし、条件で絞って2,357本を対象にしました。雑誌に載った論文をほぼ全部扱うので、数としては十分です。しかし、3,131件から2,357件へ減らした「必要な絞り込み」の中身が書かれておらず、何が除かれたか分かりません。開始年を2009年(PubMed 収載の年)にした理由は示されていますが、1949年からの長い歴史の大半は対象外です。正誤表(13本)のような論文でない記録も分析に含まれており、選び方はやや粗いと言えます。

### ③ 方法論の適切性

CPP、RCI、TLS などの標準的な指標を使い、ネットワーク図で共同研究やテーマの構造を見せる方法は、計量書誌学の定番です。ただし、RCI を「分野の期待引用数で割った値」と定義しながら、表の値は実際には「雑誌全体の平均で割った値」になっており、定義と計算が一致していません。また、引用までの年数が論文ごとに違うのに、年数で補正した指標を使っていないため、前半と後半の CPP を単純に比べてしまっています。テーマ分類が Scopus の自動索引語に頼っている点も、精度の限界になります。

### ④ 統計分析の妥当性(=指標の計算と集計)

検定や信頼区間はなく、記述統計だけです。年平均成長率9.16%は「各年の増加率の平均」で、手元で計算し直すと一致しましたが、16年間を通した複利の成長率(約6.5%)より大きく見える計算方法です。本文と表の数値にいくつか食い違いがあります:上位25人の占有率(本文44.68%、表47.39%)、インドの RCI(CPP からは1.02のはずが0.90)、50回超引用論文の割合(本文約4.3%、表から計算すると約4.0%)、妄想型統合失調症の合計などです。共同論文の二重計上についての説明もありません。

### ⑤ 結果の信頼性と再現性

検索式・期間・データベース・ソフトが明示されているため、手順の再現性は高めです。ただし Scopus の引用数は日々変わるため、取得日が書かれていないと同じ数値は再現できません。上に挙げた表と本文の不一致は、転記ミスがあることを示し、他の数値の正確さにも疑問を残します。また、外国の国別 CPP は11〜16本程度の小さな数に基づいており、1〜2本の人気論文で順位が入れ替わるため、「外国の論文のほうが引用されやすい」という結論は安定したものとは言えません。

### ⑥ 結論の妥当性

「出版数と IF が伸び、共同研究が増えた」という結論は、データとよく合っています。著者ら自身も、IF などが4%程度のよく引用される論文に支えられていること、後半の CPP 低下は時間の短さによることを認めており、慎重な面もあります。一方、「81.3%が1回以上引用されたことは論文の質を示す」「受賞講演論文は質が高い」といった解釈は、引用数を質と同一視しすぎています。自誌引用の多さや、COVID-19 特需による一時的な IF 上昇(2023年に下落)を考えると、「評価が着実に上がり続けている」という表現はやや楽観的です。

### ⑦ 新規性

IJP を対象とした計量書誌学研究はこれが初めてだと著者らは述べており、インドの精神医学研究の担い手・テーマ・共同研究の地図を一度に示した点には記録としての価値があります。ただし手法自体は、同じ著者グループ(Vaishya、Gupta ら)がインド整形外科学雑誌などで行ってきたものと同じ型で、方法論の新しさはありません。著者らは「精神医学雑誌の計量書誌学研究は見つからなかった」と書いていますが、実際には他国の精神医学雑誌を対象にした研究も存在すると考えられ、文献調査の範囲が狭い可能性があります。

### ⑧ 臨床的意義

患者の治療に直接役立つ研究ではありません。意義は、インドの精神医学研究が、どの機関に集中し、どの病気に関心を向け、どの国とつながっているかを示した点にあります。少数の一流機関に研究が集中しているという結果は、研究資金や環境の地域差を示しており、研究体制の改善を考える材料になります。日本の読者にとっては、オランザピンや電気けいれん療法などの薬物・身体療法の研究が多い一方、ヨガや家族制度など文化に根ざしたテーマも目立つ、という研究文化の違いを知る手がかりになります。

## 4. 整合性の最終チェック

- **読んだ範囲**:PDF 全15ページ(本文 pp.510–516 の7ページと、補足資料8ページ)をすべて読んだ。Read ツールの PDF 直接読み込みは使わず、スキル同梱の `extract_pdf_text.py`(pdfplumber)でテキストを抽出して読んだ。2段組みのため行が混ざっている箇所は、文脈から段を分けて読んだ。
- **図表の網羅**:本文で言及される Figure 1、Table 1〜3、Supplementary Figure 1、Supplementary Table 1〜9 の計14点をすべて解説した。Figure 1 と Supplementary Figure 1 は画像のため中身は見えず、本文の記述に基づいて説明した。
- **数値の照合**:2,357本、26,726回、CPP 11.33、年平均成長率9.16%、IF 0.384→3.1、インド人著者88.63%、単著28.65%→9.9%、スイス CPP 22.36 などがノートと原文で一致することを確認した。年平均成長率は Table 1 から再計算して9.16%(各年の増加率の平均)になることを確かめた。被引用1回以上の割合(1,918÷2,357=81.4%)、上位30本の占有率(5,029÷26,726=18.8%)も計算で確かめた。
