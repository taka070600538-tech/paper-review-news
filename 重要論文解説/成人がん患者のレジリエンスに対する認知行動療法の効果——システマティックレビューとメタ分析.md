# 成人がん患者のレジリエンスに対する認知行動療法の効果——システマティックレビューとメタ分析 精読ノート

> 役割：日本トップクラスのサイエンスコミュニケーターとしての精読プロンプト（デフォルトフォーマット）に基づく分析結果。本論文は一次研究ではなく**メタ分析（既存研究の統合）**なので、8項目評価は文献検索・選択基準、研究間の異質性の扱いなどレビューの文脈に読み替えて行う。

## 1. 概要（500字以内）

がん患者は不安や抑うつを抱えやすく、困難から立ち直る心の力である「心理的レジリエンス」も一般人より低いとされる。認知行動療法（CBT、考え方と行動のくせを見直す心理療法）がこの力を高めるかは、がん患者に絞ると未整理だった。著者らは5つのデータベースを2023年8月まで検索し、成人がん患者を対象に対照群を置いた13試験（計1185人、平均約91人）を統合した。主指標はHedges' g（群間差の大きさを標準化した指標）で、治療直後のレジリエンスの改善はg=1.211（95%CI 0.933〜1.490、p<0.001）と、大きな効果が報告された。ただし研究間のばらつきは大きく（I²=77.7%）、GRADEで証拠の確実性は「中」に格下げされた。メタ回帰では、スマートフォンなどのモバイル配信、集団形式、腫瘍が残っている患者で効果が大きいと報告された。一方、13試験中11試験が中国の研究で、フォロー期間の長い研究は2件のみである。著者らは、CBTを日常的な心理支援に組み込むことを勧める。

## 2. FigureとTableの解説

本文で言及されるのは Fig. 1〜3 と Table 1〜3 の計6点。補足資料（SDC Table：各データベースの検索式）は PDF に含まれず、本文で参照されるのみ。

### Fig. 1 研究選択のフローチャート
データベースから1,191件を検索し、重複1,059件を除いて132件をスクリーニングした。全文確認を経て13件が基準を満たした、という流れを示すPRISMA形式の図（図の中身は画像で、テキストでは本文記載の数値のみ確認した）。ステップごとに「何件が残ったか」が追えるため、検索の網羅性と選別の透明性を判断する材料になる。

### Fig. 2 治療直後のレジリエンスへの効果のフォレストプロット
各試験の効果量（Hedges' g）と信頼区間を横棒で並べ、最下段に統合値（g=1.211）を示す図（フォレストプロット＝試験ごとの結果と統合結果を一望する図）。本文では統合値が大きく有意で、出版バイアスの証拠はなく、失敗安全数（fail-safe N、結果を無効にするのに必要な未発表の「効果なし」研究数）が1141と基準115を大きく上回ると説明される。ただし試験間のばらつき（I²=77.7%）が大きい点には注意が必要。

### Fig. 3 バイアスリスクの評価
Cochraneのバイアスリスクツールで、無作為化、割り付け隠蔽、盲検化、データ欠落、選択的報告、治療の実施精度、利益相反の各項目を13試験について評価した図。本文では評価者2名の一致は91判定中87（95.6%）。図そのものは画像で内訳（どの項目が高リスクか）は本ノートでは確認できていない。心理療法では参加者の盲検化が難しいため、一般にバイアスリスクが高く出やすい領域である。

### Table 1 採択研究の特徴（13件）
著者・発表年・国、がんの種類と病期、平均年齢、性別、対象人数（介入群/対照群）、CBTの型、形式（個人・集団・夫婦）、配信法（対面・モバイル）、セッション数と期間、測定時点をまとめた表。11件が中国、他は米国とイランが各1件。乳がんが5件で最多、尺度は12件がCD-RISC（Connor-Davidson Resilience Scale、レジリエンス尺度）、1件がResilience Scale。セッション数は1〜12回（平均6回）、期間は2〜12週。伝統的CBT 7件、現代的CBT 6件。対照は多くが通常ケアである。PDF上では表が回転しており、個別セルの読み取りは概要の確認にとどまる。

### Table 2 治療直後の統合効果とサブグループ解析
全体と、性別・がん種・腫瘍の有無・病期・主要評価項目か否か・尺度・CBTの型・形式・配信法・期間別のg、95%CI、I²、fail-safe Nを示す表。全体g=1.211。モバイル1.472対対面1.103、集団1.479対個人1.146、腫瘍あり1.346対なし1.106、伝統的CBT 1.400対現代的CBT 0.936、レジリエンスが主要評価項目1.416対副次0.991。サブグループにより件数が1〜3件と少なく、解釈は慎重にすべきである。

### Table 3 メタ回帰（共変量の影響）
各条件が効果量をどれだけ左右するかを回帰で調べた表。腫瘍あり（係数1.047、P=0.037）、対面（係数−0.765、P=0.012）、集団形式（係数−0.105、P=0.042）が有意とされ、がん種・病期・性別・CBTの型・期間は有意でなかった。ただし本文の数値（β=0.284、0.181、0.285）や、t値とP値の対応が表と合わない箇所があり（後述）、表の信頼性に疑問が残る。

## 3. 8項目評価（レビュー論文向けに読み替え）

**① 研究デザイン**
PRISMAに準拠し、PROSPERO（CRD42021256841）に事前登録された、検索・選択・データ抽出・バイアス評価を2名が独立して行う標準的な構成である。一方、選択基準は「対照群のある研究」とされ、本文は「13件のRCT」と書く箇所と「controlled trials」と書く箇所が混在し、全13件が本当に無作為化されたかが曖昧である。CBTの定義も広く、マインドフルネスや肯定的心理的介入まで含められている。

**② サンプルサイズと選択基準（文献検索・選択基準）**
5つのデータベースを検索し、芋づる式検索も行ったが、言語を英語と中国語に限り灰色文献を除外した。結果として13件中11件が中国の研究で、人口・文化的な偏りが強い。合計1185人は一定の規模だが、サブグループは1〜3件のこともあり検出力は弱い。レジリエンスが主要評価項目の試験は6件のみ（本文は7件と書く箇所もあり不整合）。

**③ 方法論の適切性**
介入が「レジリエンスを直接の標的にしていなくてもよい」とされ、CBTの型も「伝統的」「現代的」とまとめて扱われるため、介入の異質性が大きい。1試験につき1つの効果量に絞ったのは独立性を保つ点で妥当。尺度は事実上CD-RISCに偏り、尺度間比較は成立していない。長期効果は2試験（1か月、3か月）のみで、持続性は評価できない。

**④ 統計分析の妥当性**
ランダム効果モデルを採用したのは異質性が高いため妥当である。しかし方法で「I²≤50%なら固定効果」と書きつつ全分析でランダム効果としており、説明が混乱している。さらに、g=1.2は心理療法のメタ分析としては異例に大きく、「small but significant」と書く要旨と矛盾する。Table 2のRS（1件）はCIが0をまたぐのにP<0.001と記載され、Table 3は係数とP値・t値の対応が不自然（例：t=4.05でP=0.056）である。10個の共変量を13試験に当てはめた回帰は過剰適合のおそれが強い。出版バイアスはfail-safe Nのみで、Egger検定やファンネルプロットは未実施（著者も限界として認める）。

**⑤ 結果の信頼性と再現性**
I²=77.7%と異質性が高く、GRADEは「中」へ格下げされた。評価者間一致（κ=0.817、判定一致95.6%）は良好で、検索式も補足資料で公開され、再現しやすい点は強み。反面、元試験の多くは小規模で盲検化が難しく、通常ケア対照では期待効果（プラセボ的な影響）が混入しうる。上記の数値の不整合は、再現性を損ねる要因である。

**⑥ 結論の妥当性**
「CBTはがん患者のレジリエンスを高める」という大枠の結論は、方向としては妥当である。しかし「モバイルや集団が対面・個人より優れる」という結論は、モバイル配信が3試験のみで、交絡（配信法と対象・国・介入内容の違い）を調整できておらず、間接比較の域を出ない。著者が推奨する「CBTを日常的支援へ組み込む」「AIを使ったモバイルCBT」も、本論文のデータが直接示す範囲を超えた考察である。乳がんで効果が弱かった点の説明も推測にとどまる。

**⑦ 新規性**
がん患者に絞り、レジリエンスを結果指標としてCBTの効果を量的に統合した点が新しい（著者は初の包括的メタ分析と主張）。配信法・形式・腫瘍の有無といった実装上の論点を検討した点も実用的である。ただし先行する、がん患者のレジリエンス介入に関するレビューやネットワークメタ分析（本文引用）との差異や、介入全般との直接比較は十分に論じられていない。

**⑧ 臨床的意義**
精神腫瘍学の臨床で、CBT系の介入が患者のレジリエンスを改善しうるという裏づけは、サイコオンコロジー導入の根拠となる。集団形式やモバイル配信は人員・時間・移動の制約を補う点で現実的な示唆である。反面、効果量の大きさは過大評価の可能性があり、日本を含む中国以外の医療環境、進行がんの終末期、実際のQOLや生存への影響に一般化するのは時期尚早。フォロー期間が短く、効果の持続は不明である。
