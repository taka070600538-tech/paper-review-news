# 問題的なソーシャルメディア利用と思春期の精神的ウェルビーイング——社会経済的格差に関する国際比較研究 精読ノート

## 概要(500字以内)

SNSにのめり込み、やめられない・家族と揉める・嫌な気分から逃げるために使うといった「問題的なソーシャルメディア利用(PSMU)」が、思春期の心の健康を損なうことは知られています。本研究は、その害が「家庭の豊かさ」と「国の所得格差」によって変わるのかを調べました。WHO協力の学校調査HBSC(2017/18年)から、35か国・約14万5千人の11〜15歳のデータを、個人と国の二層を同時に扱うマルチレベルモデルで解析しています。結果、PSMUが高いほど心理的不調(落ち込み・いらいら・神経過敏・不眠)が多く、生活満足度が低いという関係は全ての国で一貫していました。この関係は低所得家庭の子で強く、特に生活満足度で差が目立ちました。国レベルでは、格差が中くらいの国で害が最も大きく、格差の小さい国と大きい国では同程度という逆U字型でした。家庭による差は国の格差水準が違っても概ね保たれていました。ただし横断データで因果は言えず、効果量も小さめです。

## Figure・Tableの解説

本文で言及される図表は、Figure 1(3パネル)、Table 1、Table 2、付録のTable A1・Table A2の計5点です。

### Table 1:国別の記述統計(個人レベル・国レベル)

35の国・地域(ベルギーはフランダース/ワロン、英国はイングランド/スコットランド/ウェールズに分かれる)ごとに、人数、女子割合、年齢、家庭の豊かさ尺度(FAS)、頻繁なSNS利用(FSMU)、PSMU、心理的不調(PC)、生活満足度(LS)、国の1人当たりGDP、中等教育への支出割合、インターネット利用率、ジニ係数(0=完全平等〜100=完全不平等の格差指標)を並べた表です。PSMUの平均はマルタが最高(2.98、満点9)、アイスランドが最低(1.27)。心理的不調はイタリアが最高(1.75)、カザフスタンが最低(0.80)で、カザフスタンは生活満足度も最高(8.56)。ジニ係数はスロベニア24.6〜イスラエル38.6の範囲です。全体では平均年齢13.63歳、女子53%、PSMU平均1.87でした。なお合計行の国レベル列は数値の並びがずれているように見えます(ジニ係数欄が82.91など)。

### Table 2:心理的不調と生活満足度のマルチレベル回帰

各結果変数について3段階のモデルを示します。Model 1(1a・1b)では、PSMUが1点上がるごとに心理的不調が0.139点増え(0〜4点尺度)、生活満足度が0.167点下がりました(0〜10点尺度)。高SES(家庭が豊か)の子は不調が少なく満足度が高い傾向です。Model 2で「PSMU×SES」の交互作用(ある要因の効果が別の要因の水準で変わるか)を入れると、低SESの子の傾き(不調+0.141、満足度−0.179)に比べ、高SESでは不調で−0.006、満足度で+0.021だけ害が弱まりました。Model 3では国レベル変数との交互作用(クロスレベル交互作用)を加え、国間の傾きのばらつきの28%(不調)と47%(満足度)を説明しました。表の下部にはランダム効果の分散、AIC・BIC(モデルの当てはまりを比べる指標)が載っています。

### Figure 1:交互作用の効果をまとめた図(95%信頼区間)

Table 2とTable A2の交互作用項を、点と横線(推定値と95%信頼区間)で描いた図です。Panel A(個人レベル)では、生活満足度で中SES・高SESの点が0より右にあり、低SESに比べ害が小さいことが一目で分かります。心理的不調では高SESだけがわずかに0より左です。Panel B(国レベル)では、中格差国(Mid-Gini)が不調で右、満足度で左に寄り、害が強いことを示します。高GDP国は不調で左(害が弱い)、インターネット普及率が中・高の国は満足度で左(害が強い)。Panel C(3要因の交互作用)では、中格差国の低SESが不調で大きく右、満足度で左に寄っていますが、多くの線は0をまたいでいます。

### Table A1(付録):国レベル変数が切片に与える固定効果

Model 3・4で、国の特徴が「そもそもの不調・満足度の水準」(切片)をどう変えるかを示す表です。GDP、教育支出、ジニ係数の各区分はほとんど統計的に有意ではなく、唯一、Model 4bで中格差国の生活満足度の水準が低格差国より0.257点低いことだけが有意でした。インターネット普及率の中・高区分で生活満足度に−0.067、−0.092が示されていますが、これはTable 2の「PSMU×インターネット普及率」の交互作用係数と全く同じ数値で、転記の誤りの可能性があります。高教育支出の標準誤差0.663も他と比べて不自然に大きい値です。

### Table A2(付録):SES×ジニ係数×PSMUの三重交互作用

家庭の豊かさと国の格差の組み合わせによって、PSMUの害がさらに変わるかを調べたModel 4の係数表です。心理的不調では三重交互作用が全体として有意で(χ²検定 p=0.007)、中格差国の低SESで傾きが0.032強まり、中格差国の中SESで−0.027弱まるなどの項が有意でした。生活満足度では全体として有意ではありません(p=0.606)が、中格差国の低SESで−0.041、低格差国の高SESで+0.027が個別に有意です。著者らはこれを「SES間の差は国の格差水準によらず安定(仮説3b)」と解釈していますが、心理的不調の結果はこの解釈と完全には一致しません。

## 8項目評価

### ①研究デザイン

国際学校調査HBSCの2017/18年データを使った横断研究で、生徒(個人)が国の中に入れ子になった構造を、マルチレベルモデル(階層ごとのばらつきを分けて推定する手法)で扱っています。家庭(ミクロ)と国(マクロ)の格差を同時に調整要因として検討する枠組みは明快で、3つの研究課題と仮説(H1、H2、H3a/3b)も事前に整理されています。問題点は、1時点の調査なので「PSMUが心を悪くする」のか「心の不調がPSMUを招く」のかを区別できないことです。著者も限界として認めています。また学校単位の抽出なのに、学校という中間層をモデルに入れていません。

### ②サンプルサイズと選択基準

最終サンプルは35か国・144,934人と非常に大きく、個人レベルの推定精度は十分です。一方、国の数は35で、それを三分位(3群)にすると1群12か国前後です。国レベルの交互作用や「逆U字」を論じるには国数が少なめです。除外基準では、変数欠損のある4か国と国データ欠損の7か国を除き、SNSを使っていない8,151人、各変数の欠損(PSMUだけで16,407人)を除いています。合計約4万人の除外を、χ²検定とt検定(結果は非提示)だけで「ランダムな欠損」と判断しており、根拠が弱いです。さらにSNSを使わない子を除いたため、結果は利用者に限られます。

### ③方法論の適切性

心理的不調(HBSC症状チェックリスト、α=0.78)、生活満足度(キャントリルの梯子)、PSMU(SNS障害尺度9項目、α=0.89)、FAS(家庭の豊かさ6項目)と、国際比較で検証済みの尺度を使っています。国レベル変数は世界銀行の2018年データです。問題点は、ジニ係数・GDPなどを連続値でなく三分位の区分にしたことです。外れ値には強くなりますが、情報が失われ、著者自身も「非線形の形は推定できない」と述べています。FASは国内三分位で相対化しており、国をまたいだ絶対的な豊かさは比べられません。FSMUを「4段階」としつつ選択肢を0〜4の5つ挙げるなど、記述にも不整合があります。

### ④統計分析の妥当性

段階的にモデルを積み上げ、交互作用全体の有意性をχ²検定で確かめ、ランダム傾きの分布を95%予測区間で示し、多重共線性(説明変数同士が似すぎる問題)も条件指数で確認しています。問題点はいくつかあります。Table 2のPSMUの95%予測区間(不調0.190〜0.383、満足度−0.506〜−0.181)が、固定効果の平均(0.139、−0.167)を含んでいません。平均が区間の外にあるのは通常あり得ず、計算か表記の誤りが疑われます。また重み付けや大標本国を除いた感度分析は「結果は示さない」とされ、検証できません。多数の交互作用を検定しているのに多重比較の補正もありません。

### ⑤結果の信頼性と再現性

データはHBSCのオープンアクセスで公開されており、尺度も標準的なので、再分析は比較的しやすい研究です。PSMUと不調・低満足度の関連が35か国すべてで同じ向きだったことは、先行研究(Boerら2020の29か国研究など)とも一致し、信頼できる結果と言えます。一方、SESによる差の大きさは、生活満足度で低SESの傾き−0.179に対し高SESで+0.021(約12%弱まる)、心理的不調ではわずか−0.006で、p値も0.029と境界的です。中格差国だけ害が強いという結果も、国の区分の切り方で変わり得る脆い所見です。文中で「ロシア(37.5)」と除外したはずの国のジニ係数を挙げているなど、記述の誤りもあります。

### ⑥結論の妥当性

「PSMUはどの国でも心の健康の悪化と関連する」「低SESの子でより強い」という結論は、データとおおむね合っています。ただし「低SESの子により害を与える」という因果的な言い回しは、横断データの範囲を超えています。「逆U字型」という表現も、3区分の比較で中央だけが違うという結果からは強すぎます。「SES間の差は国の格差によらず安定(H3b支持)」という結論は、心理的不調で三重交互作用が有意(p=0.007)だった点と食い違いますが、その矛盾は十分に議論されていません。結論部では分析していない「学校」の格差にも触れています。中格差国の結果を説明する同類性(同じ階層の人とつながる傾向)などの仮説も、検証されていない後付けの説明です。

### ⑦新規性

PSMUと思春期のウェルビーイングの関連を、家庭のSESと国の所得格差という2層の格差で同時に調整要因として検討したのは、著者の知る限り初めてとされています。PSMUと格差の関係はLenziら(2022)が「格差の大きい国ではPSMUそのものが多い」ことを示していましたが、本研究は「PSMUの害の強さ」が格差でどう変わるかに焦点を移しました。デジタル格差論・技術普及論・社会的比較論を一つの枠組みにまとめた理論面の整理も価値があります。ただしデータは既に広く分析されているHBSC 2017/18で、PSMUと不調の関連自体は新しい知見ではありません。新規性は「格差による調整」の部分に限られます。

### ⑧臨床的意義

精神科や学校保健の現場では、「SNSにのめり込む子の中でも、家庭の経済的余裕が少ない子は生活満足度の低下が起きやすい」という視点が、リスク評価の参考になります。著者らは、低SES家庭を重点にした早期のデジタル介入、学校カリキュラムへのデジタル・ウェルビーイング教育、デジタル資源の普及策を提案しています。ただし効果量は小さく、個々の患者の予後を予測できる水準ではありません。介入研究でもないため、どの支援が効くかは示されていません。データは2018年でTikTok普及前、日本も含まれないので、現在の日本の子どもにそのまま当てはめるには注意が必要です。
