# 学業成績と大学生の主観的ウェルビーイング - 北京の327人の調査 精読ノート

## 概要(500字以内)

本研究は、中国・北京工商大学の学部生327人(2022年10月のオンライン調査、新入生は前年度GPAがないため除外)を対象に、学業成績と主観的ウェルビーイング(自分の幸福感を1〜10点で自己評価)の関連を、順序プロビット回帰で検討した横断研究である。

主な結果は次の通り。(1)ウェルビーイングの平均は6.875点と「中の下」で、6点以下が35.78%、8点以上は37.61%にとどまった。(2)前年度GPA(絶対的成績)が1点高いほど、統制変数を入れた後でも、より高いウェルビーイング区分を報告する確率が0.034上がった(p<0.05)。(3)GPAの学内順位(相対的成績)では、上位25%を基準として、上位25〜50%と50〜75%の学生のウェルビーイングが有意に低く(限界効果−0.026、−0.038)、下位25%では有意差がなかった。著者らはこれを社会的比較理論で説明し、最下位層については「寝そべり(躺平)」心性という事後的な仮説を挙げている。(4)サブグループ解析では、関連は女性と低学年でより強く、出身地(都市/農村)では交互作用が有意でなかった。(5)サークル加入、専攻への好意、外向性、自己評価の健康もウェルビーイングと正の関連を示した。大学入学時の配置試験成績を操作変数とした内生性検定でも結果は頑健だった。著者らは単一大学・横断・単一項目尺度・自己申告GPAという限界を認め、因果ではなく関連として解釈すべきと明記している。

## Figure・Tableの解説

本文で言及される図は3点(Figure 1〜3)、表は7点(Table 1〜7)である。

### Figure 1:サンプル選択(約200字)

調査の流れを示すフロー図。オンライン調査プラットフォーム「問巻星(QuestionStar)」で作成したリンクを授業のグループチャットやWeChatモーメンツで配布し、422件の回答を得た。主要変数の欠損や非現実的な値(年齢50歳超、負のGPAなど)を除いて398件(有効回答率94.3%)、さらに前年度GPAを持たない新入生71人を除外して最終解析対象327人となった。内訳は2年生48.62%、3年生28.44%、4年生22.94%、人文社会系58.41%、自然科学系41.59%。配布経路が自発的な回答者に偏る便宜的標本であり、母集団(同大学の学部生全体)の構成と比較されていない点に注意が要る。

### Figure 2:学生の主観的ウェルビーイングの分布(約200字)

1〜10点で自己評価したウェルビーイングの分布を示す図。平均は6.875点、6点以下が35.78%、8点以上が37.61%で、著者らは「全体の水準は高くない」と評する。学年別では2年生7.019点、3年生6.667点、4年生6.827点、性別では女性6.934点、男性6.786点であった。ただし本文の「時間とともに低下する傾向」という表現は、横断データの学年差から推測したものであり、同じ学生を追跡したわけではない(3年生より4年生の方が高い点も単調低下とは言えない)。1項目尺度の分布は天井・床効果や回答様式の影響を受けやすいことも留意点である。

### Figure 3:学業成績のカーネル密度推定(約200字)

前年度GPA(0〜5の範囲で自己申告)の分布を滑らかな密度曲線で示した図。平均3.402、最大4.32、最小1.50で、「平均を上回る水準にあり、現在の『内巻(過当競争)』の社会環境と密接に関係する」と著者らは述べる。少数の学生は試験に不合格だった。GPAが自己申告であることから、社会的望ましさによる上方バイアスの可能性があるが、匿名性の保証によって正直な回答を促したと説明される。分布の形状(歪みや多峰性)についての定量的記述は本文にない。

### Table 1:変数の定義と記述統計(約200字)

従属変数(ウェルビーイング1〜10点、平均6.875)、関心のある独立変数(前年度GPA、1.50〜4.32、平均3.402)、統制変数(学年、年齢18〜26歳・平均20.177、性別[男性40.1%]、専攻[社会科学58.4%]、クラス幹部[46.2%]、出身地[都市63.6%]、家庭収入5段階・平均2.899、月生活費5段階・平均2.963、サークル加入数0〜5・平均1.101、専攻への好意5段階・平均3.459、学業プレッシャー5段階・平均3.431、性格[内向〜外向5段階]・平均3.080、自己評価の健康1〜10点・平均6.954)を一覧にしている。家庭収入や生活費などの区分の定義も示される。標準偏差が示されていないため、各変数のばらつきは読み取れない。

### Table 2:絶対的な学業成績がウェルビーイングに与える影響(約200字)

OLS(通常の最小二乗法、参考)と順序プロビット(限界効果)の4本の回帰。統制変数なしではGPAの係数はOLS 0.698(p<0.01)、順序プロビット限界効果0.056(p<0.01)、統制変数ありではOLS 0.390(p<0.05)、限界効果0.034(p<0.05)で、GPAが高いほどウェルビーイングが高い。統制変数では男性で低く(−0.032、p<0.05)、サークル加入(0.011、p<0.1)、専攻への好意(0.028、p<0.01)、外向性(0.014、p<0.05)、健康(0.051、p<0.01)が正の関連。学年・年齢・専攻・幹部・出身地・収入・生活費・学業プレッシャーは有意でない。統制変数を入れるとOLSのR²が0.028から0.537へ跳ね上がるが、その多くは健康変数の寄与とみられ、GPA単独の説明力はごく小さい(R²=0.028)。「限界効果0.034」が順序プロビットのどの区分に対する確率変化なのかは本文で明示されていない。

### Table 3:相対的な学業成績(GPA順位)がウェルビーイングに与える影響(約200字)

前年度のGPA順位を「上位25%」「上位25〜50%」「上位50〜75%」「下位25%」の4区分で尋ね、上位25%を基準にした順序プロビットの限界効果。統制変数なしでは3区分とも有意に負(−0.069、−0.074、−0.093、いずれもp<0.01)だが、統制変数を入れると上位25〜50%が−0.026(p<0.1)、50〜75%が−0.038(p<0.05)、下位25%は0.021で有意でなくなる。著者らは「順位が低いほどウェルビーイングが低い比較効果」と解釈するが、最下位層で関連が消える点は仮説2(順位が低いほど低い)と整合しない。これについて著者らは「寝そべり」心性を挙げつつ、測定誤差・少人数による検出力不足・外的帰属(採点の不公平感)なども排除できない探索的解釈だと明記している。

### Table 4:内生性検定の結果(約200字)

ウェルビーイングが高いから成績が良いという逆因果や欠落変数の懸念に対し、大学入学時の配置試験成績(5段階の自己評価)を操作変数とした条件付き混合過程(CMP)モデルの結果。モデル(1)では第1段階で配置試験成績がGPAと強く関連し(0.159、p<0.01)、第2段階でGPAの係数は0.811(p<0.05)と正のまま、内生性パラメータatanhrho_12は−0.228で有意でなく、GPAが外生であるという帰無仮説は棄却されない。モデル(2)の順位でも25〜50%が−0.246(p<0.1)、50〜75%が−0.376(p<0.05)、下位25%は0.163で有意でない。ただし操作変数の外生性(入学時成績がウェルビーイングに成績以外の経路で影響しない)は検証できず、著者らも「懸念を減らすが排除はしない」と述べる。入試成績が5段階の自己評価である点も弱い。

### Table 5:異質性分析の結果(約200字)

性別・学年・出身地でサンプルを6群に分けた順序プロビットの限界効果。女性0.033(p<0.05、n=196)に対し男性0.026(有意でない、n=131)、低学年(2年生)0.045(p<0.1、n=159)に対し高学年0.021(p<0.05、n=168)、都市出身0.046(p<0.05、n=208)に対し農村出身0.028(有意でない、n=119)。著者らは「女性・低学年・都市出身で関連が強い」と述べるが、低学年と高学年では点推定値の差であって有意性はむしろ高学年の方が高く、群間差の検定はTable 6の交互作用項に委ねられる。農村群は119人と小さく、非有意は検出力不足の可能性があると著者らも限界で述べている。

### Table 6:交互作用の検定(約200字)

GPA×性別、GPA×出身地の交互作用項を入れた2本の順序プロビット。GPA×性別は−0.091(p<0.05)で、男性(=1)で関連が弱いこと、すなわち女性で有意に強いことが確認される。GPA×出身地は−0.003で有意でなく、Table 5で見えた都市/農村の差は標本変動による見かけ上のものと著者らは結論づける。学年についての交互作用検定は示されておらず、「低学年で強い」という主張は統計的に裏付けられていない。なお本文の頑健性の節で「推定結果はTable 6の2列目・3列目」と書かれているが、内容からTable 7の誤記と思われる。

### Table 7:頑健性検定の結果(約200字)

絶対的成績について、順序プロビットをトビットモデルに置き換えた推定(GPA 0.434、p<0.05)と、GPAの代わりに「前年度GPAへの満足度」を用いた順序プロビット(0.014、p<0.05)。相対的成績について、トビット(上位25〜50% −0.343 p<0.1、50〜75% −0.524 p<0.05、下位25% 0.252 非有意)と、ウェルビーイングを10区分から5区分にまとめた順序プロビット(−0.051 p<0.1、−0.061 p<0.1、0.028 非有意)。いずれも主結果と同じ方向で、著者らは「完全に一致し頑健性を証明する」と述べるが、同じデータに対する別仕様の推定であり、外的妥当性(他大学・他時期での再現)を示すものではない。

## 8項目評価

### ①研究デザイン(約200字)

単一大学での横断的オンライン調査であり、因果の方向(成績→ウェルビーイングか、その逆か)を決められない設計である。著者らは操作変数法で内生性を検討し、本文と抄録で「関連であって因果ではない」と繰り返し明記しており、この誠実さは評価できる。先行研究が中高生に偏る中で大学生を対象とし、絶対的成績(GPA)と相対的成績(順位)を分けて検討した着眼は妥当である。一方、調査時期が2022年10月というコロナ禍の行動制限下であり、著者らも述べるように結果がその特殊状況を反映している可能性が高い。縦断追跡や複数大学の比較を欠くため、設計としては探索的な位置づけにとどまる。

### ②サンプルサイズと選択基準(約200字)

最終解析対象327人は、主効果の検出には足りるが、6つのサブグループ解析(最小119人)には不十分で、著者らも事前の検出力計算を行っていないと認めている。回答者はWeChatやグループチャット経由で自発的に参加した便宜的標本で、回答率(母集団の何%が答えたか)は不明であり、ウェルビーイングの高い学生や協力的な学生に偏る自己選択バイアスが避けられない。有効回答率94.3%は「集まった回答のうち使えた割合」であって代表性の指標ではない。女性が約6割、都市出身が約64%と偏りがあり、大学も北京の一校のみで、中国全体や他国への一般化は難しい。

### ③方法論の適切性(約200字)

ウェルビーイングを「1〜10点の単一項目」で測った点が最大の方法論的弱点である。単一項目は大規模調査で用いられる実績はあるが、学業・心理・身体・社会・精神的側面といった多次元性を捉えられず、著者らも限界として挙げている。GPAも自己申告で、成績証明との照合はない。順位は4区分の自己申告で、実際の順位分布との対応も不明である。一方、順序尺度の従属変数に順序プロビットを用い、OLSを参考として併記し、トビットや区分変更で頑健性を確認する手順は計量経済学の標準に沿っている。統制変数は幅広いが、学習動機・時間管理・家族の期待など著者ら自身が序論で重要と述べた変数は測定されていない。

### ④統計分析の妥当性(約200字)

順序プロビットの限界効果を「より高いウェルビーイング区分を報告する確率が0.034増える」と説明しているが、順序プロビットの限界効果は区分ごとに定義されるため、どの区分の確率を指すのか不明確である。R²が統制変数の投入で0.028から0.537へ跳ね上がるのは、健康(係数0.637)の寄与が大きいためで、GPA自体の説明力は小さい。操作変数の外生性は理論的に主張されるだけで、過剰識別検定などはできない(操作変数が1つのため)。異質性分析では学年の交互作用検定を欠いたまま「低学年で強い」と結論づけており、点推定値の比較だけでは根拠不足である。多重比較の補正もない。

### ⑤結果の信頼性と再現性(約200字)

GPAとウェルビーイングの正の関連は、著者らも引用するメタ解析や中高生の先行研究と方向が一致しており、効果の大きさも小さいながら妥当な範囲にある。頑健性検定で同方向の結果が得られた点も信頼性を支える。しかし、相対的成績で最下位層だけ関連が消えるという結果は、先行研究に照らして解釈が定まっておらず、著者ら自身が「事後的・探索的仮説」と位置づけている。単一大学・単一時点・便宜的標本・自己申告という条件が重なるため、他の大学や非コロナ期で同じパターンが再現されるかは不明である。データは「要求に応じて提供」とされ、公開リポジトリには置かれていない。

### ⑥結論の妥当性(約200字)

主要な結論(絶対的・相対的な成績がウェルビーイングと関連する、女性で関連が強い、サークル・専攻への好意・外向性・健康も関連する)は、提示された結果と概ね整合している。ただし「ウェルビーイングは時間とともに低下する傾向」という抄録の記述は横断データの学年差からの推測で、しかも3年生より4年生が高いという結果と噛み合わない。政策提言(順位の公表をやめる、専攻ナビゲーション科目、サークル参加の奨励、体育の強化)は妥当な方向だが、相関研究から導けるのは仮説の提示までであり、提言が「とるべき対策」として断定的に書かれている点はやや踏み込みすぎである。

### ⑦新規性(約200字)

大学生を対象に、絶対的成績と相対的順位を分けて主観的ウェルビーイングとの関連を調べ、性別・学年・出身地での異質性を体系的に検討した点に一定の新しさがある。特に「順位が中位の学生で有意に低く、最下位層では有意でない」という非単調なパターンは、社会的比較理論だけでは説明しきれない興味深い知見で、今後の研究課題になりうる。ただし「成績が良いほど幸福感が高い」という中心的結果自体は先行研究の再確認であり、理論的枠組み(自己決定理論、社会的比較理論、マズロー、マインドスポンジ理論)も既存のものを並べたにとどまる。中国の「内巻」「寝そべり」という社会文脈への言及は、国際的な読者にとって示唆的である。

### ⑧臨床的意義(約200字)

直接の臨床研究ではないが、大学生のメンタルヘルスに関わる精神科医や学生相談にとって、「成績そのものより順位の可視化がウェルビーイングを損なう可能性」「女性でその影響が強い」「サークル参加や専攻への適合感、外向性、健康が保護要因になりうる」という示唆は、面接で確認すべき要因のリストとして有用である。中国の競争的教育環境の知見は、受験競争の強い日本にもある程度あてはまるであろう。一方、ウェルビーイングを1項目で測った相関研究であり、うつ・不安などの臨床的転帰は測定していないため、介入の根拠として引用するには弱い。コロナ禍の行動制限下という特殊な時期のデータであることも、適用の際に考慮が必要である。
