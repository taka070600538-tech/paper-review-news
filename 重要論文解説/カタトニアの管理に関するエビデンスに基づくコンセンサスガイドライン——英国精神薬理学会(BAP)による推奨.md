# カタトニアの管理に関するエビデンスに基づくコンセンサスガイドライン——英国精神薬理学会(BAP)による推奨 精読ノート

## 概要（500字以内）

本稿は英国精神薬理学会（BAP）が作成した、カタトニア（緊張病、思考・言語・運動・情動に異常をきたす重篤な神経精神症候群）の管理に関する初の包括的な多職種コンセンサスガイドラインである。一般成人精神科、神経精神医学、小児青年精神科、リエゾン精神科、周産期精神科、自己免疫神経学、運動障害神経学、薬剤師、プライマリケアの専門家に加え患者代表も交えた国際的な専門家集団が、既存のシステマティックレビューと一次文献を収集・評価し、Shekelleらの基準に基づいてエビデンスの強さを格付けした上で推奨を作成した。診断・病因・臨床像・疫学から始まり、病歴聴取・身体診察・検査・チャレンジテストといった評価法、ベンゾジアゼピン・ECT・NMDA受容体拮抗薬などの治療、周期性緊張病・悪性緊張病・悪性症候群・抗精神病薬誘発性緊張病といった特殊病型、さらに小児・高齢者・周産期女性・自閉スペクトラム症・腎肝肺疾患患者など特別な集団における配慮までを網羅する。カタトニアに関する臨床試験はきわめて少なく、推奨の大半は小規模観察研究・症例集積・症例報告に基づかざるを得ない現状が繰り返し強調されており、無作為化比較試験（RCT）と前向きコホート研究の必要性を訴えて結ばれている。

### Figure 1：カタトニア管理のためのクイックリファレンス・アルゴリズム（330ページ）
本文中の推奨事項全体を1枚のフローチャートに要約した図で、診断の確定からベンゾジアゼピン投与、反応性の評価、ECTへの移行、悪性化した場合の対応までの臨床的意思決定の流れを一覧できるようにしたものである。テキスト抽出の都合上、図中の個別の分岐条件そのものは本ノートでは再現できていないが、本文の各節（治療、悪性緊張病、NMSなど）に記載された推奨がこの図に集約されている。

### Table 1：エビデンスと推奨の強さの分類（331ページ）
Shekelleら（1999）およびBarnesら（2020）の分類法を採用し、因果関係・治療効果についてはIa（メタ解析）からIV（専門家意見）まで、非因果関係についてはI（大規模代表サンプル）からIV（専門家意見）までを区分。推奨の強さはA（カテゴリーI直接根拠）からD（カテゴリーIV根拠）、および系統的根拠を欠く合意のみに基づく「S」まで設定されている。

### Table 2：主要な用語の定義（332ページ）
「薬剤誘発性緊張病」「物質誘発性緈張病」「悪性（劇症・致死性）緊張病」「重症疾患におけるカタトニア」「周期性緊張病」「緊張型統合失調症」「器質性緊張病性障害」「精神運動概念」「運動概念」の9用語を定義した表。特に「悪性緊張病」が現在推奨される用語であることを明記している。

### Table 3：カタトニアの基盤となりうる主要な身体疾患（333ページ）
中枢神経系の自己免疫・炎症性疾患、感染症、内分泌疾患、局所神経病変、薬物の投与・離脱、代謝性疾患、神経変性疾患、けいれん性疾患、中毒、その他多岐にわたる原因疾患を一覧化した大規模な表。抗NMDA受容体脳炎をはじめとする自己免疫性脳炎が特に重視されている。

### Table 4：カタトニア患者の病歴聴取における重要事項（335ページ）
個人・家族歴（精神疾患、緊張病やNMSの既往、神経疾患、けいれん性疾患等）と、個人の薬物歴（セロトニン作動薬、ドパミン拮抗薬、クロザピン中止、ベンゾジアゼピン・アルコール離脱、違法薬物等）を整理した聴取項目リストである。

### Table 5：カタトニア患者における身体診察項目（335ページ）
栄養状態、体温、循環器系（ECT実施を想定した評価を含む）、呼吸状態、局在神経徴候の有無、深部静脈血栓症の徴候、圧迫部の褥瘡の有無という、身体合併症を見逃さないための診察項目を列挙している。

### Table 6：カタトニアの評価手段（336ページ）
DSM-5-TRとICD-11の双方に共通する徴候（昏迷、興奮、姿勢保持、常同症など）、ICD-11のみに含まれる徴候（衝動性、攻撃性など）、いずれの診断基準にも含まれない徴候（両価性の試み等）を、観察・誘発・身体診察・情報収集・バイタルサインという評価手段別に整理した表である。

### Table 7：カタトニア評価尺度の比較（337ページ、PDFのテキスト抽出では文字順が反転した状態で取得されたため図表としての詳細な数値配置は本ノートでは完全に再現できない）
Bush-Francis Catatonia Rating Scale（BFCRS）、Northoff Catatonia Rating Scale（NCRS）、Bräunig尺度、Rogers緊張病尺度、Kanner尺度の5尺度について、開発年、対象集団、項目数、スコアリング方式、DSM-5-TR/ICD-11基準との対応、臨床使用における長所・短所を比較している。本文の記述と合わせると、BFCRSが最も広く臨床使用され、NCRSが最も包括的である一方、RogersとKanner尺度は日常臨床には不向きとされている。

### Table 8：診断マニュアルおよび主要評価尺度における筋緊張関連項目の対応（338ページ）
姿勢保持（posturing）、カタレプシー、蝋屈症（waxy flexibility）、筋強剛（rigidity）について、DSM-5-TR、ICD-11、Northoff、Bush-Francis、Bräunigの各評価体系がどのように定義・分類しているかを対比した表で、特に蝋屈症の定義が尺度間で微妙に異なる点を示している。

### Table 9：ロラゼパムチャレンジテストのプロトコル例（339ページ）
BFCRSなどの標準化尺度でベースラインの緊張病徴候を評価した上で、ロラゼパム1〜2mgを静注・筋注・経口投与し、5分（静注後）・15分（筋注後）・30分（経口後）で再評価、スコアが50%低下すれば陽性反応とみなし、陰性の場合は非経口投与でさらにチャレンジを行うという手順を示す実践的プロトコルである。

### Table 10：カタトニアの鑑別診断（340〜341ページ、こちらもPDFのテキスト抽出で文字順が反転して取得されている）
硬直人症候群、パーキンソニズム、ジストニア、アカシジア、悪性症候群（NMS）、セロトニン症候群、失語、選択性緘黙、非けいれん性てんかん重積状態（NCSE）、閉じ込め症候群、昏睡・遷延性意識障害、無動症、躁病、機能性神経障害、自閉スペクトラム症、詐病・作為症など多数の鑑別疾患について、カタトニアとの類似点と鑑別に役立つ特徴を対比列挙している。

### Table 11：今後の主要な研究課題（355ページ）
カタトニア症候群の境界線をロラゼパムチャレンジで検証できるか、新たな基盤疾患の同定、症例報告レベルの関連が大規模観察研究でも再現されるか、薬剤誘発性カタトニアやNMSの遺伝的・環境的素因、ベンゾジアゼピンの厳密なRCTでの検証、ECTの至適条件、rTMSパラメータの最適化、ベンゾジアゼピン・ECT非奏効例への対応、抗精神病薬の役割、心理社会的治療の可能性、年齢層による病態生理・治療反応の違いなど、13項目の重要な研究課題を列挙している。

## 内容についての8項目評価

本論文はRCTのような一次研究ではなく、多数の観察研究・症例報告・既存システマティックレビューを統合したコンセンサスガイドラインであるため、以下の評価では「サンプルサイズ」「統計分析の妥当性」等の基準を、文献の収集・選択過程やエビデンス統合の妥当性という観点に読み替えて評価する。

**①研究デザイン**：エビデンスに基づく実践ガイドラインとしての体裁は整っており、Shekelleらの標準化されたエビデンス格付け・推奨強度分類システムを一貫して適用している点は評価できる。しかし、文献検索の具体的な検索式・データベース・検索期間・PRISMAに準じた選定フローチャートなどは本文中に明記されておらず、系統的レビューとしての再現性・透明性の観点ではやや弱い。

**②サンプルサイズと選択基準（文献の収集・選択基準に読み替え）**：引用されている一次研究の多くが症例報告・小規模症例集積であり、著者ら自身が「50例を超える研究はわずか4件」と明言している。エビデンスベースの絶対的な乏しさは本ガイドラインの限界というより対象疾患カタトニア自体の希少性・研究困難性に起因するが、結果として推奨の多くがカテゴリーC・D・Sという弱いエビデンスレベルにとどまっている。

**③方法論の適切性**：バーチャル会議での分担執筆、複数回のドラフト回状・修正という合意形成プロセスは妥当であり、患者代表を当初から参加させた点は臨床ガイドラインとして先進的である。一方、専門家パネルの選定基準や、意見対立が生じた場合の合意形成手続き（デルファイ法の使用有無等）については記載がなく、透明性に欠ける部分がある。

**④統計分析の妥当性（エビデンス統合の妥当性に読み替え）**：本文中で言及される唯一の定量的メタ解析（ECTの前後比較で標準化平均差-3.14）は他の系統的レビュー（Leroy et al., 2018）からの引用であり、本ガイドライン自体が新たな統合解析を行っているわけではない。異なる出典・母集団・尺度にまたがるエビデンスを定性的に統合する手法が中心であり、異質性の評価は限定的である。

**⑤結果の信頼性と再現性**：カテゴリーS（系統的根拠を欠く合意のみに基づく）に分類される推奨が随所に見られ、これらは専門家の臨床経験に大きく依存する。特に悪性緊張病やNMSの治療アルゴリズムのように生命に関わる状況ほど、エビデンスが乏しく専門家合意に頼らざるを得ない構造的な限界がある。

**⑥結論の妥当性**：ベンゾジアゼピンとECTを第一選択とする結論は、複数の観察研究間で一貫した反応率（ベンゾジアゼピンで66〜100%、ECTで59〜100%）に支えられており、妥当性は高いと考えられる。一方、抗精神病薬の使用に関する記述はやや慎重で、根底に精神病性障害がない場合は使用を避けるべきとする一方、実臨床での必要性も認めるという両論併記的な結論にとどまっている点は、エビデンスの弱さを反映した誠実な記述と評価できる。

**⑦新規性**：カタトニアに特化した多職種・国際的コンセンサスガイドラインとして、英国国内にはこれまで存在しなかった空白を埋める点で新規性が高い。周期性緊張病、悪性緊張病、NMS、抗精神病薬誘発性緊張病という重複しつつも異なる病態を整理し、小児・高齢者・周産期・自閉スペクトラム症・臓器障害患者への個別配慮まで踏み込んだ点も類書に比して包括的である。

**⑧臨床的意義**：日常臨床で見逃されやすいカタトニアの診断基準・評価尺度（BFCRS・NCRSの使い分け）、ロラゼパムチャレンジテストの具体的プロトコル、ECTへの移行基準などを明確な推奨として提示しており、実地臨床への応用可能性はきわめて高い。特に悪性緊張病・NMSにおける薬剤中断とECTのタイミングに関する推奨は、生命に関わる意思決定を要する臨床現場に直接資する内容である。
