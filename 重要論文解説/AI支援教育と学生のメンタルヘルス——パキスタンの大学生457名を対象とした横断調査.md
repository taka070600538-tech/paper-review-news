# AI支援教育と学生のメンタルヘルス——パキスタンの大学生457名を対象とした横断調査 精読ノート

> 役割：日本トップクラスのサイエンスコミュニケーターとしての精読プロンプトに基づく分析結果

## 1. 概要（500字以内）

生成AIや知的個別指導システム（ITS）が大学教育に急速に浸透する一方、それが学生の心の健康に何をもたらすかは十分に検証されていない。本研究はパキスタンのパンジャブ州・シンド州の公立・私立大学に在籍する学部生・大学院生457名を対象に、Googleフォームによる横断的な質問紙調査を行い、「AI支援教育の利用・評価」と「心理的ウェルビーイング」の関連を検討した。AI支援教育の尺度はHolmesらとKasneciらの論考をもとに独自に作成し、ウェルビーイングはRyffの心理的ウェルビーイング尺度（自己受容、環境制御、成長、自律性、人生の目的、良好な対人関係）を下敷きにした項目で測定、いずれも5件法。SPSS 27で解析した結果、両者には**r = .684（p < .001）の正の相関**があり、回帰分析ではAI支援教育がウェルビーイングの分散の**46.8%**を説明した。さらに女性の方が男性よりウェルビーイングが高く（3.92対3.74、p = .001）、学年間にも有意差があった（F = 7.684, p < .001）。著者らは「AIを責任ある形で導入すれば学習だけでなく心の健康も支えうる」と結論し、大学に対しカウンセリング体制、教員研修、倫理指針、デジタル・ウェルビーイング施策の整備を提言している。**ただし後述のとおり、この結論を支える統計的根拠には重大な問題が複数ある。**

### Table 2：AI支援教育と学生メンタルヘルスのピアソン相関（N = 457）

両変数の相関は **r = .684（両側 p < .001）**。著者らは「中程度に強い正の相関」と表現し、AI支援教育を有効と感じている学生ほど心理的ウェルビーイングが高いと解釈している。注意すべきは、**この2変数が同一の質問紙の中で、同一の回答者から、同一の5件法で、同時に測定されている**点である。共通方法バイアス（同じ人が同じ形式で答えることによって相関が水増しされる現象）を検証する手続き（Harmanの単一因子テスト等）は一切行われていない。

### Table 3：AI支援教育がメンタルヘルスを予測する重回帰分析（N = 457）

モデル要約は R = .684、R² = .468、調整済みR² = .467、推定値の標準誤差 .421。分散分析は F = 403.298（df = 1, 455）, p < .001。係数は定数項 B = 1.128（SE = .136, t = 8.294）、AI支援教育 B = .701（SE = .035, β = .684, t = 20.082, p < .001）。

**この表の最大の問題は、「重回帰分析（Multiple Linear Regression）」と題されているが、投入されている予測変数が1つしかない点である。** 回帰の自由度が1であること、R が Table 2 のピアソン相関 r と完全に一致すること、標準化係数 β = .684 が r と一致することは、いずれもこれが単回帰分析であることを示す。性別も学年も年齢も統制されていない。したがって「AI支援教育が学生のメンタルヘルスを規定するもっとも重要な変数である」という本文の主張は、比較対象となる他の変数をモデルに入れていない以上、導けない。なお内部計算自体は整合している（t² = 20.082² ≒ 403.3 = F、B/SE = .701/.035 ≒ 20.0）。

### Table 4：性別によるメンタルヘルスの独立サンプルt検定（N = 457）

男性（n = 221）平均3.74（SD 0.61）、女性（n = 236）平均3.92（SD 0.58）、t = −3.247, df = 455, p = .001。女性の方が有意に高い。**ただし効果量（Cohen's d）も信頼区間も報告されていない。** SDから概算するとd ≒ 0.30で、統計的には有意でも実質的には小さい差である。等分散性の検定（Levene検定）の結果も示されていない。

### Table 5：学年別メンタルヘルスの一元配置分散分析（N = 457）

群間平方和 8.432（df = 3, 平均平方 2.811）、群内平方和 165.702（df = 453, 平均平方 0.366）、全体 174.134（df = 456）、F = 7.684, p < .001。学年によってウェルビーイングに差があるとされる。**しかし、どの学年とどの学年が異なるのかを示す多重比較（Tukey法等の事後検定）が行われていないため、この有意差から実質的な知見を取り出すことができない。** さらに決定的な問題として、**Table 3 の回帰分析では同じ従属変数の全体平方和が152.200（df = 456）とされているのに対し、Table 5 では174.134（df = 456）となっている。同一標本・同一変数の全体平方和が2つの表で異なることは数学的にありえない。**

## 3. 8項目評価

> **注記**：本論文は一次データを収集した原著研究（量的・横断的質問紙調査）であるため、8項目評価は一次研究の基準をそのまま適用する。

### ① 研究デザイン

「AI支援教育が心の健康に与える影響」という問いに対して、**横断デザインは原理的に因果の向きを決められない**。AIツールをよく使い高く評価している学生ほどウェルビーイングが高いのか、もともと心身の調子がよい学生ほど新しいツールを積極的に使いこなし高く評価するのか、あるいは第三の要因（学業成績、経済状況、デジタルリテラシー）が両方を押し上げているのかを区別できない。にもかかわらず抄録と結論は「AI支援教育は学生のメンタルヘルスに**肯定的な影響を与えた**（positively affected）」「メンタルヘルスの**強力な予測因子**である」と因果的な表現を用いている。これはデザインから許容される範囲を明確に超えている。また、**倫理審査委員会（IRB）の承認について言及がなく**、記載されているのは電子的インフォームド・コンセントと匿名性の確保のみである。

### ② サンプルサイズと選択基準

457名という標本数は、相関・単回帰・t検定・一元配置分散分析を行うには十分である。しかし選択方法に深刻な問題がある。**便宜的標本抽出により、大学のメーリングリストとWhatsApp・Facebook等の学術系ソーシャルメディアでGoogleフォームのリンクを配布した**ため、自己選択バイアスが避けられない。AI教育ツールに関心のある学生ほど回答する傾向が強く、これは独立変数そのものと直結する選択バイアスである。**配布数・回答率・欠測値の扱いは一切報告されていない。** さらに、**対象大学の一覧が抄録（10校）と本文の「Population」節（15校）で一致しない**（本文にはムハンマド・ナワーズ・シャリフ農業大学ムルターン、教育大学ムルターン校、工科大学ラホール、COMSATS大学ラホール校、シャー・アブドゥル・ラティフ大学ハイルプルが追加されている）。この不一致は、どの母集団を対象としたのかという基本情報を不確かにする。

### ③ 方法論の適切性

**測定尺度の妥当性がもっとも大きな弱点である。** 「AI支援教育」尺度は Holmes ら（2022）と Kasneci ら（2023）を「修正・採用」したとされるが、これら2文献はいずれも教育におけるAIを論じた概念的・展望的な論考であり、心理測定尺度を提示した研究ではない。したがってこの尺度には確立された因子構造も妥当性の検証もなく、本研究でも探索的・確証的因子分析は行われていない。項目数も項目内容も示されていない。従属変数についても、Ryff（1989）とTennantら（2007＝WEMWBS）という**「ポジティブなウェルビーイング」を測る尺度**を用いながら、論文全体では「メンタルヘルス」という語が使われている。うつ・不安・バーンアウトといった精神的不調は一切測定されていないため、序論・考察で論じられる「デジタル疲労」「認知的過負荷」「監視される不安」といった負の側面は、**本研究のデータでは検証不可能**である。イノベーションとウェルビーイングの「バランス」を標題に掲げながら、測定されているのは片側だけである。

### ④ 統計分析の妥当性

**この項目に本論文の致命的な問題が集中している。**
1. **信頼性係数が報告されていない。** 方法の節で「Cronbach's Alphaによる内的整合性の検討を行った」と明記しているにもかかわらず、結果のどこにもα係数の値が示されていない。尺度が自作である以上、これは省略できない情報である。
2. **「重回帰分析」が実際には単回帰分析である**（df = 1、R = r、β = r）。統制変数が1つも投入されていない。
3. **Table 3 と Table 5 で、同一変数の全体平方和が152.200と174.134と食い違う。** 少なくとも一方の解析は、異なるデータセットまたは異なる変数に基づいている。
4. **有意な分散分析に対する事後検定が行われていない。**
5. **効果量と信頼区間がどこにも報告されていない。** t検定・相関・回帰のいずれについても。
6. **多重比較の調整がない。** 4つの仮説を同一データで検定しているが、補正は行われていない。
7. **共通方法バイアス、回帰の前提（残差の正規性、等分散性、独立性）の検証がない。**

### ⑤ 結果の信頼性と再現性

上記④の問題により、報告された数値をそのまま信頼することはできない。とくに**平方和の不整合は、解析の実施過程そのものに疑義を生じさせる**性質のものである。加えて、生データも質問紙の全項目も公開されておらず、データ利用可能性に関する記述もないため、第三者による再現・検証の手段がない。r = .684、R² = .468という値は、心理学の観測研究としては例外的に大きい。同種の自己報告どうしの相関としてはありうる範囲だが、**共通方法バイアスの検証を欠いたまま「AI支援教育が心の健康の46.8%を説明する」と述べるのは過大な主張**である。査読期間も投稿から受理まで31日間（2026年6月4日投稿、6月19日改訂、7月5日受理）と短い。

### ⑥ 結論の妥当性

「AIを責任をもって導入すれば、学習成果と心理的ウェルビーイングの双方を支えうる」という穏当な言い方であれば、データと矛盾はしない。しかし実際の結論は**「AI支援教育は学生のメンタルヘルスに肯定的な影響を与え、その強力な予測因子である」**という因果的・断定的なもので、横断デザイン・単回帰・自作尺度という手続きが支えられる範囲を大きく超えている。一方、7項目の提言（個別最適化されたAIツールの導入、AI学習プラットフォーム利用者への定期的な心理カウンセリング、教員への倫理研修、責任あるAI利用の方針策定、教師と学生の関係を置き換えず補完する設計、デジタル・ウェルビーイング施策、多様な集団・デザインでの追試）自体は、本研究の結果に直接依拠しない一般的な内容ではあるものの、実務的には妥当で害のないものである。

### ⑦ 新規性

「AIと教育」「学生のメンタルヘルス」はそれぞれ膨大な研究蓄積があり、両者の関連を扱った研究も既に多い。本研究が主張する新規性は、**開発途上国（パキスタン）の高等教育という、これまで手薄だった文脈でのデータである**という一点に集約される。この地域性には一定の価値があるが、**その価値を活かすための文脈固有の分析——たとえば公立／私立の差、州の差、専攻分野の差、インターネット接続環境や端末所有の影響——は、デモグラフィック情報として収集されていながら一切解析されていない**。性別と学年という2つの軸しか検討されておらず、しかもその2つについても事後検定や効果量がない。収集したデータを活かしきれていないという意味で、新規性の主張は十分に実現されていない。

### ⑧ 臨床的意義

精神科医の立場から見た場合、**本研究を根拠に何かを判断することは推奨できない**。測定されているのはウェルビーイングの自己評価であって精神症状ではなく、因果の向きも不明で、統計解析に内部矛盾がある。それでも読む価値があるとすれば、以下の2点である。第一に、**大学生のAI利用が「学習補助」の域を超えて日常に組み込まれている実態**を、南アジアの大規模標本で確認できること。日本の学生にも同様の状況があり、診察で学業の話題が出たときに「AIをどう使っているか」を尋ねる意味は増している。第二に、**序論・文献レビューで整理されている負の側面のリスト**——デジタル疲労、長時間のスクリーン曝露、認知的過負荷、対面接触の減少、アルゴリズムによる常時監視への不安、プライバシー懸念、批判的思考力の低下、学業不正への不安——は、思春期・青年期の患者の主訴を聞く際の視点として実用的である。ただしこれらはいずれも**引用に基づく記述であって本研究が検証したものではない**ことを、明確に区別して受け取る必要がある。
