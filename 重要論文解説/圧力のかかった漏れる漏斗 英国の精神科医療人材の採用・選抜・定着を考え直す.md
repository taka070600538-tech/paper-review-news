# 圧力のかかった漏れる漏斗 英国の精神科医療人材の採用・選抜・定着を考え直す 精読ノート

## 概要

英国では精神科の研修(コア研修)に応募が殺到し、2025年は500枠未満に1万人以上、競争率は約21倍になった。ところがコンサルタント(日本でいう指導医・常勤専門医)の27%、SAS医師(研修外の中堅医師)の32%の枠が空席か非常勤で埋まり、2020年には1536人が入って1455人が辞め、人員はほとんど増えていない。コア研修3年目から専門研修4年目へ直接進む人は43%にとどまる。

著者らはこの「入口は大盛況なのに上の層が育たない」矛盾を「採用と定着のパラドックス」と呼び、それを説明する概念モデル「圧力のかかった漏れる漏斗」を提案する。漏斗は、0 接触と志向、1 応募、2 選抜、3 研修環境、4 キャリアの結果、の5段階からなる。上流からは国の勧誘策・選抜制度・労働市場の圧力が入口を押し広げ、下流では各段階から人が漏れ出していく。各段階の漏れは、社会的アイデンティティ理論、社会認知的キャリア理論、人と環境の適合理論、自己決定理論、専門職アイデンティティ形成と期待理論で説明される。

結論として、競争率や充足率ではなく、進級率・修了までの期間・コンサルタントの定着率を成果の物差しにし、精神科に合う資質を測る選抜と、定着を支える研修環境づくりを一体で進めるべきだと主張する。

## FigureとTableの解説

本文で言及される図表は Figure 1・2 と Table 1・2 の計4点で、すべて以下で解説する。

### Figure 1 人と専門科の適合度×定着の4象限

縦軸が「選抜時の人と専門科の適合度(アラインメント)」、横軸が「時間がたっても辞めずに残るか(定着)」の2×2の図。ステップ1:両方が高い右上は「持続可能な人材」。ステップ2:適合は高いが定着が低い左上は「よく合った医師を失う」、つまり育てた人材の損失。ステップ3:適合は低いが定着は高い右下は「役割が合わないまま残る」。ステップ4:両方が低い左下は「ずっと合わず、入れ替わりが続く」状態。データの図ではなく考え方の図で、改革の目標は左下から右上へ系を動かすことだと後半で再び使われる。入口の人数だけを見ても、この4つの違いは見えない、というのが図の要点である。

### Figure 2 圧力のかかった漏れる漏斗モデル

上から下へ細くなる漏斗の図。ステップ1:上部に「上流の圧力」として、国の勧誘策(RCPsych の Choose Psychiatry キャンペーンなど)、選抜制度の設計、労働市場の状況の3つの矢印が入口に押し込まれる。ステップ2:漏斗は段階0(接触と志向)→1(応募)→2(選抜)→3(研修環境)→4(キャリアの結果)と下がる。ステップ3:右側に「下流の漏れ」として、応募段階では動機のばらつき、選抜段階では選抜方法と専門科の要求のずれ、研修段階では業務量・指導・差別・所属感など積み重なる負担、キャリア段階では努力と報酬が釣り合わない感覚、が書かれる。ステップ4:下向きの矢印は時間の経過に伴う進級を示す。入口の圧力を上げても、途中の穴をふさがなければ出口の量は増えないことを1枚で示した図である。

### Table 1 漏斗の各段階を説明する理論

各段階に、なぜ人が漏れるのかを説明する理論(理論的レンズ=物の見方の枠組み)を割り当てた表。ステップ1:段階0は社会的アイデンティティ理論で、実習や手本になる医師との出会いが「精神科は自分に合う進路か」の感覚をつくる。ステップ2:段階1は社会認知的キャリア理論で、「自分はうまくやれる」という自己効力感と「良い結果が得られる」という結果期待が応募を決める。汎用の選抜試験で「受かりそう」と感じやすくなり、適合が不確かなまま応募が膨らむ。ステップ3:段階2は社会的アイデンティティと人と環境の適合理論。ステップ4:段階3は自己決定理論で、自律性・有能感・関係性という3つの心理的欲求が満たされないと意欲が削られる。ステップ5:段階4は専門職アイデンティティ形成と期待理論で、努力に見合う報酬(持続可能なコンサルタント職)が見込めないと、辞めることが合理的な選択になる。

### Table 2 モデルを実行に移す指標と介入

段階ごとに「仕組み・測るべき指標・介入策」を並べた表。ステップ1:段階0は、関心は高いが適合が浅いまま上流から圧がかかる。指標は精神科に接した学生・研修医のうち実際に応募した割合、介入は現実的な仕事の下見(リアリスティック・ジョブ・プレビュー)。ステップ2:段階1は、志より市場の都合で応募が膨らむ「応募インフレ」。戦略的な応募と本気の応募を見分ける目印を指標にし、隠れたカリキュラム(明文化されない職場の慣習)まで含めて現実を率直に伝える。ステップ3:段階2は汎用の選抜試験が適合を測れない「潜在的な漏れ」。選抜点数とその後の定着の関連を指標にし、精神科に特化した選抜を導入する。ステップ4:段階3は意欲と職業的コミットメントが削られる「活動中の漏れ」。所属感・心身の健康・残る意思をリアルタイムで測り、(a) RCPsych の Retention Charter(定着憲章)に沿った面談と「ステイ・インタビュー」(辞める前に不満を聞く面接)、(b) 海外医学部卒業医(IMG)への導入研修と専門職アイデンティティ形成の支援、(c) CT3→ST4 など移行点での応募・試験支援、(d) 重大事故や死因審問の後の構造化された支援、を挙げる。ステップ5:段階4は中堅・上級医の合理的な離職による「後期の漏れ」。コンサルタント職へ進んだ割合を指標にし、柔軟な勤務計画とリーダーシップ支援で役割疲れを防ぐ。

## 8項目評価

本論文は原著研究ではなく、既存の統計・研究・理論をつないで新しい概念モデルを示す論考(Feature)である。そのため一次研究向けの基準(標本数、統計検定)はそのまま当てはめず、「どの資料を選んで根拠にしたか」「理論と現実データのつなぎ方は妥当か」「モデルは検証可能か」という観点に読み替えて評価する。

### ①研究デザイン

採用・選抜・定着を別々の政策分野として扱う現状に対し、それらを一つの流れ(パイプライン)としてとらえる概念モデルを提示する論考。既存の「漏れるパイプライン」の比喩を下敷きに、段階ごとの記述(どこで漏れるか)と理論による説明(なぜ漏れるか)、実務への提言(どう直すか)の三層に整理した構成はわかりやすい。問題点は、系統的な文献検索の手順が示されていない叙述的な論考であり、どの研究を採り、どれを採らなかったかが読者に見えないことである。モデルの各段階を区切った根拠や、別の段階区分を検討したかも書かれていない。

### ②サンプルサイズと選択基準(→根拠資料の選び方に読み替え)

根拠は29本の参考文献で、王立精神科医学会(RCPsych)の人員調査・定着憲章、UKMED(英国医学教育データベース)を使った進級の生存分析、NHS England の資料、BMJ・BJPsych Bulletin の論考などが中心。英国の公的データを押さえている点は良い。一方で、学会の声明やニュース記事(BMJ のニュース、学会のプレス対応)と査読付き研究が同じ重みで並び、数字の出どころの質に差がある。2020年の入職・離職数は2021年の論考からの引用で、やや古い。英国以外の国の経験や、他の診療科との比較データはほとんど使われていない。

### ③方法論の適切性

5つの段階それぞれに、医学教育・組織心理学で確立された理論(社会的アイデンティティ、社会認知的キャリア、人と環境の適合、自己決定、期待理論)を当てる手法は筋が通っており、Table 1 で一覧化されているのは親切である。ただし、理論の割り当ては著者らの解釈で、段階ごとに違う理論を使うため、理論どうしがどう連動するのかは説明されない。たとえば段階2と3の「適合」と段階3の「欲求充足」が同じ現象の別の言い方なのか、別の要因なのかが曖昧である。段階0〜4の区分は直感的だが、研修外で働く SAS 医師のように漏斗の外側を通る経路はモデルに十分取り込まれていない。

### ④統計分析の妥当性(→数値の扱い方に読み替え)

新しい解析はない。引用している数値の読み方には慎重さが見られ、競争率21:1は複数科への併願や IMG の増加を反映しているため「注意して解釈すべき」と自ら断っている。問題点として、コア研修の競争率21.8:1と専門研修の1.39:1を比べて「20倍の差」と呼ぶのは、母集団も選抜段階も違う数を割り算しているだけで、動機のばらつきの直接の証拠にはならない。また、本文では競争率を「約21:1」「21.8:1」「約12.4:1から2.4:1へ」と複数の数字で示しており、それぞれの算出条件(年度、母数、IMG の扱い)の違いが読者には分かりにくい。

### ⑤結果の信頼性と再現性(→モデルの検証可能性に読み替え)

著者ら自身が「モデルの各段階の漏れを直接測ったデータは存在しない」と認め、段階別の離職報告が日常的に行われていないことを課題に挙げている。Table 2 で段階ごとの指標(応募への転換率、選抜点と定着の関連、所属感の継続測定、コンサルタントへの進級率)を示したことで、モデルは原理的に検証可能な形になっている点は評価できる。しかし現時点では、モデル全体が仮説であり、どの段階の漏れが最も大きいのかという量の比較は、CT3→ST4 の57%という一点を除いて示されていない。

### ⑥結論の妥当性

「入口の圧力を上げても途中の損失は補えない」「物差しを充足率から進級率・定着率へ移すべき」という結論は、示された数字(入職と離職がほぼ同数、ST4 への直接進級43%)と矛盾せず、説得力がある。一方、「汎用試験 MSRA では精神科への適合が測れず、潜在的な漏れを生む」という主張は、MSRA が試験成績を予測するという研究はあるが、適合や定着との関連は未検証であると著者ら自身が書いており、証拠より推論が先行している。現実的な仕事の下見で「応募は減るが定着は良くなる」という見込みも、精神科での実証はない。

### ⑦新規性

採用・選抜・定着をばらばらに論じてきた英国精神科の人材議論を、一枚の漏斗図と4象限図にまとめ直した点に新しさがある。「応募インフレ」「潜在的な漏れ」「活動中の漏れ」「後期の漏れ」という名前を段階ごとに付けたことで、議論の共通語を作った意義も大きい。ただし「漏れるパイプライン」という比喩自体は、女性研究者の離脱や医師の地域偏在の議論で以前から使われており、使われている理論もすべて既存のものである。新しいのは要素ではなく組み合わせ方である。

### ⑧臨床的意義

直接の患者アウトカムの論文ではないが、精神科医の不足は診療の質と待ち時間に直結するため、間接的な意義は大きい。日本でも、精神科を選ぶ若手医師の数と、地方の病院や中堅層で医師が足りない現実との間に似たずれがあり、研修中の所属感・指導体制・柔軟な働き方を測って手を打つという Table 2 の考え方は応用しやすい。限界として、英国 NHS の研修制度(コア研修・専門研修、MSRA、IMG が応募者の81%)に強く依存した議論であり、制度の異なる日本へそのまま移すことはできない。提言の多くは費用対効果が未評価で、著者ら自身も選抜を手厚くすれば臨床医の時間がかかると認めている。
