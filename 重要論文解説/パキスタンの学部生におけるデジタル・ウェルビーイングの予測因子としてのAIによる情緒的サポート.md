# パキスタンの学部生におけるデジタル・ウェルビーイングの予測因子としてのAIによる情緒的サポート 精読ノート

> [!info] 読むときの注意
> 小規模な便宜標本(大学付属カレッジ1校の学部生206人)による横断的な自己記入式調査で、因果関係は示せない。予測因子の尺度は著者らが自作したもので、妥当性の検証は報告されていない。本文中の表番号のずれや記述の食い違いもいくつかある(後述)。

## 概要

ChatGPT などの会話型AIは、勉強の道具にとどまらず、悩みを打ち明けたり励ましをもらったりする「話し相手」としても使われ始めている。この研究は、パキスタンの学部生がAIからどの程度の情緒的サポート(気持ちを受け止めてもらう、安心させてもらう、対処を手伝ってもらうなど)を受けていると感じているか、そしてそれが「デジタル・ウェルビーイング」(デジタル機器と健全に、バランスよく、自分でコントロールしながら付き合えている度合い)と関係するかを調べた。

パンジャブ大学付属カレッジの心理学・ウルドゥー語・英語・教育学の学部生210人にオンライン質問紙を実施し、注意確認の設問に落ちた4人を除く206人を解析した。AIによる情緒的サポートは5段階で平均3.32と「中程度」、デジタル・ウェルビーイングは4段階で平均2.78だった。両者の相関は r = .70 と強く、単回帰でAIサポートはデジタル・ウェルビーイングのばらつきの48.8%を説明した。専攻による差はなかった。

著者らは、AIによる情緒的サポートを大学のカウンセリングの補助として検討すべきだと提言するが、横断研究なので「AIのサポートがウェルビーイングを高める」とは言えず、自作尺度と自己記入の測定の重なりが相関を大きく見せている可能性がある。

## FigureとTableの解説

図表は Table 1・2・3・5・6・7・8・9 の8点と、Figure 2・3・4 の3点、計11点。Figure 1 と Table 4 は本文に存在せず、番号が飛んでいる。また、本文は Table 1 の人口統計表を「Table 2」と呼んでおり、表番号の表記に乱れがある。

### Table 1:回答者の属性(N = 206)

解析対象206人の内訳。性別は女性110人(53.4%)、男性96人(46.6%)。学年は2学期生88人(42.7%)、4学期生118人(57.3%)。専攻は心理学51人、ウルドゥー語51人、英語53人、教育学51人とほぼ4等分になっている。AIの使用頻度は「まれに」19人(9.2%)、「ときどき」55人(26.7%)、「しばしば」75人(36.4%)、「いつも」57人(27.7%)で、半数以上が日常的な利用者だった。年齢は19〜23歳と本文にあるが表には入っていない。なお、使用頻度はこのように測定されているのに、以降の解析(統制変数など)には一度も使われていない点に注意したい。

### Figure 2:参加者の属性の棒グラフ

Table 1 と同じ内容(性別、学年、専攻、AI使用頻度の各カテゴリーの割合)を棒グラフにしたもの。注記によれば、棒は206人に占める各カテゴリーの割合を表す。新しい情報は加わっておらず、Table 1 を視覚的に確認するための図である。テキスト抽出では図そのものの数値は読めないが、本文と注記から Table 1 の再掲と判断できる。番号は Figure 2 から始まっており、Figure 1 に当たる図(概念モデル図など)は論文中に見当たらない。

### Table 2:専攻別のAI情緒的サポート尺度(AIES)の平均

AIES(AI-Driven Emotional Support Scale、著者らが作った17項目・5段階の尺度。高いほどAIから情緒的な支えを受けていると感じている)の専攻別の平均と標準偏差(SD、ばらつきの目安)。教育学3.33(0.70)、英語3.34(0.72)、心理学3.43(0.68)、ウルドゥー語3.17(0.72)。最も高い心理学と最も低いウルドゥー語の差は0.26点で、SDの半分以下にとどまる。著者らはこの小さな差を、次の分散分析が有意でなかったことと整合すると述べている。

### Table 3:専攻別AIESの一元配置分散分析

一元配置分散分析(ANOVA、3つ以上のグループの平均に差があるかを調べる検定)の結果。群間平方和1.84(自由度3)、群内平方和100.42(自由度202)、F(3, 202) = 1.23、p = .299で、有意差はなかった。効果量 η²(イータ二乗、全体のばらつきのうち専攻の違いで説明できる割合)は .018、つまり約1.8%にすぎない。表中の数値は互いに計算が合っている(1.84÷102.26 ≒ .018、0.61÷0.50 ≒ 1.23)。各群51〜53人では小さな差を見つける力(検出力)は低く、「差がない」と言い切るより「大きな差は見られない」と読むのが妥当である。

### Figure 3:専攻別AIES平均と95%信頼区間

Table 2 の平均値を、95%信頼区間(真の平均がおそらく入る範囲)つきで図示したもの。注記は p = .299。4つの専攻の信頼区間が大きく重なっていることを目で確かめるための図で、Table 2・3 と同じ結論を示している。テキスト抽出では図中の区間幅の数値は読み取れなかったが、SD約0.7・各群約51人から計算すると、区間はそれぞれ平均の上下約0.2点の幅になるはずで、心理学(3.43)とウルドゥー語(3.17)の区間もわずかに重なる程度と推測される。

### Table 5:AIESとデジタル・ウェルビーイング尺度(DWS)の記述統計

研究課題1への答えとなる表。AIESは平均3.32(SD 0.71、1〜5点)で「中程度」。DWS(Appianingら2026年の41項目・4段階の尺度を改変して使用。高いほど健全)の総合点は2.78(SD 0.70、1〜4点)。6つの下位尺度は、課題への支障2.27、デジタルの安全と責任ある利用2.90、知覚されたコントロールと満足2.82、デジタル生活のバランス2.61、感情調整2.19、デジタル依存と欲求不満2.12。著者らは感情調整と課題への支障を「最も低い=困難」と解釈している。ただし、6つの下位尺度の単純平均は約2.49で、総合点2.78はこれより高い。各下位尺度の項目数が示されていないため検証できず、集計方法には疑問が残る。

### Table 6:AIESとDWS総合点のピアソン相関

ピアソン相関係数(2つの量がどれだけ直線的に一緒に動くかを−1〜1で示す)は r = .70(自由度204、p < .001)。帰無仮説(関係はない)は棄却され、「AIから情緒的サポートを多く受けていると感じる学生ほど、デジタル・ウェルビーイングも高い」という強い正の関連が示された。r² ≒ .49 で、一方のばらつきの約半分が他方と共通していることになる。社会科学の質問紙調査としては異例に強い相関で、両尺度の内容の重なり(AIESには「対処の手助け」、DWSには「感情調整」がある)や、同じ回答者が同時に答えたことによる共通方法バイアスを疑う必要がある。

### Figure 4:AIESとDWS総合点の散布図と回帰直線

1点が1人の学生を表し、横軸にAIES、縦軸にDWS総合点をとった散布図に、回帰直線を重ねたもの。本文の「As shown in Figure」はこの図を指す。r = .70 の右上がりの関係を視覚的に示している。この種の図では、外れ値の有無、天井・床効果(点数が上限や下限に張りつく現象)、関係が本当に直線かどうかを確認できるはずだが、論文はそうした回帰の前提(残差の正規性・等分散性など)の検討をまったく報告していない。

### Table 7:回帰モデルの要約

AIESを予測変数(説明する側)、DWS総合点を基準変数(説明される側)とした単回帰の要約。R = .70、R² = .488、調整済みR² = .486、推定の標準誤差0.502。R²(決定係数)は、DWSのばらつきのうちAIESで説明できる割合で、約48.8%となる。予測変数が1つだけなので、R は Table 6 の相関係数と同じ値になる。著者ら自身も考察で、残りの半分以上は対面の社会的支援、学業ストレス、スクリーンタイム、自己調整の個人差など、測っていない要因によると認めている。

### Table 8:回帰モデルの分散分析表

回帰全体が有意かを確かめる分散分析。回帰平方和49.17(自由度1)、残差平方和51.51(自由度204)、F(1, 204) = 194.70、p < .001。49.17÷100.67 ≒ .488 で Table 7 の R² と一致し、残差の平均平方0.25の平方根0.50が推定の標準誤差0.502とも合う。総平方和100.67から逆算したDWSのSDも約0.70で Table 5 と整合する。数値の内部整合性は保たれているが、これは「単回帰を正しく計算した」ことの確認であり、測定の妥当性や因果の方向を保証するものではない。

### Table 9:回帰係数

定数(切片)0.481(標準誤差0.169、t = 2.85、p = .005)、AIESの非標準化係数 B = 0.693(標準誤差0.050)、標準化係数 β = .70、t = 13.96、p < .001。AIESが1点上がるごとに、DWS総合点は0.693点高いと予測される。t² ≒ 195 で Table 8 の F と一致し、平均値を代入すると 0.481 + 0.693×3.32 ≒ 2.78 となって Table 5 の平均とも合う。ただし「予測する」とは統計上の言い方であり、同時点で測った相関を一次式で表しただけで、AIを使えばウェルビーイングが上がるという意味ではない。

## 8項目評価(原著研究として評価)

### ①研究デザイン

量的・横断的・予測相関型デザイン(ある一時点で2つの変数を測り、一方からもう一方を統計的に予測する設計)で、問いに対しては素直な設計である。研究課題が2つと明確で、帰無仮説も明示されている。しかし横断研究では時間的な前後関係がわからず、「ウェルビーイングの高い学生がAIを上手に使える」という逆向きの説明や、第3の要因(性格、自己調整力、ITへの慣れ)による見かけの相関を排除できない。問題は、要約と提言が「予測因子」「カウンセリングの補助に使うべき」と因果を思わせる書き方をしている点で、結論部の「因果を意味しない」という注記と食い違っている。

### ②サンプルサイズと選択基準

210人(解析206人)は、単回帰で中程度以上の効果を見つけるには十分な人数である。注意確認の設問で4人(1.9%)を除いた手順は評価できる。一方、対象はパンジャブ大学付属の1カレッジ、4専攻、2学期生と4学期生に限られ、便宜標本(集めやすい人を集める方法)である。理工系・医学系や他地域の学生は含まれず、AIを情緒的に使う人がとくに回答しやすかった可能性(自己選択バイアス)もある。回答率や、配布した人数、データ収集の期間・時期も記載がなく、標本の代表性を判断する材料が乏しい。

### ③方法論の適切性

DWSは1,533人の大学生で開発・検証された既存尺度で、改変使用でも信頼性α = .86 と良好である。問題はAIESで、著者らが本研究のために作った17項目の尺度だが、示されたのは「100人で予備調査した」ことと α = .80 だけで、因子分析(項目がまとまった概念を測っているかの確認)や他尺度との妥当性の検証は報告されていない。項目内容も公開されていない。さらに、AIESの「対処の手助け」とDWSの「感情調整」は内容が重なりうる。DWSをどう「改変」したか、下位尺度の項目数、逆転項目の扱いの詳細も不明で、再現は難しい。

### ④統計分析の妥当性

記述統計、ピアソン相関、単回帰、補足の一元配置ANOVAと、分析そのものは標準的で、表の数値も互いに計算が合っている(F = t²、R² = 回帰平方和÷総平方和など)。しかし、回帰の前提(正規性、等分散性、外れ値)の確認がない。相関と単回帰は同じ情報の言い換えにすぎず、性別・学年・AI使用頻度といった測定済みの変数を統制した重回帰が行われていない。共通方法バイアス(同じ人・同じ質問紙・同じ時点で測ることで相関が水増しされる現象)への対処(ハーマンの単一因子検定など)もない。下位尺度ごとの相関も示されていない。

### ⑤結果の信頼性と再現性

内的一貫性は両尺度とも良好で、表の数値は内部で整合している。一方で、再現性を損なう要素が多い。AIESの項目が非公開、DWSの改変内容が不明、データ・解析コードの公開もない。記述の食い違いも目立つ。Table 1 を本文が「Table 2」と呼び、Figure 1 と Table 4 が欠けている。DWS総合点2.78が下位尺度の単純平均(約2.49)より高い理由が説明されていない。文献レビューに参考文献リストにない「Oliver et al., 2020」が登場し、内容はQasimら(2025)のパキスタン医学生研究と重なる。受付から受理まで約6週間と査読期間も短い。

### ⑥結論の妥当性

「AIによる情緒的サポートとデジタル・ウェルビーイングが強く関連する」という結論は、データの範囲内では支持される。しかし「大学はAIの情緒的支援ツールをカウンセリングの補助として検討すべき」という提言は、横断研究・自作尺度・単一施設のデータからは飛躍がある。考察には矛盾もある。「本研究は使用頻度や強度を測っていない」と書くが、方法と Table 1 では使用頻度を測っている。文献レビューでは「自己への思いやりの調整効果も調べる」とあるが、そのような変数は測られていない。結論部では対象を「心理学・ウルドゥー語・英語」と書き、教育学が抜けている。

### ⑦新規性

先行研究の多くが、うつ・不安・孤独・チャットボット依存といった臨床的・限定的な結果を扱ってきたのに対し、本研究は多次元のデジタル・ウェルビーイング尺度を結果として使い、しかも研究の少ないパキスタンの一般学部生を対象とした点に新しさがある。ただし、デザインは単純な2変数の相関研究であり、方法論的な新しさはない。また、AIの情緒的利用を「健全」と「依存的」に分ける視点は文献レビューで丁寧に論じられているのに、それを検証する変数(使用頻度との交互作用、依存傾向など)が解析に組み込まれておらず、議論の新しさがデータで生かされていない。

### ⑧臨床的意義

精神科・学生相談の臨床から見ると、「AIに気持ちを話すこと」が一律に有害とは限らないことを示唆するデータとして参考になる。Fangら(2025)の、日々の使用量が多いほど孤独や依存が増すという無作為化研究と並べると、「どれだけ使うか」より「どう使うか(目的的か代替的か)」が大事という仮説を立てる材料になる。しかし本研究からは、AIの利用を学生に勧めてよいという実践上の根拠は得られない。自殺リスクのある学生やAIへの過度の依存といった安全面の評価は全くなく、カウンセリングの補助として導入するには、縦断研究や介入研究による検証が不可欠である。
