# 体育授業での能力の露出と大学生の心理的ウェルビーイング - 媒介要因としての評価不安と、文脈条件としての体育への所属感・不利な立場 精読ノート

## 概要

体育は「体を使い、人前で行い、他人と比べられる」授業でもある。本研究は、自分の運動能力や苦手さが人前にさらされ、比べられ、評価されると感じる度合い(能力の露出)が、大学生の心理的ウェルビーイング(前向きな気分・情緒の安定・自己満足・活力)とどう関係するかを調べた。

中国の大学生648人に質問紙調査を行った。能力の露出が強い学生ほど評価不安(人からどう見られるかへの緊張や気恥ずかしさ)が高く、ウェルビーイングが低かった。両者の関係のおよそ7割(間接効果 −0.226/総効果 −0.316)は評価不安を経由する形で統計的に説明された(部分媒介)。体育への所属感(クラスで受け入れられている感覚)は不安の低さ・ウェルビーイングの高さと、「体育で不利な立場にある」という自己認識は不安の高さ・ウェルビーイングの低さと関連した。ただし、これらが露出→不安→ウェルビーイングの道筋の強さを変える「調整効果」は有意でなかった。

著者は、体育の心理的な意味は参加そのものより「体の出来ばえがどう見られ、評価されるか」に左右されるとし、全員にとって脅威の少ない授業設計を提案する。横断研究のため因果は言えない。

## FigureとTableの解説

本論文には Figure 1 点と Table 10 点(Table 1〜7、Table 8A・8B・8C)がある。補足資料の表は本文中に言及がない。

### Figure 1 研究の概念モデル

仮説の全体図である。step 1:左端の「能力の露出」から中央の「評価不安」へ正の矢印(H1)。step 2:評価不安から右端の「心理的ウェルビーイング」へ負の矢印(H2)。この二つをつなぐのが媒介(H3。原因と結果の間に入って関係を伝える変数)。step 3:「体育への所属感」が露出→不安の矢印に、「不利な立場」が不安→ウェルビーイングの矢印にそれぞれ割り込む形で描かれ、矢印の強さを変える調整変数(モデレーター)として想定されている。step 4:両者は不安とウェルビーイングに直接効く主効果も持つ(H4、H5)。なお本文の抽出テキストでは図の中身は読めず、構成は本文の説明から再構成した。

### Table 1 参加者の属性

648人の内訳。step 1:性別は男性307人(47.4%)、女性341人(52.6%)。step 2:学年は1年203人(31.3%)、2年227人(35.0%)、3年218人(33.6%)、専攻は文系309人(47.7%)、理系339人(52.3%)とほぼ均等。step 3:自己評価の運動能力は「とても弱い」10.2%〜「普通」37.8%〜「とても強い」10.2%と左右対称に近い。step 4:週の運動頻度は「ほぼなし」14.7%、「2〜3回」36.4%が最多。step 5:「体育で不利な立場にある」と答えた学生は173人(26.7%)で、著者はこれを意味のあるリスク群とみなす。4年生がいない点、在籍者数が不明で回答率が出せない点に注意。

### Table 2 記述統計と相関

5変数の平均・標準偏差と相関係数(r。−1〜1で関係の強さと向きを示す)。step 1:平均は能力の露出3.36、評価不安3.28、所属感3.62、ウェルビーイング3.58(5段階)。step 2:露出と不安は r=0.579(中〜強い正の相関)。step 3:不安とウェルビーイングは r=−0.651 と最も強い負の相関。step 4:所属感はウェルビーイングと r=0.590、不安と r=−0.486。step 5:不利な立場(0/1)は露出 0.202、不安 0.320 と正、所属感 −0.243、ウェルビーイング −0.279 と負。すべて p<0.001 で、仮説の向きと一致する。

### Table 3 尺度の信頼性と収束妥当性

4尺度(各6項目)の測定の質。step 1:Cronbach の α(項目どうしがそろって同じものを測っているかの指標。0.7以上が目安)は0.887〜0.906と高い。step 2:CR(合成信頼性)も0.888〜0.906。step 3:AVE(平均分散抽出。項目のばらつきのうち、測りたい概念で説明できる割合。0.5以上が目安)は0.568〜0.617。step 4:標準化因子負荷量(各項目が概念をどれだけ反映するか)は0.720〜0.796。すべての尺度で各指標が非常に狭い範囲にそろっている点は、後述の評価で問題にする。

### Table 4 弁別妥当性

4つの概念が互いに別物として測れているかを、Fornell-Larcker 基準(各概念の AVE の平方根が、他の概念との相関より大きければよい)で確かめた表。step 1:対角線に AVE の平方根(露出0.754、不安0.778、所属感0.785、ウェルビーイング0.757)。step 2:対角線外は Table 2 と同じ相関。step 3:最大の相関は不安とウェルビーイングの |−0.651| で、両者の平方根(0.778、0.757)を下回るので基準を満たす。ただし差は大きくなく、HTMT のようなより厳しい基準は使われていない。

### Table 5 評価不安の媒介を調べた階層的重回帰

統制変数(性別・学年・専攻・運動能力の自己評価・運動頻度)を入れた3つのモデル。数値は標準化係数 β。step 1:モデル1で露出は不安を強く予測(β=0.495、R²=0.412)。step 2:モデル2で露出はウェルビーイングを負に予測(β=−0.342、R²=0.331)。step 3:モデル3で不安を加えると、不安 β=−0.496、露出は β=−0.097 に縮むが有意なまま(p=0.006)で、説明率が0.145増えた(R²=0.476)。step 4:運動能力の自己評価(不安 −0.237、ウェルビーイング 0.309)と運動頻度も一貫して保護的。露出の効果が残るため「部分媒介」と解釈される。

### Table 6 直接効果と間接効果のブートストラップ検定

ブートストラップ(データから3,000回くじ引きのように再標本を作り、効果のばらつきを推定する方法)による非標準化効果。step 1:総効果(露出→ウェルビーイング)−0.316、95%信頼区間[−0.378, −0.254]。step 2:直接効果(不安を経由しない分)−0.089[−0.153, −0.025]。step 3:間接効果(露出→不安→ウェルビーイング)−0.226[−0.273, −0.184]。信頼区間が0を含まないので有意。総効果のうち約72%が不安経由という計算になる。本文では間接効果の下限を−0.185、Boot SE を0.023と記しており、表(−0.184、0.022)とわずかに食い違う。

### Table 7 体育への所属感の調整効果

所属感が「露出→不安」の結びつきを弱めるか(緩衝するか)を、交互作用項(露出×所属感)で調べた表。step 1:モデル1で露出 β=0.446、所属感 β=−0.276 と、所属感が高いほど不安は低い。step 2:モデル2で交互作用は β=−0.047(SE 0.030、p=0.117、95%CI[−0.106, 0.012])と有意でない。step 3:説明率の増加は ΔR²=0.002 とごくわずか。つまり所属感は不安を全体的に下げるが、露出が不安を高める傾き自体は変えていない。H4 は主効果としてのみ支持された。

### Table 8A 不利な立場の調整効果

「不利な立場」が「不安→ウェルビーイング」の負の結びつきを強めるかを調べた表。step 1:モデル1で不安 β=−0.506、不利な立場 β=−0.259(ウェルビーイングが低い)。step 2:モデル2で交互作用(不安×不利な立場)は β=−0.069(SE 0.067、p=0.309、95%CI[−0.201, 0.063])と有意でない。step 3:ΔR²=0.001。不利な立場の学生はウェルビーイングが全体に低いが、不安が同じだけ上がったときの落ち込み方は他の学生と変わらなかった。表注には p<0.05 の記号の説明がなく、表記がやや不統一である。

### Table 8B 条件付き間接効果

所属感(平均±1標準偏差の低・高)×不利な立場(なし・あり)の4組み合わせで、露出→不安→ウェルビーイングの間接効果を推定した表。step 1:所属感が低く不利ありで最大(−0.250、[−0.323, −0.181])。step 2:所属感が低く不利なし −0.212、高く不利あり −0.202。step 3:所属感が高く不利なしで最小(−0.172、[−0.221, −0.128])。step 4:4つとも信頼区間が0を含まず有意。理論どおりの順序だが、次の Table 8C で差は有意でないので、著者も「記述的な傾向」にとどめている。

### Table 8C 調整媒介指数

調整媒介(媒介の強さが第三の変数によって変わること)の正式な検定。step 1:露出→不安の経路を所属感が調整する指数は0.02(Boot SE 0.013、95%CI[−0.005, 0.048])。step 2:不安→ウェルビーイングの経路を不利な立場が調整する指数は −0.034(0.028、[−0.088, 0.021])。step 3:どちらも信頼区間が0をまたぐため有意でない。したがって、調整媒介モデルは支持されず、中心の媒介経路は学生の下位集団をまたいで比較的一様に働いている、と著者は解釈する。

## 8項目評価

本論文は原著研究(一次データを集めた横断調査)なので、一次研究向けの基準をそのまま当てはめて評価する。

### ①研究デザイン

「露出→評価不安→ウェルビーイング」という具体的な仮説経路を立て、所属感と不利な立場を保護要因・危険要因として組み込んだ設計は、理論と検証の対応がわかりやすい。しかし1時点の横断調査で、同じ学生の自己報告だけから全変数を取っている。因果の向きは決められず、「不安が強い人ほど人目を意識して露出を強く感じる」という逆の説明も同じデータで成り立つ。授業の実際の形式(公開デモの有無など)を客観的に測っておらず、「授業設計を変えれば改善する」という提言の根拠は間接的である。

### ②サンプルサイズと選択基準

648人は回帰・媒介分析には十分な規模で、性別・学年・専攻の偏りも小さい。一方、標本は単一大学(著者所属の河池学院とみられるが明記なし)の体育履修者で、4年生を含まず、在籍者数が残っていないため回答率も算出できない。オンラインの自主参加なので、体育に関心のある学生や不安の強い学生が偏って回答した可能性を否定できない。サンプルサイズの事前計算(検出力分析)もない。中国の一地方の大学の結果を、他国や他の教育制度にそのまま広げるのは難しい。

### ③方法論の適切性

尺度はいずれも6項目・5段階で、「大学体育の文脈に合わせて改変した」とあるが、元になった既存尺度の名前も出典も示されていない。「全項目の内容を示す」と書きながら、本文にも付録にも項目が載っていない。表面妥当性の事前検討をしていないことは著者も限界として認めている。「不利な立場」は「はい/いいえ」の1項目で、運動が苦手なのか、体型の悩みか、障害かが区別できない。クラス単位のまとまり(同じ授業の学生は似る)を無視して個人単位で分析した点も、標準誤差を小さく見積もる方向に働く。

### ④統計分析の妥当性

階層的回帰、ブートストラップ3,000回、交互作用項の標準化、VIF(多重共線性の指標、1.01〜1.70)の確認と、手順自体は標準的である。標準化 β と非標準化効果の違いを本文で注意している点も丁寧である。ただし、24項目4因子の CFA で χ²(246)=228.94、p=0.776、CFI=1.00、TLI=1.00、RMSEA=0.00 という「完全な」適合は、実データの質問紙では極めてまれで、全尺度の負荷量が0.72〜0.80に狭くそろう点と合わせ、データの性質に疑問が残る。共通方法バイアスの検討も1因子モデルとの比較だけで弱い。本文と Table 6 の数値の小さな食い違いもある。

### ⑤結果の信頼性と再現性

主な相関(r=0.58、−0.65)や媒介効果は大きく、信頼区間も狭いので、この標本の中では安定した結果といえる。運動能力の自己評価と運動頻度を統制しても媒介が残る点は、単なる「運動が苦手な人ほど不安」の言い換えではないことを示す材料になる。しかし、データは「求めに応じて提供」とされ公開されておらず、尺度項目も示されていないため、第三者が同じ尺度で追試できない。単著で、概念化から解析・監督までをすべて一人が担っており、独立した点検の仕組みも見えない。

### ⑥結論の妥当性

「露出は評価不安を介してウェルビーイングの低さと関連する」という結論は、データの範囲では支持される。著者が一貫して「関連」「統計的媒介」と慎重な言葉を使い、調整効果が出なかったことを正直に報告している点は評価できる。ただし、調整効果が有意でなかったことから「中心の仕組みは集団をまたいで頑健」「全員のための授業設計が必要」と積極的に読むのは、検出力不足による見逃し(とくに173人の不利群)と区別できず、やや飛躍がある。主効果がともに有意なのに H5 を「部分的支持」とする記述も、仮説の書き方と整合しない。

### ⑦新規性

体育の利点を強調する研究が多い中で、「体の出来ばえが人目にさらされること」自体を独立した概念(能力の露出)として取り出し、社会的評価脅威の理論と結びつけて媒介経路として検証した点は新しい。インクルーシブ体育の議論を「誰を入れるか」から「参加の感情的な条件をどう設計するか」へ移す提案も示唆に富む。一方、社会的評価脅威や体育での否定的評価への恐れ自体は既知の知見で、能力の露出と評価不安は概念的に近く、相関0.58が「別の概念の関係」なのか「同じ不安の別側面」なのかは議論の余地がある。

### ⑧臨床的意義

精神科の視点では、評価への恐れと自己注目を中心とする社会不安の認知モデル(Morrison & Heimberg を引用)が、体育という日常の場面に当てはまることを示した点に意味がある。社交不安傾向のある若者が体育で強い苦痛を感じ、回避や不登校につながる経路の理解や、学校・大学への助言(公開の実演や順位づけを減らし、技能の多様さを当たり前にする)に使える。CBT の観点では、評価不安という介入しやすい媒介変数が示されたことになる。ただし、ウェルビーイング尺度は臨床的な抑うつや不安障害を測っておらず、介入研究もないため、臨床現場での効果はまだ言えない。
