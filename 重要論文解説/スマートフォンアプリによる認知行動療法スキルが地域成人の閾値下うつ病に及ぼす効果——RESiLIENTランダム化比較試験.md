# スマートフォンアプリによる認知行動療法スキルが地域成人の閾値下うつ病に及ぼす効果——RESiLIENTランダム化比較試験 精読ノート

> 役割：日本トップクラスのサイエンスコミュニケーターとして、原著研究論文をデフォルト精読フォーマット（概要・全図表解説・8項目評価・整合性チェック）に沿って分析した結果

## 1. 概要（500字以内）

認知行動療法（CBT）は通常、複数の技法を「パッケージ」としてまとめて提供される。しかし、そのうちどの部品が実際に効いているのかは分かっていなかった。京都大学の古川壽亮らは、5つの代表的CBTスキル——行動活性化（BA：楽しい活動を増やして気分を上げる）、認知再構成（CR：落ち込みを支える否定的思考を修正する）、問題解決（PS：問題を分解して解決策を選ぶ）、アサーション訓練（AT：相手を傷つけずに自分の希望を伝える）、不眠の行動療法（BI：睡眠制限・刺激統制を学ぶ）——をスマートフォンアプリに実装した。そして「マスタープロトコル」という設計（共通の対照群を共有しながら複数の仮説を1つの試験基盤で検証する方式）のもと、4つの2×2要因試験を同時に走らせた。2022年9月〜2024年2月に閾値下うつ病（うつ病の診断基準には届かない軽度の抑うつ）の成人3,936人が組み入れられ、6週時点の追跡率97%、プログラム完遂率84%という高い水準を達成した。結果、5スキルとその組み合わせはすべて、待機・健康情報・自己チェックという3種類の対照条件をいずれも上回った（PHQ-9変化量の効果量−0.67〜−0.16）。効果は26週まで持続した。CBTの「有効成分」を特定した、この分野で初めての大規模実証である。

## 2. Figure・Tableの解説

本論文には本文中に **Figure 1点・Table 5点**、Extended Data（拡張データ）として **Figure 2点・Table 8点**、さらに **Supplementary Table 12点**（オンライン補足資料。本PDFには収載されていない）への言及がある。以下、本PDFに収載されている図表を順に解説する。

### Figure 1｜CONSORTフローチャート（参加者の流れ）

試験参加者がどう絞り込まれたかを示す図。34,123人が適格性を評価され、28,759人が除外された（選択基準を満たさず16,577人、参加辞退12,105人、ベースライン調査未完了77人）。5,364人が同意して12群にランダム割付され、2人が同意撤回、さらにベースラインPHQ-9が4点以下だった1,426人を除いた **3,936人がITT（intention-to-treat：割り付けたまま解析する）コホート** となった。各群およそ328人ずつと均等である。図の下部は、BA群と待機群を4試験で共有する設計（点線の四角）を示しており、これがサンプルサイズを節約する要となっている。

### Figure 1 の脚注が示す「4つの2×2試験」の構造

Figure 1 の解析欄は、試験1＝BA×CR、試験2＝BA×PS、試験3＝BA×AT、試験4＝BA×BI という4つの2×2要因試験を並べている。各試験は「両方あり（例：BA+CR）／BAのみ／もう一方のみ（例：CR）／どちらもなし（待機）」の4セルからなる。試験4では、交代制3交替勤務者199人（全体の5.1%）は不眠の行動療法の恩恵を受けにくいと考えられるため、主解析・感度分析から除外されている。

### Table 1｜ITTコホートのベースライン特性

3,936人の背景を示す表。平均年齢43.1歳（SD 10.7）、男性51%、既婚69%、大学以上の学歴72%、就労者92%と、比較的社会的に安定した集団である。臨床指標はPHQ-9平均8.07（SD 2.74＝軽度うつ相当）、GAD-7（不安）5.84、ISI（不眠重症度）10.01、SWEMWBS（精神的ウェルビーイング）22.03。17%がCAGE 2点以上（アルコール問題の疑い）、29%が精神科治療歴あり、33%が何らかの身体疾患を有していた。パーソナリティ（Big Five）や逆境的小児期体験（4点以上が9%）まで測定しており、後の個別化研究の布石になっている。

### Table 2｜主要評価項目の主効果解析（6週PHQ-9、待機群対照）

各スキルについて「そのスキルあり」群と「なし」群を比較した、事前規定の主解析。MMRM（mixed-model repeated measures：欠測を扱いながら経時測定を解析する統計モデル）で推定した6週時点の効果量（SMD＝標準化平均差）は、**BA −0.38（95%CI −0.48〜−0.27）、CR −0.27、PS −0.27、AT −0.24、BI −0.27** であり、いずれもP値は10のマイナス6乗以下と極めて小さい。マイナスはうつ症状の減少を意味する。BAがやや大きいが、5スキルとも横並びに近い小〜中程度の効果を示した点が重要である。

### Table 3｜主効果＋交互作用を含めた解析（6週PHQ-9、待機群対照）

Table 2 と同じデータを、2スキル間の交互作用（相互の打ち消し合い）を明示的にモデルに入れて再解析したもの。交互作用は4試験すべてで検出された（P＝6.2×10⁻⁸〜3.8×10⁻¹¹）。交互作用を考慮すると単一スキルの効果量はPS −0.52からBA −0.65まで拡大し、2スキル併用はBA+BI −0.57からBA+PS −0.67の範囲にとどまった。つまり **2つ学んでも効果は2倍にならない（拮抗的交互作用）**。待機群自体の6週変化は−0.65〜−1.22点と小さい。

### Table 4｜統合解析（6週PHQ-9、3種の対照すべてと比較）

4試験を1つのデータセットにプールし、9つの介入群を3つの対照群すべてと対比した表。対照の「厳しさ」に序列があることが明快に示される。待機＜健康情報＜自己チェックの順に対照として強く、たとえばBAの効果量は待機比−0.63、健康情報比−0.48、自己チェック比−0.29と縮小する。それでも **全介入群の95%信頼区間は全対照に対して0を跨がなかった**。待機群は健康情報比0.17、自己チェック比0.35と、むしろ悪化方向にずれている。

### Table 5｜個別CBTスキルの成分解析（6週 vs 26週）

最も理論的に興味深い表。効果を「ns（非特異的効果＝プラセボ・励ましメール・自己チェック）」「ba/cr/ps/at/bi（各スキルの特異的効果）」「wl（待機リスト効果）」に分解している。6週時点では **ns が −0.18 と有益に働き、wl が +0.17 と有害に働いていた**。26週になると ns は 0.08（有意でない）に消え、スキル間の交互作用も弱まる一方、各スキルの特異的効果はむしろ増大する（例：bi −0.27→−0.34、cr −0.18→−0.27）。「非特異的な下駄」は時間とともに剥落し、学習した技能だけが残るという解釈を裏づける。

### Extended Data Fig. 1｜介入・対照の内容（a：構成表、b：アプリ画面）

aは12群それぞれで7章（導入・第1〜5章・エピローグ）のうちどの章・レッスンが提供されるかを一覧化した図。bは実際のスマートフォンアプリのスクリーンショット。介入群#1〜#10（BA〜自己チェック）は毎週PHQ-9に回答し、研究事務局の臨床研究コーディネーターから週1回の励ましメールを受け取った。一方 #11（健康情報）と #12（待機）は3週・6週のみPHQ-9に回答し、励ましメールを受け取らなかった。この差が、後の成分解析で ns と wl を分離する鍵になっている。

### Extended Data Fig. 2｜ベースラインから26週までのPHQ-9変化

統合MMRMモデルによる推定平均変化を折れ線で示した図（誤差棒は6週・26週で標準誤差）。全介入群が対照を下回ったまま26週まで推移する。26週時点では健康情報群と自己チェック群がもはや対照として区別できなくなること（本文記載）が視覚的に確認できる。待機群は6週以降に実際の介入へ移行するため、26週解析からは除外されている。

### Extended Data Table 1・2｜対照条件を変えた感度分析（健康情報／自己チェック）

Table 3 と同じ交互作用込みの解析を、対照を健康情報（Table 1）・自己チェック（Table 2）に差し替えて再実施したもの。より厳しい対照ほど推定効果量は小さくなるが、**最も厳しい自己チェック対照でさえ、PS −0.16（−0.30〜−0.02）からBA+PS −0.31（−0.45〜−0.17）まで、全介入で有意な特異的効果が残った**。結果の頑健性を支える中核的な感度分析である。

### Extended Data Table 3・4・5｜副次評価項目の統合解析（GAD-7／ISI／SWEMWBS）

6週時点の不安（GAD-7）、不眠（ISI）、精神的ウェルビーイング（SWEMWBS）についての統合解析。不安では全介入が待機・自己チェックを上回り、健康情報と比べてもBA（−0.24）とBI（−0.21）が優れた。不眠では健康情報比で優越したのはBI（−0.33）とBA+BI（−0.27）のみ、と理論通りの特異性を示す。ウェルビーイングでは自己チェック比で優れたのはBA（0.15）、BI（0.17）、BA+AT（0.13）にとどまり、健康情報を上回った介入はなかった。この3表の脚注はいずれも「PHQ-9」と誤記されている（実際は各尺度）点に注意。

### Extended Data Table 6｜プログラム所要時間（分）

各群が週ごとにアプリに費やした時間の中央値と四分位範囲。新しいスキルを導入する第1章、および2スキル群が2つ目のスキルを学び始める第3章では **20〜60分**、復習が中心の章では **10〜20分** であった。6週（あるいは10週）を過ぎると利用は激減し、**月あたり平均わずか1〜4分** になる。本文によれば実際の利用は「2〜10分の細切れセッション」で、日中の隙間時間に使われていた。

### Extended Data Table 7｜アドヒアランス（遵守率）

2つの定義で遵守率を示す表。全7章完遂は6週時点で群により51〜84%（平均63%）、主要教材である第4章までの完遂は74〜93%（平均78%）。30週まで待つと、それぞれ平均79%・84%へ上昇する。これは文献上の非ガイドiCBTの30%、治療者ガイド付きiCBTの68%と比べて高い。PS、CR、BA+PS、BA+CRは他群より遵守率が低い傾向にあった（認知的負荷が高いためと推測される）。

### Extended Data Table 8｜26週時点PHQ-9の統合解析

介入効果の持続性を示す表。全介入が26週でも2つの対照（健康情報・自己チェック）に対する優越を維持した。さらに **単一スキル群（−2.88点）より2スキル群（−3.17点）の変化が大きく、群間差−0.29点、効果量−0.08（−0.16〜−0.00、P=0.049）** となった。6週では加算的でなかった併用の利益が、長期では現れることを示す。ただしP=0.049・上限0.00とぎりぎりの結果であり、脚注に「−02.9」「95%CU」というタイプミスが残っている点も指摘しておく。

ベースライン変数の群間バランス（S1）、副次評価項目の主効果・交互作用（S2〜4）、追跡完了率（S5）、事前規定の全感度分析（S6〜9）、26週までの解析（S10）、6週・26週の成分解析（S11・12）が含まれる。本文の記述によれば、すべての感度分析が主結果を支持した。本ノートはこれらを本文の記述を通じてのみ参照している。

## 3. 8項目評価

### ① 研究デザイン

本研究は原著の個別ランダム化比較試験であり、**マスタープロトコル設計**（共通対照を共有しながら複数の介入を1つの試験基盤で同時評価する枠組み）に4つの2×2要因試験を埋め込むという、心理療法研究では先駆的な設計を採る。BA群と待機群を4試験で共有することで、必要症例数を大幅に節約している。事前登録（UMIN000047124）、プロトコル公表、統計解析計画（SAP）の事前公表と、透明性は極めて高い。問題点は、要因デザインが「効果は加算的」という前提に立ちやすいのに対し、実際には全試験で拮抗的交互作用が生じたことで、主解析の主効果推定値の解釈が単純ではなくなった点である。また5スキルすべての総当たり組み合わせではなく、BAを軸とした4通りに限定したため、BAを含まない併用（例：CR+PS）の効果は未検証のまま残る。

### ② サンプルサイズと選択基準

各要因試験でSMD 0.2をα=0.05・β=0.10で検出するのに1,053人（1群264人）、12群で3,168人、脱落10%を見込んで3,520人という事前計算に基づき、実際に3,936人を確保して要件を満たした。心理療法の成分研究としては桁違いに大きい（従来の解体研究は1群10人程度と本文が指摘する）。選択基準はPHQ-9 5〜9点、または10〜14点でも項目9（希死念慮）が0〜1点、精神科治療中でない18歳以上のスマートフォン所持者。問題点は代表性である。健康保険組合・企業経由の募集が中心で、就労率92%・大学以上72%と一般人口より恵まれた層に偏る。日本語話者・日本在住に限られ、無職者、高齢者、重い併存疾患をもつ人、デジタル機器に不慣れな層への一般化可能性は乏しい。

### ③ 方法論の適切性

アプリという固定された媒体で介入を提供したことで、対面CBTにつきまとう治療者の腕前のばらつきを排除できており、成分の効果を分離するには理想的な設計といえる。3種類の対照条件（待機・健康情報・自己チェック）を同時に置き、それぞれの「厳しさ」を実測した点は本研究最大の方法論的貢献である。コーディネーターには治療的内容の提供を禁じ、割付は事前作成の置換ブロック法で、ブロックサイズは独立統計家のみが知る形で秘匿された。問題点として、参加者・運営チームとも盲検化されておらず（心理療法では不可避）、全アウトカムが自己記入式である。著者は「12群あり各群の位置づけを参加者に強調しなかった」と反論するが、待機群だけは介入が保留されていることが明白であり、非盲検の影響が最も強く出る群でもある。また累計6,000円の金銭的謝礼（3週1,000円・6週2,000円・26週1,000円・50週2,000円）が回答行動に与えた影響は検討されていない。

### ④ 統計分析の妥当性

主解析はMMRMで、治療・訪問（カテゴリ）・治療×訪問の固定効果を置き、ベースラインPHQ-9・就労状況・年齢・性別で調整。共分散構造は無構造、自由度はKenward-Roger法で補正と、欠測を含む経時データの標準的かつ堅実な扱いである。解析コードはGitHubで公開されている。効果量はベースラインSD（群内変化）と6週SD（群間差）で算出、と算出根拠も明記されている。問題点は多重比較調整を行っていないことで、著者は「各仮説は独立した試験として検証された」と正当化するが、Table 4 の統合解析では9介入×3対照＝27通りの対比が同一表に並んでおり、この論理は苦しい。さらに26週までの延長解析と成分解析は事後解析（post hoc）であり、Table 5 の魅力的な「非特異的効果の消退」という所見は探索的な位置づけにとどまる。Extended Data Table 8 のP=0.049という結果も、事後解析としては脆弱である。

### ⑤ 結果の信頼性と再現性

6週追跡率97.2%、3週95.3%という数字は心理療法試験として例外的に高く、欠測による偏りの懸念を大きく減じる。遵守率も6週78%・30週84%と、文献値（非ガイドiCBT 30%）を大きく上回る。事前規定の感度分析（対照条件の差し替え、ベースライン重症度による層別、床効果・天井効果の緩和）がすべて主結果を支持し、既報の成分ネットワークメタ解析の推定値とも信頼区間が重なった点も再現性を支持する。問題点として、この高い追跡率・遵守率自体が金銭的謝礼と週次の励ましメールに支えられた「研究環境」の産物であり、実装現場で同じ数字が出る保証はない。またアプリはKokoro-appとして知的財産化され、筆頭著者・共著者が特許とライセンス供与の利害を有する。データは出版24か月後にUMIN-ICDRで公開予定とされるが、本ノート作成時点では第三者による独立再解析はまだ行えない。

### ⑥ 結論の妥当性

「5つのCBTスキルはいずれも差次的に有効で、その効果は26週まで持続する」という結論は、提示されたデータからおおむね妥当に導かれている。最も厳しい自己チェック対照でも全介入が有意であったこと、効果量が事前想定（SMD 0.2）を上回ったことが根拠となる。ただし効果の絶対値は控えめであることを見落としてはならない。**BA群のPHQ-9改善は6週で約3.46点、待機群でも1.25点で、その差は約2.2点** にすぎない。ベースライン平均8.07点の集団において、この差の臨床的実感がどの程度かは別途検討を要する。また著者は「待機リスト対照は確証試験に使うべきでない」「今後のメタ解析は異なる対照条件を混ぜてはならない」と強い規範的主張を展開するが、これは1試験の直接比較に基づく提言であり、他集団・他介入への一般化は慎重であるべきだ。

### ⑦ 新規性

新規性は高い。第一に、CBTの個別成分の効果を「単一の大規模ランダム化試験で直接」推定した点。従来の知見は間接比較に基づく成分ネットワークメタ解析か、1群10人規模の小規模解体研究に依存していた。第二に、既報のメタ解析では支持が弱かった **認知再構成（CR）それ自体の有効性を実証** した点。第三に、心理療法試験における対照条件の序列（待機＜健康情報＜自己チェック）を実測し、待機リストが効果を約0.35SD過大推定する「ノセボ条件」であることを直接示した点。第四に、「すべての真正な心理療法は等しく有効」というDodo bird判定（不思議の国のアリスの「みんなが勝者で、みんなが賞をもらうべき」に由来する主張）に対し、スキル間・アウトカム間で効果が異なることを示して反証を提示した点。問題点を挙げるなら、リラクセーション・マインドフルネス・アクセプタンスといった第三世代の要素が意図的に除外されており、現代のCBT実践の全体像を覆うものではない。

### ⑧ 臨床的意義

閾値下うつ病は世界人口の約11%が該当し、大うつ病エピソード発症リスクを3倍に高める一方、対面心理療法を全員に提供する人的資源は存在しない。本研究は、どのスキルを優先的にパッケージ化すべきかというエビデンスを初めて提供した点で、実装上の価値が大きい。不眠が主訴ならBI、不安が強ければBAまたはBI、というアウトカム別の使い分けも示唆される。日本人集団で検証された点は、日本の精神科臨床・産業保健にとって直接的な参照価値をもつ。問題点として、対象は「精神科治療を受けていない」閾値下うつ病であり、**大うつ病性障害の患者にそのまま外挿することはできない**（著者自身も限界として明記）。また6週後にアプリ利用が月1〜4分まで激減した事実は、著者の言う「真の学習の証」とも読めるが、単に飽きられただけとも読める。26週を超える長期効果、および本来の主目的である「大うつ病エピソードの発症予防」（50週時点の解析2）の結果は今後の報告を待つ必要がある。
