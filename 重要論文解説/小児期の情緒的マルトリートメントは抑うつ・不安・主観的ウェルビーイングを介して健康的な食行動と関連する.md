# 小児期の情緒的マルトリートメントは抑うつ・不安・主観的ウェルビーイングを介して健康的な食行動と関連する 精読ノート

## 概要(500字以内)

子ども時代に親などから言葉で傷つけられたり、情緒的に無視されたりする「情緒的マルトリートメント(CEM)」は、身体的虐待より目立たないが長く影響する。本研究は中国の大学生3,007人(6大学、2024年10〜12月、有効回答率91.1%)にオンライン調査を行い、CEMが大学生の健康的な食行動(果物・野菜の摂取頻度から炭酸飲料の摂取頻度を引いた得点)と関連するか、その間を「情緒的苦痛(抑うつ・不安)」と「主観的ウェルビーイング(SWB:自分の暮らしの幸福感)」がつなぐかを検討した。CEMは抑うつ(r=0.356)・不安(r=0.371)と正に、SWB(r=−0.317)・食行動(r=−0.217)と負に相関した。PROCESSマクロ(Model 80)による連鎖媒介分析では、CEMから食行動への総効果−0.212のうち37.7%が間接効果で、抑うつ経由(14.2%)、不安経由(10.4%)、SWB経由(7.6%)が主で、抑うつ→SWB、不安→SWBを経る連鎖経路はそれぞれ3%未満と小さかった。競合モデルの比較では並列媒介モデルの方が適合度指標で優れていたが、著者は理論的整合性を理由に連鎖モデルを主モデルとして採用した。横断研究のため因果は示せず、効果量も小さいが、大学生の食生活支援に心の健康への配慮を組み込む根拠を与える。

## 論文の性質

独自に収集した質問紙データを解析した**原著研究**で、デザインは一時点の**横断研究**である。Figureは2点(Fig. 1 仮説モデル、Fig. 2 連鎖媒介モデルの結果)、Tableは5点。すべて本文中に含まれ、補足資料はない。

## 用語の整理

- **CEM(childhood emotional maltreatment)**:養育者による継続的な言葉の攻撃、情緒的ネグレクト、支配、辱め、脅し、無関心。身体的虐待・性的虐待と並ぶ児童マルトリートメントの一類型。
- **情緒的苦痛(emotional distress)**:本研究では抑うつと不安の2つで操作的に定義。
- **SWB(subjective well-being)**:生活全般に対する本人の主観的評価。本研究では「現在の暮らしの幸福度」を7段階で尋ねる1項目で測定。
- **連鎖媒介モデル(chain/serial mediation)**:X→M1→M2→Yのように、媒介変数が順番につながる経路を想定するモデル。並列媒介は複数の媒介変数が互いに独立にX→M→Yをつなぐモデル。
- **PROCESS Model 80**:Hayesの媒介分析ツールの一型で、並列の媒介変数(ここでは抑うつ・不安)がさらに別の媒介変数(SWB)へつながる構造を扱う。
- **ブートストラップ95%信頼区間**:データから5,000回再標本化して間接効果の区間を推定する方法。区間が0を含まなければ有意とみなす。
- **AIC/BIC**:モデルの当てはまりと簡潔さのバランスを示す情報量基準。小さいほど良い。

## FigureとTableの解説

### Figure 1:仮説モデル
CEM(X)が抑うつ(M1)と不安(M2)を高め、両者がSWB(M3)を下げ、最終的に健康的な食行動(Y)を損なうという連鎖媒介の仮説図。仮説はH1(CEMは食行動と負の関連)、H2(情緒的苦痛が媒介)、H3(SWBが媒介)、H4(情緒的苦痛→SWBの連鎖で媒介)の4つ。自己決定理論(自律性・有能感・関係性の欲求が満たされると健康行動が増える)、生態学的システム理論、情動制御理論を根拠に組み立てられている。

### Table 1:記述統計と属性別比較
男子1,267人(42.1%)、女子1,740人(57.9%)、平均19.03±1.18歳。男子はCEM得点が高く(8.63 vs 8.24、t=3.36、d=0.124)、女子は食行動得点が高い(5.29 vs 4.86、t=−4.32、d=−0.159)。一人っ子かどうかで差はない。学年差はCEM(F=7.97、η²=0.008)、抑うつ(F=5.91)、不安(F=5.60)、SWB(F=3.83)、食行動(F=2.94)で有意だが、η²は0.003〜0.008と極めて小さい。「4年生はCEMが最も高い(10.00)」とされるが4年生はわずか11人で、この比較は不安定である。Benjamini–HochbergのFDR補正後も学年差と性差(CEM・食行動)は有意だったとされる。

### Table 2:相関分析
CEM 8.40±3.19、抑うつ3.52±1.18、不安3.36±1.22、SWB 5.04±1.39、食行動5.11±2.77。歪度・尖度はいずれも正規性の目安(|歪度|<2、|尖度|<7)内。CEMは抑うつ(0.356)・不安(0.371)と正、SWB(−0.317)・食行動(−0.217)と負の相関。抑うつと不安はSWB(−0.386、−0.378)と食行動(−0.210、−0.206)に負、SWBは食行動と正(0.185)。抑うつと不安の相関は0.785と非常に高く、両者を別々の媒介変数として扱うことの妥当性に疑問が残る。すべてp<0.001。

### Table 3:競合モデルの比較
M1(仮説の連鎖媒介)、M2(逆順:CEM→SWB→情緒的苦痛→食行動)、M3(並列媒介)、M4(単一媒介:情緒的苦痛のみ)、M5(SWBが情緒的苦痛→食行動を調整するモデル)をAMOSで比較。M1はχ²/df=3.593、CFI=0.996、RMSEA=0.029、AIC=140.264。M3はAIC=100.441、BIC=292.719、aBIC=324.719と最も低く、統計的には最良。M5はχ²/df=450.601、AIC=17,651と桁違いに悪い。著者は「M3が統計的に最適だが、理論的・発達的に妥当な時間順序を反映するM1を主モデルとして採用した」と述べる。本文中で「Table Xに示すように」という未修正の記述がある。

### Table 4:媒介モデルの段階的回帰
性別・年齢・学年・両親の学歴・一人っ子を統制。Step 1:CEM→不安β=0.374(R²=0.141)、CEM→抑うつβ=0.359(R²=0.129)。Step 2:CEM→SWBβ=−0.316、抑うつ・不安を投入するとCEMは−0.187、抑うつ−0.203、不安−0.149(R²=0.195)。Step 3:CEM→食行動β=−0.212(R²=0.052)、情緒的苦痛投入後はCEM −0.149、抑うつ−0.102、不安−0.072(R²=0.076)。Step 4(最終):SWB 0.087、CEM −0.132、抑うつ−0.084、不安−0.060(R²=0.082)。VIFは1.02〜2.71で多重共線性の問題はないとされる。最終モデルでも食行動の分散の8.2%しか説明できていない点は重要である。

### Figure 2:連鎖媒介モデルの結果
Table 4の標準化係数を経路図にしたもの。CEMから食行動への直接効果は−0.132で、媒介変数を加えても有意なまま残る(部分媒介)。1SDのCEM増加は食行動得点を0.132SD下げ、抑うつ・不安の1SD増加はそれぞれ0.084SD・0.060SD下げ、SWBの1SD増加は0.087SD上げる、という実質的な大きさの説明が添えられている。いずれも小さい効果である。

### Table 5:間接効果の分解
総効果−0.212(95%CI −0.247〜−0.177)、直接効果−0.132(−0.170〜−0.094)、総間接効果−0.080(−0.098〜−0.062、総効果の37.74%)。内訳は、CEM→抑うつ→食行動 −0.030(14.15%)、CEM→不安→食行動 −0.022(10.38%、CIの上限−0.001でぎりぎり)、CEM→SWB→食行動 −0.016(7.55%)、CEM→抑うつ→SWB→食行動 −0.006(2.83%)、CEM→不安→SWB→食行動 −0.005(2.36%)。論文の主題である「連鎖」経路は合計でも5%程度にすぎず、著者自身も考察で「SWBの媒介的役割は限定的で、情緒的苦痛を経る直接的な経路が主」と認めている。

## 8項目評価

### ①研究デザイン
3,000人規模の大学生を対象に、理論に基づく4つの仮説を立て、競合モデルとの比較まで行った点は、同種の中国の大学生調査の中では丁寧な部類に入る。しかし横断研究であり、CEM(過去)→現在の情緒状態→現在の食行動という時間順序は設計上は保証されない。特にSWBと食行動、抑うつとSWBの間は逆方向の因果(健康的に食べているから幸福感が高い)も十分あり得る。著者は「因果ではなく関連」と繰り返し断っているが、タイトルや仮説の記述は因果的な読みを誘う。競合モデル比較で統計的に優れた並列モデルを退けて連鎖モデルを採用した判断は、理論優先の姿勢としては理解できるが、結果の解釈をデータより仮説に寄せている印象を与える。

### ②サンプルサイズと選択基準
有効回答3,007人、回答率91.1%、注意確認項目や回答時間による不良回答の除外、Harmanの単一因子検定(第1因子22.6%)など、データ品質管理は記載されている。一方、便宜抽出と教員を介した雪だるま式抽出で、湖南・四川・陝西・山西・安徽の6大学(本文では5省しか挙げられていない)に限られ、代表性は乏しい。1・2年生が93%を占め、4年生は11人しかいないのに学年比較が報告されている。検出力計算(必要例数118)は形式的で、これほど大きな標本では相関0.1程度でも「p<0.001」になるため、統計的有意性より効果量で読むべきである。

### ③方法論の適切性
最大の弱点は測定の粗さである。CEMはCTQ短縮版からさらに削った4項目、抑うつ・不安はスクリーニング用のPHQ-2・GAD-2、SWBは1項目、食行動は「炭酸飲料・果物・野菜の摂取日数」3項目の合成得点にすぎない。著者は回答負担軽減のためと説明し、信頼性係数(α=0.78〜0.85)やCFAの適合度を示しているが、4項目や2項目のCFAはほぼ飽和モデルであり、適合度が良いのは当然である。食行動の指標は加工食品・間食・食事の規則性などを含まず、著者も「栄養評価ではなく食傾向の代理指標」と認めている。CEMの回想的自己報告は現在の気分に左右される想起バイアスを免れない。

### ④統計分析の妥当性
PROCESSによるブートストラップ媒介分析、人口統計変数の統制、FDR補正、VIFの確認、AMOSによる競合モデル比較と、手続きは標準的で報告も詳細である。ただし、抑うつと不安の相関が0.785と極めて高いまま並列の媒介変数として投入しており、両者の個別の間接効果(特に不安経由、CI上限−0.001)の解釈は不安定である。PROCESSは測定誤差や大学ごとのクラスター効果を扱えないことを著者自身が限界に挙げている。考察で「SWBと情緒的苦痛の相関(r=−0.371〜−0.356)」と書かれているが、この数値はCEMと情緒的苦痛の相関であり、SWBとの相関は−0.386・−0.378である。数値の取り違えとみられる。

### ⑤結果の信頼性と再現性
主要な相関の方向は先行研究と一致し、標本が大きいため推定値自体は安定していると考えられる。ブートストラップCIも報告されている。しかし、データは「研究チームの方針」により非公開で、質問項目の正確な文言(特に食行動3項目の採点法)や解析コードは公開されていない。参考文献には著者名が欠落した項目(文献97・98)、不完全な項目(文献69)、引用先の取り違え(インドネシアの研究を文献27として引用しているが、実際は文献55とみられる)があり、原稿全体の校正精度に不安が残る。

### ⑥結論の妥当性
「情緒的苦痛とSWBがCEMと食行動の関連を部分的に媒介する」という結論は、データの範囲内では支持される。著者は限界の節で横断デザイン、回想バイアス、簡略尺度、便宜抽出、文化的文脈、PROCESSの制約を網羅的に挙げ、効果量が小さく「理論的支持」と解釈すべきと明言しており、誠実である。他方、結論部で「大学の食生活プログラムに心理的要因を組み込むべき」と提言するには、総分散の8%しか説明しないモデルは根拠として弱い。食行動に最も強く関連するのは依然としてCEMの直接効果であり、心理的媒介変数に介入すれば食行動が改善するという含意は本研究からは導けない。

### ⑦新規性
CEMと摂食障害・情動的摂食の関連や、CEMと抑うつ・不安の関連は多数の先行研究があり、本研究の個々の経路に新しさは乏しい。新しいのは「健康的な食行動(病的な摂食ではなく日常の食の質)」を結果変数とし、SWBを情緒的苦痛の下流に置いた連鎖モデルを大規模標本で検証した点である。ただし、肝心の連鎖経路はほとんど効かず、並列モデルの方が適合したという結果は、むしろ「SWBは情緒的苦痛と並ぶ別の相関因子」という単純な図式を支持しており、理論的な新知見としての価値は限定的である。

### ⑧臨床的意義
精神科臨床の観点では、小児期の情緒的マルトリートメントの既往を持つ若年者で、抑うつ・不安だけでなく食生活の乱れも併せて評価する意義を示唆する点が有用である。情緒的虐待は身体的・性的虐待に比べて本人も周囲も見過ごしやすく、問診で意識的に尋ねる根拠になる。また、大学の学生相談と栄養教育を連携させるという提言は実務的である。ただし、本研究は介入研究ではなく、CBTや感情調節訓練が食行動を改善するかは検証されていない。効果量が小さいことから、食行動の改善を目的に心理介入を行う根拠としては弱く、あくまで「併存しやすい問題として注意を向ける」程度の含意にとどめるのが妥当である。
