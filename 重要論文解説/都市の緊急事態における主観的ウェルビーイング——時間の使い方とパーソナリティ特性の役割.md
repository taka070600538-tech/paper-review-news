# 都市の緊急事態における主観的ウェルビーイング——時間の使い方とパーソナリティ特性の役割

## 1. 概要

都市全体が封鎖されるような緊急事態で、人の「幸福感(主観的ウェルビーイング、SWB)」は何によって保たれるのか。本研究は2022年4月末〜5月初めの上海ロックダウン中に、オンライン質問票で住民459人の1日の時間の使い方(屋外活動・睡眠・有給の仕事・オフラインの余暇・オンラインの余暇)、生活の質の感じ方(健康の自己評価・人とのつながり・地域の住みやすさ)、SWB の4側面(生活満足度・社会的ウェルビーイング・エウダイモニア的ウェルビーイング=生きがいや成長感・感情)、ビッグファイブ性格を測りました。

構造方程式モデリング(多数の変数の因果の道筋をまとめて推定する統計手法)の結果、健康の自己評価が SWB のすべての側面を最も強く押し上げ(感情 β=0.531)、地域の住みやすさも全側面に効いていました。時間の使い方では、屋外活動・睡眠・仕事・オフライン余暇が健康感や住みやすさを高め、オンライン余暇は住みやすさを下げていました。性格で3群に分けると、神経症傾向の高い「敏感群」は屋外活動の効果が大きく、「ポジティブ群」は睡眠が健康感に強く効いていました。ただし横断データで因果は言えず、表間で数値の食い違いもあります。

## 2. FigureとTableの解説

本文の図表は Figure 1〜4 と Table 1〜6 の計10点。加えて付録 A(性格質問票 TIPI の10項目)と付録 B(弁別妥当性の相関表)がある。

### Figure 1 研究の枠組みと仮説

左から右へ「時間の使い方 → 生活の質の感じ方 → SWB」と矢印が流れる概念図です。左端に5つの活動(屋外活動・睡眠・有給の仕事・オフライン余暇・オンライン余暇)、中央に3つの生活の質(健康の自己評価・社会的つながり・地域の住みやすさ)、右端に SWB の4側面が置かれます。生活の質→SWB の矢印が H1〜H3(各4本で H1a〜d など)、活動→生活の質が H4〜H8(各3本で a=健康、b=つながり、c=住みやすさ)で、合計32本の仮説経路です。さらにパーソナリティがこれらの矢印の強さを変える「調整役(モデレーター)」として描かれています。

### Table 1 回答者の属性

有効回答459人の性別・年齢・学歴・世帯年収・居住地を、上海統計年鑑や国勢調査の分布と並べた表です。女性56.2%(統計48.2%)、31〜40歳32.9%・26〜30歳29.6%(統計ではそれぞれ10.3%・5.1%)、大卒60.8%(統計35.4%)、高卒未満は11.1%(統計44.8%)と、**働き盛りで高学歴の層に大きく偏って**います。60歳超は約2%しかいません。著者はこれをオンライン調査による「デジタル格差」で説明しています。世帯年収は10〜20万元が最多(28.1%)、郊外居住が59.7%でした。

### Table 2 測定モデルの結果(信頼性・妥当性)

各構成概念(潜在変数=直接は測れず複数の質問から推し量る概念)の因子負荷量、クロンバックα(質問項目どうしの一貫性)、CR(合成信頼性)、AVE(平均分散抽出=項目がどれだけ概念を説明しているか)を示します。5つの活動はいずれも単一項目なので全指標が1.000です。負荷量はすべて0.5超、CR は0.797〜0.901、AVE は0.505〜0.741。ただしαは健康感0.543、感情0.550、社会的ウェルビーイング0.653と低めで、著者は「0.5以上で許容」という緩い基準を採っています(一般的な目安は0.7)。

### Table 3 構造方程式モデルの結果(全体)

32本の経路の標準化係数 β、標準誤差、t値、p値です。健康の自己評価→SWB は4本とも強く(生活満足度0.474、社会的0.340、エウダイモニア0.454、感情0.531、いずれも p<0.001)。つながり→感情(H2d)だけは0.009で無関係でした。住みやすさ→SWB も4本とも有意(0.187〜0.339)。活動→生活の質では、屋外活動→健康0.117・→住みやすさ0.122、睡眠→健康0.198・→住みやすさ0.106、仕事→住みやすさ0.158、オフライン余暇→つながり0.122・→住みやすさ0.134、オンライン余暇→住みやすさ−0.107(p=0.042)が有意でした。係数の大きさは0.1前後と小さめです。

### Figure 2 SEM で有意だった経路の図示

Table 3 のうち p<0.1 の経路だけを、Figure 1 と同じ配置の矢印図に係数付きで描いたものです。生活の質→SWB の太い矢印群(特に健康感から右へ伸びる4本)と、活動→生活の質の細めの矢印群のコントラストが一目でわかります。言い換えると、「時間の使い方が直接幸福感を決める」のではなく、「時間の使い方→健康感や住みやすさ→幸福感」という間接的な道筋(媒介)が主であることを視覚的に示す図です。ただし間接効果そのものの検定値は本文に示されていません。

### Table 4 多群比較(PLS-MGA)の p 値

性格3群(内向群・敏感群・ポジティブ群)のあいだで、各経路の係数に差があるかを検定した p 値の表です。内向群 vs 敏感群では H1c(健康→エウダイモニア、p=0.039)、H2d(つながり→感情、0.042)、H4b(屋外→つながり、0.021)に差。内向群 vs ポジティブ群は H7a(0.098)のみ。敏感群 vs ポジティブ群は H1c(0.006)、H4b(0.001)、H4c(0.030)などで差がありました。32経路×3比較=96回の検定を多重比較の補正なしで行っており、p<0.1 まで「有意」と扱っている点に注意が必要です。

### Figure 3 住民の3つのパーソナリティ・プロファイル

TIPI(10問で性格の5因子を測る簡易尺度、7段階)の得点で K-means クラスタリング(似た回答の人同士を自動でグループ分けする手法)を行った結果を、群ごとの5因子の平均値で示した図です。**内向群**は外向性が2.47と際立って低く(他の2群は4.90と4.22)、開放性も低め(3.99)ですが協調性は高め(5.58)。**敏感群**は神経症傾向が最も高く(4.35)、誠実性が最も低い(3.87)。**ポジティブ群**は協調性(5.96)・外向性・誠実性・開放性が最も高く、神経症傾向が最も低い群です。各群の人数は本文に記載がありません。

### Table 5 性格群ごとのブートストラップ結果

Table 4 で差があった経路について、群ごとの係数と p 値を並べた表です(ブートストラップ=データを繰り返し再抽出して係数のばらつきを推定する方法)。健康→社会的ウェルビーイングは敏感群0.428、ポジティブ群0.196。健康→エウダイモニアは3群とも有意(内向0.381、敏感0.571、ポジティブ0.317)。屋外活動は敏感群でのみ健康(0.225)・つながり(0.277)・住みやすさ(0.250)を高めました。睡眠→健康はポジティブ群で0.329と強く、敏感群では有意でない。オフライン余暇→健康(H7a)は内向群で0.182(p=0.013)でした。表中の「–」は値が示されておらず、理由の説明もありません。

### Figure 4 性格群ごとの有意な経路係数

Table 5 の内容を p<0.1 の経路に絞って、3群それぞれの矢印図として描いたものです。敏感群では「屋外活動」から生活の質3つすべてへ矢印が伸び、外出制限の影響を最も受けやすい集団であることが視覚化されています。ポジティブ群では「睡眠→健康」が目立ち、内向群では「オフライン余暇→健康」と「つながり→感情」が残ります。同じロックダウンでも、性格によって幸福感を支える「てこ」が違うという本論文の中心メッセージを表す図です。

### Table 6 仮説検証結果のまとめ

32仮説それぞれについて「支持/限界的に支持/不支持」と主要な係数をまとめた表です。支持は H1 の4本、H2a〜c、H3 の4本、H4a・c、H5a・c、H6c、H7c、H8c(負の向き)など。不支持は H2d、H4b、H5b、H6b、H7a、H7b、H8b。限界的支持が H6a(仕事→健康、p=0.058)と H8a(オンライン余暇→健康、負、p=0.095)です。**注意点**として、H2a〜H2d の係数が Table 3 と一致しません(例:H2b は Table 3 で0.255、Table 6 で0.371。H2d は0.009/p=0.839 と0.027/p=0.547)。また H7b は Table 3 で有意(0.122、p=0.013)なのに Table 6 では「不支持」となっています。

### 付録 A・付録 B

付録 A は性格測定に使った TIPI 中国語版の10項目(「外向的で熱心」「批判的で口論しがち」など、各因子2項目で一方は逆転項目)です。付録 B はフォーネル・ラーカー基準(各概念の AVE の平方根が、他の概念との相関より大きければ「別物として区別できている」とみなす基準)の表です。ただし生活満足度とエウダイモニアの相関0.822は、エウダイモニアの AVE 平方根0.753を上回っており、本文の「すべての概念が区別できた」という記述と食い違います。両者がほぼ同じものを測っている可能性があります。

## 3. 8項目評価

本研究はオリジナルの調査データを用いた**原著研究**であるため、一次研究の基準で評価する。

### ① 研究デザイン

上海ロックダウンという「自然に起きた極端な状況」のさなかにデータを取った点は貴重で、平時の調査では観察できない時間の使い方の変化をとらえています。理論に基づいて仮説を事前に立て、媒介(活動→生活の質→SWB)と調整(性格)の両方を組み込んだ枠組みも整理されています。一方で**1時点の横断調査**であり、ロックダウン前との比較も対照集団もないため、「屋外活動が健康感を高めた」のか「健康な人が外に出られた」のかを区別できません。著者自身も双方向の関係の可能性を限界に挙げています。

### ② サンプルサイズと選択基準

553件中94件を除外し459人が有効回答で、PLS-SEM 全体には十分な規模です。しかし3群に分けた後の各群人数が示されず、群ごとの推定やMGA の検出力を評価できません。募集は地域サービスと SNS 経由の自発参加(便宜的標本)で、20〜40代・大卒・中高所得に強く偏り、高齢者・子ども・低所得者・出稼ぎ労働者がほぼ含まれません。「夜勤なし・就労能力あり」という条件も、最も脆弱な層を最初から外しています。上海住民一般への一般化は困難です。

### ③ 方法論の適切性

SWB を4側面に分けて測った点、性格を変数ごとでなく「プロファイル(組み合わせの型)」で扱った点は工夫です。しかし時間の使い方を「24時間の活動と長さを自己申告」させ、それを**単一項目**の変数として投入しているため、測定誤差を評価できません(αやAVEが1.000なのは単一項目だからで、信頼性が高いという意味ではない)。健康感のα=0.543など内的一貫性の低い尺度があり、0.5という緩い基準で許容しています。性格は2項目ずつの TIPI で、クラスタの安定性検証もありません。

### ④ 統計分析の妥当性

SRMR=0.073 と許容範囲の適合度を報告していますが、併記の GoF は PLS-SEM では適合度指標として推奨されていない指標です。付録 B では生活満足度とエウダイモニアの弁別妥当性が基準を満たしておらず、本文の記述と矛盾します。MGA は96回の比較を多重性の補正なしで行い、p=0.098 を「有意な差」と表現しています。年齢・性別・収入・同居家族などの交絡因子(結果をゆがめる第三の要因)を統制した形跡がなく、間接効果の検定値も示されていません。

### ⑤ 結果の信頼性と再現性

健康感と SWB の強い関係は先行研究とよく一致し、頑健と考えられます。しかし Table 3 と Table 6 で H2 系の係数が食い違い、H7b の判定も両表で逆になっているほか、本文では Table 5 の H1b(社会的ウェルビーイング)を H1a と書き、オフライン余暇の H7a を「オンライン余暇」と記述するなど、報告上の誤りが複数あります。データは「合理的な要請があれば提供」で公開されておらず、質問票も性格部分以外は全文が示されていないため、外部からの再現は難しい状況です。

### ⑥ 結論の妥当性

「健康感・つながり・住みやすさが SWB を支える」という結論は Table 3 の結果に沿っています。一方、活動→生活の質の係数は多くが0.1前後と小さく、「時間の使い方が SWB を大きく左右する」とまでは言いにくい規模です。結論の「オフライン余暇がつながりを育む」は Table 3 と一致しますが Table 6 の判定とは矛盾します。また性格群の違いから「敏感な住民には屋外の機会を」といった具体的施策まで提言していますが、横断データからの介入効果の推定であり、言い過ぎの面があります。

### ⑦ 新規性

ロックダウン下で、時間利用・生活の質・SWB・性格プロファイルの4者を1つのモデルにまとめて検討した点は新しい試みです。特に「性格によって幸福感を支える活動が違う」(敏感群は屋外活動、ポジティブ群は睡眠)という知見は、平均的な効果だけを見る従来研究に対する補足として意義があります。ただし、各要素(外向性と社交、神経症傾向とストレス脆弱性、睡眠と健康感)の関係自体は既知であり、方法も PLS-SEM と K-means の組み合わせという定番の手法です。

### ⑧ 臨床的意義

精神科臨床の視点では、「同じ外出制限でも、神経症傾向の高い人は屋外に出られないことで健康感・つながり・住みやすさの感覚がまとめて下がりやすい」という知見は、災害時や長期療養中の患者で誰を優先的に支えるかを考えるヒントになります。睡眠の確保やオフライン活動への置き換えは行動活性化(CBT の技法)とも通じます。ただし精神症状の臨床尺度は使われておらず、対象も比較的健康な働き盛りの一般住民で、臨床集団への直接の応用には別の検証が必要です。
