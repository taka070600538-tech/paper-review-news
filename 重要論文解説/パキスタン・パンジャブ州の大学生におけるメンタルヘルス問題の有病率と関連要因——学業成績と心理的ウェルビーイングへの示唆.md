# パキスタン・パンジャブ州の大学生におけるメンタルヘルス問題の有病率と関連要因——学業成績と心理的ウェルビーイングへの示唆 精読ノート

## 概要

パキスタン・パンジャブ州の公立3大学で、2015年1〜3月に学生1308名へ質問紙調査を行った横断研究である。知覚ストレス（PSS、14項目）、抑うつ症状（修正版ベック抑うつ評価尺度M-BDI、20項目）、心理的ウェルビーイング（WHO-5）を測定した。

PSSで「ストレスあり」と判定された学生は54.9%（平均27.6点）、M-BDIで抑うつ症状ありは44.2%（平均33.8点）と高く、一方でWHO-5の低ウェルビーイングは19.0%にとどまった。女子学生、2〜3年生、仕送りなど経済的支援が不十分な学生でリスクが高く、寮で暮らす学生は自宅生より低ウェルビーイングが少なかった。

特徴は、学業を「成績（GPA）」と「成績への満足度」の2軸に分けて4群をつくった点である。ストレスや抑うつは「成績が低いこと」そのものより「成績に満足していないこと」と結びついていた。とくに「成績が高いのに不満」の群でオッズが高かった。著者らは、2015年のデータをCOVID-19前の基準値として位置づけ、大学にカウンセリング体制とスティグマ（偏見）を減らす取り組みの充実を求めている。

## FigureとTableの解説

本論文にFigureはなく、Table 1〜6の6つだけである。

### Table 1：サンプルサイズの計算

3大学の在籍者数は、パンジャブ大学（ラホール）27,782名（55%）、バハウッディン・ザカリヤ大学（ムルタン）13,910名（27.5%）、グジュラート大学8,857名（17.5%）で、合計50,549名である。ヤマネの式 n=N/(1+Ne²)（母集団の大きさから必要人数を出す簡便式）に許容誤差e=±3%を当てはめ、必要数1087名を得た。本文はここに無回答分20%を上乗せして目標を1308名としている。ただ1087×1.2は約1304で、数字が少しずれる。在籍者数の出典は高等教育委員会の2012〜13年報で、調査時点（2015年）とは2〜3年の差がある。

### Table 2：回答者の社会人口学的特性（N=1308）

年齢は16〜28歳（平均21.5歳）で、≦20歳28.0%、21歳24.4%、22歳24.5%、≧23歳23.1%とほぼ均等に分かれた。男性657名（50.2%）、女性651名（49.8%）で、都市部出身が61.5%を占める。未婚が95.3%、無職が89.1%、ムスリムが98.9%である。BMI（体格指数）では、やせ20.5%、標準55.7%、過体重12.8%、肥満4.4%だった。項目によって合計が1308名に届かず（出身地は1271名分）、欠測があるものの、その扱いは書かれていない。本文によれば学年は2年生78.4%、3年生14.9%、4年生6.7%で、2年生に大きく偏っている。

### Table 3：ウェルビーイング・ストレス・抑うつ・GPA・主観的成績の頻度

WHO-5は低19.0%・高81.0%（n=1277）、PSSはストレスなし45.1%・あり54.9%（n=1106）、M-BDIは抑うつなし55.8%・あり44.2%（n=987）である。GPAの分布は、≦3.00が23.9%、3.01〜3.30が25.2%、3.31〜3.70が35.8%、3.71〜4.00が15.1%だった。「同級生と比べて自分の成績はどうか」には72.9%が「良い」と答え、自己評価が明らかに甘い方向へ偏っている。注意したいのは有効回答数で、PSSは1308名中1106名、M-BDIは987名しかない。M-BDIの欠測は約25%に達するが、本文で触れられているのはPSSの欠測約16%だけである。

### Table 4：メンタルヘルス問題に関連する要因（二項ロジスティック回帰）

性別・学年・住居・経済的支援などとPSS・M-BDI・WHO-5の各判定との関連を、オッズ比（OR：起こりやすさの倍率）で示した表である。女性と比べた男性のORは、ストレス0.74、抑うつ0.75、低ウェルビーイング0.70でいずれも低い。経済的支援が「十分」な学生も、それぞれ0.70、0.53、0.53と低かった。2年生のストレスは4年生の1.92倍、3年生は1.74倍である。大学寮生（0.50）と私設寮生（0.57）は低ウェルビーイングになりにくかった。ただ表の脚注は「単純な二項ロジスティック回帰」としており、調整済みなのか不明である。年齢21歳の低ウェルビーイングは「1.60（0.77–1.74）」と点推定値が信頼区間に収まっておらず、明らかな誤記がある。

### Table 5：社会人口学的特性と学業成績4群の関連（χ²検定）

学業成績を「低成績・不満」「低成績・満足」「高成績・不満」「高成績・満足」の4群に分け、性別・出身地の割合を比べた表である。「高成績・満足」群では女性が58.0%を占め、「低成績」の2群では男性が約57%と多かった（p<0.001）。出身地では、農村出身が「低成績・不満」群で41.9%、「高成績」の2群で31〜33%と、農村出身者ほど成績が低い側に集まっていた（p=0.026）。ただし「低成績」と「高成績」を分けるGPAの境界値は本文に示されておらず、4群の定義を読者が再現できない。

### Table 6：メンタルヘルス問題と学業成績4群の関連（多項ロジスティック回帰）

「高成績・満足」群を基準にして、各群に属するオッズを調整オッズ比（AOR）で示した表である。調整に使った変数は性別・出身地・大学・学部・学位課程・住居。ストレスありでは「低成績・不満」1.66、「高成績・不満」1.72、抑うつありでは1.56と1.98で、どちらも有意だった。低ウェルビーイングで有意だったのは「高成績・不満」（1.67）だけである。「低成績・満足」群はどの指標とも有意な関連がなく、本研究の主張である「成績より不満が鍵」を支える表になっている。ところが要旨にある「低成績・不満群でAOR=2.30」という数値は、この表のどこにもない。

## 8項目評価

本論文は一次データを用いた原著研究（横断的観察研究）なので、8項目は一次研究の基準で評価する。

### ①研究デザイン

公立3大学から多段階クラスター無作為抽出（大学→学部→クラスの順に無作為に選び、選ばれたクラスは全員を調査）で学生を集めた横断研究で、有病率を推定するデザインとしては妥当である。理論的な枠組みにはラザルスとフォルクマンのストレス・コーピングモデルを掲げ、変数を「要求」「資源」「評価」「結果」に対応づけている。しかし横断研究なので、ストレスが不満を生むのか、不満がストレスを生むのかという因果の向きは決められない（著者自身も認めている）。さらに、モデルの中心であるコーピング方略は実際には測定されておらず、理論と方法がつながっていない。

### ②サンプルサイズと選択基準

1308名の回答を得て回収率91.4%と報告され、規模は有病率推定に十分である。選択基準は15〜29歳で在籍1年以上、博士課程は除外とされた。ただし数字の整合性に問題が多い。目標サンプルが1308名で、回答完了も1308名、そのうえで回収率91.4%という記述は互いに両立しない。在籍1年以上を条件としたのに、学年は2年生が78.4%に集中しており、抽出が層を正しく代表しているか疑わしい。M-BDIの有効回答は987名にすぎず、実際の分析母数は名目上のN=1308よりかなり小さい。

### ③方法論の適切性

WHO-5・PSS・M-BDIはいずれも国際的に広く使われる尺度で、本研究の標本でもクロンバックα（項目間の一貫性の指標）が0.74〜0.81と許容範囲にあった。しかし説明にずれがある。PSS-14は通常0〜4の5段階で合計0〜56点だが、本文は「0〜5の5段階」と書いている。カットオフ（PSS>28、M-BDI>35）の根拠や、ウルドゥー語版の妥当性検証も十分でない。英語版とウルドゥー語版のどちらで回答したのかも書かれていない。「学業満足度」は満足か不満かの1問だけで測られ、主要な曝露変数としては粗い。

### ④統計分析の妥当性

χ²検定、二項ロジスティック回帰、多項ロジスティック回帰をSPSS 22で行った。PSSの欠測約16%はMICE（連鎖方程式による多重代入法、欠けた値を他の変数から何通りも推定して補う方法）で20セット補完したとされる。ところがTable 3のPSSはn=1106で、補完後の1277名とは食い違う。M-BDIの欠測約25%の扱いは書かれていない。Table 4は脚注で「単純回帰」とされ、調整済みかどうかがわからない。点推定値が信頼区間の外にある誤記もあり、所得区分（≦20,001と20,000〜40,000）は境界が重なっている。24以上のORを並べながら多重比較の補正をしていない点も、偽陽性の可能性を残す。

### ⑤結果の信頼性と再現性

本文と表の数値が一致しない箇所が目立つ。要旨では経済的支援十分のAOR=0.55、寮生0.47、「低成績・不満」群2.30とされるが、Table 4・6の値は0.70/0.53/0.53、0.50/0.57、1.66で、どれも一致しない。加えて、欠測データの段落が方法の節でほぼそのまま2回繰り返されている。考察の引用でも、エチオピアの研究に結核の論文（文献38）が、学業満足度の研究に近交弱勢の論文（文献57）が当てられるなど、文献の対応が崩れている。データは「合理的な要求があれば提供」とされるだけで、公開されていない。総合すると、査読と校正が不十分だった可能性が高く、数値をそのまま引用するのは危うい。

### ⑥結論の妥当性

「ストレスや抑うつは低成績より成績への不満と結びつく」という結論は、Table 6の範囲では支持される。ただし、気分が落ち込んでいると自分の成績を悲観的に評価しやすくなる（抑うつに伴う否定的認知）ので、両者が同じ回答バイアスを共有している可能性が残る。著者もこの点に言及している。一方で考察には、「問題焦点型コーピングを用いた学生は精神的健康を保てた」とまで書かれている。コーピングを測っていない以上、これはデータの裏づけを欠いた記述である。結果の節で、測定していない「不安」が高かったと述べている箇所もある。

### ⑦新規性

南アジアの公立大学で、成績という客観指標と満足度という主観的評価を組み合わせて4群に分けた点は、著者のいう通り比較的新しい視点である。経済的困窮や住居形態といった社会経済的要因を同時に調べたことも、低・中所得国の研究としては意義がある。しかし、大学生の高いストレス・抑うつ、女性に多いこと、経済的困窮との関連は既存研究でよく知られた所見の再確認にとどまる。2015年のデータを11年後に出版して「COVID前の基準値」と位置づけるのは、データの古さを言い換えた面もある。

### ⑧臨床的意義

精神科臨床の目で見ると、成績が良くても「満足していない」学生、つまり完璧主義的な傾向や自己評価の低い学生にストレスや抑うつが多いという所見は、学生相談のスクリーニングで成績だけに頼らない根拠になる。経済的支援が不十分な学生や自宅から通う学生を優先的に支援するという示唆も、実務に移しやすい。ただしM-BDIやPSSのカットオフで判定した「抑うつ」は臨床診断ではなく、44%という有病率は過大評価の可能性がある。数値の誤りが多いため、政策や臨床の判断に直接使える水準のエビデンスとは言いにくい。
