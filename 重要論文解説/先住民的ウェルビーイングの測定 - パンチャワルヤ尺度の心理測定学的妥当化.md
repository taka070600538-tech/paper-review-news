# 先住民的ウェルビーイングの測定 - パンチャワルヤ尺度の心理測定学的妥当化 精読ノート

> [!info] この論文について
> インドネシア西ジャワのスンダ人に伝わる価値観「パンチャワルヤ(Pancawaluya)」を、心理的ウェルビーイング(よく生きている状態)を測る15項目の質問紙にし、その因子構造(質問がどうまとまるか)を確かめた初期の妥当化研究。著者自身が「本格的な妥当化ではなく最初の一歩」と位置づけている。

## 1. 概要(500字以内)

心理的ウェルビーイングの代表的な理論(リフの6次元モデルなど)は西洋で作られ、自律や自己受容といった個人主義的な要素が中心である。共同体や道徳・宗教を重んじるインドネシアでは、それだけでは捉えきれない部分があるとの問題意識から、著者らはスンダ文化の五つの徳目、Cageur(心身の健康)、Bageur(親切・思いやり)、Bener(誠実・責任)、Pinter(知恵・理解力)、Singer(創造性・適応力)を各3項目、計15項目の5件法質問紙にした。オンラインで550部を配り305人の有効回答を得て、確証的因子分析(CFA:あらかじめ決めた因子のまとまりがデータに合うかを確かめる統計手法)を行った。適合度はRMSEA 0.031、CFI 0.985、GFI 0.958と良好で、合成信頼性(CR)は0.92と高かった一方、平均分散抽出(AVE)は0.42と基準の0.50に届かなかった。Bageur と Bener の負荷量・平均点が最も高く、Singer はやや低かった。著者らは、これらの価値がイスラムの倫理(イフサーン=善行、アマーナ=信頼など)と理論的に響き合うと論じ、カウンセリングや地域づくりへの応用案を示している。

## 2. Figure と Table の解説

本文で言及される Figure は2点、Table は8点である。Figure は画像のため本文テキストからは図題しか取れず、図の中身は本文の記述と Table 5 の数値から再構成して説明する。

### Table 1 研究の手順・道具・分析手法

研究の全体像を一枚にまとめた表。参加者は「スンダ人305人」とされ、15〜35歳と36〜60歳の2群に分けて記述されている。選び方は有意抽出(purposive sampling:研究者が目的に合う人を意図的に選ぶ方法で、無作為ではない)。データ収集は2段階で、第1段階がGoogleフォームによるオンライン調査(305人)、第2段階がそのうち80人への構造化面接とフォーカスグループ討論(FGD:少人数で話し合ってもらう聞き取り)である。分析はSPSS(記述統計)とLISREL 12(CFA)。ただし「スンダ人305人」と書きながら、同じ表で「さまざまな民族」とも書いており、後の Table 4 ではスンダ人は31%にすぎない。対象者の定義が表の中ですでに揺れている点に注意が要る。

### Table 2 次元・指標・採点(全15項目)

尺度の中身そのもの。各次元3項目で、例えば Cageur は「地域の伝統に沿った健康的な生活」「運動」「郷土食が健康を支える」、Bageur は「他者に親切」「人を助けると嬉しい」「思いやりを大切にしている」、Bener は「人生と宗教の務めに責任を持つ」「困難でも事実を曲げない」「過ちを隠さない」、Pinter は「学び続ける」「知識は大切」「他人の気持ちを理解しようとする」、Singer は「環境や文化から着想を得る」「芸術活動で創造性が伸びる」「変化にうまく適応できる」。採点は1(全くそう思わない)〜5(とてもそう思う)。項目は古典文献と先行研究から理論的に作り、文化研究者2人とカウンセリング専門家1人が確認した。Pinter に共感の項目(P3)が入っているのは、スンダ文化の「知恵(kawijaksanaan)」に他者理解が含まれるためと考察で説明されている。

### Table 3 統計手法と判定基準

使った指標の目的と合格ラインの一覧。t値(負荷量が偶然でないかを見る。1.96超で5%水準、2.58超で1%水準)、AVE(因子が項目のばらつきを平均で何割説明するか。0.5以上)、CR(項目全体としての一貫性。0.7以上)、RMSEA(モデルとデータのずれ。0.06以下)、CFI(何も関係を仮定しない基準モデルと比べてどれだけ良いか。0.95以上)、GFI(0.90以上)、NNFI(0.95以上)、IFI(0.90以上)。数式も載っているが、抽出テキストでは崩れている。注意点として、この表の基準(RMSEA ≦0.06、CFI ≧0.95、NNFI ≧0.95)は、結果の Table 6 で使われた基準(RMSEA <0.08、CFI・NNFI >0.90)より厳しく、論文内で合格ラインが統一されていない。

### Table 4 参加者の属性

女性65%、男性35%。年齢は15〜20歳が57%と過半数を占め、20〜30歳10%、31〜40歳11%、41〜50歳17%、51〜60歳1%、60歳超3%。学歴は高校53%、学士31%、中学11%。居住地は農村40%、準都市29%、都市30%。民族はジャワ人35%、スンダ人31%、その他14%、ミナンカバウ8%、マレー8%、ブギス4%、バタック1%。本文はこの若年偏りを「若い世代の関心が高い」と解釈しているが、単に配布経路(学校など)の偏りかもしれない。また方法の「15〜35歳/36〜60歳」の区分と表の区切りが合わず、60歳超が3%含まれる点、20歳が2つの区分に重なる点(15〜20と20〜30)も整っていない。スンダ文化の尺度なのに回答者の3分の2以上がスンダ人以外である点は、この研究最大の弱点の一つである。

### Table 5 各項目の測定特性(t値・R²・負荷量)

CFA の中心となる結果。負荷量(loading factor:その項目が因子をどれだけ強く反映しているか。1に近いほど強い)は0.53〜0.84で、全項目のt値が6.8〜16.6と1%水準で有意だった。最も高いのは B3(思いやりを大切に、0.84、R² 0.703)、BE1(責任、0.81)、B2(0.77)。低いのは C3(郷土食、0.53)、BE2(事実を曲げない、0.53)、S2(芸術活動、0.53)。R²(決定係数:その項目のばらつきのうち因子で説明できる割合)は0.28〜0.70。ただし標準化負荷量なら R² は負荷量の2乗になるはずだが、C2(負荷量0.68に対し R² 0.321)、C3(0.53に対し0.466)、BE2(0.53に対し0.518)など、数値が合わない項目が複数ある。転記の誤りか、別の値を載せている可能性があり、表の信頼性に疑問が残る。

### Figure 1 CFA のt値の結果(パス図)

LISREL が出力する、t値を書き込んだパス図(因子から各項目へ矢印を引いた図)と思われる。本文は図の直前で、RMSEA などの適合度が良好であり「モデルとして示すと Figure 1 のようになる」と述べるだけで、図そのものの説明はない。中身は Table 5 のt値(全項目が1.96、2.58を超えて有意)と対応すると考えられる。図の画像は本ノートでは確認できていないので、因子間の相関の大きさや、追加した誤差相関がどう描かれているかは不明である。

### Figure 2 スンダ文化における心理的ウェルビーイングの修正後モデル

図題は「スンダ文化における先住民的な心理的ウェルビーイング概念を測る、修正済み(fixed-fit)モデル」。本文の後段(Table 7 の説明)で、LISREL の分析で「BE2(事実を曲げずに伝える)と Singer の間の関係を追加した」と書かれており、この図はその追加パスを含む最終モデルだと読める。つまり最終モデルは純粋な5因子構造ではなく、Bener の項目が Singer 因子にもつながる(交差負荷か誤差相関)形に修正されている。修正の根拠(修正指標)や、修正前の適合度は報告されていない。

### Table 6 適合度の結果

最終モデルの適合度。RMSEA 0.0312(基準 <0.08、良好)、GFI 0.958(>0.90)、CFI 0.985(>0.90、非常に良好)、NNFI 0.980、IFI 0.986。どれも基準を大きく上回る。ただし、CFA で必須とされるカイ二乗値と自由度、SRMR(残差の平均的な大きさ)が報告されていない。さらに、この値は BE2–Singer の追加パスを入れた後のもので、事後修正で良くした適合度である。表の「Value」列(0.05、0.90、0.95…)は基準値らしいが「Criteria limits」列と食い違っており、表の作りも分かりにくい。

### Table 7 各項目の記述統計(平均・標準偏差)

15項目の平均と標準偏差(SD:ばらつき)。Cageur は3.50〜3.91と低めで、郷土食(C3、3.50)が最低、運動(C2、3.91)が最高。Bageur(4.41〜4.56)、Bener(4.38〜4.43)、Pinter(4.20〜4.45)は高く、最高は B2「人を助けると嬉しい」4.56。Singer は4.00〜4.02とやや低い。5点満点で4.4〜4.6、SD 0.6前後という分布は天井効果(多くの人が上限近くに答え、差がつきにくい状態)を示唆し、社会的望ましさ(よく見られたい答え方)の影響も疑われる。なお本文は「最も高い平均は Pinter の P2(4.45)」と書くが、表では B2(4.56)の方が高く、本文と表が食い違う。

### Table 8 パンチャワルヤ次元から導いた概念的な提言

統計からではなく理論から導いた応用案の一覧(著者自身がそう明記)。(1) Bageur と Bener の強化:道徳教育キャンペーン、慣習・宗教・行政の指導者を手本に。(2) Singer の強化:責任感を伴う創造性・技術の研修、価値観に根ざしたオンライン共同体。(3) 世代間の協働と、地域の知を残すデジタル基盤。(4) 心身の健康や経済の互助グループによる集団的ウェルビーイング。(5) 地域調査と住民の意見を反映する評価の仕組み。いずれもデータで効果を確かめたものではなく、提案の段階にとどまる。

## 3. 8項目の評価

### ① 研究デザイン

横断的なオンライン調査で、事前に決めた5因子構造を CFA で確かめ、面接・FGD の質的データで意味づけを補う「量的中心の混合研究」である。著者が「初期の構成概念妥当化」と範囲を限定し、質的データは項目作りにも統計的検証にも使っていないと明記している点は誠実である。問題は、尺度開発の標準的な手順が飛ばされていること。探索的因子分析(EFA)や予備調査がなく、収束的・弁別的妥当性(既存のウェルビーイング尺度や抑うつ尺度との相関)、再検査信頼性もない。同じ標本で事後修正したモデルを確証と呼んでおり、別標本での交差検証もない。

### ② サンプルサイズと選択基準

305人は15項目・5因子の CFA としては一般的な目安(項目あたり10〜20人)を満たす。しかし選択基準に大きな問題がある。表題も Table 1 も「スンダ人」を対象とするのに、実際のスンダ人は31%で、ジャワ人(35%)の方が多い。スンダ文化固有の価値観の尺度を、主に非スンダ人のデータで妥当化したことになる。15〜20歳が57%と若年に偏り、未成年が含まれるのに、倫理審査や保護者同意の記載は本文に見当たらない。有意抽出・オンライン配布で、回答率は55.5%。対象の母集団がはっきりしない。

### ③ 方法論の適切性

項目は古典文献に基づき、専門家3人が確認しており、内容的妥当性の入口は押さえている。一方で、専門家の確認は人数が少なく、CVI(内容妥当性指数)などの数値化もない。各因子3項目は CFA の最低ラインで、著者も AVE が低い一因と認めている。項目の中身にも疑問がある。C2(運動)や C3(郷土食)は健康行動の自己報告で、ウェルビーイングというより生活習慣である。P3(共感)を「知恵」に入れる判断は文化的に説明されているが、Bageur(思いやり)と重なりやすい。Islamic counseling との結びつきは理論上の議論にとどまり、データでは検証されていない(著者も明言)。

### ④ 統計分析の妥当性

報告の不備が多い。カイ二乗と自由度、因子間相関がなく、弁別的妥当性(5因子が互いに区別できるか)を確かめていない。CR 0.9247 と AVE 0.4214 は15項目をまとめた1つの値として示されているが、5因子モデルでは因子ごとに出すのが原則である。Table 5 の負荷量から因子ごとに計算し直すと(標準化負荷量と仮定、本ノート作成者の試算)、AVE は Cageur 0.36、Bageur 0.59、Bener 0.50、Pinter 0.45、Singer 0.44、CR は Cageur 0.62、Bageur 0.81、Bener 0.74、Pinter 0.71、Singer 0.69 となり、Cageur は CR でも基準0.70を下回る。15項目の負荷量2乗の平均は0.47で、報告の0.4214とも一致しない。R² と負荷量2乗の不一致、事後に足した BE2–Singer のパスも、手順として説明不足である。

### ⑤ 結果の信頼性と再現性

適合度が非常に良いのは、モデル修正を経た後の値で、同じデータに合わせた分だけ楽観的になっている。Table 5 の R² と負荷量の矛盾、本文と Table 7 の最高平均値の食い違い、Table 3 と Table 6 の判定基準の不統一など、数値の整合性の問題が複数あり、報告どおりの結果が再現されるかには慎重であるべきだ。平均4.4〜4.6の天井効果は、尺度が人の間の差を十分に捉えていない可能性を示す。データや LISREL の出力、全項目の原文(インドネシア語・スンダ語版)は公開されておらず、第三者が検証できない。

### ⑥ 結論の妥当性

「パンチャワルヤを一貫した構成概念として操作化できる初期証拠」という控えめな結論は、適合度の結果からは一応支持される。ただし、Bageur と Bener が「最も強い影響を持つ」という言い方は、負荷量の高さ(項目が因子をよく反映すること)を価値の重要さや影響力と取り違えている。BE2–Singer の追加パスから「誠実さが創造的な適応を支える」と解釈するのも、事後修正の統計的なつながりから因果的な意味を読み込みすぎている。カウンセリングや地域政策への提言(Table 8)は、著者が断っているとおりデータの外の話で、結論として扱うには根拠が弱い。

### ⑦ 新規性

スンダの伝統的な徳目を、定量的な尺度として初めて体系的に検討した点に新しさがある。西洋の心理的ウェルビーイングモデルを置き換えるのではなく「補う」枠組みと位置づける姿勢も、文化心理学の流れ(先住民の知を尺度化する Wicozani 尺度やインドネシア・ウェルビーイング尺度など)に沿っている。一方で、尺度としての完成度は低く、既存の尺度(リフの尺度など)と比べて何を新たに説明できるのか(増分妥当性)は示されていない。イスラム倫理との対応づけも、先行研究の概念的な議論の繰り返しにとどまる。

### ⑧ 臨床的意義

インドネシアのムスリムが多い地域で、本人の文化の言葉でウェルビーイングを語れる道具ができれば、カウンセリングで価値観に沿った目標を立てやすくなる。CBT で言えば、価値の明確化やアクセプタンス&コミットメント・セラピー(ACT)の「価値」の作業に、文化に合った手がかりを与えうる。しかし現段階では、精神的な不調や生活の質との関連、変化への感度(介入で点数が動くか)、カットオフ値がまったく調べられておらず、臨床の評価や効果判定には使えない。項目の多くが「よい人であること」の自己評価で、ウェルビーイングと道徳的な自己像を混同する恐れもある。日本の臨床への直接の応用は限られ、文化に根ざした尺度づくりの方法の一例として読むのが妥当である。
