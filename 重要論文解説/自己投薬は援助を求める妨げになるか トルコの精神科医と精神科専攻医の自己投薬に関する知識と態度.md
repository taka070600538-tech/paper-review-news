# 自己投薬は援助を求める妨げになるか トルコの精神科医と精神科専攻医の自己投薬に関する知識と態度 精読ノート

## 概要

医師が自分や家族に薬を出す「自己投薬(self-medication。WHOの定義では、自分で診断した症状に薬を使うこと)」は、誤診や依存などの危険があり、英米の倫理規範も原則として避けるよう求めています。本研究は、トルコの精神科医と精神科専攻医(研修中の医師)246人にオンラインの匿名質問票で尋ね、自己投薬の実態・知識・態度を記述しました。

主な結果は次のとおりです。過去1年に1回以上自己投薬した人は約8割(要旨では83%)。自分に処方した向精神薬は抗うつ薬(35.8%)が最多で、メチルフェニデート(9.8%)、ベンゾジアゼピン(8.9%)が続きました。80.9%が「定義を知っている」と答えた一方、家族への処方を自己投薬と見なした人は3割未満で、自己投薬に関する法規制の有無を「知らない」人が48.8%いました。理由は「軽い問題で自分で治せる」(49.6%)、「以前やってうまくいった」(30.9%)、「時間がない」(19.1%)が上位でした。著者らは、倫理教育の不足と援助を求めにくい環境が背景にあるとし、教育、乱用の恐れのある薬の自己処方の規制、医師の支援体制の整備を提言しています。

## FigureとTableの解説

本論文に Figure はなく、本文中の Table は3つです(Table 1〜3)。このほか補足資料(Supplement 1:質問票の詳細、Supplement 2:参加者の社会人口学的データ、Supplement 3:自己投薬あり群となし群の比較の詳細)が本文で言及されますが、PDF には含まれていないため、本文に書かれた範囲で触れます。

### Table 1 自己投薬に関する知識と態度

1. **教育経験**:専攻医研修中に自己投薬の講義・研修を受けた人は7.3%、医学部で受けた人は4.5%にとどまります。
2. **定義の理解**:80.9%が「定義を知っている」と回答。しかし「自己投薬に当たる行動」を選ばせると、自分の精神症状への自己処方(89.8%)や自己判断の用量変更(79.7%)はよく選ばれる一方、家族の精神科治療を組み立てること(29.7%)、家族の精神科以外の治療(24.0%)は少数でした。逆に、薬ではないマインドフルネス(18.7%)やハーブ系サプリ(39.8%)を自己投薬と見なす人もいました。
3. **法規制の認識**:トルコに規制が「ある」3.3%、「ない」42.3%、「知らない」48.8%。
4. **頻度と薬の種類**:過去1年の自己投薬は「なし」16.7%、1〜3回39.8%、4〜6回19.1%、7回以上18.7%。使った薬は「向精神薬のみ」6.1%、「抗菌薬・鎮痛薬など」22.4%、「両方」49.6%。
5. **家族への処方と同僚への依頼**:家族への自己投薬も1〜3回が42.7%と多く、自分で選んだ向精神薬の処方を同僚に頼んだ経験は41.9%でした。向精神薬の自己投薬で副作用・不快な経験をした人は13.0%です。

### Table 2 自己投薬への態度、倫理的な考え、行う理由

1. **精神科以外の症状で自分や家族に処方すること**:「している、適切だと思う」41.5%、「適切ではないと思うが、している」30.1%、「決してしない」6.5%(「その他」12人)。「不適切と知りながら行う」層が3割いる点が、知識と行動のずれを示します。
2. **倫理面の考え(複数回答、緊急時を除く)**:専門分野内で自分や家族を診ると客観性の問題が起こり得る 60.2%、専門外なら倫理的問題になり得る 52.0%、専門分野内でも倫理的に問題になり得る 48.0%。一方、専門分野内なら適切 28.9%、専門外でも適切 17.9%。
3. **自分で治療した理由(複数回答)**:軽い問題で自分で治せる 49.6%、過去に効いた 30.9%、時間がない(業務量)19.1%、受診したい精神科医がいない(若すぎる・経験不足など)15.9%、診断が職業生活に悪影響を与える不安 13.4%、自分や他人の見る目が変わる不安 10.6%、医療記録に精神科診断が残る不安 8.1%、経済的理由 4.9%、近くに他の精神科医がいない 2.4%。スティグマ(偏見)関連の理由は1割前後にとどまりました。

### Table 3 自己投薬で使われた向精神薬と処方の相手

8つの薬のグループごとに「自分に処方」「同僚に処方を依頼」「親や子に処方」の割合を示した表です。

1. **抗うつ薬**:自分 35.8%、同僚に依頼 31.3%、親や子 45.1%で、3つの経路すべてで最多。
2. **メチルフェニデート(ADHD治療薬の中枢刺激薬)**:自分 9.8%、同僚に依頼 19.5%と、自分で出すより同僚に頼む割合が倍近い点が目立ちます。
3. **ベンゾジアゼピン(即効性の抗不安・睡眠薬。依存の恐れがある)**:自分 8.9%、同僚 12.6%、親や子 14.2%。
4. **ベンゾジアゼピン以外の睡眠薬**:自分 4.1%、同僚 7.3%、親や子 11.4%。**モダフィニル(眠気を抑える覚醒維持薬)**:自分 4.9%、同僚 8.1%。
5. **少ないもの**:抗精神病薬(自分 1.6%、親や子 6.5%)、気分安定薬(自分 1.2%)、アトモキセチン(非刺激性のADHD治療薬、自分 0.4%)。

刺激薬や覚醒維持薬は治療以外に「能力を上げる目的(ニューロエンハンスメント)」でも使われ得るため、著者らは乱用の危険を指摘しています。ただし、どの診断・目的で使ったかは調べていません。

## 8項目評価

### ①研究デザイン

記述的横断研究(ある一時点で質問票に答えてもらい、割合を記述する研究)で、精神科医の自己投薬を、精神科以外の薬や家族への処方まで含めて調べた点は目的に合っています。問題は、因果関係を示せないことと、比較の軸が弱いことです。対照(他の診療科の医師や一般人口)がなく、「精神科医に特有か」は判断できません。また題名は「援助を求める妨げか」と問いますが、援助希求そのものを測る尺度は使っておらず、題名の問いに直接答える設計にはなっていません。

### ②サンプルサイズと選択基準

264人が同意し、途中離脱18人を除いた246人を解析しました。Yamane式(母集団の大きさから必要数を出す簡易式)で、トルコの精神科医約5,500人に対し誤差7%で最低197人と計算しています。しかし、SNSとメーリングリストでの便宜的標本(集めやすい人を集める方法)なので、この計算は「代表性」を保証しません。回答者は全体の約4.5%で、女性68.7%、専攻医34.6%、精神疾患の診断歴44.3%、向精神薬服用中41.9%と、関心の強い人に偏った可能性が高いです。

### ③方法論の適切性

質問票は文献と臨床経験から作り、10人で予備テストをしていますが、信頼性・妥当性の検証(内的一貫性など)の記載はありません。回答を必須にしなかったため、項目ごとに分母が変わります。さらに、選択肢の文言が分かりにくい箇所があります。たとえば理由の第1位は「軽い問題で自分で治せる(治療抵抗性なし、中等度〜重度)」と括弧内の重症度が本文の「軽度〜中等度」と食い違って見えます。スティグマは尺度で測っておらず、著者ら自身も限界として認めています。

### ④統計分析の妥当性

解析は割合の記述と、自己投薬あり群となし群のカイ二乗検定(割合の差を調べる検定)のみです。差が出たのは「職位」だけで、教授は自己投薬しない割合が高かった(p<0.001、カイ二乗値22.522)とされますが、教授は10人しかおらず、セルの度数が小さいとカイ二乗検定は不安定です。多重比較の補正もなく、詳細は補足資料3に回されて本文で確認できません。交絡(年齢や経験年数が職位と重なる)を調整した多変量解析もありません。

### ⑤結果の信頼性と再現性

数値の一貫性に問題があります。過去1年の自己投薬は、要旨と考察では83%、本文では「191人(78.2%)」で、Table 1 の頻度を足すと191人/246人=77.6%です。83%は無回答を除いた分母(191/232≈82%)で計算した可能性がありますが、説明はありません。著者らが言う「約70%が抗菌薬・鎮痛薬を使った」は22.4%+49.6%=72.0%で整合します。匿名とはいえ自己申告で、過少申告(叱責を恐れる応答バイアス)も過大な偏りもあり得ます。データは請求すれば提供とされています。

### ⑥結論の妥当性

「トルコの精神科医で自己投薬は多い」「知識・倫理教育が不足している」という結論は、記述データとしては支持されます。ただし「教育不足が自己投薬を招いた」という因果は、教育経験と自己投薬の関連を示す解析がないため推測の域です。スティグマの影響も、回答率が低かったことを「自分で解決しようとする傾向と絡み合っている」と解釈していますが、これは反証しにくい解釈です。規制や支援プログラムの提言は妥当ですが、効果は未検証です。

### ⑦新規性

精神科医の自己投薬を、精神科の薬だけでなく抗菌薬・鎮痛薬、家族への処方、同僚への処方依頼まで広げて記述した研究は少なく、トルコでは初めてに近いとされます。特に「同僚に頼んで刺激薬を出してもらう」という経路を数字で示した点は新しい知見です。一方で、2007年の Balon の米国調査(軽〜中等度うつ病の自己治療を適切とする人約43%)と同じ方向の結果であり、概念的な新しさは限られます。

### ⑧臨床的意義

精神科医自身の不調が、受診せず自分で薬を出す形で隠れやすいことを示し、医師の well-being(心身の良好な状態)を守る仕組みの必要性を具体的にしています。刺激薬やベンゾジアゼピンを同僚経由で入手する実態は、依存や判断力低下を通じて患者の安全にも関わります。ただし、トルコ特有の事情(専攻医修了後の義務的な地方勤務、1日40〜80人の診療など)が背景にあり、日本などへの一般化は慎重であるべきです。教育や規制の効果は今後の介入研究で確かめる必要があります。
