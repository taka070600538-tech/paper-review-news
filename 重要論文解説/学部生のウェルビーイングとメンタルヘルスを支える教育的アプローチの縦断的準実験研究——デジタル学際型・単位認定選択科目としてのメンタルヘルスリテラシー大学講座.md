# 学部生のウェルビーイングとメンタルヘルスを支える教育的アプローチの縦断的準実験研究——デジタル学際型・単位認定選択科目としてのメンタルヘルスリテラシー大学講座 精読ノート

> 役割：日本トップクラスのサイエンスコミュニケーターとしての精読プロンプト（デフォルトフォーマット）に基づく分析結果

## 1. 概要（500字以内）

大学入学の時期は、精神疾患を発症するリスクが最も高まる時期と重なっています。一方で、学生相談などの支援は需要に追いついていません。カナダのクイーンズ大学は、メンタルヘルスリテラシー（心の健康についての正しい知識と、対処・援助を求める力）を教える12週間のオンライン講座を開講しました。単位が出る学部横断の選択科目で、認知行動療法の考え方を取り入れています。本研究は2021〜2024年に受講した学生2,884人の受講前後の調査と、同じ期間に学内のウェルビーイング調査（U-Flourish）へ回答した非受講者を比較したものです。講座の評価は高く（7点満点で約6点）、受講後はセルフコンパッション（自分への思いやり）とレジリエンスが上がり、反すうは減りました。線形混合効果モデルで背景要因を調整したところ、受講者は非受講者に比べて12週間で次のような差がありました。不安が軽くなり（GAD-7で−0.41点）、大麻の使用が減り、睡眠の質は上がりました。非受講者では抑うつが悪化しウェルビーイングが下がりましたが、受講者ではその悪化が抑えられていました。効果は女性で特に大きく、民族や留学生かどうかによる差はみられませんでした。ただしランダム化はされておらず、効果の大きさも小さい点に注意が必要です。

## 2. Figure・Tableの解説

本文中で言及されるのは、本誌掲載のFigure 1（パネルa〜e）とTable 1〜4です。そのほか補足資料としてSupplementary Fig. 1〜2とSupplementary Table 1〜6（5a・5bを含む）が参照されていますが、補足資料は今回のPDFに含まれていません。そのため補足資料については、本文に書かれた内容だけをもとに末尾でまとめて紹介します。

### Table 1：受講し調査に回答した学生の背景（N=2,884、p.4）

ステップ1：年齢は19〜21歳が52.3%で最も多く、18歳以下が23.7%、22歳以上が24.0%です。ステップ2：性別は女性が76.4%と大きく偏っており、男性は22.1%、ノンバイナリー（男女の二分法に当てはまらない性自認）は1.0%でした。ステップ3：民族は白人57.0%、アジア系24.2%、黒人3.3%です。留学生はわずか3.7%でした。ステップ4：注目すべきは心の健康状態です。生涯に精神疾患と診断されたことがある学生が42.3%いました。受講開始時点で、不安のスクリーニング陽性（GAD-7が10点以上）が38.8%、抑うつ陽性（PHQ-9が10点以上）が35.3%、ウェルビーイング低値が19.1%、不眠の疑いが35.2%でした。受講者は「もともと悩みを抱えた学生が多い集団」だったといえます。

### Table 2：受講者本人の受講前後の変化（対応のあるt検定、p.5）

ステップ1：受講前後の両方に回答した学生（約2,000〜2,400人）について、受講前後の差を調べています。ステップ2：メンタルヘルス知識（9〜45点）は39.5点から40.4点へ上がりました（+0.92、p<0.001）。心の問題の知識、セルフヘルプ（自分でできる対処法）の知識、「どこで情報を探し、どうやって支援にたどり着けばよいかわかる」という自信も、いずれも小さいながら向上しました。ステップ3：一方、スティグマ（偏見）が受診の妨げになる度合い（BACE-3）と、感情への気づき（ESAS）は変わりませんでした。ステップ4：心理的な要因をみると、セルフコンパッションは+0.65、レジリエンスは+0.06と上がり、反すう（ブルーディング：くよくよ考え込む思考のくせ）は−0.31と減りました。ただしストレス（PSS-4）は7.29点から7.61点へ**上がっています**（+0.32、p<0.001）。学期末の試験期にストレスが高まる時期効果が反映された可能性があります。なお反すうの信頼区間は表では「−0.44 to 0.18」と印字されていますが、要旨の「−0.44 to −0.18」が正しく、表の誤植と考えられます。

### Table 3：受講者と非受講者の比較（調整済み線形混合効果モデル、p.5）

ステップ1：線形混合効果モデルを使っています。同じ人を繰り返し測ったデータを、個人ごとの出発点の違いを考慮しながら分析する手法です。年齢・性別・民族・精神疾患の既往・自殺念慮の既往などで調整したうえで、12週あたりの変化の傾き（スロープ）が両群でどれだけ違うかを「講座の効果」として推定しています。ステップ2：知識は受講者だけが伸びました（メンタルヘルス知識 +0.95）。ステップ3：心理的要因では、セルフコンパッション（+0.41）、反すう（−0.35）、ストレス（−0.12）に有意な効果がありました。一方、レジリエンス（+0.01、p=0.19）と感情への気づき（−0.11）は、非受講者と比べると差がありませんでした。ステップ4：心の健康の指標をみると、不安は受講者で−0.14減ったのに対し、非受講者では+0.26増えました（差は−0.41）。抑うつは非受講者で+0.40悪化しましたが受講者では+0.04にとどまりました（差は−0.37）。睡眠の質は+0.79、ウェルビーイングは+0.24の効果です。ステップ5：注意点もあります。受講開始時点で両群はすでに違っていました。受講者は知識・感情への気づき・ウェルビーイングが高い一方、睡眠の質は低く、反すうも多かったのです。つまり受講を選んだ学生は、もともと性質の異なる集団でした。

### Figure 1（a〜c）：不安・抑うつ・ウェルビーイングの時間推移（p.6）

ステップ1：横軸は時間で、受講開始時（0週）、受講終了時（12週）、学年末（26週）の3時点です。縦軸は各尺度の得点で、調整モデルから推定した平均値を実線で、生データを半透明の点で示しています（受講者n=2,880、非受講者n=4,840）。ステップ2：(a)不安（GAD-7）は、受講者で下がり非受講者で上がるため、2本の線が開いていきます。ステップ3：(b)抑うつ（PHQ-9）は、受講者ではほぼ横ばいですが、非受講者では上昇します。講座の「効果」は、主に非受講者側の悪化を防いだという形で現れています。ステップ4：(c)ウェルビーイング（WEMWBS-7）も同じく、受講者は横ばいで非受講者が低下しています。ステップ5：生データの点は大きく散らばっており、線で示された差は1点にも満たない小さなものであることが視覚的にわかります。

### Figure 1（d〜e）：飲酒・大麻使用頻度の推移（p.7）

ステップ1：(d)は大量飲酒（一度に5杯以上）の頻度を、「なし」から「ほぼ毎日」までの5段階で、(e)は過去1か月の大麻使用頻度を6段階で示しています。ステップ2：これらは順序のある段階データなので、比例オッズモデルで推定しています。比例オッズモデルは、「より頻度の高い段階へ移る起こりやすさ」をオッズ比（POR）で表す手法です。ステップ3：大量飲酒は、両群とも期間中にほとんど変化がありません。ステップ4：大麻は、受講者で減り、非受講者で増えるという逆向きの推移を示します。ステップ5：縦軸は段階をそのまま数値化した平均で、ほとんどの学生が「なし」や「月1回未満」に集まっているため、線の差はごくわずかに見えます。

### Table 4：大量飲酒と大麻使用に関する比例オッズモデルの推定値（p.8、横向き印刷の表）

ステップ1：大量飲酒について、受講開始時点で「一度もない」学生は、受講者33%、非受講者41%でした。開始時の比例オッズ比（POR）は1.41（95%CI 1.20–1.65）で、受講者の方が大量飲酒をする傾向が強かったことになります。ステップ2：12週間の変化は、受講者でPOR 1.02、非受講者で0.99でした。講座の効果はPOR 1.03（p=0.430）で、効果は確認できません。ステップ3：大麻の使用は、開始時点で「なし」が受講者60%、非受講者64%でした。開始時のPORは1.19（p=0.046）で、受講者の方がやや多く使っていました。ステップ4：12週間で、受講者はPOR 0.90と減り、非受講者は1.09と増えました。講座の効果はPOR 0.82（95%CI 0.75–0.90、p<0.001）と推定されました。ステップ5：「週3〜4日」「ほぼ毎日」の頻用層はどちらの群も3〜4%とごく少数です。このため効果の大半は、低頻度の使用層での小さな変化を反映していると考えられます。

## 3. 8項目評価

本論文は、オリジナルのデータを集めて分析した原著研究（準実験的な縦断研究）です。そのため、一次研究向けの基準で評価します。

### ① 研究デザイン

受講者の前後比較と、同じ大学・同じ学期・同じ尺度で集めた非受講者との比較を組み合わせています。講座を実際の授業としてそのまま評価する実践的（pragmatic）研究で、結果を現場に当てはめやすい点は優れています。しかし最大の弱点は、受講するかどうかを学生本人が選んでいる点です（自己選択）。受講者は開始時点で、女性が多く、精神疾患の既往が多く、ウェルビーイングは高いのに睡眠は悪いなど、多くの点で非受講者と異なっていました。調整に使っていない要因（講座を取ろうとする意欲、学期中の授業の負担など）による交絡（見かけ上の関連を生むゆがみ）を排除できません。著者自身も、ランダム化比較試験や待機群との比較が次の段階だと認めています。

### ② サンプルサイズと選択基準

受講者2,884人、比較に使った非受講者約4,800人という規模は、この分野では非常に大きく、これまでの研究の「サンプルが小さい」という限界を明確に乗り越えています。ただし選ばれ方の偏りは大きく、受講者の76%が女性で、留学生は3.7%です。男性と留学生は、大学全体の学生構成と比べて少なすぎます。ノンバイナリー（29人）や性別を答えなかった学生（14人）では、統計的な検出力（差を見つける力）がほとんどありません。研究への参加に成績2%分の加点がついていたため、参加の動機と回答の仕方に影響した可能性もあります。非受講者の側も、学内調査に自分から回答した学生であり、大学全体を代表しているとはいえません。

### ③ 方法論の適切性

GAD-7、PHQ-9、WEMWBS-7、SCI-8、SCS-SFなど、妥当性が確認された尺度を両群で共通に使っており、測定の土台はしっかりしています。一方、問題点もあります。第一に、すべてが自己記入式で、臨床家による評価も、行動や成績といった客観的な指標もありません。第二に、非受講者のメンタルヘルス知識は2021年秋〜2022年冬の調査でしか測られておらず、反すうも一部の学期では測られていません。そのため指標ごとに比較できる人数が違います。第三に、受講者は授業の中で、講座の内容と重なる質問に答えています。学んだ用語に沿って答えやすくなる、望ましい答えを選びやすくなるといった回答の偏りが入り込む可能性があります。

### ④ 統計分析の妥当性

個人ごとの出発点の違いを考慮した線形混合効果モデル、順序データ向けの比例オッズモデル（頑健標準誤差つき）、共変量の多重代入（20セット）、回答の脱落に対する逆確率重み付けなど、欠測や繰り返し測定への対応は丁寧です。一方、懸念もあります。第一に、多数の結果指標とサブグループ解析を行っているのに、多重比較の補正（検定をたくさん行うと偶然の有意差が出やすくなることへの対策）がされていません。第二に、傾向スコア（受講しやすさの予測値）などを使って、背景の違う2群をそろえる手法は用いられていません。第三に、Table 2（受講前後の生の平均値）とTable 3（調整後の開始時値）とで数値の水準が大きく違います（例：セルフコンパッション18.6と12.55）。この違いについて説明がなく、読者が解釈しにくくなっています。

### ⑤ 結果の信頼性と再現性

大規模なデータで信頼区間が狭く、不安・抑うつ・睡眠・セルフコンパッション・反すうについては、方向のそろった結果が得られています。しかし効果の大きさ自体は小さいものです。不安の−0.41点（0〜21点の尺度）や抑うつの−0.37点は、臨床的に意味のある最小の変化と比べてかなり小さい値です。またストレスは、受講者本人の前後比較では**上昇**しており、比較群が大きく悪化したことで「効果あり」になっているにすぎません。本文では、この違いが明確に書き分けられていません。本文中にも、講座効果0.31を「助けを求める方法の知識」と表記している（表ではセルフヘルプ戦略の知識）、非受講者数が4,847人と4,840人で食い違う、といった細かな不整合があります。データは責任著者への請求で提供されるとされていますが、解析コードは公開されていません。単一の大学での研究であり、他の大学で同じ結果が出るかは今後の検証を待つ必要があります。

### ⑥ 結論の妥当性

著者は、講座が不安と睡眠を改善し、抑うつとウェルビーイングの悪化を防いだと、因果関係に近い書き方でまとめています。しかし非ランダム化のデザインで示せるのは「関連」までです。著者自身も研究の限界の節ではこの点を認めており、要旨や結論の表現はやや強すぎます。第一に、レジリエンスへの効果は比較群との比較では有意ではありませんでした（p=0.19）。それにもかかわらず、結論では「レジリエンスを高める」と書いています。第二に、Discussionでは受講後にストレスが下がったと書いていますが、受講前後の比較ではストレスは上昇していました。この2点は結論と結果が一致していません。男性で効果が乏しかった理由を「天井効果（もともと症状が少なく、改善の余地が小さいこと）」で説明する部分も、仮説の域を出ていません。

### ⑦ 新規性

メンタルヘルスリテラシー教育の研究は、これまで中高生向けや短期間の介入が中心でした。また結果として測られるのは、知識・スティグマ・援助を求める行動にほぼ限られていました。本研究には次の新しさがあります。①単位が出る、学期いっぱいの正規の授業として開講している。②認知行動療法の要素と、学生が開発に参加する「逆メンター方式」を取り入れている。③数千人規模で、症状・睡眠・物質使用まで含めた幅広い指標を、同じ時期の比較群と比べている。また、セルフコンパッションや反すうといった「効果が生まれる経路の候補」を同時に測った点も貴重です。ただし講座の内容とその開発経緯は、同じ研究グループのパイロット研究ですでに報告されています。本研究の新しさは、主に規模の拡大と比較群の追加にあります。

### ⑧ 臨床的意義

受講者の約4割がすでに不安・抑うつのスクリーニング陽性で、42%に精神疾患の既往がありました。つまりこの講座は、実質的に、支援が必要な学生の「入口」になっています。受講を支援の入り口とみなさず、相談窓口の予約を待たずに学べる、偏見を招きにくい場として位置づけられる点は、学生相談の負担を減らすうえで現実的な価値があります。日本の大学でも、教養科目の枠で導入を検討する価値があります。ただし次の点に注意が必要です。第一に、効果は小さく、臨床的な治療の代わりにはなりません。第二に、男性やノンバイナリーの学生への効果は確認されていません。第三に、症状が重い学生を専門の治療へ確実につなぐ仕組みが別に必要です。第四に、長期的な効果（8週・12週後の追跡）はまだ報告されていません。精神科医の立場からみると、この講座は心理教育による一次・二次予防の補助と位置づけるのが妥当です。
