# 自閉スペクトラム症児の母親における心理的苦痛に対する認知行動療法(CBT)の効果——問題解決評価の役割 精読ノート

## 概要（500字以内）

本研究は、エジプト・エルベヘイラ県の自閉スペクトラム症(ASD)児を養育する母親60人を対象に、問題解決技法（問題を分析し対処選択肢を評価し実行計画を立てる訓練）を組み込んだ3か月間の認知行動療法(CBT)プログラムの効果を検証したランダム化比較試験(RCT)である。母親は介入群（週1回・約90分のCBTセッションを12回、8回は問題解決技法を含む実施セッション）と対照群（月1回の面談のみ）に1:1でランダム割付された。主要評価指標はDepression Anxiety Stress Scale(DASS-21：抑うつ・不安・ストレスを測る自己記入式尺度)、副次評価指標はProblem-Solving Inventory(PSI：問題解決に対する自己評価尺度)であった。介入群は対照群と比較し、抑うつ・不安・ストレス・総合的心理的苦痛のすべてで有意な改善を示し（すべてp<0.05）、問題解決の自信・接近-回避スタイル・個人的統制感でも有意な向上がみられた。多変量回帰では、児の年齢と自閉症重症度が母親の心理的苦痛を、家計の十分さが問題解決能力をそれぞれ有意に予測した。著者らはアラブ世界における文化的に適応したCBT介入の有効性を示す予備的エビデンスと位置づけている。

## Figure・Tableの解説

### Figure 1：フローチャート（研究5〜6ページ）
CONSORT形式に準じた参加者の流れを示す図。ASD児の母親206人がスクリーニングされ、67人が適格基準（20〜50歳、主たる養育者、ASD診断は精神科医による等）を満たし、うち7人が手順確認のためのパイロット研究に参加、残る60人がコンピュータ乱数生成によって介入群30人・対照群30人に1:1でランダム割付された経過を図示している。スクリーニングから割付・介入・追跡・解析までの各段階の人数が明示されており、RCTとしての参加者フローの透明性を担保する図である。

### Table 1：参加者の人口統計学的・ベースライン特性（研究8〜9ページ）
介入群(n=30)・対照群(n=30)の年齢、教育歴、職業、家計の十分さ、婚姻状況、児の年齢・性別・自閉症重症度をまとめた表。平均年齢34.80±10.25歳、児は男児が68.4%、自閉症重症度は軽度38.3%・中等度40%・重度21.7%とほぼ均等に分布していた。年齢や職業、家計の十分さ、児の特性には両群間で有意差がなかった一方、教育レベル（p=0.029）と婚姻状況（p=0.010）には有意差があり、介入群の方が高学歴・既婚者が多かった。

### Table 2：DASS-21スコアの介入前後比較（研究10ページ）
介入群・対照群それぞれのDASS-21（抑うつ・不安・ストレスの下位尺度と総合スコア）の介入前後の得点変化を示す表。ベースラインでは両群に有意差はなかったが、介入後は介入群がすべての指標（抑うつ、不安、ストレス、総合スコア）で対照群より有意に大きな改善を示した（総合スコアの平均低下率：介入群24.75% vs 対照群3.86%、p<0.001）。対照群は介入前後でほぼ変化がなかった。

### Table 3：問題解決スキルの介入前後比較（研究11ページ）
問題解決の自信(Problem-Solving Confidence)、接近-回避スタイル(Approach-Avoidance Style：問題に積極的に向き合うか回避するかの傾向)、個人的統制感(Personal Control：問題を自分でコントロールできるという感覚)、およびPSI総合スコアについて、両群の介入前後の変化を示す表。介入群はすべての下位尺度で対照群より有意に大きな改善を示し（PSI総合スコアの改善率：介入群11.65% vs 対照群0.93%、p<0.001）、個人的統制感の改善率の群間差のみ有意水準にわずかに届かなかった(p=0.080)。

### Table 4：心理的苦痛・問題解決スキルの予測因子に関する多変量回帰分析（研究11ページ）
DASS-21総合スコアおよびPSI総合スコアを目的変数とし、母親の年齢・教育歴・家計の十分さ・婚姻状況・児の年齢・自閉症重症度を説明変数とした重回帰分析の結果表。児の年齢（B=6.273, p=0.005）と自閉症重症度（B=2.268, p=0.043）が母親の心理的苦痛を有意に予測し(モデルはR²=0.741で分散の74.1%を説明)、家計の十分さ（B=4.938, p<0.001）のみが問題解決スキルを有意に予測した(R²=0.758)。

## 8項目評価

**①研究デザイン**：ClinicalTrials.govに事前登録(NCT05568303)されたRCTであり、割付は介入に無関係な統計家が作成したコンピュータ乱数配列を用い、ベースライン評価まで参加者・研究者双方に割付を伏せるなど手続き上の厳密さがある。一方、対照群は月1回の一般的な面談のみで能動的なプラセボ介入がなく、単盲検（参加者は自分の割付群を最終的に把握）であるため、非特異的な治療効果やホーソン効果を完全には排除できない点は著者ら自身も限界として認めている。

**②サンプルサイズと選択基準**：G*Powerによる検出力分析に基づき、中程度の効果量で検出力80%を確保できるようN=60（各群30人）を設定しており、事前の統計的裏付けはある。しかし単一地域（エジプト・エルベヘイラ県の3施設）からの限られたサンプルであり、精神科既往のある母親や重度心理的苦痛を有する母親は除外基準により対象外となっているため、より重症例や父親・他の主養育者への一般化可能性は低い。

**③方法論の適切性**：DASS-21のアラビア語版（Cronbachのα=0.903）とPSI（α=0.938）という信頼性の確認された尺度を使用し、プログラム内容も精神科看護学・小児看護学の専門家5名による事前レビューを経ている点は方法論的に堅実である。ただし、評価はすべて自己記入式であり臨床家による客観評価が組み込まれておらず、また評価は介入直後のみで長期的な効果の持続性を検証する追跡調査が行われていない。

**④統計分析の妥当性**：正規性検定（Kolmogorov–Smirnov）に基づき適切にパラメトリック・ノンパラメトリック検定を使い分け、群内変化には対応のあるt検定/Wilcoxon検定、群間比較にはt検定/Mann–Whitney検定、予測因子の検討には多変量回帰分析を用いるなど、統計手法の選択自体は妥当である。一方で、DASS-21・PSIの複数の下位尺度に対して多数の検定を繰り返しているにもかかわらず、多重比較の補正について言及がなく、偶然による有意差（第一種の過誤）の増大リスクが十分に統制されていない。

**⑤結果の信頼性と再現性**：主要仮説である「CBT群は対照群より心理的苦痛が有意に改善する」という結果はほぼ全指標で一貫しており頑健にみえる。しかし、介入群と対照群のベースラインで教育レベルと婚姻状況に有意差があり、これらの交絡因子の影響が統計的に十分に調整されていないまま群間比較が行われている点は結果の解釈に留保が必要である。また単一文化圏・単一時点のデータであり、他地域での再現性は本研究のみでは確認できない。

**⑥結論の妥当性**：著者らは本研究を「アラブ世界における文化的に適応したCBTプログラムの実行可能性と有効性を示す予備的エビデンス」と位置づけ、限界を10項目にわたり具体的に列挙するなど、過度な一般化を避ける姿勢が明確である。ただし「CBTがアラブ世界の母親の心理的ウェルビーイングを有意に改善した」という結論の強調は、対照群が非活動的（能動的プラセボなし）であった点を踏まえると、CBTに特異的な効果なのか、単に週1回90分の支援的な集団への参加自体の効果なのかを完全には切り分けられていない。

**⑦新規性**：CBTがASD児の母親の心理的苦痛軽減に有効であること自体は欧米・アジア圏の先行研究で示されているが、アラブ世界における文化適応型CBT介入、特に問題解決評価技法を明示的に組み込んだプログラムの効果をRCTで検証した点は、当該地域におけるエビデンスの空白を埋める意義ある新規性を持つ。ただし、CBTの構成要素自体（認知再構成、活動スケジューリング、問題解決訓練など）は既存の枠組みを踏襲したものであり、介入手法そのものの新規性は限定的である。

**⑧臨床的意義**：専門家不足やスティグマなどのアクセス障壁がある地域において、コミュニティメンタルヘルス看護師が実施可能な構造化プログラムとしての臨床的価値を具体的に示しており、実装可能性の観点で意義が大きい。一方、多要素からなる介入のどの構成要素（心理教育、認知再構成、問題解決訓練など）が効果に最も寄与したかは検証されておらず、また母親の改善が児自身の発達や家庭機能に波及するかどうかは未評価であるため、臨床導入の優先順位付けには追加のコンポーネント分析が必要である。
