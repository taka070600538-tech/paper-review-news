# つながりを断ち、つながり直す——スマートフォン禁止措置の種類の違いがオランダ中等教育の生徒のウェルビーイングと学校での社会的つながりに与える影響 精読ノート

> 役割：日本トップクラスのサイエンスコミュニケーターとしての精読プロンプト（デフォルトフォーマット）に基づく分析結果

## 1. 概要（500字以内）

世界の約4割の国が学校でのスマホ使用を制限しており、オランダも2024年1月に中等学校でのスマホ禁止を導入した。ただし運用は学校任せで、「教室内だけ禁止（部分禁止）」の学校と「休み時間も含め校内全体で禁止（全面禁止）」の学校が混在している。本研究は全国コホートEPoSS研究（2024年9月〜2025年2月）のデータを用い、24校（部分禁止9校・全面禁止15校）の生徒1398名（平均16.2歳）を対象に、禁止の厳しさの違いが問題的SNS利用、スクリーンタイム、ウェルビーイング、学校での社会的つながり、いじめと関連するかをマルチレベル回帰で検討した。仮説は「全面禁止の方が良い結果」だったが、**ウェルビーイング5指標といじめ4指標にはまったく差がなかった**。全面禁止校では余暇のスクリーンタイムが長い（1日3時間以上）生徒のオッズが低かった（OR 0.75）一方、**教師とのつながりが男女とも低く、女子では学校所属感も低かった**。著者らは「厳しい禁止は期待された効果をもたらさず、むしろ学校でのつながりを損なう可能性がある」と結論している。ただし横断研究であり、導入前の状態が比較できない点に注意が必要である。

## 2. Figure・Tableの解説

本論文に**Figureはなく、Table 1〜6の計6点**が掲載されている（付録A〜D＝質問紙、確認的因子分析、欠測データ、Model 1〜3の全結果はオンライン補足資料で、本PDFには含まれない）。Table 3〜6はPDF上で横向き（90度回転）に組まれており、テキスト抽出では文字列が逆順になったため、数値は1桁ずつ反転して読み取った。

### Table 1：生徒レベル（n = 1398）と学校レベル（n = 24）の共変量

生徒の属性を「全体／部分禁止校（535名）／全面禁止校（863名）」で並べた表。性別はほぼ半々（女子50.1%）、平均年齢は16.2歳（SD 1.4）。注目すべきは**2群の構成の偏り**で、全面禁止校はvwo（大学進学コース＝オランダの最上位の学業トラック）の生徒が54.8%と多く（部分禁止校31.2%）、9年生も42.3%対25.4%と多い。学校レベルでは、全面禁止校の方が大規模校（750名超）が多く（53.3%対33.3%）、都市部が多く（80.0%対55.6%）、宗派ではローマ・カトリック系が部分禁止校に集中（44.4%対0%）していた。つまり「禁止の種類」以外にも2群は多くの点で異なっており、後の回帰分析でこれらを統計的に調整する必要がある、ということを示す表である。

### Table 2：全アウトカムの平均・標準偏差・範囲

14のアウトカムの記述統計。人生満足度（0〜10点）は部分禁止7.28、全面禁止7.31とほぼ同じ。孤独感、身体的・情緒的不調、疲労（確認的因子分析で作った潜在変数＝直接は測れない「不調の度合い」を複数の質問から推定した得点）にもほとんど差はない。差が目に見えるのは、スクリーンタイム（1日3時間以上の割合：50%対42%）と**教師とのつながり（3.80対3.61）**、クラスメートとのつながり（3.92対3.82）である。いじめ・ネットいじめ（1〜5点）はいずれも平均1.2〜1.5と低く、ほとんどの生徒が「経験なし」に集中する偏った分布であることがわかる。なお人生満足度の範囲が全体「1–10」、部分禁止校「0–10」と表記が食い違っている（誤植と思われる）。

### Table 3：問題的SNS利用（線形）とスクリーンタイム（ロジスティック）のマルチレベル回帰

最終モデル（Model 3：生徒・学校の共変量をすべて投入）の結果を、全体・男子・女子で示す。**問題的SNS利用**では、全面禁止の係数は全体β = −0.03（95%CI −0.16〜0.09、p = .597）で差なし。男子ではβ = −0.20（p = .074）と減少傾向だが有意ではない。女子であることは強い予測因子（β = 0.29、p < .001）だった。**スクリーンタイム（余暇に1日3時間以上）**では、全面禁止校の生徒はオッズ比（OR：起こりやすさの比、1未満なら起こりにくい）0.75（95%CI 0.58〜0.98、p = .038）と有意に低かった。しかし男女別ではOR 0.78（p = .128）、0.76（p = .196）とどちらも有意でなくなった。年齢が上がるほど長時間利用のオッズは高かった（OR 1.14）。ICC（級内相関：結果のばらつきのうち学校の違いで説明される割合）は0.00〜0.01と非常に小さい。

### Table 4：ウェルビーイング5指標のマルチレベル線形回帰

人生満足度、孤独感、身体的不調、情緒的不調、疲労の5つについて、全面禁止の係数はすべて0に近く有意ではなかった。例えば人生満足度は全体β = 0.03（p = .820）、孤独感β = −0.02（p = .860）、身体的不調β = −0.06（p = .179）、情緒的不調β = −0.04（p = .395）、疲労β = −0.04（p = .427）。男女別でも同様で、男子の人生満足度β = −0.16（p = .419）など、いずれも有意差なし。一方、共変量は強く効いており、女子は人生満足度が低く（β = −0.44）、孤独感・身体的不調・情緒的不調・疲労が高かった。親の学歴が高い生徒は不調・疲労がむしろ多く、移民背景のある生徒は孤独感が高かった。つまり「どんな禁止をしているか」より「どんな生徒か」の方がはるかにウェルビーイングを左右している、と読める表である。

### Table 5：学校での社会的つながり3指標のマルチレベル線形回帰

本論文の主要な「予想外の」結果を示す表。**学校所属感**（学校で受け入れられ安全と感じる度合い、1〜5点）では、全体β = −0.03（p = .783）、男子β = 0.02（p = .851）で差がないが、**女子ではβ = −0.18（95%CI −0.35〜−0.01、p = .036）**と全面禁止校で有意に低かった。**教師とのつながり**（先生が自分を受け入れ、信頼できると感じる度合い）は、全体β = −0.14（p = .068、境界域）だったが、**男子β = −0.23（p = .003）、女子β = −0.18（p = .013）**と男女別ではどちらも有意に低かった。**クラスメートとのつながり**は全体β = −0.08（p = .426）など、どのモデルでも差がなかった。「休み時間にスマホを取り上げれば、生徒同士や先生との交流が増える」という政策側の想定とは逆向きの結果である。

### Table 6：いじめ4指標のマルチレベル線形回帰

学校でのいじめ被害・加害、ネットいじめ被害・加害の4つについて、全面禁止の係数はいずれも有意ではなかった（全体でそれぞれβ = 0.03、0.05、0.04、0.07、p = .533〜.835）。女子のネットいじめ被害のみβ = 0.12（p = .054）とわずかに多い方向の境界域の値だったが、有意水準には届いていない。共変量では、女子は学校でのいじめ加害（β = −0.37）やネットいじめ被害・加害が少なく、移民背景のある生徒はいじめ加害やネットいじめ被害・加害が多く、親の学歴が高い生徒はいじめ加害・ネットいじめが少なかった。スマホを校内全体で取り上げても、いじめ・ネットいじめは減らないことを示す表である。

## 3. 8項目評価

本論文は一次データを用いた**原著研究**（横断的観察研究）であるため、8項目は一次研究の基準でそのまま評価する。

### ① 研究デザイン

全国コホートの一時点データを用いた横断研究で、学校単位の政策（部分禁止か全面禁止か）を生徒単位のアウトカムと関連づけるマルチレベル設計である。政策の違いが「自然に」生じた状況を利用しており、実社会の政策評価として意義がある。しかし**問題点**は大きく三つ。第一に横断研究であり因果は言えない。第二に、全国義務化（2024年1月）以前の各校のルールや、導入前のウェルビーイング・つながりの水準が測られておらず、「もともとつながりが弱い学校が全面禁止を選んだ」という逆の因果（選択バイアス）を排除できない。第三に、禁止なしの対照群がない（2校のみで除外）ため、禁止そのものの効果は評価できない。

### ② サンプルサイズと選択基準

生徒1398名は十分な規模だが、**本質的な分析単位である学校はわずか24校（9校対15校）**で、学校レベルの説明変数を検出する検出力は限られる。1950件の回答のうち509件が同意なし・学年誤り・白紙・重複で除外され、さらに1名のみ参加の1校と、禁止未実施の2校（43件）が除外された。**問題点**として、16歳未満では保護者の能動的同意が必要だったため、社会経済的に不利な層が過少に代表されている可能性を著者自身が認めている。また27校はオランダ12地域のうち6地域からで、無作為抽出ではない。抄録の女子51.5%・年齢SD 1.2と、Table 1の女子50.1%・SD 1.4が食い違っている点も気になる。

### ③ 方法論の適切性

アウトカムは概ね確立した尺度（HBSC調査の心身症状・いじめ項目、問題的SNS利用尺度α = 0.82など）で測られ、心身症状は確認的因子分析で3因子（身体・情緒・疲労）に整理されている。**問題点**は、①主要な説明変数「禁止の種類」が各校1名の職員の自己報告だけで決まり、実際の運用の厳しさや遵守状況が測られていない、②スクリーンタイムは単一項目で「余暇」の解釈が曖昧（休み時間を含めて答えた可能性を著者も認める）、③孤独感も単一項目、④学校所属感α = 0.99、教師とのつながりα = 0.97は高すぎ、項目の冗長性か回答の一様性（一律に同じ選択肢を選ぶ回答）を疑わせる。すべて自己報告である点も共通方法バイアスの懸念を残す。

### ④ 統計分析の妥当性

生徒が学校にネストされた構造をマルチレベルモデルで扱い、欠測は多重代入（5データセット）で処理し、段階的に共変量を投入した点は適切である。VIF > 10の変数（学年、都市化度）を除外して多重共線性にも配慮している。**問題点**として、①14アウトカム×（全体・男子・女子）の多数の検定を多重比較の補正なしで行っており、女子の学校所属感（p = .036）程度の結果は偶然の可能性がある、②性差を「層別化」で検討しており、男女間の差を交互作用項で直接検定していないため「女子にだけ効く」とは厳密には言えない、③学校レベルの説明変数に「ランダム傾き」を置いたという記述は構造上不自然で、モデル仕様が不明確、④学校数24では学校レベル共変量（社会経済構成・規模）の調整も不安定である。

### ⑤ 結果の信頼性と再現性

ウェルビーイング・いじめで一貫して差がない結果は、英国のGoodyearら（2025）やノルウェーの研究とも整合し、「全面禁止でも心の健康は良くならない」という点の再現性は比較的高いと言える。一方、**教師とのつながりの低下**は全体モデルでは境界域（p = .068）で、男女別にしてはじめて有意になった。女子の学校所属感も効果量β = −0.18（1〜5点尺度で約0.2点）と小さく信頼区間の上限が−0.01に接している。ICCは多くのアウトカムで0.00〜0.05と学校間差が小さく、学校政策で説明できる余地自体が小さい。データは条件付きでのみ提供され、第三者の完全な再現は難しい。

### ⑥ 結論の妥当性

「厳しい禁止はウェルビーイングやいじめに期待された利益をもたらさない」という結論は、多数のアウトカムで一貫して差がない点から妥当性がある。しかし「全面禁止は学校でのつながりを**損なう**（undermine）」という表現は、横断データかつ導入前の比較がない状況では**因果的に言い過ぎ**である。全面禁止校にvwo生徒や大規模校・都市部の学校が多いなど2群の構成は大きく異なり、調整しきれない交絡（学校風土、教師の数、禁止の伝え方など）が残る。著者は限界の節でこれらを認めているが、要旨と結論の文言はより強く書かれており、ずれがある。

### ⑦ 新規性

スマホ禁止研究の多くは学業成績に焦点を当て、「禁止の有無」を比較してきた。本研究は①禁止の**種類（範囲）**の違いを直接比較した、英国に続く2例目の研究であること、②これまでほとんど検討されていなかった**学校での社会的つながり（所属感、教師・級友とのつながり）**を初めてアウトカムにしたこと、③性差を検討したこと、の3点で新規性がある。全国一律義務化の直後という「自然実験」的なタイミングを捉えた点も貴重である。ただし分析手法自体は標準的で、方法論的な新しさはない。

### ⑧ 臨床的意義

精神科・学校保健の立場からは、「スマホを取り上げれば思春期のメンタルヘルスが改善する」という単純な期待に対する重要な反証材料となる。問題の本体は利用時間よりも**問題的な使い方**（強迫的なチェック、感情的依存、夜間のスクロール）であり、これは校外で起きるため、診療では睡眠衛生、SNSとの付き合い方、情緒調整への介入が引き続き中心になる。また、厳しいルールが生徒に「罰」と受け取られ、教師との信頼関係を損なう可能性は、学校との連携で助言する際に留意すべき点である。ただし効果量は小さく、個々の患者の治療方針を変えるほどの根拠ではない。
