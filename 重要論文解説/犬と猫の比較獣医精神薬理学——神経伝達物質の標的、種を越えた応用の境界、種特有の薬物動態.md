# 犬と猫の比較獣医精神薬理学——神経伝達物質の標的、種を越えた応用の境界、種特有の薬物動態 精読ノート

## 概要（500字以内）

韓国カトリック大学医学部と江原大学獣医学部の2人の研究者による総説(構造化ナラティブレビュー=系統的レビューほど厳密ではないが検索手順を明示した文献まとめ)である。犬や猫の不安、恐怖、常同行動(同じ動作の繰り返し)、攻撃行動、加齢による認知機能低下に薬が使われる場面が増えているが、処方はしばしば人間の精神医学からの「流用」に頼っている。著者らは、セロトニン、ノルアドレナリン、GABA、ドパミン、グルタミン酸という5つの神経伝達系と、それぞれに効く薬、対応する行動の型を整理した。結論は3点。①受容体や輸送体(薬が結合する分子)のレベルでは種を越えた推論が成り立つが、DSMのような人間の診断名をそのまま犬猫に当てはめることはできない。②比較対照試験の裏付けは犬の分離不安・常同障害(フルオキセチン、クロミプラミン)、騒音恐怖(デクスメデトミジン、イメピトイン等)、認知機能不全(セレギリン)に集中し、猫では尿スプレーと通院時ストレスに限られる。③半減期や代謝は薬ごと・種ごとに違うため、「猫は一律に減量」のような一般則ではなく、薬ごとのデータで投与量と休薬期間を決めるべきだ、とする。

### Figure 2 重なり合う神経伝達系・機能・行動の型・代表薬

4段の横帯で構成される。最上段は5つの神経伝達系(セロトニン=5-HT、ノルアドレナリン=NE、GABAとα2δ関連、ドパミン=DA、グルタミン酸=Glu)を脳のイラストで示す。2段目はそれぞれの主な機能(5-HT=情動調節・不安と恐怖の調整、NE=覚醒・注意・ストレス応答、GABA=抑制・鎮静、DA=動機づけ・報酬・衝動制御、Glu=学習・記憶・シナプス可塑性=神経のつながりが変わる性質)。3段目は行動の型(不安と恐怖、場面ストレス、反復・常同行動、攻撃関連行動、認知機能不全)。最下段は代表薬7つ(フルオキセチン、クロミプラミン、トラゾドン、ガバペンチン、デクスメデトミジン、タシピミジン、セレギリン)。段のあいだには「多対多の重なり合う関係」という矢印が引かれ、図の下に「因果関係ではなく、もっともらしい薬理学的関係を示す」と明記されている。1つの伝達系の異常が1つの病気を起こすという単純化を避ける意図の図である。

### Table 1 神経伝達系ごとの比較トランスレーション枠組み

5つの神経伝達系それぞれについて、人間での文脈、犬の行動の型、猫の行動の型、種を越えて応用できる根拠、限界を1行ずつ並べた表である。セロトニンは人間で不安・反復行動・気分調節にかかわり、犬では分離不安と常同障害、猫では尿スプレーなどが対応し、「受容体と輸送体が保存されていて(種を越えてほぼ同じ)、一部の適応には獣医の臨床試験がある」が、「診断基準は種で違う」。ノルアドレナリンは犬の騒音恐怖・猫の場面ストレスに対応し、限界は「引き金が状況ごとに違う」。GABAは急性の不安に対応するが「鎮静で行動評価がゆがむ」。ドパミンは犬の認知機能不全・常同行動に対応するが、猫では「ほぼ未解明」。グルタミン酸は行動療法の補助として理論上の候補にとどまり、「獣医での直接試験はほとんどない」。下の行ほど根拠が薄くなる並びになっている。

### Table 2 種・研究デザイン・適応ごとの臨床エビデンス比較

本論文の中心となる表で、薬ごとに主な標的、犬の臨床エビデンス、猫の臨床エビデンスを、研究デザインのカテゴリー(A=ランダム化比較試験=RCTかメタ解析、B=前向きの非ランダム化研究、C=後ろ向き研究・症例集積、D=専門家意見・機序からの推論)とともに示す。犬ではフルオキセチン(分離不安と常同障害、常同障害は63頭)、クロミプラミン(分離不安95頭の多施設RCT)、トラゾドン(通院ストレス20頭の交差試験)、イメピトイン(騒音恐怖238頭)、デクスメデトミジン(182頭)、タシピミジン(承認用の野外試験160頭・224頭)がカテゴリーAで、セレギリンは641頭の非盲検研究でB。猫ではフルオキセチン(尿スプレー17頭)、クロミプラミン(67頭)、トラゾドン(10頭)、ガバペンチン(20頭)、プレガバリン(209頭)がAだが、イメピトイン・タシピミジン・セレギリンは猫で根拠なし。注記で「カテゴリーは研究デザインの分類で、効果の確実性ではない」「鎮静による行動の減少を抗不安効果と取り違えない」と念を押している。

### Table 3 比較精神薬理学におけるトランスレーションの境界

人間から犬猫への「持ち込み」を、5つの領域ごとに「応用できる」「部分的に応用できる」「応用できない」の3段階で仕分けた表である。機序では、受容体の標的や輸送体は応用できるが、用量反応関係は部分的、行動の完全な同等性は応用できない。診断では「不安スペクトラム」という大きな概念は持ち込めるが、強迫性のモデルは部分的、DSMの診断カテゴリー(人間の精神疾患の診断基準)は持ち込めない。治療モデルでは「薬+行動療法」は応用でき、治療期間の原則は部分的、精神療法の手法そのものの同等性は応用できない。副作用では消化器症状・鎮静・セロトニン毒性は共通、認知の鈍化は部分的、主観的な気分の報告は不可能。評価尺度では行動頻度の減少は使え、飼い主評価尺度は部分的、自己報告による感情状態は使えない。精神科医にとって、本論文の主張が最も凝縮された表である。

### Table 4 犬と猫における薬ごとの薬物動態と安全性の考慮点

12薬×犬猫の組み合わせごとに、代謝と排泄、半減期(血中濃度が半分になる時間)と活性代謝物、安全性と休薬の注意を並べた表(2ページにまたがる)。たとえばフルオキセチンは犬で反復投与により活性代謝物ノルフルオキセチンが大きく蓄積し、猫でも単回投与で半減期が約47時間(代謝物約55時間)と長い。経皮剤と経口剤は同等とみなせない。トラゾドンは犬で生物学的利用率84.6%・半減期約2.8時間、猫で54.9%(7〜96%と個体差が大きい)・約5.1時間で、猫ではガバペンチン併用で利用率が下がった小規模報告がある。デクスメデトミジンの口腔粘膜投与は犬で利用率11.2%と低く、静注のデータをそのまま使えない。セレギリンは犬で経口利用率8.5%、半減期約1時間。タシピミジンはクロミプラミンとの併用で血中濃度が上がる。猫のタシピミジンやセレギリンはデータがない。脚注で「猫のグルクロン酸抱合能の低さは、向精神薬全般に一律の減量を意味しない」と明記している。

### Table 5 行動の型(フェノタイプ)に基づく臨床判断の枠組み

代表的な6つの臨床場面ごとに、見落としてはいけない鑑別、薬の役割、使用期間、種ごとのエビデンス、よくある副作用、監視と併用すべき管理を整理した表(2ページにまたがる)。犬の分離関連の苦痛はフルオキセチン/クロミプラミンを行動修正の補助として長期に使う(A)。犬の騒音恐怖はデクスメデトミジン/タシピミジンを出来事に合わせて頓用し、徐脈・低血圧に注意し、鎮静と抗不安を区別する(A)。犬の常同行動は皮膚・神経・痛みを鑑別したうえでセロトニン系薬(A)。猫の尿スプレーは下部尿路疾患・トイレ環境・縄張りストレスを除外したうえでフルオキセチン/クロミプラミン(A)だが、慢性不安一般には広げない。猫の通院・移動ストレスはトラゾドン/ガバペンチン/プレガバリンを事前に頓用(A)。犬の認知機能不全はセレギリン(B)。どの場面でも「薬は環境・行動管理の補助」という位置づけで一貫している。

### ① 研究デザイン

PubMed、Scopus、Web of Science の3データベースを使い、検索語を「種」「行動の型」「薬・神経伝達物質」「薬物動態」の4ブロックに分けて組み合わせた構造化ナラティブレビューである。著者自身が「網羅的ではなく、系統的レビューの要件は満たさない」と明言している点は誠実だ。さらに神経伝達系→トランスレーションの境界→薬物動態→臨床判断という4層の構成は、精神科医にも獣医にも見通しがよい。問題点は、系統的レビューではないため選択の偏りを防ぐ仕組みが弱いことである。PRISMA(検索から採用までの件数を示す流れ図)に相当する件数の記載がなく、何件を検索して何件を採用したのか読者には分からない。

### ② サンプルサイズと選択基準(文献検索・採用基準)

対象は1990年1月〜2026年10月2日の英語文献で、RCT、前向き研究、観察研究、症例集積、薬物動態研究、メタ解析とガイドラインを含め、げっ歯類だけの研究と根拠のない意見論文を除外した。2人の著者が選択とデータ抽出を行い、意見の不一致は話し合いで解決したと記載されている。問題点は3つある。英語以外の文献を除外しており、欧州や日本の獣医行動学の文献を取りこぼした可能性がある。採用件数が示されていない。各試験の頭数も小さく(猫のフルオキセチン試験は17頭、トラゾドン試験は10頭)、総説全体の結論がごく少数の試験に依存している。

### ③ 方法論の適切性

エビデンスをA〜Dの研究デザインで分類し、「これは効果の確実性ではない」と繰り返し注意している点は方法として妥当で、過大な格付けを避けている。鎮静と抗不安を区別する節(6.1)を設け、デクスメデトミジン試験が覚醒度の評価で鎮静例を除外した点まで確かめているのは、行動試験を読むうえで重要な視点だ。問題点は、GRADE(バイアスのリスク、精度、一貫性も含めた確実性の評価法)のような質の評価をしていないことである。そのため、同じ「カテゴリーA」でも頭数10頭の交差試験と238頭の並行群間試験が同列に並んでしまう。製薬企業が出資した承認用試験かどうかの区別も、タシピミジン以外では示されていない。

### ④ 統計分析の妥当性(エビデンスの統合方法)

メタ解析は行わず、表による叙述的な統合にとどめている。試験の異質性(対象、評価尺度、期間がばらばら)が大きい領域なので、無理に数値を統合しなかったことは妥当といえる。問題点は、各試験の効果量、信頼区間、脱落率がまったく記載されていないことである。「有効性が示された」の中身(主要評価項目は何か、飼い主評価か盲検評価か、差はどの程度か)が読者には分からない。たとえば猫のCBD試験は「群間に有意差なし」を報告しているが、これは同等性を示したものではない。著者もこの点を注記しているが、同じ注意はほかの試験の解釈にも必要である。

### ⑤ 結果の信頼性と再現性

本文と表はおおむね一致しており、Table 2の頭数や Table 4の薬物動態の数値は出典つきで具体的に書かれている。検索式の構成も示されているので、手順を追うことはおおむね可能である。問題点は、表どうしで細かい不整合があることだ。認知機能不全症候群の略称が本文で CCD と CDS に揺れており、略語表では「CCD=cognitive dysfunction syndrome」と綴りと略称が合っていない。犬のガバペンチンの通院ストレス試験はTable 2で「カテゴリーA」とされながら、頭数も文献番号も示されていない。犬のフルオキセチンの分離不安RCTも頭数の記載がない。検索語のリストに CBD や tasipimidine、pregabalin は含まれておらず、これらは参照文献から追加されたと考えられるが、その過程は再現できない。

### ⑥ 結論の妥当性

「受容体レベルでは種を越えて推論できるが、診断名は持ち込めない」「薬物動態は薬ごとに判断せよ」という結論は、提示された根拠から無理なく導かれており、控えめで妥当である。グルタミン酸系、CBD、ウェアラブル、薬理遺伝学を「探索段階」と明確に線引きした点も、過剰な期待を抑えている。問題点は、結論の中心にある「回路レベルの枠組みは診断カテゴリーより妥当」という主張自体が、獣医領域では検証されていない仮説であることだ。著者は人間の精密精神医学(Williams 2016)を根拠に挙げているが、人間でも回路に基づく分類はまだ臨床で確立していない。したがって、この主張も「探索段階」として扱うのが一貫している。

### ⑦ 新規性

犬猫の向精神薬を「神経伝達系」「人間からの応用の境界」「種ごとの薬物動態」という3つの軸で一枚の枠組みにまとめた点が新しい。特にTable 3のように、持ち込めるもの・持ち込めないものを明示的に仕分けた表は、従来の獣医行動学の総説にはあまり見られない。2026年に米FDAが承認したタシピミジン(犬の騒音嫌悪と分離不安)や、猫のCBD試験(100頭)など最新の知見も含んでいる。問題点として、個々の情報(フルオキセチンの承認、猫のジアゼパムによる肝壊死など)は既存の教科書や総説で知られたものが大半であり、新規性は「整理の仕方」にとどまる。新しい一次データや定量的な統合はない。

### ⑧ 臨床的意義

獣医にとっては、根拠が強い適応(犬の分離不安、猫の尿スプレーなど)と弱い適応(猫の慢性不安、攻撃行動)を区別し、休薬期間を薬ごとに考える(例: フルオキセチンからセレギリンへの切り替えは最低5週間空ける)という実用的な指針になる。精神科医にとっては、「主観的体験を聞けない患者で、診断名ではなく観察できる行動と薬理で考える」という構えが、自閉スペクトラム症や重度の知的障害、認知症の患者への処方にもそのまま通じる点が示唆に富む。問題点は、具体的な用量表がなく、そのまま処方の手引きとしては使えないこと。また、根拠の多くは短期・小規模の試験で、長期の安全性や効果の持続、併用療法の実態はほとんど分かっていないことである。
