# 日常生活における感情調整の変動性と柔軟性は、ウェルビーイング・年齢・実行機能とそれぞれ異なる関連を示す

## 1. 概要

気持ちの立て直し方(感情調整、ER)は「いろいろな方法を使い分けられる人ほど健康」と言われがちです。ドイツの研究チームは、この「使い分け」を2つに分けて調べました。**変動性**(方法の使い方がどれだけばらつくか)と、**柔軟性**(そのばらつきが状況の変化にどれだけ連動しているか)です。

14〜78歳の一般の人161人が、まず自宅のパソコンで6種類の認知課題(実行機能=頭の切り替え・抑制・作業記憶の更新)を受け、その後14日間、スマホで1日5回、直近2時間に使った11種類の感情調整法と気分、状況(良い出来事か、一人か誰かといたか)を答えました。

結果は、①年齢が高いほど実行機能は低いが、実行機能は日常の変動性と無関係、②年齢が高いほど変動性は小さいが、柔軟性は年齢でほぼ変わらない、③同じ方法の強弱を状況に合わせる柔軟性は、不快な気分と**U字型**の関係(低すぎても高すぎても気分が悪い)、④うつ症状とはどの指標も無関係、でした。「実行機能が高いほど」「柔軟なほど」良いとは言えず、状況と方法の噛み合わせが大事だ、と著者は結論します。効果は小さく(説明率3%前後)、横断的な関連である点に注意が必要です。

## 2. FigureとTableの解説

本文には **Figure 1点、Table 7点**があります(全20ページを確認)。本文中で補足資料の **Figure S1(変動性の計算例)、Figure S2(うつ症状の分布)、Figure S3(年齢と実行機能の散布図)、Table S1(拡張相関行列)** にも言及がありますが、手元のPDFには補足資料が含まれていないため、本文の記述から分かる範囲で最後にまとめて触れます。

### Table 1 仮説と主要変数の一覧(p.4)

5つの仮説の一覧表です。H1:年齢が高いほど実行機能(EF)の成績が低い。H2:EFが感情調整の変動性と関連する(特に「切り替え(シフティング)」が関係すると予想)。H3:柔軟性と平均の不快な気分が**U字型**(中くらいが最も良い)。H4:柔軟性とうつ症状もU字型。H5:年齢が高いほど変動性は低いが、柔軟性は年齢と関係しない。各仮説が「個人レベルの課題成績」「個人ごとに集計した変動性」「個人ごとの柔軟性の傾き(スロープ)」など、どの水準のどの数値で検証されるかも示しています。

### Table 2 実行機能課題の記述統計(p.6)

6課題の正答率(%)の平均・ばらつき・信頼性です。切り替えはウィスコンシン・カード分類(WCST、平均81.5%)と柔軟アイテム選択(FIST、61.1%)、抑制はアンチサッケード(AST、80.0%。合図と反対側を見る課題)と持続的注意課題(SACT、84.8%)、更新は視覚複合スパン(VCST、83.0%)と空間 n バック(SNT、85.6%)。折半信頼性(テストを半分に分けた一貫性)は0.74〜0.96と良好。ただし WCST は歪度−4.01・尖度22.7と強い天井効果(ほぼ全員が高得点)で、個人差をとらえにくい点が気になります。総合EFのα=.73。

### Table 3 変動性・状況・気分の記述統計(p.10)

方法内変動性(同じ方法の強さが1日の中でどれだけ上下するか)は平均25.24、方法間変動性(その時点で特定の方法だけ強く使ったか)は平均25.74(いずれも0〜100の尺度)。状況の快・不快は平均70.22とやや良い出来事寄り、「一人」は1日1.31回、「誰かと」は2.56回(本文では2.53回)。不快な気分は平均25.90、PHQ-9(うつ症状の質問票、0〜27点)は平均4.64で、ほとんどが「なし〜軽度」です。個人間・個人内の標準偏差を分け、多層構造の信頼性(個人間α=.76〜.97)も示しています。分析対象は8,359回答・161人。

### Table 4 主要変数の相関(p.10)

スピアマン順位相関(外れ値に強い相関)で、多重比較の補正済みです。年齢はうつ症状(−0.35)・総合EF(−0.47)と負、方法の平均使用量(全体としてどれだけ感情調整をしたか)とは正(0.25)。注目点は、**変動性と平均使用量が非常に強く相関**すること(方法内0.76、方法間0.91)。つまり「たくさん調整する人ほど、ばらつきも大きい」。さらに柔軟性指標(誰かといるとき)は方法内変動性と0.87で、変動性と柔軟性が数値上ほとんど重なっていることも分かります。不快な気分とうつ症状は0.44。

### Table 5 柔軟性から不快な気分を予測する重回帰(p.11)

柔軟性の1次項(直線)と2次項(曲線)を入れた4モデルです。方法内の柔軟性では、状況の快・不快に応じた柔軟性の2次項が有意(B=0.06、p=.020、β=0.23、モデル1)、「誰かといる」状況に応じた柔軟性の2次項も有意(p=.040、モデル2)。2次項が正=U字型を意味します。「一人」の2次項は p=.054 で有意に届かず。方法間の柔軟性(モデル3・4)はすべて有意でなし。なお表のモデル3の p 値の列が標準誤差と同じ数値(1.12、0.65、0.09)になっており、転記ミスと思われます。

### Figure 1 方法内柔軟性と不快な気分のU字型の関係(p.12)

Table 5で有意だった2つの関係を図にしたものです。パネルAは状況の快・不快に応じた柔軟性、パネルBは「誰かといる」状況に応じた柔軟性が横軸、平均の不快な気分が縦軸。点が一人ひとり、曲線が2次式の予測値と95%信頼区間、縦の破線が**転換点**(気分が最も良くなる柔軟性の値。A:−2.16、B:41.46)です。どちらも転換点がデータの範囲内にあり、「中くらいの柔軟性で不快な気分が最も低い」と読めます。ただし説明率は R²=0.035・0.028と小さく、両端の少数の人が曲線を左右している可能性は図を見て判断する必要があります。

### Table 6 柔軟性からうつ症状を予測する重回帰(p.13)

Table 5と同じ組み立てで、目的変数をうつ症状(PHQ-9)にした4モデル(モデル5〜8)です。方法内・方法間のどちらの柔軟性も、1次項・2次項とも有意なものは1つもありません(方法内は全p>.36、方法間は全p>.31)。説明率も R²=0.004〜0.009 とほぼゼロです。H4(うつ症状とのU字型)は支持されませんでした。著者は、2週間の日々の測定から作った指標は「その日の気分」には反映されても、より長い時間軸で決まるうつ症状には届きにくい、と解釈しています。

### Table 7 年齢と変動性・柔軟性(p.14)

実行機能と方法の平均使用量をそろえた上での年齢の効果です。年齢が高いほど方法内変動性(β=−0.35)も方法間変動性(β=−0.31)もはっきり小さい(いずれも p<.001)。一方、柔軟性6指標はどれも有意でなく、「一人」の状況に応じた方法内柔軟性(β=−0.17、p=.052)と方法間柔軟性(β=0.15、p=.091)が境界的なだけでした。B の値(−19.92 など)は、年齢の単位をそのまま1歳とすると大きすぎ、年齢を何らかの尺度に変換していると思われますが、本文に説明はありません。

## 3. 8項目評価

本論文は原著研究のため、一次研究の基準でそのまま評価します。

### ① 研究デザイン

認知課題(最大限の能力)と14日間のスマホ調査(普段の行動)を組み合わせた多面的な設計で、計画は事前登録(OSF)されています。日常生活の中で感情調整をとらえる点は、従来の「一度きりの質問紙」や実験室研究の弱点を補います。問題点は、すべての仮説が**個人間の横断的な関連**として検証されていることで、「柔軟だから気分が良い」のか「気分が良い人は柔軟に見える」のかは区別できません。著者も「予測」は因果を意味しないと断っています。

### ② サンプルサイズと選択基準

161人(14〜78歳)で、検出力分析では6予測因子の回帰で中小程度の効果(f²=0.09)を80%以上で検出可能とされます。ただしこれは R² 全体についての計算で、2次項1つの小さな効果(R²≈0.03)を検出する力は十分とは言えません。60歳以上は23人(14.3%)、70代は6人のみで、年齢の結論は高齢層に弱い。大学卒以上が半数を超える高学歴寄りで、パソコンとスマホを持つ人に限られ、うつ症状も軽い人が中心です。慢性疼痛研究の一部である点も選択の偏りを生み得ます。

### ③ 方法論の適切性

実行機能を3領域×2課題で測り、課題特有の偏り(課題純度の問題)を減らしたのは丁寧です。気分尺度の多層信頼性も高い。一方、WCST の強い天井効果、在宅オンライン課題で環境を統制できない点は弱み。柔軟性の作り方は事前登録から変更されています(残差→個人ごとのランダム傾き。収束しなかったため)。変更は明記されていますが、結果を見る前の変更かどうかは文面から読み切れません。状況の指標が「快・不快」「一人か否か」の粗い2種類だけで、相手との関係や状況の制御可能性が入っていない点も、柔軟性をとらえる精度を下げています。

### ④ 統計分析の妥当性

マルチレベルモデルで個人内の関連を推定し、その個人別の傾きを個人間の指標として使う2段階方式です。問題は、推定された傾き(縮小推定された残差)を「測定誤差のない値」として次の回帰に入れている点で、誤差が伝わらず有意になりやすい可能性があります。また仮説検定には多重比較の補正をしていません(柔軟性6指標×2次項で多数の検定)。有意だった2次項は p=.020 と .040 で、補正すれば消える可能性があります。1次項と2次項の強い相関で β が±0.5前後に膨らみ信頼区間が広い点、Table 5 の p 値列の転記ミスも気になります。

### ⑤ 結果の信頼性と再現性

データ(匿名化した回答・課題得点・データ辞書)がOSFで公開されており、再解析が可能なのは大きな長所です。年齢と変動性の負の関連は、日ごとに集計しない別解析でも再現され、先行研究とも一致するため、頑健と言えます。一方、U字型の関係は効果が小さく、補正なしの境界的な p 値で、「一人」の状況や方法間の柔軟性では再現されませんでした。同じ研究内でも条件によって出たり出なかったりする所見で、別のサンプルでの追試がないと信頼度は中程度にとどまります。

### ⑥ 結論の妥当性

「実行機能が高い=柔軟な調整」「柔軟なほど良い」という単純な図式を支持しない、という結論はデータに沿っています。ただし、著者が強調する「方法の強弱の微調整こそが日常の気分に重要」という主張は、R²≈0.03 の2つの2次項に依存しており、言い過ぎの感があります。高齢者の変動性の小ささを「硬さではなく、状況に合った選択」と解釈する部分も、柔軟性の非有意(関連なし)を「保たれている」と読み替えたもので、同等性の検定はしていません。変動性と柔軟性がほぼ重なる(r=0.87)ことを限界で認めている点は誠実です。

### ⑦ 新規性

感情調整の「変動性」と「柔軟性」を明確に分けて同じデータで比較し、さらに実行機能・年齢・気分・うつ症状を1つの研究で扱った点は新しい。従来は直線的な関係だけが調べられがちだった柔軟性について、U字型を事前登録の仮説として検証した点も意義があります。14〜78歳という幅広い年齢で、日常データと認知課題を組み合わせた研究はまだ少数です。ただし個々の要素(加齢で変動性が下がる、実行機能と日常の感情調整の関連が弱い)は先行研究でも報告されており、確認的な部分も多く含みます。

### ⑧ 臨床的意義

臨床への示唆は「感情調整の方法を増やせばよい」「認知機能を鍛えれば調整が上手になる」という発想に慎重であるべき、という点です。CBT や弁証法的行動療法の文脈では、方法の数より「その場面にその方法が合っているか」を一緒に検討する方が大切、という実践感覚を後押しします。ただし対象は一般人口で、うつ症状とは関連が見られず、患者集団にはそのまま当てはめられません。効果も小さく、個人の評価や治療選択に使える段階ではありません。高齢者の「方法が少ない」ことを直ちに問題視しない、という見方は有用です。
