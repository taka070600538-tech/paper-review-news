# 老年期うつ病に対する認知行動療法(CBTlate)——多施設共同・無作為化・評価者盲検・対照試験の結果 精読ノート

## 概要

60歳以上で発症・経過している「老年期うつ病(LLD:Late-Life Depression)」は、抗うつ薬の効きが若年者より悪く副作用も出やすいため、精神療法への期待が大きい。しかし高齢者向けに調整した認知行動療法(CBT)を、精神科の専門外来で大規模に検証した試験はなかった。

ドイツの7施設で、中等症〜重症の大うつ病性障害をもつ60歳以上の外来患者251名を、高齢者向けCBT(LLD-CBT)と「支持的非特異的介入(SUI:共感的に話を聴き、気持ちを言葉にして返す、技法を使わない精神療法)」のどちらかに無作為に割り付けた。どちらも同じ治療者が週2回・計15セッション・8週間行い、評価者には割付を伏せた。

主要評価項目である自己記入式の老年期うつ病尺度(GDS)の治療終了時の変化量に、群間差はなかった(差 −1.01点、95%信頼区間 −2.88〜0.86、p = 0.287)。一方、両群ともうつ症状は大きく改善し(群内効果量 d = 1.75と1.47)、改善は6か月後も保たれた。高齢者専用CBTの「上乗せ効果」は示せず、改善の多くは精神療法に共通する要素(治療関係・期待・共感など)によると著者らは解釈している。

## 8項目評価

### ①研究デザイン

事前登録(NCT03735576、DRKS00013769)とプロトコル公開を済ませた、7施設の並行群間ランダム化比較試験である。施設で層別した、ブロックサイズ非公開の置換ブロック法で割り付け、評価者を盲検化し、同じ治療者が両方の介入を行うことで治療者の腕の差を相殺した点は丁寧である。問題点は、待機群や通常治療群がないため「何もしない場合」と比べた効果は直接分からないこと、そして精神療法の性質上、患者と治療者は盲検化できないことである。さらに、比較対照が同じ回数・同じ治療者による支持的療法という「強い対照」なので、差が出にくい設計でもある。

### ②サンプルサイズと選択基準

GDSで2.5点差(d = 0.4)を検出力80%で検出するため1群99名、脱落20%を見込んで248名を目標とし、251名を登録した。精神科専門外来から、構造化面接(M.I.N.I.)で確定した中等症〜重症の大うつ病患者を集めた点は、プライマリケアや自己応募の多い先行研究より臨床現場に近い。一方、認知機能が良好(MMST > 25)で、不安障害単独や強迫性障害、ベンゾジアゼピンの定期使用、急性の自殺念慮などを除外しているため、実際の高齢うつ病患者より「治療しやすい」集団である。想定した d = 0.4はパイロット試験に基づく楽観的な値で、観察された d = 0.18を検出するには検出力が足りない。

### ③方法論の適切性

両群とも8週・15セッションのマニュアル化された個人療法で、全治療者がCBTの資格をもち、2か月ごとの中央スーパービジョンと全セッションの録画、無作為抽出した録画の遵守評価を行った。評価者は中央で訓練・認定され、治療者と別の場所に配置された。問題点として、LLD-CBTの開発者(Hautzinger)が全治療者を監督しており、開発者側の思い入れ(アリージャンス効果)が入り得る。著者ら自身も、遵守評価が全録画・複数評価者・妥当性の確立した尺度で行われたわけではない点を限界として認めている。主要評価項目が自己記入式のGDSであることも、盲検化されない患者の期待の影響を受けやすい。

### ④統計分析の妥当性

事前の統計解析計画に沿い、ベースラインGDS・治療者・群・時点・群×時点の交互作用を入れた混合モデル(MMRM)で主要解析を行い、PP解析で頑健性を確認した。主要評価項目を1つに絞り、それだけを「検証的」と明言した点は適切である。問題点として、ITTの定義が「少なくとも1回の追跡評価がある人」で、無作為化された251名全員ではない(修正ITT)。また副次評価項目は多重比較を補正しておらず、5週目のGDSやGAI、SF-36の有意差は偶然の可能性が高い。寛解・反応率は計画外の追加解析である。安全性解析集団が244名(各群122名)となった経緯は本文から読み取れない。

### ⑤結果の信頼性と再現性

主要解析の結果はPP解析でも同じで、施設の影響も有意でなかった。脱落率は約9%と低く、群間差もない。性別・重症度別の解析でも群間差は出ておらず、「CBTの上乗せ効果は小さい」という結論は比較的頑健である。ただし、ベースラインで女性比率(72%対60%)と自殺企図歴(5%対14%)に偏りがあり、結果への影響は評価されていない。本文では副次評価項目の数値がITT(Table 2:SF-36精神的健康の差4.09、p = 0.020)とPP(本文:4.77、p = 0.009)で混在して書かれ、読者が取り違えやすい。データは倫理上の理由で非公開(要請に応じて提供)である。

### ⑥結論の妥当性

「LLD-CBTの支持的療法に対する優越性は確認できなかった」という主結論は、データに忠実で妥当である。一方、「両群の大きな改善は精神療法の共通因子による」「待機群の効果量0.11よりはるかに大きい」という解釈は、別の研究のメタ解析と単群の前後比較を比べたもので、自然回復、平均への回帰、併用薬の効果を区別できない。考察ではCBTが5週目のGDS・GAIで優れていたと書くが、GAIの有意差はPP解析のみで、ITTのTable 2では有意でない。SF-36身体的健康でSUIが優れた結果には触れていない。「支持的療法は習得が容易なので普及に向く」という提言は、費用や訓練時間を測っていないため推論にとどまる。

### ⑦新規性

精神科専門外来の中等症〜重症の老年期うつ病に対し、高齢者向けに調整したCBTを、同じ量・同じ治療者の支持的療法と比べた初めての大規模多施設試験とされる。先行研究の「特異的療法は支持的療法より d = 0.39優れる」というメタ解析の見積もりが、質の高い試験では再現されなかった点は重要な知見である。ただし、ドイツの単一の治療マニュアルを検証した試験であり、他のCBTプロトコルや問題解決療法などへの一般化には注意が要る。「特異的療法と支持的療法の差は小さい」という知見自体は、成人うつ病の領域ではすでに繰り返し報告されており、本研究はそれを高齢者で確認した位置づけである。

### ⑧臨床的意義

60歳以上の中等症〜重症うつ病でも、週2回・8週間の個人精神療法で症状が大きく改善し6か月持続したことは、「高齢者に精神療法は効きにくい」という思い込みを修正する重要な結果である。CBTの訓練を受けた治療者でなくても、構造化された支持的療法で同程度の効果が期待できるなら、提供者を増やしやすい。ただし、本試験の治療者は全員CBT資格をもつ経験者であり、訓練の浅い提供者が同じ効果を出せるかは未検証である。週2回の通院は高齢者には負担が大きく、日本の保険診療で同じ頻度を実現するのは難しい。認知機能が低下した人や施設入所者は対象外である。
