# 大うつ病性障害に対する生活習慣に基づくメンタルヘルスケアの臨床ガイドライン——WFSBPとASLMの合同タスクフォース 精読ノート

## 概要(500字以内)

うつ病の治療は薬と精神療法が中心ですが、効果は中程度にとどまり、全員に効くわけでもありません。世界生物学的精神医学会連合(WFSBP)とオーストラレーシア・ライフスタイル医学会(ASLM)の国際タスクフォースは、成人の大うつ病性障害(MDD)を対象に、生活習慣への介入をどう使うかの臨床ガイドラインをまとめました。運動、禁煙、就労支援、マインドフルネス・ストレス対処、食事、睡眠、孤独・社会的支援、緑地(自然)との接触の8領域について、2020年6月までの文献を系統的に検索し、WFSBPの基準でエビデンスを格付けして、9つの推奨を作りました。最も評価が高い「推奨グレード2(エビデンスは限定的)」は運動、就労支援、マインドフルネス、リラクセーション、不眠の認知行動療法(CBT-I)の5つです。食事と緑地はグレード3(エビデンス低)、禁煙と孤独対策は専門家意見にとどまります。最高のグレード1は1つもありません。著者らは、生活習慣ケアを薬や精神療法と組み合わせる「土台」と位置づけ、評価から経過観察までの流れ(4つのA)、段階的ケア、実装上の10の留意点を示しています。

## Figure・Tableの解説

本論文の図表は Figure 1〜5 と Table 1〜4 の計9点です。そのほか、領域ごとの臨床上の助言をまとめた Box 1〜9 があり、最後に簡単に触れます。検索式は電子補足資料(Supplementary material)にあり、本PDFには含まれていません。

### Table 1: 推奨の要約

9つの推奨を一覧にした表です。列は「領域」「推奨文」「エビデンスのレベル」「推奨グレード」。グレードB(エビデンスは限定的、推奨文は「could=用いることができる」)で推奨グレード2なのは、運動、就労支援(就労に焦点を当てたカウンセリングと職場での介入の組み合わせ)、マインドフルネス療法(MBCT・MBSR)、ストレス管理・リラクセーション(呼吸法、漸進的筋弛緩法)、CBT-Iの5つです。食事指導と緑地はC1(質の低い研究に基づく)、禁煙と社会的支援はC3(専門家の意見)で、いずれも推奨グレード3(推奨文は「may=用いてもよい」)です。なお本文4.4.2ではリラクセーションの推奨文が「may」になっており、表の「could」と食い違っています。

### Figure 1: 生活習慣に基づくメンタルヘルスケアの概念枠組み(4つのA)

臨床の流れを Assess(評価)→ Advise(助言)→ Assist(支援)→ Arrange(手配)の4段階で示したフローチャートです。ステップ1で生活習慣、ステップ2で社会的・文化的ニーズを評価し、ステップ3で生物心理社会モデルと行動変容技法(行動を変えるための具体的な工夫)を使って患者と共有の管理計画を立てます。支援段階には10個の箱(運動、禁煙、就労、マインドフルネス、ストレス・リラクセーション、食事、睡眠、社会的つながり、緑地、アルコール・物質)が並び、必要に応じて家族・仲間・文化的支援、デジタル提供、関連職種の関与を加え、さらに必要なら精神療法や薬物療法へ進みます。最後に経過観察を組み込みます。アルコール・物質は本ガイドラインでは格付けしていない、と注記されています。

### Figure 2: ガイドライン推奨の作成手順

推奨がどう作られたかを示す5段の流れ図です。①タスクフォースが生活習慣の領域を選ぶ → ②文献の系統的検索 → ③WFSBP基準でのエビデンス格付けと、介入の受け入れやすさ(acceptability)の評価を並行して実施 → ④見つかったエビデンスに基づいてタスクフォースが推奨を作成 → ⑤デルファイ法(匿名アンケートを繰り返して意見を集約する合意形成法)で承認、という順です。本文では、2回のデルファイで80%を超える合意が得られた時点で推奨を確定したと説明されています。

### Table 2: WFSBPのエビデンス格付け体系

エビデンスのレベルを決める基準表です(Hasan ら 2019)。A(強い、should)は「バイアスのリスクが低い独立したRCTが2本以上で有効、かつ低リスクの否定的RCTがない」など。B(限定的、could)は「中等度リスクのRCT1本でプラセボに勝る」や「中等度リスクのメタ分析で有効」、または「低リスクのメタ分析だが中身の試験が概して高リスク」の場合です。C1(低い、may)は対照付きの非ランダム化研究や良質なコホート研究、あるいは高リスクのRCT・メタ分析。C2は10人未満の症例報告など、C3はデータに基づかない専門家意見、Dはエビデンスなし。著者らは、メタ分析の格付けに、組み込まれた個々の試験のバイアスも考慮するよう基準を修正しています。運動などが「低リスクのメタ分析だが中身の試験は高リスク」でBにとどまるのはこのためです。

### Figure 3: 実装の中核的留意点・要因・生活習慣介入の円形図

同心円の図で、中心に「MDDに対する生活習慣ケア」、その外側に8つの生活習慣介入(+アルコール・物質)がエビデンスの強さで色分けされ(濃い緑=グレードB、薄い緑=グレードC、黄=専門家意見)、さらに外側に実装の視点(土台であること、個別化、多職種、ヘルスコーチングと行動変容技法、ピアサポート、文化への配慮、社会的ニーズの評価、デジタル技術、新しいケアモデル)が並びます。最外周は「社会経済・文化・環境の要因」です。個人への介入だけでなく、医療サービス側の仕組みと社会的背景をあわせて考える必要があることを1枚で示しています。

### Figure 4: 生活習慣ケアの段階的ケア(ステップドケア)モデル

ピラミッド型の図で、土台が「生活習慣アプローチ」、その上に「心理的介入」「薬物療法」「追加の治療」が積み重なります。左側の矢印は「共有意思決定」、右側は「生物心理社会的回復」を示し、斜めの矢印で社会・文化的支援(NGOや地域)、セルフマネジメント支援、デジタル技術がすべての段を貫いています。生活習慣と心理的アプローチはすべてのMDD患者と話し合うべきもので、安全性が高いため土台に置き、必要に応じて上の段の治療を足していく、という考え方です。生活習慣ケアを薬や精神療法の「代わり」とせず、「土台」とする立場がよく表れています。

### Figure 5: 生活習慣ケアのスイスチーズモデル

穴の空いたチーズの薄切りを何枚も重ねた図で、太い黒線(病気の進行)が手前の数枚の穴は通り抜けても、奥のチーズで止められる様子を描いています。左側の薄切りは生活習慣・社会的アプローチ(運動、ストレス管理、就労、マインドフルネス、睡眠、アルコール・物質、食事、緑地、禁煙、社会的つながり)、右側はケアモデルと実装(デジタル技術、ピアサポート、ヘルスコーチング、多職種連携、文化への配慮、社会的ニーズ)です。どの1枚にも穴(限界)があるので、何層も重ねるほど進行や再発を防ぎやすい、という主張を視覚化しています。

### Table 3: 領域別の評価ツールと問診の質問例

診察で使える評価道具と質問例をまとめた2ページの表です。運動ではSIMPAQ(精神疾患向けに作られた5項目の簡易身体活動質問票)や歩数計、食事では食物摂取頻度調査票・24時間思い出し法・3〜7日の食事日記、睡眠ではエプワース眠気尺度、ピッツバーグ睡眠質問票(PSQI)、不眠重症度指数(ISI)、睡眠時無呼吸のSTOP-BANG、喫煙ではファーガストローム依存度テスト、アルコールではAUDIT-C、ほかに薬物、ギャンブル、就労、孤独(UCLA孤独感尺度、LSNS-6)、ストレス(知覚ストレス尺度、DASS)、レジリエンス、社会的ニーズ(米国家庭医学会のスクリーニングツール)が並びます。緑地だけは標準化されたツールがなく、「1週間に緑や水辺でどのくらい過ごしますか」などの質問例のみです。網羅的ではなく、使うには臨床判断が必要と脚注にあります。

### Table 4: 今後の実装上の10の留意点

実装の原則を10項目に整理した表です。①生活習慣の評価と介入は治療の土台で、最初の一歩にも、薬・精神療法の併用にもなる。②複数の生活習慣介入の組み合わせは効果を高めうるが、個別の配慮が必要。③全患者で介入の前後に生活習慣を評価する。④住居・食料・保育などの社会的ニーズを正式に評価する。⑤行動変容技法と生物心理社会モデルを使った個別化。⑥文化的に安全で配慮ある対応。⑦ピアサポートワーカー・家族・介護者の参加。⑧デジタルで支えるセルフマネジメントは低コストで実現可能。⑨運動生理士や管理栄養士など関連職種の関与。⑩物質使用を評価し、既存のアルコール・薬物ガイドラインを使う。著者らは、これらは系統的レビューではなく合意に基づく「目標」だと断っています。

### 補足:Box 1〜9(臨床上の助言とコツ)

Box 1は全領域共通(4つのAの枠組みに沿う、能力・機会・動機の確認、社会的要素の組み込み、デジタルの活用など)、Box 2は運動(楽しめる運動、監督付きプログラム、低〜中強度から開始し、座りがちな時間を減らす工夫)、Box 3は禁煙(渇望への対処法「DEaDS」=Delay・Escape・Distract・Substitute、ニコチン置換療法・バレニクリン・ブプロピオン)、Box 4は就労(段階的復職、ボランティア)、Box 5はストレス(ボックス呼吸=4秒吸う・4秒止める・4秒吐く・4秒止める、漸進的筋弛緩法)、Box 6は食事(未加工食品中心、エキストラバージンオリーブオイル、超加工食品を減らす)、Box 7は睡眠衛生、Box 8は孤独・社会的支援(SNS使用の評価、社会的処方)、Box 9は緑地です。

## 8項目評価

本論文は新しいデータを集めた原著研究ではなく、既存の系統的レビュー・メタ分析・RCTを格付けして推奨を作る「臨床ガイドライン」です。そのため、②「サンプルサイズ」は推奨の根拠になった研究の規模と文献の選び方、④「統計分析」は効果量の扱いと格付けの手続きの妥当性に読み替えて評価します。

### ① 研究デザイン

系統的な文献検索、WFSBP基準によるエビデンス格付け、受け入れやすさの評価、2段階のデルファイ合意、関係者による外部査読(2021年11〜12月)という、ガイドラインとして標準的な手順を踏んでいます。9か国、高・中・低所得国からの委員、当事者の参加も強みです。一方で、検索は「まず系統的レビュー、なければRCT、さらに非ランダム化試験」と段階的に下りる方式で、良質なレビューが1本あれば個々のRCTは新たに統合していません。また、背景や「臨床上の考慮点」、実装の10項目は系統的手順の外で書かれており、推奨本体とエビデンス水準が異なる文章が同じ紙面に混在している点に注意が必要です。

### ② サンプルサイズと選択基準(ガイドラインの文脈に読み替え)

根拠の規模は領域によって大きく違います。運動はメタ分析2本(25〜35試験、1487〜2498人)と比較的厚い一方、マインドフルネスは9試験762人、リラクセーションは8試験365人、CBT-Iは8試験491人、食事はRCT4本395人、緑地は4研究116人にすぎません。対象を「診断されたMDD」に限り、軽いうつ症状(閾値下うつ)の研究や健康な人の研究を除いたのは妥当ですが、結果として根拠が細くなりました。英語論文のみ、2020年6月まで(以降は委員が知っていたものだけ追加)という条件も、出版バイアスや選び方の偏りの余地を残します。

### ③ 方法論の適切性

PICO(対象・介入・比較・結果)を明示し、2人の独立したスクリーニング、AMSTAR-2(系統的レビューの質を評価する道具)、RoB 2(RCTのバイアス評価)、JBIチェックリストと、評価道具の選択は適切です。ただし結果を「抑うつ症状の軽減」1つに絞ったため、再発予防、生活の質、入院期間、身体合併症への効果は評価対象外です。生活習慣介入の利点として本文が強調する「身体の健康への二重の効果」は、推奨の格付けには反映されていません。比較対照(待機群か実薬か)で研究を除外しなかったことも、効果の大きさの解釈を難しくしています。ヨガのように複数領域にまたがる介入をどこに入れるかの線引きも、著者ら自身が難しいと認めています。

### ④ 統計分析の妥当性(エビデンス統合と格付けの手続きに読み替え)

効果量は元のメタ分析や試験からそのまま取り出し、Cohenの基準で小・中・大に分類しただけで、新たな統合計算はしていません。著者ら自身も、効果量は単独療法か併用か、標本が小さいかなどの違いがあるため慎重に見るべきで、治療選択の順位付けには使わないよう求めています。運動のSMD 0.66〜1.11や食事のSMD 0.65〜1.16は「中〜大」と書かれていますが、待機群との比較や盲検化できない試験が多く、過大評価の可能性が高い数字です。緑地では「複数の効果量指標が混在」したまま「小〜大」とまとめており、定量的な意味はほとんどありません。デルファイの合意率(>80%)の各推奨ごとの実際の数値も示されていません。

### ⑤ 結果の信頼性と再現性

格付けの手順と基準表(Table 2)が公開されており、同じ手順を踏めばほぼ同じ結論に至る透明性はあります。しかし、根拠となった個々の試験の多くはバイアスのリスクが高く、これがグレードAが1つもない主な理由だと著者らも明記しています。生活習慣介入は二重盲検ができないという構造的な限界があり、期待効果や治療者との接触時間の影響を切り分けられていません。食事のRCTは主にオーストラリアの小規模試験で(SMILES試験など)、委員の中にその試験の研究者が含まれる点も、独立した追試で確かめる必要があることを示しています。研究の期間も1〜3か月が多く、長期の効果の持続は未確認です。

### ⑥ 結論の妥当性

「生活習慣ケアをMDD治療の土台として推奨する」という結論は、安全性の高さ、低コスト、身体合併症への波及効果を考えれば臨床的にうなずけます。ただし推奨はすべてグレード2〜3で、「強い推奨」の根拠はありません。それにもかかわらず実装の節(Figure 4、留意点#1)では「中核的な構成要素」「土台」と強めに表現しており、エビデンスの強さと主張の強さに差があります。特に禁煙と孤独対策は専門家意見のみです。推奨文の言い回しも、リラクセーションで表(could)と本文(may)が食い違うなど整理不足があります。また、筆頭著者や食事分野の委員には食品・乳業企業からの研究資金や講演料の開示があり、利益相反として読み手が意識すべき点です。

### ⑦ 新規性

著者らによれば、既存および新しい生活習慣介入のエビデンスを格付けして臨床医に示した、MDD向けのガイドラインはこれまでありませんでした。RANZCP(オーストラレーシアの精神科医会)やNICE草案が扱った4領域(運動・食事・睡眠・禁煙)に、孤独・社会的支援、マインドフルネスとストレス管理、緑地、就労支援を加えて格付けした点が新しい貢献です。4つのA、段階的ケア、スイスチーズモデルといった実装の枠組みを図で示したことも実用的です。一方、個々の領域の知見そのものは既存のメタ分析の要約で、新しいエビデンスを生み出したわけではありません。

### ⑧ 臨床的意義

一般の精神科外来でも、運動、睡眠(CBT-I)、マインドフルネス、リラクセーション、就労支援は「エビデンスは限定的だが使ってよい」と自信をもって勧められる根拠になります。Table 3の質問例やBox内のコツ(ボックス呼吸、DEaDS、段階的復職など)は、短い診察時間でもすぐ使える実用性があります。喫煙が一部の抗うつ薬・抗精神病薬(クロザピン、オランザピン、フルボキサミン、デュロキセチン、ミルタザピンなど)の代謝に影響するため、禁煙時に血中濃度の監視が必要という指摘も、薬理学的に重要です。ただし、急性期・重症例や双極性の素因がある人(CBT-Iの睡眠制限が躁転のリスクになりうる)への適用には注意が要ること、関連職種や費用・時間の確保という医療制度側の課題が大きいことも本文が認めており、推奨をそのまま日本の診療に持ち込むには工夫が必要です。
