# 世界生物学的精神医学会連合（WFSBP）による不安症・強迫症・PTSDの治療ガイドライン第3版 第I部——不安症 精読ノート

> 役割：日本トップクラスのサイエンスコミュニケーターとしての精読プロンプト（デフォルトフォーマット）に基づく分析結果

## 1. 概要（500字以内）

世界生物学的精神医学会連合（WFSBP）が2002年・2008年に続いて出した、不安症・強迫症（OCD）・心的外傷後ストレス障害（PTSD）の治療ガイドライン第3版の前半（第I部）で、不安症を扱う。22か国の専門家33名が、2022年3月までに発表された成人・小児のランダム化比較試験（RCT）1007本を評価した。今回の特徴は、薬だけでなく精神療法や運動などの非薬物療法にも「薬と同じ厳しい物差し」を当てたこと。待機リスト（何もしない順番待ち群）との比較で勝っただけでは強い推奨を与えず、「心理的プラセボ」（専門技法を含まない雑談的面接）など能動的な対照に勝つことを求めた。結論として、パニック症・全般不安症・社交不安症ではSSRIとSNRI（ベンラファキシン、デュロキセチン）が第一選択薬であり、ベンゾジアゼピンやプレガバリンは効果が確かでも依存・乱用リスクから第二選択に下げられた。認知行動療法（CBT）は第一選択の精神療法とされたが、能動的対照との差は小さく（効果量d＝0.23〜0.61）、全般不安症では有意差に届かなかった。精神力動的精神療法は「使わないよう推奨」とされた。

## 2. FigureとTableの解説

本文PDFに実際に掲載されている図表はTable 1〜17の17点である。Figure 1〜7はすべてオンライン補足資料（Supplementary Appendix）にあり、本文PDFには含まれない。本文から読み取れる範囲で最後にまとめて紹介する。

### Table 1：RCTの質のチェックリスト
ガイドラインに採用する試験の「合格基準」の一覧である。スコットランドのガイドライン機関SIGNの基準をもとに項目を追加している。DSM/ICDによる診断、適切なランダム化（くじ引きによる割り付け）、同一外観のプラセボなどの適切な対照、精神療法研究では盲検評価者（どの群か知らされていない評価者）の使用、脱落の記載と解析方法（ITT解析＝割り付けたとおりに全員を解析する方法、など）、並行群デザイン、事前の症例数計算、多重検定の補正、倫理審査、試験登録などが並ぶ。ここで大事なのは、薬物試験で当然とされる基準を精神療法試験にもそのまま当てはめると宣言している点である。

### Table 2：「心理的プラセボ」対照の標準案
精神療法の効果を正しく測るために著者らが提案する「理想的な対照群」の条件である。実験群と同じ長さ・頻度で面接を行うこと、面接者は精神療法の訓練を受けていないスタッフとすること、心理社会的な話題は扱うが病気の心理教育はしないこと、共感や励ましは許されること、破局的な解釈の修正のような専門技法やマニュアルは使わないこと、が挙げられている。薬の試験の「見た目が同じ偽薬」にあたるものを精神療法でも作ろうという発想である。心理的プラセボの前後比較の効果量（d＝0.83）は錠剤プラセボ（d＝1.29）より小さい、というデータも本文で示されている。

### Table 3：WFSBPのエビデンスレベル（LoE）
Hasanら（2019）のWFSBP統一基準によるエビデンスの格付けである。肯定側はA（強い）、B（限定的）、C（弱い）、否定側はA−（「効かない」ことの強いエビデンス）、B−、C−で、Dは「エビデンスなし」を意味する。通常の格付けは「効く証拠の強さ」だけを示すが、この体系は「効かないことが繰り返し示された」ことも明示的にランク付けできる。これが本ガイドラインの特徴になっている。各レベルの詳しい定義は補足資料のTable 2にある。

### Table 4：推奨グレード（RG）
推奨の強さを1（強い推奨）、2（限定的推奨）、3（弱い推奨）、4（推奨不能）、1−・2−・3−（使用しないよう推奨）の7段階で示し、濃い緑から赤までの色で塗り分ける。エビデンスレベルがAでも、依存性・代謝症候群・重い心血管リスク・危険な相互作用などの「リスク」があれば推奨グレードは下がる。代表例がベンゾジアゼピン（LoE AなのにRG 2）である。臨床ではまずRG 1の治療を試し、それが効かなければ別のRG 1を試し、そのあとでRG 2に進むという「階段」として使うよう説明されている。費用は国ごとに違うため考慮されていない。

### Table 5：各不安症の簡潔な定義
ICD-10/11とDSM-5にもとづき、対象となる6疾患を短く説明している。パニック症（数分でピークに達する激しい恐怖発作をくり返す）、広場恐怖症（逃げにくい場所への恐れ。パニック症の約3分の2に合併）、全般不安症（多方面への過剰な心配と身体症状）、社交不安症（他者から否定的に評価されることへの強い恐れ）、限局性恐怖症（高所・動物・血液・歯科治療など特定の対象への恐怖）、分離不安症（愛着対象から離れることへの過剰な不安）、場面緘黙（家では話せるのに学校などでは一貫して話せない）が並ぶ。

### Table 6：12か月有病率と生涯有病率
大規模疫学調査（米国のECA・NCS-R、欧州のESEMeD、欧州27研究、中国精神保健調査）をまとめた有病率の幅である。たとえば限局性恐怖症は12か月で2.6〜11.1%、生涯で2.6〜13.8%、社交不安症は12か月で0.6〜8.0%、生涯で0.6〜13.0%、全般不安症は生涯で0.3〜6.2%と、調査による差が非常に大きい。広場恐怖症の12か月有病率（0.4〜10.5%）の上限が生涯有病率（0.4〜2.6%）の上限を上回っており、論理的に矛盾している。原表のまま載せられた誤記と考えられる。

### Table 7：成人の推奨1日用量
SSRI（エスシタロプラム10〜20mg、パロキセチン20〜60mg、セルトラリン50〜200mgなど）、SNRI（ベンラファキシン75〜225mg、デュロキセチン60〜120mg）、三環系抗うつ薬（TCA）、ベンゾジアゼピン、プレガバリン150〜600mg、クエチアピン50〜300mg、ヒドロキシジン、ブスピロン、ラベンダーオイル抽出物シレキサン80〜160mg、プラゾシンなどの用量範囲を示す。脚注では、シタロプラム40mg超とエスシタロプラム20mg超の適応外用量について、QT延長（不整脈の前兆となる心電図変化）のリスクから心電図の定期的な確認を勧めている。高齢者や東アジア人では半量以下から始めるよう本文で助言されている。

### Table 8：抗不安薬それぞれの長所と短所
主な薬を「長所」と「短所」の2列で比べた一覧である。SSRI/SNRIは依存性がなく過量服薬でも比較的安全だが、効き始めるまで2〜6週かかり、飲み始めのそわそわ感や性機能障害、中止時の離脱症状がある。プレガバリンは効き始めが速い一方、物質使用歴のある人では乱用の問題がある。TCAは過量服薬で致死的になりうる。ベンゾジアゼピンは即効性があり過量服薬でも比較的安全だが、依存性がある。モクロベミド、MAO阻害薬、ブスピロン、アゴメラチン（肝毒性）、ヒドロキシジン（長期使用の経験がない）も並ぶ。本文の結論は「すべての患者に理想的な薬はなく、個別に選ぶ」である。

### Table 9：パニック症・広場恐怖症（PDA）の推奨まとめ
薬ではSSRI 6剤とベンラファキシンがA/1、クロミプラミンとイミプラミンは副作用の多さからA/2、ベンゾジアゼピン4剤もA/2である。ブスピロン、プロプラノロール、トラゾドンは「効かない」ことが確立してA−/1−とされた。精神療法では、CBTがA/1（能動的対照とのメタアナリシスでd＝0.23、95%CI 0.02〜0.44、p＝.035）、インターネットCBT（iCBT）は待機期間の橋渡しや追加治療としてB/2である。精神力動的療法とEMDR（眼球運動による脱感作と再処理法）はA−/1−となった。併用療法は「CBT＋薬＞CBT単独」がA/1、「CBT＋薬＞薬単独」はB−/2−、運動は追加治療としてB/2である。

### Table 10：全般不安症（GAD）の推奨まとめ
第一選択（A/1）はエスシタロプラム、パロキセチン、セルトラリン、ベンラファキシン、デュロキセチン、アゴメラチンである。イミプラミン、プレガバリン（乱用の可能性）、ビラゾドン（比較試験・長期試験がない）、ベンゾジアゼピンはA/2、ヒドロキシジンとクエチアピン（代謝症候群の懸念）はA/3とされた。ボルチオキセチンはB−/2−、ブスピロンはD/4である。治療抵抗例への追加薬としてオランザピンやプレガバリンの上乗せがB/3。精神療法ではCBTが能動的対照に有意差を示さず（d＝0.44、p＝.098）B/2にとどまり、応用リラクセーション、精神力動的療法、インターネット版精神力動的療法はB−/2−である。併用療法のデータは結論が出ておらずD/4とされた。

### Table 11：小児・青年の全般不安症・分離不安症・混合性不安症
フルボキサミン（とセルトラリン）がA/1、エスシタロプラム・フルオキセチン、デュロキセチン・ベンラファキシンはそれぞれプラセボ対照試験1本ずつでB/2、アルプラゾラムはプラセボに勝てずB−/2−である。CBTは待機リストにすら勝てない試験があり、能動的対照とのメタアナリシスも有意ではなかった（d＝0.15、p＝.13）ため、D/4という成人よりずっと低い評価になった。一方、CBTとセルトラリンの併用が両方の単独治療に勝った試験が1本あり、B/2とされている。表の中では「SSRIエスシタロプラムとフルオキセチン」の行の説明文が「フルオキセチンとセルトラリン」になっていて、本文とも食い違う誤記がある。

### Table 12：社交不安症（SAD）の推奨まとめ
SSRI 4剤（エスシタロプラム、フルボキサミン、パロキセチン、セルトラリン）とベンラファキシンがA/1である。プレガバリンとフェネルジン（食事制限と相互作用）はA/2。シタロプラム、ブロマゼパム・クロナゼパム、モクロベミド（メタアナリシスでd＝0.33）、ミルタザピン、ガバペンチンはB/2、ケタミンはB/3、フルオキセチンはD/4とされた。デスベンラファキシンとブスピロンはB−/2−、アテノロールはA−/1−である。CBTは能動的対照14比較のうち有意差が出たのは2つだけだが、メタアナリシスで小さな有意差（d＝0.27、95%CI 0.10〜0.43）が出たためA/1とされた。精神力動的療法はA−/1−、VR曝露とD-サイクロセリン併用はD/4である。

### Table 13：小児・青年の社交不安症
薬ではパロキセチンとベンラファキシンがプラセボ対照試験1本ずつでB/2、フルオキセチンは有効だがCBTより劣ったためB/3とされた。CBTは待機リストに勝てない試験もあったが、能動的対照とのメタアナリシスで中程度の効果（d＝0.61、0.27〜0.97、p＝.001）を示してA/1となった。iCBTは心理的プラセボにも勝った試験があってB/2である。小児の全般不安症・混合性不安症（Table 11）ではCBTがD/4だったのと対照的で、同じ年代でも疾患によってCBTの裏付けがかなり違うことがわかる。

### Table 14：限局性恐怖症
対象ごとに整理されている。クモ・小動物恐怖では実際の対象を使う曝露療法（in vivo曝露）がA/1、VR曝露はD/4。高所恐怖ではVR曝露がD/4である。飛行機恐怖では曝露療法とVR曝露がいずれもA/1とされた。歯科恐怖ではCBTがB/2、VR曝露とEMDRはD/4、薬ではミダゾラムがA/1、アルプラゾラムとプレガバリンが頓用でB/2である。さまざまな恐怖症に対するパロキセチンはB/2、D-サイクロセリンによる曝露療法の増強はすべて陰性でA−/1−とされた。ただし飛行機恐怖の曝露療法について、本文は「待機リスト比較が1本のみ（LoE D/RG 4）」と書いており、表のA/1と食い違っている。

### Table 15：場面緘黙
質の高い試験がほとんどない領域である。CBTは待機リストと明確な差がなく、心理教育に勝った試験が1本あるだけで、D/3とされた。薬は、小規模RCT・症例集積・症例報告からSSRI（シタロプラム、エスシタロプラム、フルオキセチン、セルトラリン）とフェネルジンに「一定の効果」があるとしてC/3である。Table 4の体系ではLoE D（エビデンスなし）はRG 4（推奨不能）に対応するはずなので、D/3という組み合わせは格付け規則との整合性に疑問が残る。

### Table 16：高齢者の不安症
高齢のGAD患者では、シタロプラムとセルトラリンがRCT1本ずつでB/2である。プレガバリン（眠気・ふらつき）とクエチアピン（代謝症候群・不整脈）は効果があっても第三選択のB/3とされた。パロキセチンは検出力不足の試験のみでD/4。CBTは待機リストに勝ったのが3試験中2試験だけで、心理的プラセボには勝てず、セルトラリンより劣ったためD/4である。本文では「シタロプラム、セルトラリン、プレガバリン、クエチアピン（LoE B/RG 2）」とまとめて書かれており、表のプレガバリン・クエチアピン（RG 3）と一致しない。

### Table 17：開発後期段階にある新規抗不安薬候補
作用する標的ごとに候補を並べている。セロトニン系（ゲピロン、シロシビン、MDMA）、グルタミン酸系（ケタミン、ラニセミン）、神経ペプチド系（オキシトシン、バソプレシンV1a拮抗薬SRX246、オレキシン拮抗薬スボレキサント、ニューロペプチドY/S）、GABA系（ズラノロン）、カンナビノイド（カンナビジオール）、イオンチャネル（リルゾール、トロリルゾール）、鋤鼻受容体（PH94B/アロラジン、鼻の受容体に作用する点鼻薬）、その他（クルクミン、ガルフィミンB、キセノンガス）がある。著者らは、安価なジェネリック薬と競合するため新薬開発は経済的リスクが高いと述べている。

## 3. 内容の8項目評価

> 本論文はオリジナルデータを集めた原著研究ではなく、RCTを系統的に集めて専門家の合議で推奨を決める**診療ガイドライン（総説系）**である。そのため、一次研究向けの評価項目を次のように読み替えて評価する。「研究デザイン」はガイドラインの作成手順、「サンプルサイズと選択基準」は文献の検索・採用基準と対象研究の規模、「統計分析の妥当性」は独自メタアナリシスと異質性の扱い、「再現性」は格付けの透明性と第三者が同じ結論にたどり着けるか、とする。

### ① 研究デザイン（ガイドライン作成手順）
22か国33名の専門家パネルが、RCTの系統的収集、LoE/RGの2軸による格付け、意見が割れたときの投票、という手順で推奨を決めている。2019年のWFSBP統一基準を使い、「効かない」ことも格付けする点は優れている。しかし問題もある。GRADE（国際的に標準となっているエビデンス評価法）のようにバイアスリスク・非一貫性・非直接性を明示して評価する手順がない。患者代表や精神療法を専門とする心理職の参加も書かれていない。投票の結果（賛否の割合）も公表されていない。筆頭著者の過去のメタアナリシスが判断の根拠として繰り返し使われている点も、独立性の面で気になる。

### ② サンプルサイズと選択基準（文献検索・採用基準）
MEDLINEとWeb of Scienceを2022年3月まで検索し、手作業の追加も含めて1007本のRCTを採用した。規模は非常に大きい。1群10人未満の試験、併存症の混ざった集団、軽症例だけの研究を除外し、非劣性比較では1群50人以下を「検出力不足」と明示した。これは妥当である。一方で、検索対象は2データベースのみで、PsycINFO・Embase・Cochrane CENTRALを使っていない。精神療法研究は心理学系データベースに多いため、取りこぼしが心配される。未発表試験（試験登録や規制当局の資料）も含めていない。小児の混合性不安症にだけ「混合診断は除外」という原則の例外を設けており、基準の運用が一貫していない。

### ③ 方法論の適切性
薬と精神療法に同じ基準を当てはめ、待機リスト対照（前後比較でd≒0.2）と錠剤プラセボ（d≒1.3）では効果の見え方がまったく違うことを示した。そのうえで、能動的対照に勝つことを強い推奨の条件にしたのは方法論的に筋が通っている。問題は、精神療法では完全な二重盲検が原理的にできないことである。「心理的プラセボ」の基準（Table 2）も著者らの提案にとどまり、研究の世界で合意されたものではない。応用リラクセーションやTAU（通常治療）を能動的対照として扱うかどうかの判断が研究ごとに揺れている。さらに、薬の試験は短期で行われ、精神療法の試験は長期で重症度も低めという構造的な違いがあり、同じ物差しを当てても公平な比較になるとは限らない。

### ④ 統計分析の妥当性（独自メタアナリシスと異質性の扱い）
メタアナリシスは結果が割れた論点だけに限定し、3本以上の試験を条件にした。ランダム効果モデル（試験ごとの違いを前提にする統合方法）、Egger検定、trim-and-fill法（未発表と推定される研究を補って偏りを補正する方法）を使い、2名が独立にデータを抽出した（採否の一致率κ＝.86）。ここまでは標準的である。しかし、異質性I²の具体的な値、Egger検定の結果、補正後の効果量は本文に示されていない。多重検定の事後補正（Bonferroni-Holm）で元論文の「有意」を「差なし」に書き換えることもしており、判定が保守的な方向へ偏る可能性がある。また、同じ厳しさを薬剤の比較にも当てはめたかどうかは本文からは確かめられない。

### ⑤ 結果の信頼性と再現性（格付けの透明性）
すべての推奨に根拠となるRCT表（補足資料のTable 5〜28）が付いており、第三者が確かめられる構造になっている。この点は評価できる。一方で、本文と表の間に食い違いがいくつかある。GADのブスピロン（本文では6試験で有効、表では7試験）、飛行機恐怖の曝露療法（本文ではD/4、表ではA/1）、高齢者のプレガバリン・クエチアピン（本文ではRG 2、表ではRG 3）、Table 11の薬剤名の誤記、補足Figure 6の番号重複、Table 6の有病率の矛盾である。臨床で参照されるガイドラインとしては校正の甘さが目立ち、再現性の信頼を下げている。

### ⑥ 結論の妥当性
SSRI/SNRIを第一選択とし、ベンゾジアゼピンはリスクから格下げするという結論は、既存の各国ガイドラインとも一致し、妥当である。一方、CBTについては評価が割れている。「能動的対照との差は小さい」「薬の前後比較の効果量は精神療法より大きい（薬の改善の60%程度しか精神療法で得られない）」と強調しながら、PDAとSADのCBTはA/1を維持している。論旨と格付けの間に緊張がある。精神力動的療法をA−/1−とした判断も、試験数が少なく質も低い中で「効かない」ことの強い証拠とするのはやや踏み込みすぎで、「エビデンス不足（D）」との区別があいまいである。

### ⑦ 新規性
2008年の第2版から14年ぶりの改訂である。精神療法・運動・インターネット介入・VR曝露まで網羅的に格付けしたことが最大の新しさである。「心理的プラセボ」の標準案を示したこと、待機リスト研究を低く扱う方針を明示したことも、精神療法研究の方法論に対する問題提起として価値がある。ただし、新しく加わった薬は少ない（アゴメラチン、ビラゾドン、ボルチオキセチンの陰性評価など）。個別の論点の多くは筆頭著者グループの既発表メタアナリシス（2015年、2018年など）の再掲で、まったく新しい知見は限られる。

### ⑧ 臨床的意義
用量表、長所短所表、「第一選択が効かなければ別の第一選択へ切り替え、次に第二選択、増強療法より切り替えを優先」という階段式の考え方、寛解後6〜12か月の継続、高齢者・東アジア人は半量から開始、といった内容は、日常診療ですぐ使える実践的な指針である。日本の著者（貝谷、井上）も参加している。ただし、ビラゾドン、オピプラモール、シレキサン、ヒドロキシジンのように日本で未承認または適応外の薬も多い。費用を考慮しない方針のため、精神療法を受けにくい地域での現実的な選択とは離れる面もある。また、この厳しい基準では多くの精神療法が低い格付けになるため、心理職の多い現場や英国NICEなどCBT重視のガイドラインとの間で混乱を招くおそれがある。
