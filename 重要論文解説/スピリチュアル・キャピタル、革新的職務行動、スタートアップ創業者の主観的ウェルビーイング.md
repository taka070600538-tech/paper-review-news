# スピリチュアル・キャピタル、革新的職務行動、スタートアップ創業者の主観的ウェルビーイング 精読ノート

## 概要

本論文は、インドネシア・スラバヤのスタートアップ創業者107名を対象に、「スピリチュアル・キャピタル」(意味・目的・価値観・内的な強さといった精神的な資源)が「主観的ウェルビーイング」(人生への満足や快の感情など、本人が自分の人生を主観的に評価したもの)を高めるか、また「革新的職務行動」(新しいアイデアを出し、広め、実現する行動)がその橋渡し役(媒介変数)になるかを調べた横断調査である。2023〜2024年にGoogleフォームで質問紙を配布し、5件法の尺度(スピリチュアル・キャピタル8項目、革新的職務行動3側面、主観的ウェルビーイング4項目の計18指標)に回答してもらい、SmartPLS 3によるPLS-SEM(部分的最小二乗法による構造方程式モデリング)で解析した。結果、スピリチュアル・キャピタルは主観的ウェルビーイングに直接正の効果(経路係数0.189、p = 0.024)、革新的職務行動に強い正の効果(0.472、p < 0.001)を示し、革新的職務行動を介した間接効果(0.247、p < 0.001)も有意で、著者らは「部分媒介」と結論した。決定係数R²は革新的職務行動で0.223、ウェルビーイングで0.404であった。著者らは、研修やメンタリングで精神的価値と革新能力を育てることを提案する。ただし、横断データ・便宜的標本・自己報告という限界に加え、表の不整合や統計の記述の誤りが目立つ点には注意が要る。

## FigureとTableの解説

本文に登場するFigureはFigure 1〜2の2点、TableはTable 1〜6の6点、計8点である(補足資料・付録はなし)。

### Figure 1: 研究の概念枠組み
スピリチュアル・キャピタル(X)、革新的職務行動(Z)、主観的ウェルビーイング(Y)の三者の関係を示す図である。経路は3本で、H1はXからYへの直接効果、H2はXからZへの効果、H3はZがXとYの関係を媒介するというものである。Zを「橋」として、精神的資源が行動を通じてウェルビーイングに変換されるという仮説モデルを表す。なお、PDFのテキスト抽出では図中の矢印そのものは読み取れず、本文の説明から内容を確認した。

### Figure 2: PLS-SEMの構造モデルと測定モデル
各潜在変数(観測できない概念)と、それを測る質問項目(指標)をつなぐ経路図である。本文によれば、18指標すべての外的負荷量(指標が概念をどれだけ反映するかを示す値)は0.704〜0.867で、基準の0.7を超える。図中の個々の係数はテキストからは読み取れず、本文の記述に依拠した。構造部分の経路係数は後続のTable 5に対応する。

### Table 1: 回答者の属性
年齢は20〜25歳が37名(35%)、26〜30歳が53名(50%)、31〜35歳が9名、36〜40歳が8名。男性70名(65%)、女性37名(35%)。学歴は職業学校16名、学士82名(77%)、修士9名。起業経験は2〜3年が78名(73%)と最多。従業員数は1〜3人が30名、4〜9人が36名、10〜15人が32名、15人超が9名。若い世代が中心の集団であることが分かる。ただし表には数値の矛盾が多い(後述)。

### Table 2: 決定係数R²
R²は、モデルが結果の「ばらつき」をどれだけ説明するかを示す。革新的職務行動はR² = 0.223(調整後0.216)、主観的ウェルビーイングはR² = 0.404(調整後0.392)。つまりスピリチュアル・キャピタルは革新的職務行動の分散の22.3%を、ウェルビーイングは両者合わせて40.4%を説明する。本文は残り(77.7%、59.6%)は未投入の要因によるとする。

### Table 3: 予測的関連性Q²(ブラインドフォールディング)
データの一部を隠して予測し直す手続きで、モデルの予測力を調べる指標である。Q²はスピリチュアル・キャピタル0.597、革新的職務行動0.482、主観的ウェルビーイング0.508で、いずれも0を超えるので予測的関連性ありと判断された。ただし、SSO(観測数に相当)が400,000や500,000と表示され、n = 107の調査として不自然である。また、他の変数に説明されない外生変数にQ²を示している点も通常の解釈と合わない。

### Table 4: 効果量f²
f²は、ある説明変数を除いたときにR²がどれだけ下がるかを表す。スピリチュアル・キャピタルから革新的職務行動へは0.287、ウェルビーイングへは0.047。本文は0.047を「中程度」と呼ぶが、一般的な基準(0.02が小、0.15が中、0.35が大)では小さい効果にあたる。0.287も本文は「強い」とするが、基準では中〜大の中間である。

### Table 5: 直接効果の経路係数と仮説検定
X → Y(ウェルビーイング)は係数0.189、t = 2.287、p = 0.024で有意(H1採択)。X → Z(革新的職務行動)は係数0.472、t = 5.619、p < 0.001で有意(H2採択)。判定にはt表の臨界値1.982を使っている。注目すべきは、図1で想定した「革新的職務行動からウェルビーイングへの直接経路」の係数が、どの表にも示されていない点である。

### Table 6: 間接効果(媒介)の検定
X → Z → Y の間接効果は係数0.247、t = 4.670、p < 0.001で有意。直接効果も有意なので、著者らは部分媒介とする。逆算すると、Z → Yの係数は約0.52(0.247 ÷ 0.472)と推定でき、総合効果は約0.44(0.189 + 0.247)で、間接効果が総合効果のおよそ57%を占める計算になる(この逆算は本ノート作成者によるもので、論文には記載がない)。

## 8項目評価

本論文は一次研究(横断調査)であり、そのまま通常の基準で評価する。

### ① 研究デザイン
横断的な質問紙調査で、同一時点で3つの概念を同時に測っている。そのため「スピリチュアル・キャピタルが革新的行動を促し、それがウェルビーイングを高める」という因果の向きは検証できず、ウェルビーイングの高い人ほど革新的に行動する、あるいは精神的資源を肯定的に答える、という逆方向や共通の第三因子も排除できない。にもかかわらず本文は「Xが…を高める」と因果的に記述し、Table 6の解説でも「逆に悪ければ減る」と断定的である。媒介分析は縦断データや介入が望ましい。

### ② サンプルサイズと選択基準
有効回答は107名。選択基準は「スラバヤで活動するスタートアップ創業者」とされるが、定義や確認方法は書かれていない。さらに、方法では「全母集団を対象とした」としつつ要旨では便宜的標本抽出と述べ、記述が矛盾する。母集団の総数も示されず、回収率の記載もない(本文は全員が回答したと述べる)。Googleフォームによるオンライン配布で、20代が85%を占め、起業経験もほぼ5年未満という偏りがある。一都市に限った標本で、一般化には強い制約がある。

### ③ 方法論の適切性
尺度の出典に疑問がある。スピリチュアル・キャピタルの8項目は「グリーン知的資本」に関する製造業SMEの研究[40]に基づくとされ、宗教性や精神性を直接測る標準尺度ではない可能性がある。革新的職務行動は博士論文[41]の3側面から作った項目、ウェルビーイングは4項目で、翻訳・妥当化の手続きは書かれていない。主観的ウェルビーイングの標準尺度(生活満足度尺度など)の使用も明記されない。また方法の節では尺度の根拠として「最近の文献」と曖昧な表現が使われている。共通方法バイアス(同じ回答者が同じ方法で全部答えることによる見かけの相関)の検討もない。

### ④ 統計分析の妥当性
PLS-SEMは小標本でも使いやすく、予測志向の媒介モデルに向く点は妥当である。信頼性(Cronbachのα 0.830〜0.904、CR 0.887〜0.922)と収束妥当性(AVE 0.588〜0.663)は基準を満たすと報告された。しかし問題点が多い。f² = 0.047を「中程度」と誤記し、Q²の表の値(SSO 400,000)は不自然である。弁別妥当性ではAVEの平方根(Fornell-Larcker基準)に言及するが、その表は示されていない。媒介の検定にブートストラップの信頼区間が示されず、サンプルサイズの根拠(検出力分析)もない。Z → Yの経路係数が未報告である点も解釈を難しくする。

### ⑤ 結果の信頼性と再現性
データは「要請があれば入手可能」とされ、公開されておらず、質問項目の全文や項目別の係数も本文にない。表の内部矛盾が信頼性を損なう。Table 1では「36〜40歳が8名で4%」(8/107は約7%)、「職業学校16名で2%」(約15%)、起業経験の合計は97名で、107名に満たない。本文は「20〜25歳が38%」とし、表の35%と食い違う。「丸めの誤差と無回答のため」と説明するが、説明になっていない。参考文献にも不適切な引用(人工肺の論文[47]、言語学習の論文[33]、サーバント・リーダーシップの論文[18]など)が混ざる。

### ⑥ 結論の妥当性
スピリチュアル・キャピタルの直接効果は小さく(f² = 0.047、係数0.189)、結論の主張「ウェルビーイングの重要な決定要因」は強すぎる印象がある。結論は「レジリエンスと責任感を通じて」と述べるが、これらは測定されておらず根拠がない。「直接の心理的効果が間接より優勢」という考察も、逆算では間接効果(0.247)が直接効果(0.189)を上回るため、数値と食い違う。部分媒介という結論自体は、直接・間接とも有意という数字とは整合するが、因果の主張には留保が要る。

### ⑦ 新規性
スピリチュアル・キャピタルを、一般の起業家やSMEではなくスタートアップ創業者に絞り、革新的職務行動を媒介に置いてウェルビーイングとの関係を見た点に新規性を主張する。インドネシアの起業家のウェルビーイングを扱う実証研究は少なく、地域的な貢献はある。一方、既に同じ著者グループが女性起業家の成功を対象に同様の媒介モデルを検討している[17]など、枠組みの新しさは限定的である。「スピリチュアル」が宗教的実践か、価値観か、内的強さかの概念上の整理も弱い。

### ⑧ 臨床的意義
臨床研究ではなく、精神疾患のアウトカムは扱っていない。意義は、起業家のメンタルヘルス支援や予防の観点から「意味・目的・価値観を支える研修やメンタリング」を提案する点にとどまる。ただし因果が未確認で、効果も小さいため、介入の根拠としては弱い。精神科臨床の視点では、起業のストレスが高い集団でのウェルビーイングの規定因の仮説生成として参考になる程度で、うつや不安などの指標との関係は不明である。ウェルビーイング研究の観点では、横断データのため「自己申告の意味づけ」が幸福感の高さと結びつく可能性にとどまる。
